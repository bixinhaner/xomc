# 本地测试环境 — 访问地址与默认账号

> 适用于本机 Docker Desktop 上以 `dc.sh` 拉起的 GOOMC 测试环境（compose 项目名 `omc`）。
> 拉起方式：`cd goomc && bash deployments/docker/dc.sh up -d --build`
> 端口与凭据取自 compose 实际配置（`docker-compose.yml` + 容器 env），随配置变化请以 `docker compose -p omc ps` 为准。
> 生成日期：2026-06-16

---

## 1. 应用访问入口（最常用）

| 入口 | 地址 | 默认账号 / 密码 | 说明 |
|------|------|----------------|------|
| **前端 Web UI（主皮肤 v1）** | **http://localhost:8081/** | `admin` / `admin123` | OMC NMS 主界面；nginx 同时把 `/api/` 反代到后端 app |
| 前端皮肤 v2（shadcn） | http://localhost:8081/v2/ | 同上 | 同一套后端，不同 UI 皮肤 |
| 前端皮肤 v3（STARFORGE HUD） | http://localhost:8081/v3/ | 同上 | 同一套后端，不同 UI 皮肤 |
| ACS（TR-069 南向接入） | http://localhost:8080/ | — | 设备侧 CWMP 接入；浏览器 `GET /` 返回 404 属正常（只应 POST） |
| ACS TLS | https://localhost:7558/ | — | CWMP over TLS（容器内端口，按需映射） |

> ⚠️ **端口职责易混**：`:8081` 是**前端 + API**，`:8080` 是 **ACS**。两者是 nginx 容器内的两个 server 块。
> 备用登录账号：`system`（系统内置账号）。首次用 `admin` 登录可能触发**强制改密**。

### psql 快速连接

```bash
# 业务库
docker exec -it omc-postgres-1 psql -U omcgo -d omcgo
# 时序库
docker exec -it omc-postgres-tsdb-1 psql -U omcgo -d omcgo
# 或从宿主（需本机装 psql）
psql "postgresql://omcgo:omcgo123@localhost:5432/omcgo"
```

## 6. 常用运维命令

```bash
cd /Users/a1/Desktop/vscode/goomc

bash deployments/docker/dc.sh ps                  # 查看全部服务状态
bash deployments/docker/dc.sh logs -f app acs     # 实时日志
bash deployments/docker/dc.sh restart app         # 重启单个服务（不重编）
bash deployments/docker/dc.sh up -d --build app   # 改了代码后重建并重启
bash deployments/docker/dc.sh down                # 停止全栈（保留数据卷）
bash deployments/docker/dc.sh down -v             # 停止并清除所有数据卷（彻底重置）
```

## 7. 与本机其它项目的关系

- 本环境部署前已 **`docker stop` 现有 `deploy` 项目的 16 个容器**（数据卷完整保留），以腾出冲突端口
  （`8080 8081 5432 6379 4222 8222 9000 9001`）。
- 恢复旧 `deploy` 项目前，先停 GOOMC（`dc.sh down`）或调整旧项目端口，避免再次冲突。

> ⚠️ 默认账号/密码均为**开发测试用弱口令**，**严禁用于生产或公网暴露**。生产部署请通过根目录 `.env`
> 覆盖 `OMCGO_JWT_SECRET` / `POSTGRES_PASSWORD` / `MINIO_ROOT_PASSWORD` / Grafana 口令等。

# Map Page 地图页

## 线框
```
┌──────────┬─────────────────────────────────┐
│ Panel    │              Map / Canvas         │
│ (30%)    │                                   │
│          │     🗼    🗼    🗼               │
│ [搜索..] │           🗼                      │
│ 站点列表  │     🗼         🗼               │
│ 或树     │                                   │
│          │   [⚙] [📏] [⤡] [⟳]  ← 浮动工具栏 │
│          │   ┌─ 统计 ──────┐                │
│          │   │ 总数: 128   │  ← 浮动统计面板  │
│          │   │ 正常: 100   │                │
│          │   └─────────────┘                │
└──────────┴─────────────────────────────────┘
```

## 规格
- 左面板: 30% (8/24栏)
- 右地图/画布: 70% (16/24栏)
- 浮动工具栏: 右上角，z-index 10
- 浮动统计面板: 右下角，可展开/收起

## 使用模块
GIS 基站地图监控、拓扑画布。

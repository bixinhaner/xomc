# Form Page 表单页

## 概述
复杂创建/编辑流程的全页表单布局，使用可折叠区段卡片。

## 线框
```
┌──────────────────────────────────────────┐
│ ┌─ 任务信息 ──────────── [▾ 收起] ─────┐ │
│ │ 任务名称: [________________] *        │ │
│ │ 启用状态: [● 开]                      │ │
│ │ 执行类型: [立即执行 ▾]                │ │
│ │ 备注:     [________________]          │ │
│ └───────────────────────────────────────┘ │
│ ┌─ 设备选择 ──────────── [▾ 收起] ─────┐ │
│ │ [按网元 | 按分类 | 按模板]             │ │
│ │ [DeviceSelector 组件]                  │ │
│ └───────────────────────────────────────┘ │
│ ┌─ 调度设置 ──────────── [▾ 收起] ─────┐ │
│ │ 周期: [天 ▾]   时间: [16:00:00]      │ │
│ └───────────────────────────────────────┘ │
├──────────────────────────────────────────┤
│      [取消]      [保存草稿]      [确认]   │
└──────────────────────────────────────────┘
```

## 规格
- 区段卡片垂直堆叠，间距 `space-4` (16px)
- 每个区段: 标题 + 展开/收起图标 + 内容
- 底部操作栏: 固定在页面底部 (sticky)
- 按钮: 取消(左) / 保存草稿(中, 可选) / 确认(右, Primary)

## 使用模块
创建备份任务、创建升级计划、创建 MR 任务、创建告警规则。

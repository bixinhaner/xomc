# Detail Page 详情页

## 概述
展示单个实体的详细信息，包含信息区和关联数据 Tab。

## 线框
```
┌──────────────────────────────────────────┐
│ 页面标题                    [编辑] [返回] │
├──────────────────────────────────────────┤
│ ┌─ 基本信息 ──────────────────────────┐ │
│ │ 设备名称: BU-001    SN: SN12345     │ │
│ │ 产品类别: gNB       型号: Model-A    │ │
│ │ 连接状态: ● 在线    区域: 广州       │ │
│ └─────────────────────────────────────┘ │
│                                          │
│ [告警] [性能] [配置] [拓扑]               │
│ ┌─────────────────────────────────────┐ │
│ │ (选中 Tab 的内容区域)                 │ │
│ │ 嵌入的表格/图表                       │ │
│ └─────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

## 使用模块
设备详情、告警详情、任务详情。

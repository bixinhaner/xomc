# Task Panel 任务面板

## 概述
全局常驻的底部任务跟踪面板，所有模块共享。

## 收起状态 (40px)
```
┌──── 任务 (3) ──────────────────── [▲ 展开] ─┐
└──────────────────────────────────────────────┘
```

## 展开状态 (240px)
```
┌──── 任务 (3) ──────────────────── [▼ 收起] ─┐
│ [单任务] [批量任务] [导出]                     │
│ ┌────┬──────┬──────┬──────┬──────┬────────┐ │
│ │ ID │ 网元 │ 类型 │ 步骤 │ 状态 │ 消息    │ │
│ ├────┼──────┼──────┼──────┼──────┼────────┤ │
│ │ 1  │BU-01│ 同步 │ 3/5 │● 进行│ 同步中  │ │
│ │ 2  │BU-02│ 升级 │ 1/3 │● 等待│ 排队中  │ │
│ └────┴──────┴──────┴──────┴──────┴────────┘ │
└──────────────────────────────────────────────┘
```

## 3 个 Tab
| Tab | 列 | 说明 |
|-----|-----|------|
| 单任务 | ID, 网元, 类型, 步骤, 状态, 消息 | 单设备任务 |
| 批量任务 | 计划ID, 开始时间, 批次, 类型, 状态, 结果 | 批量操作 |
| 导出 | ID, 名称, 状态, 进度, 创建时间 | 导出/下载任务 |

## 规格
- z-index: 200
- 自动刷新: 5s
- 完成/失败时弹出 Toast 通知
- 点击任务行可跳转到相关模块页面

# 三套源系统对比分析 (Three System Comparison)

> OMC 统一网管系统 - 附录

## 概述

OMC 统一网管系统的 UI 设计基于对三套现有网管系统的深度分析：OMC 原系统、Comba 系统、广研院系统。本文对比三套系统的 UI 模式，并说明新设计中各组件的取舍依据。

---

## 1. 导航模式对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| 导航层级 | 3 级 (顶栏模块 + 侧栏子菜单 + 页面 Tab) | 2 级 (侧栏主菜单 + 子菜单) | 2 级 (侧栏主菜单 + 子菜单) |
| 顶栏 | 模块级导航 Tab (设备/告警/性能...) | Logo + 系统名 + 用户信息 | 水平菜单栏 + 用户信息 |
| 侧栏 | 二级菜单 (可折叠) | 完整导航树 (带图标) | 折叠式菜单 (图标 + 文字) |
| 侧栏宽度 | 200px | 220px | 180px |
| 菜单图标 | 有 (简单线性图标) | 有 (彩色图标) | 有 (线性图标) |
| 面包屑 | 有 | 有 | 无 |
| 快捷导航 | 无 | 无 | 收藏菜单 |

### 新设计采纳方案

```
采纳: OMC 原系统的 3 级导航架构
  - 顶栏: 模块级 Tab 导航 (快速切换主模块)
  - 侧栏: 该模块下的子功能菜单 (可折叠)
  - 内容区: 页面内 Tab (如需要)

原因:
  - OMC 系统模块众多 (10+), 2 级导航无法承载
  - 顶栏 Tab 提供模块间快速切换能力
  - 侧栏折叠后释放更多内容空间

优化点 (相比 OMC 原系统):
  - 侧栏增加搜索功能
  - 支持侧栏图标模式 (折叠为 64px)
  - 增加面包屑导航辅助定位
```

## 2. 色彩主题对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| 主色 | 橙色 (#FF6600 系) | 蓝色 (#1890FF 系) | 蓝色渐变 (#2B5AED → #6B8CF7) |
| 侧栏背景 | 深灰 (#333) | 深蓝 (#001529) | 白色 |
| 顶栏背景 | 橙色渐变 | 白色 | 蓝色渐变 |
| 表格斑马纹 | 有 (灰白交替) | 有 (浅蓝白交替) | 无 |
| 告警颜色 | 红/橙/黄/蓝 | 红/橙/黄/蓝 | 红/橙/黄/绿 |
| 整体风格 | 传统企业风 | 现代扁平 | 现代渐变 |

### 新设计采纳方案

```
采纳: 基于 Comba 系统的蓝色主题, 结合广研院的现代感

主色: #1890FF (Ant Design 默认蓝)
原因:
  - 蓝色在企业级 B 端产品中更专业、稳重
  - Ant Design 原生蓝色, 减少自定义成本
  - 与中国运营商/通信行业色调习惯一致
  - 橙色过于强烈, 长时间使用视觉疲劳

侧栏: 深色模式 (#001529), 参考 Comba
  - 深色侧栏与内容区形成明确分区
  - 白色侧栏 (广研院) 区分度不够

告警颜色: 统一为 红/橙/黄/蓝 四级
  - 与 3GPP 告警级别标准一致
```

## 3. 表格功能对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| 分页位置 | 表格底部右侧 | 表格底部居中 | 表格底部右侧 |
| 分页样式 | 页码 + 前后翻 | 页码 + 前后翻 + 跳转 | 简洁页码 |
| 每页条数 | 固定 20 | 可选 10/20/50/100 | 可选 20/50/100 |
| 总条数显示 | 有 "共 N 条" | 有 "共 N 条" | 无 |
| 列排序 | 点击表头 | 点击表头 + 排序图标 | 点击表头 |
| 列筛选 | 无 | 表头漏斗图标 | 无 |
| 列显隐 | 无 | 齿轮图标 + Checkbox | 无 |
| 列宽调整 | 无 | 拖拽表头边界 | 无 |
| 行选择 | Checkbox | Checkbox + Shift 范围选 | Checkbox |
| 批量操作 | 简单下拉 | 工具栏按钮 + 计数 | 简单按钮 |
| 行展开 | 无 | 有 (展开详情行) | 无 |
| 虚拟滚动 | 无 | 无 | 无 |
| 斑马纹 | 有 | 有 | 无 |

### 新设计采纳方案

```
采纳: 以 Comba 系统表格为基础, 补充增强功能

分页: Comba 方案 (页码 + 跳转 + 每页条数 + 总数)
  - 最完整的分页信息和操作

列操作: 全部采纳 Comba 方案
  - 排序: 点击表头 (asc → desc → none)
  - 筛选: 表头漏斗图标
  - 显隐: 齿轮图标
  - 列宽: 拖拽调整

行选择: Comba 方案增强
  - Checkbox + Shift 范围选 + Ctrl 追加选
  - 跨页记忆选择 (新增)

新增功能 (三套系统均无):
  - 虚拟滚动 (1000+ 行)
  - 列拖拽排序
  - 列配置持久化 (localStorage)
  - 行右键菜单
```

## 4. Modal 弹窗对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| 尺寸 | 固定 600px | 多尺寸 (400/600/800) | 固定 520px |
| 关闭方式 | X + 取消 | X + 取消 + ESC + 遮罩 | X + 取消 |
| 遮罩 | 有 (较深) | 有 (标准) | 有 (较浅) |
| 动画 | 无 | Fade + Scale | Fade |
| 嵌套弹窗 | 不支持 | 支持 (2 层) | 不支持 |
| Drawer | 无 | 有 (右侧滑出) | 有 (右侧, 较窄) |
| 表单确认 | 简单确认 | Loading + 成功关闭 | 简单确认 |
| 未保存提醒 | 无 | 有 | 无 |

### 新设计采纳方案

```
采纳: Comba 系统的弹窗方案

原因:
  - Comba 的弹窗交互最完整 (多尺寸、多关闭方式、动画)
  - Drawer 组件在详情查看场景下体验优秀
  - Loading + 成功关闭 + 刷新父页面的流程最佳
  - 未保存提醒防止数据丢失

优化:
  - 增加全屏模式选项
  - 标准化尺寸: S(416) / M(600) / L(800) / XL(1000)
```

## 5. 表单模式对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| Label 位置 | 左侧 (水平) | 左侧 (水平) | 上方 (垂直) |
| 必填标记 | 红色星号 (前置) | 红色星号 (前置) | 红色星号 (后置) |
| 验证时机 | 仅提交时 | 失焦 + 提交 | 仅提交时 |
| 错误位置 | 弹窗提示 | 字段下方 inline | 弹窗提示 |
| 表单分区 | 无 | 有 (折叠面板) | 有 (Tab) |
| 联动下拉 | 有 | 有 | 有 |
| 自动保存 | 无 | 无 | 无 |

### 新设计采纳方案

```
采纳: Comba 系统表单方案 + 增强

验证: Comba 的 onBlur + onSubmit 双重验证 (最佳实践)
错误: 字段下方 inline 错误 (Comba, 更直观)
分区: 折叠面板 (Comba, 适合参数多的表单)
Label: 左侧水平 (OMC + Comba, 表单更紧凑)
必填: 红色星号前置 (OMC + Comba, 视觉一致)

新增:
  - 自动保存草稿 (三套系统均无)
  - 未保存变更提醒
  - 提交时滚动到首个错误字段
```

## 6. 图表库对比

| 特征 | OMC 原系统 | Comba 系统 | 广研院系统 |
|------|-----------|-----------|-----------|
| 图表库 | ECharts 4.x | ECharts 5.x | Highcharts |
| 交互 | 基础 Tooltip | Tooltip + 缩放 + 图例 | Tooltip + 图例 |
| 图表类型 | 折线/柱状/饼图 | 折线/柱/饼/仪表盘/地图 | 折线/柱/饼图 |
| 导出 | 无 | PNG 导出 | 无 |
| 主题 | 默认 | 自定义蓝色主题 | 默认 |

### 新设计采纳方案

```
采纳: ECharts 5.x (Comba 方案)

原因:
  - ECharts 5.x 是最新版本, 性能更好
  - 中国地图支持最佳 (Highcharts 地图支持差)
  - 丰富的图表类型满足所有场景
  - 社区活跃, 文档完善
  - 免费开源 (Highcharts 商用需授权)

增强:
  - 统一图表主题 (与设计系统色彩一致)
  - 图表导出 PNG/SVG
  - 数据导出 Excel
  - 响应式适配
```

## 7. 各系统优劣势总结

### OMC 原系统

```
优势:
  ✓ 功能最全面, 覆盖所有网管场景
  ✓ 3 级导航适合大型系统
  ✓ 运维人员使用习惯已形成

劣势:
  ✗ UI 风格陈旧 (10+ 年老系统)
  ✗ 交互模式不一致 (不同模块风格差异大)
  ✗ 缺少现代 Web 交互特性
  ✗ 性能较差 (大数据量表格卡顿)
```

### Comba 系统

```
优势:
  ✓ UI 设计最现代, 交互最完整
  ✓ 表格功能最丰富 (排序/筛选/列操作)
  ✓ Drawer 详情查看体验好
  ✓ 错误处理机制完善

劣势:
  ✗ 2 级导航无法承载所有 OMC 模块
  ✗ 功能覆盖面不如 OMC 原系统
  ✗ 部分交互过于复杂 (学习成本高)
```

### 广研院系统

```
优势:
  ✓ 视觉设计现代感强 (渐变、圆角)
  ✓ 简洁干净的界面风格
  ✓ 收藏菜单功能实用

劣势:
  ✗ 表格功能基础 (缺少列操作、行展开等)
  ✗ 表单验证体验差 (仅提交时验证)
  ✗ 缺少错误处理机制
  ✗ 功能覆盖面最小
```

## 8. 新设计组件采纳汇总

| 组件/模式 | 采纳来源 | 原因 |
|-----------|---------|------|
| 导航架构 | OMC (3 级) | 模块数量多, 需要 3 级承载 |
| 色彩主题 | Comba (蓝色) | 专业稳重, Ant Design 原生 |
| 侧栏样式 | Comba (深色) | 区分度好, 企业级标准 |
| 表格分页 | Comba | 信息最完整 |
| 表格列操作 | Comba | 功能最丰富 |
| 行选择 | Comba + 增强 | 最完善 + 跨页支持 |
| Modal 弹窗 | Comba | 交互最完整 |
| Drawer 抽屉 | Comba | 详情查看体验佳 |
| 表单验证 | Comba | onBlur + inline 错误 |
| 表单布局 | OMC + Comba | 水平 Label + 折叠分区 |
| 图表库 | Comba (ECharts 5) | 功能强, 地图支持好 |
| 告警颜色 | OMC + Comba | 行业标准四级颜色 |
| 面包屑 | OMC + Comba | 导航辅助定位 |
| 收藏/快捷 | 广研院 | 实用功能保留 |
| 视觉风格 | 广研院 + Comba 融合 | 现代感 + 专业感 |

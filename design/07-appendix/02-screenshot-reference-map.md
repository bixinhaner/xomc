# 截图参考映射 (Screenshot Reference Map)

> OMC 统一网管系统 - 附录

## 概述

本文档将新设计方案中的每个页面映射到其参考的原始系统截图。设计师和开发者可通过此映射快速查找设计灵感来源和对比参考。

---

## 映射格式说明

```
新设计页面路径 → 参考截图来源
  [OMC]    = OMC 原系统截图
  [Comba]  = Comba 系统截图
  [广研院]  = 广研院系统截图
  [综合]   = 综合多套系统优点
```

## 注意事项

```
1. 截图文件存放在项目的 /screenshots/ 目录下
2. 截图命名格式: {系统}_{模块}_{页面}_{序号}.png
   如: omc_alarm_current_01.png
       comba_device_list_01.png
       gyyuan_dashboard_01.png
3. 新设计页面不是简单复制任何一个系统
4. 每个页面都经过了交互优化和视觉统一
5. 具体截图文件路径请参考项目实际目录结构
```

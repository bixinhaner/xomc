# 拓扑显示设置 (Topology Display Settings)

## 页面用途

拓扑画布的显示配置弹窗，用于控制告警级别的可见性、连线样式以及节点图标的自定义。从拓扑画布工具栏的设置图标触发。

## 布局模板

**Modal Dialog（模态弹窗）**

## 导航路径

```
OMC 统一网管 > 拓扑管理 > 拓扑树 > [设置按钮]
```

## 路由

```
/topology/tree  （弹窗不改变路由）
```

## 弹窗规格

### 弹窗 1: 拓扑显示设置

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 拓扑显示设置 |
| 尺寸 | 520px x auto |
| 触发 | 拓扑画布工具栏 ⚙ 设置图标 |

**网元告警数量显示:**

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 警告告警 | Toggle Switch | ON | 控制蓝色告警角标是否显示 |
| 次要告警 | Toggle Switch | ON | 控制黄色告警角标是否显示 |
| 主要告警 | Toggle Switch | ON | 控制橙色告警角标是否显示 |
| 紧急告警 | Toggle Switch | ON | 控制红色告警角标是否显示 |

**连线显示设置:**

| 字段名称 | 组件类型 | 默认值 | 选项 | 说明 |
|---------|---------|-------|------|------|
| Xn/X2 连线显示 | Toggle Switch | ON | -- | 是否显示 Xn/X2 连线 |
| 线条粗细 | Select | 2号 | 1号/2号/3号/4号 | 连线粗细程度 |
| 线条类型 | Select | 虚线 | 实线/虚线/点线 | 连线样式 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| 取消 | Default | 关闭弹窗，不保存更改 |
| 确定 | Primary | 应用设置到画布并关闭弹窗 |

### 弹窗 2: 图标设置

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 图标设置 |
| 尺寸 | 600px x auto |
| 触发 | 拓扑画布工具栏或显示设置中的图标设置入口 |

**图标配置表格:**

| 类型名称 | 默认图标 | 操作 |
|---------|---------|------|
| 设备集(存在断开设备) | 云图标+警告 | [更换] [恢复默认] |
| 设备集(全连接) | 云图标 | [更换] [恢复默认] |
| 核心网(4G) | 4G 信号图标 | [更换] [恢复默认] |
| 核心网(5G) | 5G 信号图标 | [更换] [恢复默认] |
| 4G一体化 | 基站图标 | [更换] [恢复默认] |
| 板卡(Slot) | 板卡图标 | [更换] [恢复默认] |
| 基带单元(BU) | BU 图标 | [更换] [恢复默认] |
| 内置射频单元(RU) | RU 图标 | [更换] [恢复默认] |

**[更换] 操作:** 打开文件选择器，支持 PNG/SVG，最大 512KB，建议 64x64px

| 按钮 | 类型 | 行为 |
|------|------|------|
| 取消 | Default | 关闭弹窗，不保存更改 |
| 确定 | Primary | 保存图标设置，刷新画布节点图标 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 图标上传中 | 图标预览区显示加载动画 |
| 图标格式错误 | 红色提示 "仅支持 PNG/SVG 格式" |
| 图标尺寸过大 | 红色提示 "文件大小不能超过 512KB" |
| 恢复默认 | 即时预览默认图标，确定后生效 |
| 设置已修改 | 弹窗关闭时若有未保存更改，提示 "是否放弃更改？" |

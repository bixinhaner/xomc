# GIS 地图视图 (GIS Map View)

## 页面用途

基站监控的核心地图页面，以 GIS 地图形式展示所有基站站点的地理分布和实时状态。左侧面板提供设备分组和站点列表的管理入口，右侧为全屏交互式地图。支持站点状态可视化（颜色编码）、聚合显示、详情弹窗和测距工具等功能。


## 筛选栏配置

### 左侧面板筛选

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| Site Name | SearchInput | 用户输入 | 空 | 站点名称模糊搜索 |

### 地图筛选器（浮动复选框组）

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| All | Checkbox | 勾选 | 全选/取消全选 |
| Site | Checkbox | 勾选 | 显示/隐藏站点标记 |
| eNB | Checkbox | 勾选 | 显示/隐藏 4G 基站 |
| gNB | Checkbox | 勾选 | 显示/隐藏 5G 基站 |
| GSM | Checkbox | 勾选 | 显示/隐藏 GSM 基站 |
| Site Name | Checkbox | 勾选 | 显示/隐藏站点名称标签 |

## 数据表规格

### 站点列表表格

| 列名 | 字段 Key | 宽度 | 排序 | 对齐 | 渲染规则 |
|------|----------|------|------|------|---------|
| (序号) | _index | 40px | -- | center | 自动行号 |
| (状态图标) | status | 32px | -- | center | 圆点: 🟢Normal / 🟠Abnormal / 🔴Offline |
| Site Name | siteName | flex | -- | left | 文本，点击定位地图到该站点 |
| Latitude | latitude | 100px | -- | right | 浮点数，6 位小数 |
| Longitude | longitude | 100px | -- | right | 浮点数，6 位小数 |
| (操作) | _actions | 64px | -- | center | 编辑(✏️) + 删除(🗑) 图标按钮 |

## 工具栏操作

### 左侧面板工具栏

| 按钮名称 | 图标 | 类型 | 行为 |
|---------|------|------|------|
| + 新增站点 | plus-circle | Primary | 打开新增站点弹窗 |

### 地图浮动工具栏（右上角）

| 按钮名称 | 图标 | 类型 | 行为 |
|---------|------|------|------|

## 弹窗规格

### 站点详情弹窗（Marker 点击触发）

| 属性 | 值 |
|------|-----|
| 触发方式 | 点击地图 Marker |
| 类型 | Map Popup (非模态弹窗) |
| 位置 | Marker 上方 |
| 关闭方式 | X 按钮 / 点击地图其他区域 |

| 展示字段 | 说明 |
|---------|------|
| Site Name | 站点名称（弹窗标题） |
| Latitude | 纬度 |
| Longitude | 经度 |
| eNB Count | 4G 基站数量 |
| gNB Count | 5G 基站数量 |
| GSM Count | GSM 基站数量 |
| eNB Throughput | 4G 吞吐量 DL:XX.XX / UL:XX.XX |
| gNB Throughput | 5G 吞吐量 DL:XX.XX / UL:XX.XX |

### 新增/编辑站点弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 新增站点 / 编辑站点 |
| 尺寸 | 560px x auto |

| 字段名称 | 组件类型 | 必填 | 校验规则 | 说明 |
|---------|---------|------|---------|------|
| Site Name | TextInput | 是 | 1-128 字符 | 站点名称 |
| Latitude | NumberInput | 是 | -90 ~ 90，6 位小数 | 纬度，可手动输入或地图取点 |
| Longitude | NumberInput | 是 | -180 ~ 180，6 位小数 | 经度，可手动输入或地图取点 |
| 地图取点 | MapPicker | -- | -- | 点击在小地图上取点，自动填入经纬度 |
| Description | Textarea | 否 | 0-255 字符 | 站点描述 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗 |
| Save | Primary | 保存站点，刷新列表和地图 |

### 删除站点确认

| 属性 | 值 |
|------|-----|
| 弹窗类型 | Confirm Dialog |
| 内容 | "确定删除站点 '{siteName}'？删除后该站点下的设备关联将被移除。" |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭 |
| Delete | Danger | 执行删除，刷新列表和地图 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 地图加载中 | 地图区域显示加载动画 |
| 站点数据加载中 | 左侧列表显示 Skeleton，地图显示已缓存标记 |
| 空数据 | 地图显示空白底图，左侧列表显示 "暂无站点数据，请添加站点" |
| 密集区域 | Marker 聚合显示，圆圈内标注数量，放大后展开 |
| 地图离线 | 显示离线提示 + 缓存底图 |
| 站点状态变更 | 实时更新 Marker 颜色和 Location 统计面板 |

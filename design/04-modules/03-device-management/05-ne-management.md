# 网元管理 (NE Management)

## 页面用途

管理设备下属的网络元素 (Network Element)，包括 BU (Baseband Unit)、EU (Extension Unit)、RU (Radio Unit) 三种类型。提供统一的网元查看、管理界面，头部展示资源统计概览。

## 布局模板

使用 02-list-page 布局，头部增加统计面板。

## 导航路径

设备管理 > 网元管理

## 路由

`/device/ne`

## 资源统计卡片

四个 mini KPI 卡片，展示各类网元总数。

| 卡片       | 图标                  | 背景色     | API 字段     |
|-----------|----------------------|-----------|-------------|
| BU 总数    | `CloudServerOutlined`| #1890FF   | buCount     |
| EU 总数    | `DesktopOutlined`    | #52C41A   | euCount     |
| RU 总数    | `WifiOutlined`       | #722ED1   | ruCount     |
| Slot 总数  | `AppstoreOutlined`   | #FA8C16   | slotCount   |

**卡片样式：** 高度 72px, 单行布局, 图标 + 标签 + 数值。

## Sub-Tab 定义

### BU 管理 Tab

**筛选栏：**

| 字段名称   | 英文标识      | 组件类型  | 说明                |
|----------|-------------|---------|---------------------|
| 设备名称  | deviceName  | Input   | 模糊搜索             |
| BU 名称  | buName      | Input   | 模糊搜索             |
| 状态     | status      | Select  | 全部/在线/离线        |

**表格列：**

| 列名称     | 英文标识         | 数据类型   | 可排序 | 宽度    |
|-----------|-----------------|-----------|--------|--------|
| BU 名称   | buName          | String    | 是     | 140px  |
| 所属设备   | deviceName      | String    | 是     | 160px  |
| 设备 SN   | deviceSn        | String    | 是     | 140px  |
| 产品类别   | productType     | String    | 是     | 100px  |
| 型号       | model           | String    | 是     | 120px  |
| Slot 信息  | slotInfo        | String    | 否     | 100px  |
| 状态       | status          | Status    | 是     | 80px   |
| 告警等级   | alarmLevel      | Severity  | 是     | 90px   |
| 上线时间   | onlineTime      | DateTime  | 是     | 160px  |
| 操作       | actions         | Actions   | 否     | 80px   |

### EU 管理 Tab

**表格列 (在 BU 列基础上增加/替换)：**

| 列名称     | 英文标识         | 说明           |
|-----------|-----------------|----------------|
| EU 名称   | euName          | 替换 BU 名称    |
| 所属 BU   | parentBu        | 父级 BU 信息    |
| EU 类型   | euType          | 单板/模块       |
| 端口数     | portCount       | 物理端口数量     |

### RU 管理 Tab

**表格列 (RU 特有列)：**

| 列名称     | 英文标识         | 说明            |
|-----------|-----------------|-----------------|
| RU 名称   | ruName          | 替换 BU 名称     |
| 所属 EU   | parentEu        | 父级 EU 信息     |
| 频段       | freqBand        | 工作频段         |
| 功率       | power           | 发射功率 (dBm)   |
| 天线数     | antennaCount    | 天线端口数       |
| 小区数     | cellCount       | 关联小区数       |

## 数据接口

```typescript
// BU 列表
GET /api/device/ne/bu?deviceType={type}&page={page}&size={size}&...

// EU 列表
GET /api/device/ne/eu?deviceType={type}&page={page}&size={size}&...

// RU 列表
GET /api/device/ne/ru?deviceType={type}&page={page}&size={size}&...

// 资源统计
GET /api/device/ne/statistics?deviceType={type}

interface NEStatistics {
  buCount: number;
  euCount: number;
  ruCount: number;
  slotCount: number;
}
```

## 状态处理

| 状态           | 处理方式                                 |
|---------------|------------------------------------------|
| 统计加载中     | 卡片 Skeleton 骨架                        |
| 表格加载中     | 表格 Skeleton 骨架 (5 行)                  |
| 数据为空       | Empty "暂无{NE类型}数据"                   |
| 加载失败       | 错误提示 + 重试按钮                        |
| 切换 Tab       | 保留上一个 Tab 的筛选状态, 新 Tab 独立筛选   |

# 开站管理 (Commissioning)

## 页面用途

管理设备开站（基站开通）任务流程。提供开站任务的创建、追踪、进度监控功能。每个开站任务包含多个步骤，支持查看各步骤的执行状态和详细结果。

## 布局模板

使用 02-list-page 布局。

## 导航路径

设备管理 > 开站管理

## 路由

`/device/commissioning`

## 筛选栏配置

| 字段名称   | 英文标识        | 组件类型         | ���填 | 选项/说明                              |
|----------|---------------|----------------|------|---------------------------------------|
| 任务名称  | taskName      | Input          | 否   | 模糊搜索                               |

### 开站步骤指示器

```
① ─── ② ─── ③ ─── ④ ─── ⑤
✓      ✓      ●      ○      ○
配置下发 参数校验 软件加载 小区激活 业务验证
```

| 步骤   | 步骤名称     | 图标/状态                              |
|-------|-------------|----------------------------------------|
| Step 1 | 配置下发    | ✓ 完成(绿) / ● 进行中(蓝) / ✗ 失败(红) / ○ 待执行(灰) |
| Step 2 | 参数校验    | 同上                                    |
| Step 3 | 软件加载    | 同上                                    |
| Step 4 | 小区激活    | 同上                                    |
| Step 5 | 业务验证    | 同上                                    |

**步骤指示器样式：** 使用 Ant Design Steps (mini size, dot style)，显示在单元格内。

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 表格加载中     | Skeleton 骨架屏                         |
| 数据为空       | Empty "暂无开站任务"                     |
| 任务执行中     | 步骤指示器实时更新 (WebSocket/轮询)       |
| 步骤失败       | 失败步骤红色标记, 显示失败原因             |
| 重试操作       | 从失败步骤重新开始执行                    |

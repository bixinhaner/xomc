# 导入导出 (Import & Export)

## 页面用途

提供设备数据的批量导入和导出功能。导入支持文件上传、数据预览、校验错误展示；导出支持自定义列选择、格式选择和进度追踪。

## 布局模板

使用 Tab 切换布局（导入 / 导出 两个 Tab）。

## 导航路径

设备管理 > 导入导出

## 路由

`/device/import-export`

## 导入规格

### 文件上传

| 属性          | 值                              |
|--------------|---------------------------------|
| 支持格式      | .csv, .xlsx                     |
| 最大文件大小   | 10MB                           |
| 最大记录数    | 1000 条                         |
| 上传组件      | Ant Design Upload.Dragger       |
| 拖拽上传      | 支持                            |

### 模板下载

| 模板     | 格式    | 包含内容                           |
|---------|--------|-----------------------------------|
| CSV 模板 | .csv   | 表头行 + 2 行示例数据 + 填写说明行  |
| Excel 模板| .xlsx | 表头行 + 2 行示例数据 + 数据校验下拉 |

### 校验规则

| 校验项          | 规则                        | 错误级别 |
|---------------|----------------------------|---------|
| SN 非空        | 必填                        | Error   |
| SN 格式        | 3-64 字符, 字母数字下划线    | Error   |
| SN 文件内唯一   | 文件内不重复                 | Error   |
| SN 系统内唯一   | 数据库中不存在               | Error   |
| 产品类别合法    | 系统定义值                   | Error   |
| 厂商合法       | 系统定义值                   | Error   |
| IP 格式        | IPv4/IPv6 (如填写)          | Warning |
| 型号匹配       | 厂商下存在该型号              | Error   |

### 预览表格列

| 列名称     | 宽度    | 说明                         |
|-----------|--------|------------------------------|
| 行号       | 60px   | 原文件行号                    |
| 设备 SN   | 140px  | -                            |
| 产品类别   | 100px  | -                            |
| 厂商       | 100px  | -                            |
| 设备型号   | 120px  | -                            |
| IP 地址   | 140px  | -                            |
| 校验状态   | 80px   | ✓ 通过(绿) / ✗ 失败(红)      |
| 错误原因   | 200px  | 失败时显示具体原因             |

## 导出规格

### 导出范围选项

| 选项         | 说明                                    |
|-------------|----------------------------------------|
| 全部设备     | 当前设备类型下的所有设备                   |
| 当前筛选结果  | 从设备列表页携带过来的筛选条件对应的数据    |
| 选中设备     | 从设备列表页选中的设备 (仅从列表页跳转时可用) |

### 导出进度

```
导出中... ████████████░░░░░░░░ 60%
正在处理 153 / 256 条记录
```

| 属性         | 值                                |
|-------------|-----------------------------------|
| 进度条       | Ant Design Progress               |
| 更新频率     | 每 500ms 更新一次进度              |
| 完成后       | 自动触发浏览器下载                   |
| 超时         | 60s 超时提示                       |

## 状态处理

| 状态             | 处理方式                                |
|-----------------|----------------------------------------|
| 文件上传中       | Upload 组件进度条                       |
| 文件解析中       | "正在解析文件..." Spin                  |
| 校验中           | "正在校验数据..." Spin + 进度           |
| 导入中           | 确认按钮 Loading + 进度条               |
| 导入完成         | Toast "成功导入 {n} 条设备"             |
| 导入部分失败     | Alert "成功 {n} 条, 失败 {m} 条"       |
| 导出中           | 进度条 + 百分比                         |
| 导出完成         | 自动下载 + Toast "导出完成"              |
| 导出失败         | 错误提示 + 重试按钮                      |

# 设备注册 (Device Registration)

## 页面用途

提供新设备注册入口，支持单台设备表单注册和批量导入注册两种模式。单台模式通过表单逐项填写设备信息；批量模式通过上传 CSV/Excel 文件实现批量注册。

## 布局模板

使用 Modal/Drawer 组件，从设备列表页触发。

## 导航路径

设备管理 > 设备列表 > 注册设备

## 路由

`/device/list` (弹窗模式, 不单独占路由)

## 弹窗规格

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Drawer (右侧抽屉)               |
| 宽度         | 640px                          |
| 关闭方式     | 点击 × / 点击遮罩 / ESC 键      |
| 销毁行为     | 关闭后销毁表单状态               |

## 单台注册表单字段

| 字段名称   | 英文标识        | 组件类型       | 必填 | 校验规则                              | 说明           |
|----------|---------------|--------------|------|--------------------------------------|---------------|
| 设备 SN  | deviceSn      | Input        | 是   | 非空, 3-64 字符, 字母数字下划线, 唯一性校验 | 自动去除首尾空格 |
| 产品类别  | productType   | Select       | 是   | 非空                                  | 默认取全局设备类型 |
| 厂商      | vendor        | Select       | 是   | 非空                                  | 选项从字典加载  |
| 设备型号  | deviceModel   | Select       | 是   | 非空                                  | 联动厂商选项    |
| IP 地址   | ipAddress     | Input        | 否   | IPv4/IPv6 格式校验                     | -             |
| 设备名称  | deviceName    | Input        | 否   | 最大 128 字符                          | 不填则自动生成  |
| 网络制式  | networkType   | Select       | 否   | -                                    | LTE-FDD/LTE-TDD/NR/NB-IoT |
| 区域      | region        | Cascader     | 否   | -                                    | 省/市/区级联    |
| 基站 ID  | stationId     | Input        | 否   | 数字, 唯一性                           | -             |

### 字段联动规则

| 触发字段     | 联动字段       | 联动逻辑                          |
|------------|--------------|----------------------------------|
| 产品类别    | 厂商          | 过滤该产品类别支持的厂商选项         |
| 厂商        | 设备型号      | 过滤该厂商下的设备型号选项           |
| 产品类别    | 网络制式      | 过滤该产品类别支持的网络制式选项      |

## 批量注册规格

### 模板格式

CSV/Excel 模板包含以下列:

| 列名           | 必填 | 说明                |
|---------------|------|---------------------|
| 设备SN         | 是   | 唯一标识             |
| 产品类别        | 是   | eNB/gNB/CPE/eGW    |
| 厂商           | 是   | 厂商名称             |
| 设备型号        | 是   | 型号名称             |
| IP地址          | 否   | IPv4/IPv6           |
| 设备名称        | 否   | -                   |
| 网络制式        | 否   | LTE-FDD/LTE-TDD/NR |
| 区域           | 否   | 省/市格式            |

### 校验规则

| 校验项          | 校验内容                          | 错误提示                  |
|---------------|----------------------------------|--------------------------|
| SN 非空        | 必填字段不能为空                    | "第 {n} 行: SN 不能为空"  |
| SN 唯一        | 文件内不重复 + 系统内不重复          | "第 {n} 行: SN 已存在"   |
| SN 格式        | 3-64 字符, 字母数字下划线           | "第 {n} 行: SN 格式不合法"|
| 产品类别合法    | 必须是系统定义的类别                 | "第 {n} 行: 产品类别无效" |
| 厂商合法       | 必须是系统定义的厂商                 | "第 {n} 行: 厂商不存在"  |
| IP 格式        | 如填写, 必须符合 IPv4/IPv6 格式     | "第 {n} 行: IP 格式错误" |
| 文件大小        | 不超过 5MB                        | "文件大小超过 5MB 限制"   |
| 记录条数        | 不超过 500 条                      | "记录数超过 500 条限制"   |

### 预览表格

| 列名      | 说明                                    |
|---------|------------------------------------------|
| 行号     | 原文件行号                                |
| SN      | 设备 SN                                  |
| 产品类别  | -                                        |
| 厂商     | -                                        |
| 型号     | -                                        |
| 校验结果  | ✓ 通过 (绿色) / ✗ 失败原因 (红色)          |

## 状态处理

| 状态               | 处理方式                                    |
|-------------------|--------------------------------------------|
| 表单提交中          | 确认按钮 Loading 态, 表单字段只读             |
| 注册成功           | Toast "设备注册成功", 关闭抽屉, 刷新列表       |
| 注册失败           | 错误提示 (如 SN 已存在), 表单字段保留          |
| SN 唯一性校验中    | SN 输入框右侧 Spin + "校验中..."             |
| SN 唯一性校验失败   | SN 输入框红色边框 + "该 SN 已被注册"           |
| 文件上传中          | Upload 组件进度条                            |
| 文件解析失败        | 错误提示 "文件格式错误, 请使用模板文件"          |
| 批量部分失败        | 预览表格标红失败行, 底部显示统计                |

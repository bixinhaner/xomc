# 在线监控 (Online Monitoring)

## 页面用途

实时监控设备在线/离线状态，提供多维度的设备连接状态统计面板和详细的设备状态列表。帮助运维人员快速发现离线设备并跟踪离线时长分布。

## 布局模板

使用 02-list-page 布局，头部增加统计面板。

## 导航路径

设备管理 > 在线监控

## 路由

`/device/online`

## 状态统计面板

### 统计卡片定义

| 卡片名称    | 英文标识           | 颜色     | 计算逻辑                       | 可点击 |
|-----------|-------------------|---------|-------------------------------|--------|
| 总数       | total             | #1890FF | 设备总数                        | 是     |
| 在线       | online            | #52C41A | 当前在线设备数                    | 是     |
| 离线       | offline           | #FF4D4F | 当前离线设备数                    | 是     |
| 6h 内离线  | offline6h         | #FA8C16 | 离线时长 <= 6 小时的设备数        | 是     |
| 12h 内离线 | offline12h        | #FA8C16 | 6h < 离线时长 <= 12h 的设备数    | 是     |
| 24h 内离线 | offline24h        | #FADB14 | 12h < 离线时长 <= 24h 的设备数   | 是     |
| 7 天内离线 | offline7d         | #8C8C8C | 24h < 离线时长 <= 7d 的设备数    | 是     |

### 卡片样式

| 属性         | 值                                |
|-------------|-----------------------------------|
| 高度         | 80px                              |
| 宽度         | 自适应 (7 等分)                    |
| 背景色       | #FFFFFF, 选中时对应颜色 opacity 0.1 |
| 边框         | 1px solid #E8E8E8, 选中时对应颜色   |
| 数值字体     | font-size: 28px, font-weight: 700 |
| 标签字体     | font-size: 13px, color: #8C8C8C   |
| 百分比字体   | font-size: 12px, 对应颜色          |
| 点击行为     | 选中后筛选表格数据为对应状态          |
| 选中样式     | 底部 3px 对应颜色边框               |

## 筛选栏配置

| 字段名称   | 英文标识      | 组件类型       | 必填 | 选项/说明                  |
|----------|-------------|--------------|------|---------------------------|
| 设备名称  | deviceName  | Input        | 否   | 模糊搜索                   |
| 设备 SN  | deviceSn    | Input        | 否   | 精确/模糊搜索              |
| 连接状态  | connStatus  | Select       | 否   | 全部/在线/离线              |
| 区域      | region      | TreeSelect   | 否   | 省 > 市 > 区级联           |

## 数据表规格

| 列名称     | 英文标识         | 数据类型    | 可排序 | 宽度    | 说明                       |
|-----------|-----------------|-----------|--------|--------|---------------------------|
| 设备名称   | deviceName      | String    | 是     | 160px  | 蓝色链接                   |
| 设备 SN   | deviceSn        | String    | 是     | 140px  | 可复制                     |
| 产品类别   | productType     | String    | 是     | 100px  | -                         |
| 厂商       | vendor          | String    | 是     | 100px  | -                         |
| 区域       | region          | String    | 是     | 120px  | -                         |

### 离线时长显示规则

| 时长范围        | 显示格式       | 文字颜色   |
|---------------|---------------|----------|
| 在线           | "-"           | #52C41A  |
| < 1 小时       | "Xm"          | #FA8C16  |
| 1-24 小时      | "Xh Xm"      | #FA8C16  |
| 1-7 天         | "Xd Xh"      | #FF4D4F  |

## 自动刷新

| 属性           | 值                              |
|---------------|--------------------------------|
| 默认间隔       | 60 秒                          |
| 可选间隔       | 30s / 60s / 120s / 300s / 关闭  |
| 刷新指示器     | 页面右上角倒计时进度条             |
| 刷新行为       | 静默刷新, 不闪烁不跳转分页        |

## 数据接口

```typescript
GET /api/device/online/statistics?deviceType={type}

interface OnlineStatistics {
  total: number;
  online: number;
  offline: number;
  offline6h: number;
  offline12h: number;
  offline24h: number;
  offline7d: number;
}

GET /api/device/online/list?deviceType={type}&status={status}&page={page}&size={size}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 统计加载中     | 卡片 Skeleton 骨架                      |
| 表格加载中     | 表格 Skeleton 骨架                      |
| 全部在线       | 离线卡片显示 0, 表格正常显示             |
| 全部离线       | 总数卡片和离线卡片数字一致, 红色高亮       |
| 自动刷新中     | 右上角显示刷新进度条                     |

# 交维管理 (Handover Management)

## 页面用途

管理设备从工程建设阶段到运维阶段的交接任务。跟踪设备的交维状态，记录交维验收过程。与开站管理流程衔接，确保开站完成的设备顺利移交给运维团队。

## 布局模板

使用 02-list-page 布局。

## 导航路径

设备管理 > 交维管理

## 路由

`/device/handover`

## 筛选栏配置

| 字段名称   | 英文标识        | 组件类型         | 必填 | 选项/说明                          |
|----------|---------------|----------------|------|-----------------------------------|
| 任务名称  | taskName      | Input          | 否   | 模糊搜索                           |
| 设备 SN  | deviceSn      | Input          | 否   | 精确/模糊搜索                       |
| 交维状态  | status        | Select         | 否   | 全部/待提交/待验收/验收中/已通过/已驳回 |
| 创建时间  | createTime    | DateRangePicker| 否   | 时间范围选择                        |
| 操作人    | operator      | Input          | 否   | 模糊搜索                           |
| 验收人    | reviewer      | Input          | 否   | 模糊搜索                           |

## 数据表规格

| 列名称     | 英文标识         | 数据类型    | 可排序 | 宽度    | 说明                    |
|-----------|-----------------|-----------|--------|--------|------------------------|
| 任务名称   | taskName        | String    | 是     | 140px  | 蓝色链接                |
| 设备 SN   | deviceSn        | String    | 是     | 140px  | -                      |
| 设备名称   | deviceName      | String    | 是     | 140px  | 蓝色链接                |
| 交维状态   | status          | Tag       | 是     | 100px  | 颜色标签 (见下方)        |
| 创建时间   | createTime      | DateTime  | 是     | 160px  | -                      |
| 验收时间   | reviewTime      | DateTime  | 是     | 160px  | 未验收显示 "-"          |
| 操作人     | operator        | String    | 是     | 100px  | 提交人                  |
| 验收人     | reviewer        | String    | 是     | 100px  | 验收人, 未指定显示 "-"   |
| 操作       | actions         | Actions   | 否     | 160px  | 详情/验收/驳回/重新提交   |

### 交维状态标签

| 状态     | Tag 颜色   | 说明                    |
|---------|----------|------------------------|
| 待提交   | default  | 任务已创建, 尚未提交验收  |
| 待验收   | processing | 已提交, 等待验收人处理  |
| 验收中   | processing | 验收人正在审核          |
| 已通过   | success  | 验收通过, 交维完成       |
| 已驳回   | error    | 验收驳回, 需重新处理     |

### 行操作按钮 (按状态显示)

| 状态     | 可用操作                        |
|---------|--------------------------------|
| 待提交   | 详情 / 提交验收 / 删除           |
| 待验收   | 详情 / 撤回                     |
| 验收中   | 详情                           |
| 已通过   | 详情                           |
| 已驳回   | 详情 / 重新提交                  |

## 弹窗规格

### 新建交维任务弹窗

| 属性     | 值                        |
|---------|---------------------------|
| 标题     | 新建交维任务               |
| 宽度     | 560px                     |

**表单字段：**

| 字段名称     | 组件类型    | 必填 | 校验规则                        |
|------------|----------|------|--------------------------------|
| 任务名称    | Input    | 是   | 非空, 2-64 字符                 |
| 设备选择    | Select   | 是   | 搜索选择, 仅显示已开站完成的设备  |
| 验收人      | Select   | 否   | 从用户列表选择                   |
| 交维内容    | TextArea | 是   | 非空, 最大 1000 字符             |
| 附件       | Upload   | 否   | 支持 pdf/doc/xlsx, 最大 20MB    |

### 验收操作弹窗

| 属性     | 值                              |
|---------|--------------------------------|
| 标题     | 交维验收                        |
| 宽度     | 480px                          |

**表单字段：**

| 字段名称     | 组件类型    | 必填 | 说明                 |
|------------|----------|------|---------------------|
| 验收结果    | Radio    | 是   | 通过 / 驳回          |
| 验收意见    | TextArea | 是   | 非空, 最大 500 字符   |

## 状态处理

| 状态           | 处理方式                               |
|---------------|---------------------------------------|
| 表格加载中     | Skeleton 骨架屏                        |
| 数据为空       | Empty "暂无交维任务"                    |
| 提交成功       | Toast "提交成功", 状态变更为 "待验收"    |
| 验收成功       | Toast "验收通过", 状态变更为 "已通过"    |
| 驳回成功       | Toast "已驳回", 状态变更为 "已驳回"      |

## 跨模块导航

# 回收站 (Recycle Bin)

## 页面用途

存放已删除的设备记录，提供恢复或永久删除操作。设备删除后默认进入回收站，保留 30 天后自动永久删除。避免误操作造成数据丢失。

## 布局模板

使用 02-list-page 布局。

## 导航路径

设备管理 > 回收站

## 路由

`/device/recycle`

## 筛选栏配置

| 字段名称   | 英文标识      | 组件类型         | 必填 | 选项/说明          |
|----------|-------------|----------------|------|-------------------|
| 设备名称  | deviceName  | Input          | 否   | 模糊搜索           |
| 设备 SN  | deviceSn    | Input          | 否   | 精确/模糊搜索       |
| 删除时间  | deleteTime  | DateRangePicker| 否   | 时间范围选择        |

## 数据表规格

| 列名称     | 英文标识         | 数据类型    | 可排序 | 宽度    | 说明                    |
|-----------|-----------------|-----------|--------|--------|------------------------|
| 复选框     | selection       | Checkbox  | 否     | 48px   | 全选/单选               |
| 设备名称   | deviceName      | String    | 是     | 160px  | 灰色文字 (已删除状态)    |
| 设备 SN   | deviceSn        | String    | 是     | 140px  | -                      |
| 产品类别   | productType     | String    | 是     | 100px  | -                      |
| 厂商       | vendor          | String    | 是     | 100px  | -                      |
| 区域       | region          | String    | 是     | 120px  | -                      |
| 删除人     | deletedBy       | String    | 是     | 100px  | 执行删除操作的用户       |
| 删除时间   | deleteTime      | DateTime  | 是     | 160px  | YYYY-MM-DD HH:mm:ss   |
| 剩余天数   | remainDays      | Number    | 是     | 90px   | 距永久删除的天数         |
| 操作       | actions         | Actions   | 否     | 120px  | 恢复 / 永久删除         |

### 剩余天数样式

| 天数范围    | 文字颜色   | 额外样式          |
|-----------|----------|------------------|
| > 14 天    | #52C41A  | -                |
| 7-14 天    | #FAAD14  | -                |
| 1-7 天     | #FF4D4F  | font-weight: 600 |
| < 1 天     | #FF4D4F  | 闪烁效果          |

## 工具栏操作

| 操作名称       | 图标                    | 类型     | 启用条件           | 说明                 |
|-------------|------------------------|---------|-------------------|---------------------|
| 批量恢复     | `UndoOutlined`         | Primary | 至少选中 1 项      | 恢复到设备列表        |
| 批量永久删除  | `DeleteOutlined`       | Danger  | 至少选中 1 项      | 不可恢复             |
| 清空回收站   | `ClearOutlined`        | Danger  | 回收站非空          | 永久删除全部          |

## 弹窗规格

### 恢复确认弹窗

| 属性     | 值                                        |
|---------|-------------------------------------------|
| 类型     | Modal.confirm (info)                       |
| 标题     | 确认恢复                                   |
| 内容     | "确定要恢复选中的 {n} 台设备吗？恢复后设备将回到设备列表。" |
| 确认按钮  | "确认恢复" (primary)                        |

### 永久删除确认弹窗

| 属性     | 值                                        |
|---------|-------------------------------------------|
| 类型     | Modal.confirm (danger)                     |
| 标题     | 永久删除                                   |
| 内容     | "确定要永久删除选中的 {n} 台设备吗？此操作不可恢复！" |
| 二次确认  | 输入 "DELETE" 确认 (防止误操作)              |
| 确认按钮  | "永久删除" (danger)                         |

### 清空回收站确认弹窗

| 属性     | 值                                        |
|---------|-------------------------------------------|
| 类型     | Modal.confirm (danger)                     |
| 标题     | 清空回收站                                  |
| 内容     | "确定要清空回收站吗？共 {n} 台设备将被永久删除，此操作不可恢复！" |
| 二次确认  | 输入 "CLEAR ALL" 确认                      |
| 确认按钮  | "确认清空" (danger)                         |

## 数据接口

```typescript
// 回收站列表
GET /api/device/recycle?page={page}&size={size}&...

// 恢复设备
POST /api/device/recycle/restore
{ deviceSns: string[] }

// 永久删除
DELETE /api/device/recycle/permanent
{ deviceSns: string[] }

// 清空回收站
DELETE /api/device/recycle/clear
```

## 状态处理

| 状态           | 处理方式                                     |
|---------------|----------------------------------------------|
| 表格加载中     | Skeleton 骨架屏                               |
| 回收站为空     | Empty "回收站为空" + 清洁图标                   |
| 恢复成功       | Toast "已成功恢复 {n} 台设备", 刷新列表         |
| 恢复失败       | 错误提示 (如 SN 冲突等)                        |
| 永久删除成功   | Toast "已永久删除 {n} 台设备", 刷新列表          |
| 即将过期设备   | 剩余天数 < 3 天时行背景色 #FFF1F0              |

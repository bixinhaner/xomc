# 用户文件与固件管理 User File & Firmware Management

> 模块路径：`/file-mgmt/user-files`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：Comba UMS 用户上传文件 + 设备固件文件

---

## 1. 页面概述

管理用户上传到网管系统的各类文件（脚本、配置模板、补丁等）以及设备固件文件。采用双 Tab 布局：用户上传文件和设备固件文件。

---

## 5. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看文件库 | `file:library:view` |
| 上传用户文件 | `file:library:upload` |
| 添加固件 | `file:firmware:upload` |
| 下载文件 | `file:library:download` |
| 删除文件 | `file:library:delete` |

# 获取日志文件 Log File Retrieval

> 模块路径：`/file-mgmt/log-retrieval`
> 布局模板：树-列表 + 上下分屏（同获取配置文件）
> 数据来源：Comba UMS 获取日志文件

---

## 1. 页面概述

从网元设备获取（拉取）运行日志文件。页面布局与获取配置文件完全一致（左树 + 右上网元列表 + 右下结果 + 底部任务面板），仅操作按钮和结果字段略有不同。

---

## 2. 页面结构

同 `01-config-file-retrieval.md`，以下为差异点：

### 2.1 工具栏差异

| 按钮 | 说明 |
|------|------|
| 移除 / 清空 / 导入网元 | 同配置文件页 |
| **立即获取日志** | Primary 按钮（替代"获取配置文件"） |

### 2.2 获取日志对话框

> 点击 [立即获取日志] 后弹出

```
┌─────────────────────────────────────┐
│ 获取日志文件                          │
├─────────────────────────────────────┤
│                                     │
│ 目标网元：已选择 8 台                  │
│                                     │
│ 日志类型  ☑ 运行日志                   │
│           ☑ 告警日志                   │
│           ☐ 调试日志                   │
│           ☐ 安全日志                   │
│                                     │
│ 时间范围  [2024-01-14] ~ [2024-01-15]│
│                                     │
│ 压缩格式  ○ 不压缩  ● tar.gz  ○ zip  │
│                                     │
│          [取消]    [开始获取]          │
└─────────────────────────────────────┘
```

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 日志类型 | Checkbox Group | ✅ | 至少选一个 |
| 时间范围 | DateRangePicker | — | 默认最近 24 小时 |
| 压缩格式 | Radio | — | 默认 tar.gz |

---

## 3. 操作结果表格

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 网元名称 | `neName` | 140px | |
| 序列号 | `sn` | 160px | |
| 日志类型 | `logType` | 100px | 运行/告警/调试/安全 |
| 文件名 | `fileName` | 200px | |
| 文件大小 | `fileSize` | 100px | |
| 获取状态 | `status` | 100px | 成功/失败/进行中 |
| 失败原因 | `failReason` | 200px | |
| 获取时间 | `retrieveTime` | 160px | |
| 操作 | — | 100px | [下载] [重试] |

---

## 4. 与配置文件获取的统一交互

两个页面共享以下能力：
- 左侧树形网元选择器（6 维度 Tab）
- 导入网元对话框
- 底部任务面板（任务/批量任务/导出）
- WebSocket 实时进度推送

---

## 5. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看页面 | `file:log-retrieval:view` |
| 获取日志文件 | `file:log-retrieval:retrieve` |
| 下载文件 | `file:log-retrieval:download` |

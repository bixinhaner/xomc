> 模块路径：`/file-mgmt/config-retrieval`
> 布局模板：树-列表 + 上下分屏 — 参考 `03-layouts/04-tree-list-page.md` + `03-layouts/06-split-panel-page.md`
> 数据来源：Comba UMS 网元文件管理 — 获取配置文件

---

## 1. 页面概述

从网元设备获取（拉取）配置文件并存储到网管系统。页面采用复合布局：左侧网元类型树 + 右上网元列表 + 右下操作结果 + 底部任务面板。是文件管理模块最核心的高频操作页面。

## 3. 左侧网元分类树

### 3.1 Tab 切换维度

| Tab | 树结构 |
|-----|--------|
| 按类型 | 网元类型 → 设备型号 → 网元 |
| 按子网 | 子网 → 网元 |
| 按站点 | 站点 → 网元 |
| 按区域 | 省 → 市 → 区 → 网元 |
| 按模板 | 模板名 → 匹配网元 |
| 按分组 | 自定义分组 → 网元 |

### 3.2 树交互

- 顶部搜索框：过滤节点
- 勾选节点：添加到右上网元列表
- 全选/反选按钮
- 树节点计数徽章

## 6. 获取配置文件流程

```
1. 通过左侧树或导入对话框选择网元
   ↓
2. 勾选目标网元 → 点击 [获取配置文件]
   ↓
3. 确认对话框（显示选中数量 + 预估耗时）
   ↓
4. 创建获取任务（任务面板显示进度）
   ↓
5. 结果逐台更新到操作结果表格
   ↓
6. 完成后 Toast 通知
```

---

## 7. 底部任务面板

| Tab | 内容 |
|-----|------|
| 任务 | 当前正在执行的获取任务列表（实时进度） |
| 批量任务 | 历史批量获取任务记录 |
| 导出 | 文件导出任务（将获取到的配置文件打包下载） |

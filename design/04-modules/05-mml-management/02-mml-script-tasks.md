# MML 脚本任务 (MML Script Tasks)

## 页面用途

管理批量 MML 脚本执行任务。采用上下分栏布局：上方为任务列表，下方为选中任务的执行结果明细。支持任务创建、启动、终止、删除等操作，以及右键上下文菜单。

## 布局模板

使用 split-panel-page 布局（上下分栏，可拖拽调整比例）。

## 导航路径

MML 管理 > 脚本任务

## 路由

`/mml/tasks`

## 上栏: 任务列表

### 工具栏

| 操作名称   | 图标                | 类型     | 说明              |
|---------|--------------------|---------|--------------------|
| 新建任务  | `PlusOutlined`     | Primary | 打开新建任务对话框   |

### 任务列表表格

| 列名称        | 英文标识       | 数据类型    | 可排序 | 宽度    | 说明                    |
|-------------|---------------|-----------|--------|--------|------------------------|
| 任务名称      | taskName      | String    | 是     | 160px  | 蓝色链接, 点击在下栏显示  |
| 创建人        | creator       | String    | 是     | 100px  | -                      |
| 创建时间      | createTime    | DateTime  | 是     | 140px  | -                      |
| 执行类型      | executeType   | Tag       | 是     | 80px   | 即时/定时/周期           |
| 状态          | status        | Tag       | 是     | 90px   | 颜色标签 (见下方)        |
| 进度          | progress      | Progress  | 否     | 120px  | 进度条 + 百分比          |
| 执行结果      | result        | String    | 否     | 160px  | 成功/失败/总计 格式      |
| 操作          | actions       | Actions   | 否     | 120px  | 按状态显示不同操作        |

### 任务状态标签

| 状态         | 英文标识       | Tag 颜色     | 说明            |
|-------------|---------------|-------------|-----------------|
| 等待执行     | Waiting       | blue        | 任务已创建, 等待触发 |
| 执行中       | InProgress    | blue + Spin | 正在执行          |
| 已完成       | End           | default     | 全部执行完毕       |
| 已终止       | Terminate     | orange      | 用户手动终止       |

### 行操作按钮 (按状态)

| 状态       | 可用操作                    |
|-----------|---------------------------|
| Waiting   | 启动 / 编辑 / 删除          |

| End       | 查看日志 / 重新执行 / 删除   |
| Terminate | 重新执行 / 删除              |

## 下栏: 执行结果明细

选中上栏某个任务后，下栏显示该任务的逐设备执行结果。

### 头部信息

```
任务: {taskName}  状态: {status}  设备: {totalCount} 台
成功: {successCount}  失败: {failCount}  执行中: {runningCount}  等待: {waitingCount}
```

### 结果明细表格

| 列名称      | 英文标识       | 数据类型  | 可排序 | 宽度    | 说明                |
|-----------|---------------|---------|--------|--------|---------------------|
| SN        | deviceSn      | String  | 是     | 130px  | 设备 SN              |
| 小区名称   | cellName      | String  | 是     | 140px  | -                   |

| 执行结果   | execResult    | String  | 否     | 140px  | RETCODE 或简要结果    |
| 失败原因   | failReason    | String  | 否     | 160px  | 失败时显示原因         |

| 状态     | Tag 颜色     | 图标                   |
|---------|-------------|------------------------|
| 成功     | success     | `CheckCircleOutlined`  |

## 分栏调整

| 属性         | 值                              |
|-------------|--------------------------------|
| 分隔条       | 水平拖拽条, 4px 高, #E8E8E8     |
| 最小上栏高度  | 200px                          |
| 最小下栏高度  | 200px                          |
| 默认比例     | 上 40% / 下 60%                |
| 拖拽光标     | `row-resize`                   |

## 数据接口

```typescript
// 任务列表
GET /api/mml/tasks?page={page}&size={size}

// 任务执行结果明细
GET /api/mml/tasks/{taskId}/results?page={page}&size={size}

// 启动任务
POST /api/mml/tasks/{taskId}/start

// 终止任务
POST /api/mml/tasks/{taskId}/terminate

// 删除任务
DELETE /api/mml/tasks/{taskId}
```

## 状态处理

| 状态             | 处理方式                                  |
|-----------------|------------------------------------------|
| 上栏加载中       | 表格 Skeleton 骨架                        |
| 下栏未选中任务   | 显示 "请选择一个任务查看执行结果"           |
| 下栏加载中       | 表格 Skeleton 骨架                        |
| 任务执行中       | 上栏进度条实时更新, 下栏状态实时刷新 (轮询)  |
| 启动成功         | Toast "任务已启动"                        |
| 终止确认         | Popconfirm "确定要终止此任务吗？"          |
| 删除确认         | Modal.confirm "确定要删除此任务吗？"       |

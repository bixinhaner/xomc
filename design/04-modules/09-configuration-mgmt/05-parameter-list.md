# 网元参数列表 (Network Element Parameter List)

## 页面用途

展示所有网元的完整参数列表，支持通过快捷模板切换预设列组合。提供模板管理功能（新建/编辑/查看/删除参数模板），以及数据导出能力。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 网元参数列表
```

## 路由

```
/config/param-list
```

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 查询 | Primary | 执行查询 |
| +模板管理 | Link | 打开模板管理页面（新标签页） |
| 导出 | Default | 导出当前数据 |

## 弹窗规格

### 模板管理（新标签页）

**表格列:** 复选框 / 模板名称 / 是否启用 / 是否共享 / 设备类型 / 设备子类 / 设备制式 / 设备型号 / 创建用户 / 备注

**操作:** 新建 / 编辑 / 查看 / 删除

### 添加模板弹窗

**基础信息 Tab:** 模板名称(*) / 是否启用(Toggle) / 是否共享(Toggle) / 备注(Textarea)

**参数选择 Tab:** 设备类型/子类/制式/型号(下拉) + 已选参数/未选参数(Transfer) + 参数标识/名称/路径/描述

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 无模板选择 | 显示所有默认列 |
| 模板切换 | 动态调整显示列组合 |

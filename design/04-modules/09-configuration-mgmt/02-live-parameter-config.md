# 现网参数配置 (Live Parameter Configuration)

## 页面用途

对在网设备进行实时参数查询和修改。三栏布局：左侧菜单导航、中间设备类型树及网元列表、右侧参数配置区域（支持下拉选择参数集并在线编辑参数值）。底部为任务面板追踪配置下发进度。

## 布局模板

**Tree-List Page Layout（三栏树形列表页）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 现网参数配置
```

## 路由

```
/config/live-param
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 设备类型 Tab | TabBar | 类型/子网/站点/区域/模板/群组 | 类型 | 切换设备分类维度 |
| 网元搜索 | SearchInput | 用户输入 | 空 | 搜索网元名称/小区 |
| 参数集选择 | Select | API: 参数集列表 | 请选择 | 选择后加载对应参数到右侧 |

## 数据表规格

### 网元列表（中间面板）

| 列名 | 字段 Key | 宽度 | 说明 |
|------|----------|------|------|
| 网元名称 | neName | flex | 网元标识名称 |
| 小区 | cellName | 100px | 小区名称 |

### 参数配置表（右侧面板）

| 列名 | 字段 Key | 宽度 | 说明 |
|------|----------|------|------|
| 参数名称 | paramName | 200px | 参数英文标识，只读 |
| 参数值 | paramValue | flex | 可编辑: TextInput / NumberInput / Select（根据参数类型动态渲染） |

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 参数全同步 | Primary | 将当前网元的所有参数从设备同步到平台 |

## 弹窗规格

无独立弹窗（参数编辑直接在右侧面板内联进行）

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未选择网元 | 中间列表显示 "暂无数据"，右侧显示 "请选择网元" |
| 未选择参数集 | 右侧显示 "请选择参数集" |
| 参数加载中 | 右侧显示 Skeleton |
| 参数修改后 | 修改的字段高亮标记，保存按钮激活 |
| 配置下发中 | 底部任务面板更新进度 |

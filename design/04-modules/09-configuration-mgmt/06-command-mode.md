# 命令模式 (Command Mode)

## 页面用途

提供 MML 命令行式的参数查询和下发接口。用户通过选择命令类型、输入 SN/OUI 和参数路径构建命令，在预览区确认后下发到设备，结果显示在下方的等宽字体文本区域。

## 布局模板

**Form + Result Layout（表单 + 结果区布局）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 命令模式
```

## 路由

```
/config/command
```

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 命令选中 | Default | 选中当前命令文本 |
| 命令下发 | Primary | 将构建的命令下发到设备执行 |
| 命令清空 | Default | 清空命令表单和预览区 |
| 全部清空 | Link (结果区) | 清空结果文本区域 |

### 表单字段

| 字段名称 | 组件类型 | 说明 |
|---------|---------|------|
| 命令类型 | Select | 查询参数 / 设置参数 / 其他 |
| SN | TextInput | 设备序列号，双击打开网元选择弹窗自动填入 |
| OUI | TextInput | 组织唯一标识，双击打开网元选择弹窗自动填入 |
| 参数路径 | TextInput | 参数 OID 路径，双击打开参数路径选择器 |

## 弹窗规格

### 网元选择弹窗（SN/OUI 双击触发）

| 属性 | 值 |
|------|-----|
| 类型 | 简化列表选择 |
| 内容 | 网元列表，支持搜索，单选 |
| 行为 | 选中后自动回填 SN 和 OUI |

### 参数路径选择器（参数路径双击触发）

| 属性 | 值 |
|------|-----|
| 类型 | 树形选择弹窗 |
| 内容 | 参数路径树形结构 (Device. > ManagementServer. > ...) |
| 行为 | 选中叶子节点后回填完整路径 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 命令预览实时更新 | 表单字段变更时自动更新命令预览文本 |
| 命令执行中 | 结果区显示 "Executing..." 动画 |
| 命令成功 | 结果区追加输出，末尾显示 "OK" |
| 命令失败 | 结果区追加红色错误信息 |
| 结果区 | 等宽字体(monospace)，支持文本选择和复制 |

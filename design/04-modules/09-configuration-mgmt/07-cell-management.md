# 小区管理 (Cell Management)

## 页面用途

管理网络小区的完整生命周期，包括小区列表查看、编辑、同步和参数配置。支持丰富的筛选条件和批量操作，提供小区详细配置弹窗（含基本信息、小区参数、VoLTE 参数、PLMN 参数四个标签页）。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 小区管理
```

## 路由

```
/config/cells
```

## 弹窗规格

### 小区配置弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 小区配置 |
| 尺寸 | 800px x 600px |
| Tab 页 | 基本信息 / 小区参数管理 / VoLTE参数 / PLMN参数管理 |

**顶部基本信息区（键值对只读展示）:**
小区ID / PCI / ECI / 设备SN号 / 设备名称 / 网络制式 / 产品分类 / 厂商名称 / 所属区域 / 小区闭塞 / 运行状态 / 管理状态

**小区参数管理 Tab:** ECI / 频带指示 / 下行带宽 / 上行带宽 / 下行EARFCN / 上行EARFCN / 参考信号功率 / PSCH功率偏置 / SSCH功率偏置 / PBCH功率偏置 / PCI

**VoLTE参数 Tab:** QCI上行SPS功能开关 + 分QCI头压缩功能开关子表格(QCI序号/开关/操作)

**PLMN参数管理 Tab:** 突发事件区域ID / TAC + PLMN子表格(PLMN实例序号/PLMNID/小区预留标识/操作)

| 按钮 | 类型 | 行为 |
|------|------|------|
| 刷新 | Default | 重新加载参数 |
| 编辑 | Primary | 切换为编辑模式 |

# 常用配置 (Common Configuration)

## 页面用途

提供按配置分类组织的常用参数配置管理。左侧为 NR/LTE 双制式配置项树形导航（涵盖小区、邻区、核心网、WAN口、移动性、QOS、RRC、SON 等配置域），右侧为对应的筛选栏和数据表格。支持组合配置和批量配置（含文件上传模板方式）。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）**

```
+------------------------------------------------------------------+
| 顶部导航栏                                                         |
+------------------------------------------------------------------+
| 左侧配置树 (20%)          | 右侧内容区 (80%)                      |
| NR/LTE 配置分类树          | 筛选栏 + 工具栏 + 数据表格             |
+------------------------------------------------------------------+
```

## 筛选栏配置

筛选条件随左侧树节点选择动态变化。以 NR 小区工参配置为例:

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 小区名称 | TextInput | 空 | 小区名称搜索 |
| 小区ID | TextInput | 空 | 小区ID搜索 |
| NCI | TextInput | 空 | NCI搜索 |
| 设备名称 | TextInput | 空 | 设备名称搜索 |
| 设备SN号 | TextInput | 空 | SN号搜索 |
| 厂商名称 | Select | 全部 | 厂商筛选 |

### 左侧配置树结构

**NR设备配置:**
- 小区参数配置: 小区工参配置 / 小区TA配置 / 小区PLMN配置 / 小区切片配置
- 邻区配置: NR邻区配置 / LTE邻区配置
- 核心网配置: AMF配置
- WAN口参数配置: WAN口配置 / vlan子接口配置 / 子接口IPv4配置 / 子接口IPv6配置 / 路由配置
- 移动性参数配置: A1~A5事件测量控制 / B1/B2事件测量控制 / 异系统相关配置 / 异频相关配置 / 同频重选配置
- QOS参数配置 / RRC参数配置 / SON参数配置

**LTE设备配置:** 与 NR 基本对称，核心网含 MME配置/S1-U配置

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 组合配置 | Primary | 打开组合配置弹窗 |
| 隐藏列 | Dropdown | 控制列显示 |
| 批量操作 | Dropdown | 批量编辑等 |
| 导出 | Dropdown | 导出已选/全部 |
| 批量配置 | Primary | 打开批量配置文件上传弹窗 |
| 刷新 | Icon | 刷新列表 |

## 弹窗规格

### 组合配置弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 配置网络制式 | Select | 是(*) | NR / LTE |
| 任务名称 | TextInput (0/64) | 是(*) | 任务名称 |
| 配置内容 | Dynamic Area | 是(*) | "请先选择网络制式，再添加配置" |
| 执行计划 | RadioGroup | 是(*) | 立即执行(默认) / 定时执行 |
| 执行时间 | DateTimePicker | 条件必填 | 仅定时执行时可用 |

### 批量配置文件上传弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 任务名称 | TextInput (0/64) | 是(*) | 任务名称 |
| 配置文件 | FileDragUpload | 是(*) | "将文件拖到此处，或点击上传" |
| 模板下载 | Link | -- | "[配置名称]文件模板.xls" |
| 导出携带数据 | Checkbox | 否 | "导出的模板携带现有数据" |
| 执行计划 | RadioGroup | 是(*) | 立即执行(默认) / 定时执行 |
| 执行时间 | DateTimePicker | 条件必填 | 仅定时执行时可用 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未选择配置分类 | 右侧显示 "请在左侧选择配置项" |
| 树节点切换 | 右侧筛选栏和表格列动态刷新 |
| 组合配置未选制式 | 配置内容区提示 "请先选择网络制式" |

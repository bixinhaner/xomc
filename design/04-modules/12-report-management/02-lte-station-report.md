# LTE 基站报表 (LTE Station Report)

## 页面用途

按 LTE 基站维度查看性能 KPI 报表，与 LTE 标准报表共享相同的页面结构和交互模式，但报表分类聚焦于基站级别的关键性能指标，包括接入性、移动性、保持性、资源类、时延类和 PDCP 层流量等维度。适用于基站级别的性能评估和问题定位。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）** — 与 LTE 标准报表完全一致

- 类型 (网元/小区/业务区/厂商/站点/全网/设备类别)

## 数据表规格

与 LTE 标准报表相同的动态列结构，KPI 列根据报表分类动态生成。

### 报表分类

| 分类 | 说明 |
|------|------|
| 接入性 | RRC 连接建立成功率、S1 信令连接建立成功率等基站级接入 KPI |
| 移动性 | X2 切换成功率、S1 切换成功率、切换平均时延等基站级移动性 KPI |
| 保持性 | E-RAB 掉话率、无线掉线率等基站级保持性 KPI |
| 资源类 | 上行/下行 PRB 平均利用率、最大连接用户数等基站级资源 KPI |
| 时延类 | 用户面上行/下行平均时延、控制面时延等基站级时延 KPI |
| PDCP层流量 | 上行/下行 PDCP 层数据流量、峰值速率等基站级流量 KPI |

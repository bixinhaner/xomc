# LTE 标准报表 (LTE Standard Report)

## 页面用途

LTE 网络标准性能报表查询页面。左侧提供 LTE 报表分类树（接入性、移动性、保持性、资源类、时延类、PDCP 层流量、计数器等），右侧提供多维度筛选（统计类型、时间粒度、查询条件、时间范围）和三种内容视图（表格/统计图/KPI说明）。与性能管理的 KPI 标准报表结构一致，聚焦于 LTE 网络的标准性能指标。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）**


## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 类型 | Select | 网元/小区/业务区/厂商/站点/全网/设备类别 | 网元 | 报表统计维度 |
| 粒度 | Select | 分钟/小时/天/周/月 | 天 | 时间粒度 |
| 查询条件 | Select | 网元名称/设备标识/SN/区域 | 网元名称 | 过滤字段 |
| 匹配方式 | Select | 包含/不包含/等于/不等于 | 包含 | 匹配逻辑 |
| 过滤值 | TextInput | 用户输入 | 空 | 过滤关键词 |
| 时间范围 | Select | 前三天/前两天/昨天/前7天/自定义 | 前三天 | 快捷时间选择 |
| 从 | DatePicker | -- | 自动计算 | 起始日期 |
| 至 | DatePicker | -- | 自动计算 | 结束日期 |

**特殊交互:**
- 过滤条件支持通过 [+] 按钮添加多个条件组合
- 时间范围支持通过 [+] 按钮添加多个时间段，实现多时段叠加查询
- 已添加的时间范围显示为蓝色标签（带 [x] 可删除）

## 数据表规格

表格列根据选中的报表分类动态生成。通用列:

| 列名 | 字段 Key | 宽度 | 说明 |
|------|----------|------|------|
| 网元名称/小区名称 | entityName | 200px | 统计维度对应的实体名称 |
| 日期 | date | 120px | 统计日期 |
| (动态KPI列) | kpi_xxx | 120px | 根据报表分类动态生成，每个KPI一列 |

### 报表分类

| 分类 | 说明 |
|------|------|
| 接入性 | RRC 连接建立、S1 信令连接、E-RAB 建立等接入相关 KPI |
| 移动性 | X2/S1 切换成功率、切换时延等移动性 KPI |
| 保持性 | 掉话率、E-RAB 异常释放率等保持性 KPI |
| 资源类 | PRB 利用率、CCE 利用率等资源 KPI |
| 时延类 | 用户面时延、控制面时延等 KPI |
| PDCP层流量 | 上下行 PDCP 层数据流量 KPI |
| 计数器 | 底层原始计数器数据 |
| 切换指标 | 基站间/基站内切换相关指标 |
| ETL关键指标 | ETL 数据处理相关关键指标 |

## 工具栏操作

### 表格视图工具栏

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 导出 | Dropdown | 导出格式: CSV(默认) / Excel |
| 单位 | Dropdown | KB / MB / GB（流量类指标） |
| 设置 | Icon | 表格列显示/隐藏配置 |

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 选择网元 | Button + Clear | 选择/清除展示的网元 |
| 选择图形 | RadioGroup | 柱状图(默认) / 折线图 / 饼图 |
| 导出 | Button | 下载图表图片 |
| 查询 | Button | 执行图表查询 |

## 弹窗规格

无独立弹窗

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未查询 | 表格区域为空，提示 "请设置查询条件后点击查询" |
| 查询中 | 表格显示加载动画 |
| 无数据 | 显示 "查询无结果" |
| 多报表Tab | 可同时打开多个报表分类为独立子 Tab（带 [x] 关闭） |
| 图表未选网元 | 图表区提示 "请先选择网元" |
| KPI说明视图 | 显示报表名称、描述、KPI 名称/定义/单位表格 |
| 模板查询 | 选择内置模板后加载预定义的查询条件和列配置 |

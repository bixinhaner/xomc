# License 操作 (License Operations)

## 页面用途

定义 License 管理模块的核心操作流程，包括 Send License（发送 License 到设备）、Download License（下载 License 文件）、Delete License（删除 License）以及批量输入 SN 的弹窗规格。所有操作均从 License 设备列表页的工具栏触发。

## 布局模板

**Modal Dialog（模态弹窗）** — 所有操作均以弹窗形式覆盖于列表页之上。

## 导航路径

```
OMC 统一网管 > License 管理 > License 设备列表 > [操作弹窗]
```

## 路由

```
/license/list  （弹窗不改变路由）
```

## 弹窗规格

### 弹窗 1: Send License

| 属性 | 值 |
|------|-----|
| 弹窗标题 | Send License |
| 尺寸 | 640px x auto |
| 关闭方式 | X 按钮 / Cancel 按钮 / ESC 键 |
| 遮罩层 | 半透明黑色遮罩，点击不关闭 |

| 字段名称 | 组件类型 | 必填 | 校验规则 | 说明 |
|---------|---------|------|---------|------|
| 已选设备列表 | TagList (只读) | 是 | 至少 1 个设备 | 从列表页带入已选设备，支持单个移除 |
| 添加更多设备 | Link Button | -- | -- | 点击打开 Batch Input 弹窗追加设备 |
| License 文件 | FileUpload (拖拽) | 是 | .lic 格式，<=10MB | 支持拖拽或点击上传，单文件 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗，不执行操作 |
| Send | Primary | 校验通过后开始发送流程，弹窗切换为进度面板 |

### 弹窗 2: Batch Input

| 属性 | 值 |
|------|-----|
| 弹窗标题 | Batch Input |
| 尺寸 | 520px x auto |
| 关闭方式 | X 按钮 / Cancel 按钮 / ESC 键 |

| 字段名称 | 组件类型 | 必填 | 校验规则 | 说明 |
|---------|---------|------|---------|------|
| Serial Number | Textarea | 是 | 非空，每项符合 SN 格式 | 多行文本框，高度 200px，支持分号/空格/换行分隔 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default (灰色) | 关闭弹窗 |
| OK | Primary (主色) | 解析输入内容，将有效 SN 添加到设备列表选中状态 |

**解析规则:**
- 分隔符: 分号(;)、空格、换行符
- 自动去重
- 无效 SN 格式弹出警告提示
- 底部实时显示 "已识别: N 个设备"

### 弹窗 3: 删除确认

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 确认删除 |
| 尺寸 | 420px x auto |
| 图标 | ⚠️ 警告图标 |
| 内容 | "确定删除已选的 N 个 License 文件？此操作不可��销。" |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗 |
| Delete | Danger (红色) | 执行删除，完成后刷新列表 |

### 弹窗 4: 发送进度

| 属性 | 值 |
|------|-----|
| 弹窗标题 | Send License - 进度 |
| 尺寸 | 560px x auto |
| 关闭方式 | 仅在完成或失败后可关闭 |
| 遮罩层 | 半透明，发送中不可点击关闭 |

**进度展示:**
- 顶部总进度条: 百分比 + (已完成/总数)
- 设备明细列表: 每行显示 SN + 状态图标 + 进度
- 状态图标: ✅ Success (绿色) / ❌ Failure (红色) / ⏳ Sending (蓝色动画) / ⏸ Pending (灰色)

| 按钮 | 类型 | 条件 | 行为 |
|------|------|------|------|
| Close | Default | 全部完成后可见 | 关闭弹窗，刷新列表和日志 |
| Retry | Primary | 存在失败项时可见 | 仅重试失败的设备 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 文件上传中 | 上传区域显示进度条，Send 按钮 disabled |
| 文件格式错误 | 上传区域显示红色错误提示 "仅支持 .lic 格式文件" |
| 文件超大 | 上传区域显示红色错误提示 "文件大小不能超过 10MB" |
| SN 解析无效项 | Batch Input 弹窗显示 Warning: "以下 SN 格式无效: XXX" |
| 发送中网络异常 | 对应设备行标记为 Failure，允许 Retry |
| 全部发送成功 | 弹出 Success 通知，自动刷新列表和日志面板 |

# 固件上传与版本管理 Firmware Upload & Version Management

> 模块路径：`/software/firmware`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 软件版本管理三 Tab 页

---

## 1. 页面概述

固件上传与版本管理页面统一管理所有软件版本文件，提供版本的上传、下载、编辑和升级任务管理。采用三 Tab 布局：设备版本（只读同步）、软件版本管理（版本库 CRUD）、升级任务（任务跟踪）。

---

## 6. 上传版本文件对话框

> 模态对话框，宽度 520px

```
┌─────────────────────────────────────┐
│ 上传版本文件                          │
├─────────────────────────────────────┤
│                                     │
│ 版本信息：                            │
│ v3.2.1 — eNodeB — Baicells — LTE   │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │                                 │ │
│ │   📁 点击或拖拽文件到此区域上传    │ │
│ │                                 │ │
│ │   支持格式：.bin .img .tar.gz    │ │
│ │   最大文件：2 GB                 │ │
│ │                                 │ │
│ └─────────────────────────────────┘ │
│                                     │
│ firmware_v3.2.1.bin                  │
│ ████████████████░░░░ 78%  35.2 MB   │
│                                     │
│          [取消]    [开始上传]         │
└─────────────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 拖拽上传 | 支持 |
| 文件格式 | `.bin` `.img` `.tar.gz` `.zip` |
| 最大大小 | 2 GB |
| 进度展示 | 进度条 + 百分比 + 已上传大小 |
| 断点续传 | 支持（大文件场景） |
| MD5 校验 | 上传完成后自动校验 |

| 操作 | 所需权限 |
|------|---------|
| 查看设备版本 | `software:device-version:view` |
| 同步设备版本 | `software:device-version:sync` |
| 管理软件版本 | `software:firmware:manage` |
| 上传固件文件 | `software:firmware:upload` |
| 下载固件文件 | `software:firmware:download` |
| 管理升级任务 | `software:upgrade-task:manage` |

# 升级软件计划 Software Upgrade Plan

> 模块路径：`/software/upgrade-plan`
> 布局模板：列表页 + 全页表单 — 参考 `03-layouts/02-list-page.md` + `03-layouts/12-form-page.md`
> 数据来源：Comba UMS 升级软件计划

---

## 1. 页面概述

管理软件升级计划的创建、编辑、调度和执行。计划列表展示所有升级计划及其调度状态，新建/编辑进入全页表单，包含三个折叠分区：任务信息、升级信息、网元选择。

---

## 4. 表单字段详情

### 4.1 任务信息

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 计划名称 | Input | ✅ | 2-60 字符 |
| 启用 | Switch | — | 默认开启 |
| 触发类型 | Radio | ✅ | 立即/定时/周期 |
| 执行模式 | Select | 定时/周期时必填 | 指定时间/每天/每周/每月 |
| 执行时间 | DatePicker + TimePicker | 定时时必填 | |
| 周期配置 | Schedule Picker | 周期时必填 | 参考 `02-components/05-data-entry/schedule-picker.md` |
| 批量完成超时 | InputNumber | — | 默认 120 分钟 |
| 备注 | TextArea | — | 最多 500 字 |

### 4.2 升级信息

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 设备类别 | Select | ✅ | 联动网络制式 |
| 网络制式 | Select | ✅ | |
| 升级目标 | Radio | ✅ | 主程序/BootLoader/FPGA |
| 固件名称 | Input + 选择按钮 | ✅ | 从固件库选择 |
| 激活模式 | Radio | ✅ | 自动激活/手动激活 |
| 版本检查 | Switch | — | 默认开启 |
| 成功条件 | Radio + InputNumber | — | 全部成功/比例达标 |
| 超时时间 | InputNumber | — | 默认 30 分钟 |

### 4.3 网元选择

| Tab | 说明 |
|-----|------|
| 按网元 | 使用导入网元对话框（6 维度树），逐台选择 |
| 按分类 | 按设备类别+制式批量匹配网元 |
| 按模板 | 选择预定义模板，自动匹配网元集合 |

# 系统首页仪表盘 System Dashboard

> 模块路径：`/system/dashboard`
> 布局模板：Dashboard 卡片栅格 — 参考 `03-layouts/07-dashboard-page.md`
> 数据来源：Comba UMS 首页六面板图表布局

---

## 1. 页面概述

系统管理模块的首页仪表盘，以六面板网格布局展示系统运行概况。包括网元数量统计、活跃告警分布、设备故障情况、7 天告警趋势、系统健康度和历史告警统计。左侧可选配设备分类侧栏过滤。

## 3. 告警徽章栏

页面顶部横向排列 4 级告警计数徽章：

| 等级 | 颜色 | 图标 | 交互 |
|------|------|------|------|
| 紧急 | `#F5222D` 红色 | 实心圆 | 点击跳转当前告警（筛选紧急） |
| 主要 | `#FA8C16` 橙色 | 实心圆 | 点击跳转当前告警（筛选主要） |
| 次要 | `#FAAD14` 黄色 | 实心圆 | 点击跳转当前告警（筛选次要） |
| 警告 | `#1890FF` 蓝色 | 实心圆 | 点击跳转当前告警（筛选警告） |

- 数字实时更新（WebSocket 推送）
- 紧急告警 > 0 时徽章脉冲动画

## 4. 六面板详细设计

### 4.1 面板 ① — 网元数量统计

| 属性 | 值 |
|------|-----|
| 图表类型 | 分组柱状图（ECharts `bar`） |
| X 轴 | 网元类型（eNodeB、gNodeB、EPC、网关等） |
| Y 轴 | 数量 |
| 分组 | 在线（`#52C41A`）/ 离线（`#F5222D`） |
| 交互 | 悬浮显示 Tooltip，点击柱体跳转设备列表 |
| 刷新 | 左上角手动刷新按钮 |

### 4.2 面板 ② — 活跃告警分布

| 属性 | 值 |
|------|-----|
| 图表类型 | 饼图 / 环形图（ECharts `pie`） |
| 数据 | 按告警等级分组统计 |
| 颜色 | 紧急 `#F5222D` / 主要 `#FA8C16` / 次要 `#FAAD14` / 警告 `#1890FF` |
| 中心文字 | 告警总数 |
| 交互 | 点击扇区跳转告警列表（对应等级筛选） |
| 图例 | 底部水平排列 |

### 4.3 面板 ③ — 设备故障统计

| 属性 | 值 |
|------|-----|
| 图表类型 | 柱状图（ECharts `bar`） |
| 右上角 | 下拉筛选器：按类型 / 按厂商 / 按区域 |
| X 轴 | 故障分类（硬件/软件/通信/环境/其他） |
| Y 轴 | 故障数量 |
| 颜色 | 多色柱体，使用图表调色板 |
| 交互 | 下拉切换维度时图表动画过渡 |

### 4.4 面板 ④ — 7 天告警趋势

| 属性 | 值 |
|------|-----|
| 图表类型 | 多系列折线图（ECharts `line`） |
| X 轴 | 近 7 天日期 |
| Y 轴 | 告警数量 |
| 系列 | 4 条线：紧急/主要/次要/警告，使用对应颜色 |
| 样式 | 平滑曲线 `smooth: true`，区域填充 `areaStyle` 半透明 |
| 图例 | 右上角可点击切换显隐 |
| 交互 | 悬浮显示 Tooltip，点击数据点跳转对应日期告警 |

### 4.5 面板 ⑤ — 系统健康度

| 属性 | 值 |
|------|-----|
| 图表类型 | 仪表盘（ECharts `gauge`）× 3 |
| 指标 | CPU 使用率 / 内存使用率 / 磁盘使用率 |
| 颜色分段 | 0-60% 绿色 / 60-80% 黄色 / 80-100% 红色 |
| 中心文字 | 百分比数值 |
| 布局 | 三个仪表盘水平排列 |
| 刷新 | 每 30 秒自动刷新 |

### 4.6 面板 ⑥ — 历史告警统计

| 属性 | 值 |
|------|-----|
| 图表类型 | 堆叠柱状图（ECharts `bar` stack） |
| X 轴 | 近 30 天（按周分组） |
| Y 轴 | 告警数量 |
| 堆叠 | 按等级堆叠，使用告警 4 级颜色 |
| 交互 | 悬浮显示详细 Tooltip |

## 5. 左侧设备分类筛选栏

| 属性 | 值 |
|------|-----|
| 宽度 | 240px，可折叠至 0 |
| 结构 | 树形复选框 |
| 层级 | 设备大类 → 设备型号 |
| 交互 | 勾选/取消后图表联动刷新 |
| 默认 | 全部选中 |
| 折叠 | 点击边缘收起按钮隐藏 |

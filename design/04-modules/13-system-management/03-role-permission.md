# 角色权限管理 Role & Permission Management

> 模块路径：`/system/roles`
> 布局模板：列表页 + 树形权限面板 — 参考 `03-layouts/02-list-page.md`
> 设计推断：基于 Comba UMS 用户菜单功能扩展

---

## 1. 页面概述

角色权限管理页面提供 RBAC（基于角色的访问控制）配置。左侧角色列表，右侧为选中角色的权限配置树。支持角色的增删改查以及细粒度的功能权限和数据权限分配。

## 3. 角色列表（左侧）

### 3.1 角色卡片

每个角色显示为卡片式列表项：

| 元素 | 说明 |
|------|------|
| 角色名称 | 主标题，如"运维工程师" |
| 用户数量 | 副标题 Badge `(N)` |
| 内置标记 | 系统内置角色显示 ☆ 标签，不可删除 |
| 选中态 | 左侧蓝色边框 `#1677FF` 3px |

### 3.2 角色操作

| 操作 | 触发方式 | 说明 |
|------|---------|------|
| 新增 | 列表顶部按钮 | 打开新增对话框 |
| 编辑 | 右键菜单 / Hover 编辑图标 | 修改角色基本信息 |
| 复制 | 右键菜单 | 基于已有角色复制权限 |
| 删除 | 右键菜单 | 需确认，有用户关联时不可删除 |

---

## 4. 新增/编辑角色对话框

> 模态对话框，宽度 480px

| 字段 | 组件 | 必填 | 规则 |
|------|------|------|------|
| 角色名称 | Input | ✅ | 2-30 字符，唯一 |
| 角色标识 | Input | ✅ | 英文+下划线，如 `ops_engineer` |
| 描述 | TextArea | — | 最多 200 字 |
| 状态 | Switch | — | 默认启用 |
| 排序号 | InputNumber | — | 0-999 |

## 5. 功能权限树（右侧 Tab 1）

### 5.1 权限树结构

三级树形结构：模块 → 页面 → 操作

```
☑ 设备管理                    ← 一级：模块
├─ ☑ 设备列表                 ← 二级：页面
│  ├─ ☑ 查看 (view)          ← 三级：操作
│  ├─ ☑ 新增 (create)
│  ├─ ☐ 编辑 (edit)
│  ├─ ☐ 删除 (delete)
│  └─ ☑ 导出 (export)
├─ ☑ 设备详情
│  ├─ ☑ 查看
│  └─ ☐ 编辑配置
└─ ...
```

### 5.2 交互规则

| 行为 | 说明 |
|------|------|
| 勾选父节点 | 自动勾选所有子节点 |
| 取消父节点 | 自动取消所有子节点 |
| 部分子节点勾选 | 父节点显示半选态（indeterminate） |
| 搜索 | 权限树顶部搜索框，实时过滤匹配节点 |
| 全选/反选 | 工具栏快捷操作 |

---

## 6. 数据权限（右侧 Tab 2）

控制用户可访问的数据范围：

| 维度 | 组件 | 说明 |
|------|------|------|
| 数据范围 | Radio Group | 全部数据 / 本部门 / 本部门及以下 / 自定义 |
| 区域范围 | Tree 多选 | 按省/市/区选择可管辖区域 |
| 网元类型 | Checkbox Group | 勾选可操作的网元类型 |
| 设备类型 | Checkbox Group | 勾选可操作的设备类型 |

---

## 7. 预设角色

| 角色 | 说明 | 典型权限 |
|------|------|---------|
| 超级管理员 | 系统内置，不可修改 | 全部权限 |
| 运维工程师 | 日常运维 | 设备管理、告警管理、配置管理、备份恢复（全操作） |
| 监控值班员 | 值班监控 | Dashboard、告警查看/确认、拓扑查看（只读为主） |
| 只读审计员 | 审计查看 | 所有模块查看权限，无编辑/删除权限 |

---

## 8. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看角色列表 | `system:role:view` |
| 新增角色 | `system:role:create` |
| 编辑角色 | `system:role:edit` |
| 删除角色 | `system:role:delete` |
| 配置功能权限 | `system:role:assign-permission` |
| 配置数据权限 | `system:role:assign-data` |

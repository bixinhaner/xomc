# 地图分布组件 (Map Widget)

## 页面用途

Dashboard Row 3 右侧迷你地图组件，以地图热力点形式展示设备在各区域的分布情况。提供快速的地理视角概览，点击可导航至完整的拓扑监控模块。

## 布局模板

内嵌于 Dashboard 页面 Row 3 第三列，`Col span={8}`。

## 地图规格

### 基本配置

| 属性           | 值                                  |
|---------------|--------------------------------------|
| 地图类型       | 中国省级行政区划地图 (简化版)            |
| 图表库         | ECharts geo 组件 / AntV L7           |
| 地图区域高度    | 200px                               |
| 底图颜色       | #F5F5F5 (省份填充)                    |
| 边界线颜色     | #D9D9D9                              |
| 省份 Hover 色  | #E6F7FF                              |

### 散点标记

设备分布用大小和颜色不同的散点表示。

| 设备数量     | 散点尺寸   | 散点颜色   | 形状   |
|------------|----------|----------|--------|
| 1-10 台     | 4px      | #91D5FF  | 圆点   |
| 11-50 台    | 8px      | #1890FF  | 圆点   |
| 50+ 台      | 12px     | #0050B3  | 圆点   |
| 有紧急告警   | 原尺寸    | #FF4D4F  | 圆点 + 脉冲动画 |

### 散点脉冲动画

有紧急告警的区域散点带有脉冲扩散动画：

```css
@keyframes pulse {
  0% { box-shadow: 0 0 0 0 rgba(255, 77, 79, 0.6); }
  70% { box-shadow: 0 0 0 10px rgba(255, 77, 79, 0); }
  100% { box-shadow: 0 0 0 0 rgba(255, 77, 79, 0); }
}
/* animation: pulse 2s infinite; */
```

| 属性         | 值                                       |

| 区域名链接   | color: #1890FF, 可点击跳转                 |

## 数据接口

```typescript
GET /api/dashboard/device-distribution?deviceType={deviceType}

interface DeviceDistribution {
  regions: RegionData[];
  topRegions: TopRegion[];
}

interface RegionData {
  regionCode: string;      // 省份代码
  regionName: string;      // 省份名称
  longitude: number;       // 经度
  latitude: number;        // 纬度
  deviceCount: number;     // 设备总数
  onlineCount: number;     // 在线数
  offlineCount: number;    // 离线数
  criticalAlarmCount: number; // 紧急告警数
}

interface TopRegion {
  regionName: string;
  deviceCount: number;
}
```

## 交互行为

| 操作              | 行为                                     |
|------------------|------------------------------------------|
| 点击散点          | 跳转到设备管理 > 设备列表, 筛选对应区域       |
| 点击省份区域      | 同上                                      |
| 点击 "查看完整地图" | 跳转到基站监控 > 拓扑地图                  |
| 鼠标滚轮          | 不响应 (迷你地图不支持缩放)                  |
| 地图拖拽          | 不响应 (迷你地图固定视角)                    |

## 状态处理

| 状态           | 处理方式                                  |
|---------------|------------------------------------------|
| 加载中         | 地图区域显示 Skeleton 矩形骨架              |
| 数据为空       | 显示灰色底图 + "暂无设备分布数据"            |
| 加载失败       | 显示 "地图加载失败" + 重试按钮              |
| 地图资源加载失败 | 降级为文字列表展示 TOP10 区域设备数          |

## 跨模块导航

| 来源             | 目标                    | 触发方式                |
|-----------------|------------------------|-----------------------|
| 查看完整地图链接  | 基站监控 > 拓扑地图      | 点击链接               |
| 散点/省份点击    | 设备管理 > 设备列表      | 点击, 携带 region 参数  |
| 热点区域名称链接  | 设备管理 > 设备列表      | 点击, 携带 region 参数  |

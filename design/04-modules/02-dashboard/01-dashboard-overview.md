# Dashboard 总览 (Dashboard Overview)

## 页面用途

系统首页 Dashboard，整合三套原有系统的精华设计，提供全局运维态势感知。包括关键 KPI 指标卡片、告警摘要、设备状态图表、地图分布等组件，帮助运维人员快速掌握系统整体运行状况。

## 布局模板

使用 dashboard-page 布局。基于网格系统 (Grid) 的响应式卡片布局。

## 导航路径

Dashboard

## 路由

`/dashboard`

## 网格布局规格

| 区域             | Grid 配置                    | 高度        |
|-----------------|------------------------------|------------|
| Row 1 KPI 卡片   | 4 列, `Col span={6}` 等分     | 120px      |
| Row 2 告警摘要    | 1 列, `Col span={24}` 通栏   | 80px       |
| Row 3 图表上排    | 3 列, `Col span={8}` 等分     | 320px      |
| Row 4 图表下排    | 3 列, `Col span={8}` 等分     | 320px      |

**间距：** 行间距 16px, 列间距 16px。

**页面内边距：** padding: 16px 24px。

## 数据刷新策略

| 组件           | 刷新方式                    | 刷新间隔       |
|---------------|----------------------------|---------------|
| KPI 卡片       | REST API 轮询              | 60s           |
| 告警摘要        | WebSocket 推送             | 实时           |
| 设备状态图表    | REST API 轮询              | 120s          |
| 告警趋势图      | REST API 轮询              | 300s          |
| 地图组件        | REST API 轮询              | 300s          |
| TOP10 告警设备  | REST API 轮询              | 120s          |

**手动刷新：** 页面右上角提供 "刷新" 按钮，点击后所有组件同时重新加载。

## 状态处理

| 状态         | 处理方式                                        |
|-------------|------------------------------------------------|
| 首次加载     | 各组件独立 Skeleton 加载态, 不阻塞彼此             |
| 部分加载失败  | 失败组件显示 "加载失败, 点击重试", 其他组件正常      |
| 全部加载失败  | 显示全局错误提示 + 刷新按钮                        |
| 无数据       | 各组件显示对应空状态 (Empty 组件)                   |
| 设备类型切换  | 所有组件显示加载态 → 重新请求数据 → 渲染             |

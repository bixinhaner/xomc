# 性能下载任务管理 (Performance Download Task Management)

## 页面用途

管理性能数据的下载任务，分为资源下载和报表下载两个子标签页。展示下载任务的执行状态、进度和结果，支持批量删除和任务管理。

## 布局模板

**Tab + List Page Layout（标签页 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > 性能管理 > 下载任务
```

## 路由

```
/performance/tasks/resource    （资源下载 Tab）
/performance/tasks/report      （报表下载 Tab）
```

## 筛选栏配置

### 资源下载 Tab

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 报表名称 | TextInput | 空 | 报表名称搜索 |
| 任务状态 | Select | 全部 | 待执行/执行中/已完成/失败 |

### 报表下载 Tab

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 任务类型 | Select | 全部 | 任务类型筛选 |
| 任务状态 | Select | 全部 | 待执行/执行中/已完成/失败 |

## 工具栏操作

| 按钮名称 | 类型 | 条件 | 行为 |
|---------|------|------|------|
| 批量删除 | Danger | 选中 >= 1 项 | 二次确认后批量删除 |
| 刷新 | Icon | 始终可见 | 刷新任务列表 |

## 弹窗规格

### 删除确认弹窗

| 内容 | "确定删除已选的 N 个下载任务？关联的文件将一并删除。" |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 任务执行中 | 状态列显示蓝色 ⏳ + 旋转动画 |
| 任务失败 | 状态列显示红色 ❌，结果详情显示失败原因 |
| 文件已过期 | 下载按钮 disabled，Tooltip 提示 "文件已过期" |

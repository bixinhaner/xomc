# KPI 基站报表 (KPI Station Report)

## 页面用途

按基站维度查看性能 KPI 报表，与标准报表共享相同的页面结构和交互模式，但报表分类聚焦于基站级别的关键性能指标，包括接入性、移动性、保持性、资源类、时延类和 PDCP 层流量等维度。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）** — 与 KPI 标准报表完全一致

## 导航路径

```
OMC 统一网管 > 性能管理 > 性能指标查询 > KPI 基站报表
```

## 路由

```
/performance/kpi/station
```

## 筛选栏配置

与 `01-kpi-standard-report.md` 完全一致:
- 类型 (网元/小区/业务区/厂商/站点/全网/设备类别)
- 粒度 (分钟/小时/天/周/月)
- 查询条件 + 匹配方式 + 过滤值
- 时间范围 (快捷 + 自定义)

## 数据表规格

与标准报表相同的动态列结构，KPI 列根据报表分类动态生成。

### 报表分类

| 分类 | 说明 |
|------|------|
| 接入性 | RRC 连接建立、S1 信令连接等接入相关 KPI |
| 移动性 | 切换成功率、切换时延等移动性 KPI |
| 保持性 | 掉话率、会话保持等 KPI |
| 资源类 | PRB 利用率、CCE 利用率等资源 KPI |
| 时延类 | 用户面时延、控制面时延等 KPI |
| PDCP层流量 | 上下行 PDCP 层数据流量 KPI |

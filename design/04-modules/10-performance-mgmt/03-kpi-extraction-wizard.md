# KPI 指标提取向导 (KPI Extraction Wizard)

## 页面用途

以 4 步向导流程引导用户自定义提取性能指标数据。步骤包括: 计数器/指标选择(模板或自定义) > 网元选择(按网元/分类/模板) > 时间设置(模板或自定义) > 查询结果(表格+图表)。支持将配置保存为模板复用。

## 布局模板

**Wizard Page Layout（向导页面布局）**

```
+------------------------------------------------------------------+
| 顶部导航栏                                                         |
+------------------------------------------------------------------+
| 左侧步骤导航 (15%)        | 右侧当前步骤内容 (85%)                 |
| ① 计数器/指标              |                                       |
| ② 网元                    | 当前步骤的表单/选择内容                  |
| ③ 时间                    |                                       |
| ④ 查询结果                |              [上一步] [下一步]          |
+------------------------------------------------------------------+
```

## 导航路径

```
OMC 统一网管 > 性能管理 > 性能指标提取 > 历史指标查询
```


## 筛选栏配置

### Step 1 筛选

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 模式选择 | RadioGroup | 是 | 从模板选择 / 自定义 |
| 报表类型 | Select | 是(*) (自定义模式) | 报表类型选择 |
| 测量对象类型 | Select | 是(*) (自定义模式) | 测量对象选择 |
| 测量族 | Select | 否 | 测量族选择 |
| 计数器/指标 | Transfer | 是(*) (自定义模式) | 穿梭框，最大 500 项 |

### Step 2: 网元选择三种模式

| 模式 | 说明 |
|------|------|
| 按网元 | 表格选择: 已选/未选 Tab + 添加/移除/清空/导入 |
| 按分类 | 按区域/类型/厂家/子网/站点/群组/制式/工程状态(8维度) + 搜索+全选/递归选择/反选 |
| 按模板 | 预置模板/用户自定义模板/共享模板 树形选择 + 网元总数 |

### Step 3: 时间设置

| 字段名称 | 组件类型 | 说明 |
|---------|---------|------|
| 模式选择 | RadioGroup | 从模板选择 / 自定义 |
| 时间范围 | DateRangePicker | 自定义模式下的时间范围 |
| 另存为模板 | Button | 保存当前时间配置为模板 |

## 弹窗规格

无独立弹窗（向导式页面内操作）

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 步骤未完成 | 下一步按钮 disabled，提示必填项 |
| 计数器超限 | 穿梭框右侧标注 "500/500"，禁止继续添加 |
| 未查询 | Step 4 图表区橙色横幅 "请先查询表格数据!" |
| 当前步骤高亮 | 左侧步骤导航中当前步骤蓝色高亮 + ● 标记 |

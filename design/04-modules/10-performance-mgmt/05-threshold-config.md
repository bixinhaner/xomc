# 性能门限配置 (Performance Threshold Configuration)

## 页面用途

管理性能指标的门限阈值配置。当指标超过门限时触发告警。支持按网络制式、范围类型配置不同的门限条件，提供门限的启用/禁用开关控制。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > 性能管理 > 性能门限
```

## 路由

```
/performance/threshold
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 门限指标 | TextInput | 用户输入 | 空 | 指标名称搜索 |
| 网络制式 | Select | 字典: NR/LTE | 全部 | 制式筛选 |
| 范围类型 | Select | API: 范围类型列表 | 全部 | 门限适用范围筛选 |
| 门限状态 | Select | 字典: ON/OFF | 全部 | 启用状态筛选 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 排序 | 渲染规则 |
|------|----------|------|------|---------|
| 门限指标 | thresholdIndicator | 180px | -- | 文本 |
| 网络制式 | standard | 80px | -- | NR / LTE |
| 范围类型 | rangeType | 100px | -- | 全网/区域/站点 等 |
| 范围选择 | rangeSelection | 120px | -- | 具体范围名称 |
| 门限条件 | thresholdCondition | 160px | -- | 条件表达式文本 |
| 门限状态 | thresholdStatus | 80px | -- | Toggle: 🟢ON / 🔴OFF |
| 修改人 | modifier | 100px | -- | 文本 |
| 修改时间 | modifyTime | 160px | -- | YYYY-MM-DD HH:mm |
| 操作 | _actions | 120px | -- | [编辑] [删除] |

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 新增 | Primary | 打开新增门限弹窗 |

## 弹窗规格

### 新增/编辑性能门限弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 新增门限 / 编辑门限 |
| 尺寸 | 520px x auto |

| 字段名称 | 组件类型 | 必填 | 默认值 | 说明 |
|---------|---------|------|-------|------|
| 网络制式 | Select | 是(*) | NR | NR / LTE |
| 门限指标 | Select | 是(*) | -- | 根据网络制式动态加载指标列表 |
| 门限状态 | Toggle Switch | 是(*) | OFF | 启用/禁用门限 |
| 范围类型 | Select | 是(*) | -- | "请选择范围类型" |
| 门限条件 | TextInput (带提示) | 是(*) | -- | 门限阈值条件表达式，带格式提示图标 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭 |
| Confirm | Primary | 保存门限配置 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 无门限数据 | 表格显示 "暂无门限配置" |
| 门限触发 | 关联到告警管理模块，自动生成性能告警 |
| 状态Toggle切换 | 行内直接切换，无需打开弹窗 |

| 触发元素 | 目标页面 | 传递参数 |
|---------|---------|---------|

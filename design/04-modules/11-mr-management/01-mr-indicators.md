# MR 基础指标 (MR Basic Indicators)

## 页面用途

管理 MR (Measurement Report) 基础指标的定义。左侧提供 NR/LTE 分类树（按 MRO/MRE/MRS 测量类型组织），右侧为指标列表，支持新增、编辑、删除、导入和映射查看。指标是 MR 数据分析的基础元数据。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 指标 > 基础指标
```

## 路由

```
/mr/indicators/basic
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 中文名称 | TextInput | 用户输入 | 空 | 中文名称模糊搜索 |
| 英文名称 | TextInput | 用户输入 | 空 | 英文名称模糊搜索 |
| 统计方式 | Select | API: 统计方式列表 | 全部 | 如平均、求和等 |
| 统计粒度 | Select | API: 粒度列表 | 全部 | 如 Beam、UE 等 |
| 上报方式 | Select | API: 上报方式列表 | 全部 | 上报方式筛选 |

## 工具栏操作

| 按钮名称 | 类型 | 条件 | 行为 |
|---------|------|------|------|
| 批量删除 | Danger | 选中 >= 1 项 | 批量删除已选指标 |

## 弹窗规格

### 新增/编辑基础指标弹窗

| 字段名称 | 组件类型 | 必填 | 字符限制 | 说明 |
|---------|---------|------|---------|------|
| 编号 | TextInput | 否 | 0/64 | 指标编号 |
| 中文名称 | TextInput (带提示) | 是(*) | 0/64 | 指标中文名称 |
| 英文名称 | TextInput (带提示) | 是(*) | 0/64 | 指标英文名称 |
| 网络制式 | Select | 是(*) | -- | NR / LTE |
| 分类名称 | Select | 是(*) | -- | MRO / MRE / MRS |
| 统计方式 | Select | 是(*) | -- | 统计方式 |
| 统计粒度 | Select | 是(*) | -- | 统计粒度 |
| 单位 | Select | 是(*) | -- | 指标单位 |
| 描述 | TextInput | 否 | 0/255 | 描述信息 |

### 导入基础指标弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 网络制式 | Select | 是(*) | NR / LTE |

| 导出携带数据 | Checkbox | 否 | "导出的模板携带现有数据" |

| 属性 | 值 |
|------|-----|

| 内部表格 | 设备关联指标名称 / 所属厂商 / 设备型号 / 网络制式 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 树节点切换 | 右侧表格按选中分类过滤 |
| 映射为空 | 映射弹窗显示 "暂无设备关联" |
| 删除确认 | "确定删除指标 '{name}'？" |

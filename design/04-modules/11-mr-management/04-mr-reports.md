# MR 报表查询 (MR Report Query)

## 页面用途

查询和浏览 MR 测量报表数据。左侧提供报表分类树（5G-MRO/5G-MRE/4G-MRO/4G-MRE），右侧为多条件筛选区和报表数据表格。支持按时间、地域、设备等多维度筛选，提供下载和全屏功能。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 报表
```

## 路由

```
/mr/reports
```

## 筛选栏配置

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 时间粒度 | Select | 日表 | 日表/时表 |
| 采集开始时间 | DateTimePicker | 7天前 | 采集起始时间 |
| 采集结束时间 | DateTimePicker | 当前 | 采集结束时间 |
| 测量小时 | Select | 全部 | 按小时粒度 |
| 网元粒度 | Select | 小区统计 | 统计粒度 |
| 事件类型 | Select | 全部 | 仅 MRE 报表有此字段 |
| 地市 | Select | 全部 | 地市筛选 |
| 区县 | Select | 全部 | 区县筛选(联动地市) |
| 产品分类 | Select | 全部 | 产品分类 |
| 设备型号 | Select | 全部 | 设备型号 |
| 设备名称 | Select | 全部 | 设备名称 |
| 设备SN号 | Select | 全部 | SN号 |

## 数据表规格

表格列根据选择的报表类型动态变化。以 5G-MRE 主服小区报表为例:

| 列名 | 字段 Key | 宽度 | 渲染规则 |
|------|----------|------|---------|
| 所属地市 | city | 80px | 文本 |
| 所属区县 | district | 80px | 文本 |
| 产品分类名称 | productCategory | 100px | 文本 |
| 设备型号 | model | 100px | 文本 |
| 设备名称 | deviceName | 140px | 文本 |
| 设备SN号 | serialNumber | 160px | 文本 |
| 基站ID | enbId | 80px | 整数 |
| 站内小区ID | cellId | 80px | 整数 |
| NCI | nci | 100px | 文本 |
| 小区名称 | cellName | 120px | 文本 |
| NR服务小区PCI | servingPci | 80px | 整数 |
| NR服务小区Arfcn | servingArfcn | 100px | 整数 |
| 事件类型 | eventType | 80px | 文本(仅MRE) |
| 测量日期 | measureDate | 100px | 日期 |
| MR样本总数 | mrSampleTotal | 100px | 整数 |
| RSRP覆盖率 | rsrpCoverage | 100px | 百分比 |
| (更多KPI列) | kpi_xxx | 100px | 动态生成 |

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 查询 | Primary | 执行报表查询 |
| 重置 | Default | 重置筛选条件 |
| 查询模板 | Dropdown | 保存/加载查询模板 |
| 下载 | Default | 下载报表数据 |
| 刷新 | Icon | 刷新数据 |
| 全屏 | Icon | 全屏展示表格 |
| 前往下载列表 | Link | 跳转下载任务页面 |

## 弹窗规格

无独立弹窗

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未选择报表 | 右侧显示 "请选择你需要查看的报表" |
| 未查询 | 表格为空 |
| 查询中 | 加载动画 |
| 无数据 | "查询无结果" |
| 4G 与 5G 区别 | 4G 报表使用 ECI/LTE相关字段，5G 使用 NCI/NR相关字段 |

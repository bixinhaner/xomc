# MR 设备指标关联 (MR Device Indicator Mapping)

## 页面用途

管理 MR 指标与具体设备型号的映射关系。左侧为设备厂商/型号树（按厂商和型号分层展示），右侧为指标关联列表，支持新增、编辑、删除和导入。

## 布局模板

**Tree-List Page Layout（树形 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 指标 > 设备指标关联
```

## 路由

```
/mr/indicators/device-mapping
```

## 筛选栏配置

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 设备关联指标名称 | TextInput | 空 | 设备指标名搜索 |
| 基础指标英文名字 | TextInput | 空 | 英文名搜索 |
| 基础指标中文名称 | TextInput | 空 | 中文名搜索 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 渲染规则 |

| (复选框) | _selection | 48px | Checkbox |
| 设备关联指标名称 | deviceIndicatorName | 220px | 文本 |
| 所属厂商 | manufacturer | 80px | 文本 |
| 设备型号 | model | 100px | 文本 |

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 批量删除 | Danger | 批量删除 |
| 导出 | Dropdown | 导出已选/全部 |
| 导入 | Default | 打开导入弹窗 |
| 新增 | Primary | 打开新增弹窗 |

## 弹窗规格

### 新增/编辑设备指标关联弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 设备关联指标名称 | TextInput (0/64, 带提示) | 是(*) | 设备侧指标名称 |
| 所属厂商 | Select | 是(*) | 设备厂商 |
| 设备型号 | Select | 是(*) | 设备型号(联动厂商) |
| 网络制式 | Select | 是(*) | NR / LTE |
| 适用测量类型 | Select | 是(*) | MRO / MRE / MRS |
| 基础指标名称 | Select | 是(*) | 平台基础指标选择 |
| 描述 | TextInput (0/255) | 否 | 描述信息 |

### 导入设备指标关联弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 所属厂商 | Select | 是(*) | 设备厂商 |
| 设备型号 | Select | 是(*) | 设备型号 |
| 指标文件 | FileDragUpload | 是(*) | 上传关联模板文件 |
| 模板下载 | Link | -- | "设备MR指标关联模板" |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 树节点切换 | 右侧表格按选中设备筛选 |
| 无关联数据 | 显示 "该设备暂无指标关联" |
| 厂商选择变更 | 型号下拉联动刷新 |

# MR 任务管理 (MR Task Management)

## 页面用途

管理 MR 测量任务的创建、查看、同步、停止和删除。任务列表展示所有 MR 任务及其调度状态，创建任务时需配置任务信息、MR 测量参数（含同步策略、服务器地址、采集周期等）和目标网元选择。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 任务管理
```

## 路由

```
/mr/tasks
```

## 筛选栏配置

| 字段名称 | 组件类型 | 说明 |
|---------|---------|------|
| Id | TextInput (列头内联) | 按任务 ID 筛选 |
| 任务名称 | TextInput (列头内联) | 按任务名称筛选 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 渲染规则 |
|------|----------|------|---------|
| (复选框) | _selection | 48px | Checkbox |
| Id | id | 80px | 整数 |
| 任务名称 | taskName | 140px | 文本 |
| 调度状态 | scheduleStatus | 80px | 已完成/执行中/已停止 |
| 涉及网元 | relatedNEs | 120px | "网元数量=N" |
| 计划开始时间 | planStartTime | 160px | 日期时间 |
| 更新时间 | updateTime | 160px | 日期时间 |
| 备注 | remarks | flex | 文本 |

## 工具栏操作

| 按钮名称 | 类型 | 条件 | 行为 |
|---------|------|------|------|
| 新建 | Primary | 始终可见 | 打开添加 MR 测量任务表单页 |
| 查看 | Default | 选中 1 项 | 只读查看任务详情 |
| 同步到网元 | Default | 选中 1 项 | 将任务下发同步到目标网元 |
| 停止 | Default | 选中执行中的任务 | 停止任务 |
| 删除 | Danger | 选中 >= 1 项 | 二次确认删除 |

## 弹窗规格

### 添加 MR 测量任务（整页表单）

**Section 1: 任务信息设置（可折叠）**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 任务策略名称 | TextInput | 是(*) | 任务名称 |
| 是否启动 | Toggle Switch | 是(*) | 默认开启 |
| 任务触发类型 | Select | 是(*) | 立即下发 |
| 执行方式 | Select | 是(*) | 立即执行 |
| 批次完成时间 | Select + NumberInput | 是(*) | 时间单位 + 数值 |
| 注释 | Textarea | 否 | 备注 |

**Section 2: MR测量任务信息（可折叠）**

| 字段名称 | 组件类型 | 说明 |
|---------|---------|------|
| 测量任务同步策略 | RadioGroup | 新增/覆盖(默认)/去重覆盖 |

**MR 配置子表格:**

| 列名 | 说明 |
|------|------|
| 使能开关 | 是否启用 |
| MR服务器地址 | 数据上报服务器 URL |
| MR服务器用户名 | 认证用户名 |
| MR服务器密码 | 认证密码 |
| 文件类型 | MR 文件类型 |
| OMC-R名称 | OMC-R 标识 |
| 采样周期(ms) | 采样间隔(毫秒) |
| 采集周期(min) | 采集间隔(分钟) |
| 测量开始时间 | 开始时间 |

子表格操作: [+新建] [查看] [编辑] [删除]

**Section 3: 网元选择（可折叠）**

三个 Tab: 按网元 / 按分类 / 按模板（与配置管理中的网元选择器规格一致）

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 取消返回列表 |
| Confirm | Primary | 提交创建任务 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 任务执行中 | 状态列蓝色标签 |
| 任务已完成 | 状态列绿色标签 |
| 同步进行中 | 全局通知 + 列表刷新 |
| MR 配置子表格为空 | 提示 "请至少添加一条 MR 测量配置" |

## 原系统二级菜单 vs 新系统

### 1. Performance Management (性能管理)

**原系统文件：** `pm/perfmgmt/` — 8 个文件

#### 原系统 kpi_management.jsp
**表格列：**
| 列 | 字段名 |
|----|-------|
| 指标 ID | kpiId |
| 指标名称 | kpiName |
| 测量状态 | isEnable |
| 产品类型 | product_type |

**筛选条件：** 指标名称/ID 搜索、产品类型、等级

**操作按钮：** 添加、导出、测量、取消测量

**其他页面：**
| 页面 | 功能 |
|------|------|
| `kpi_addKpi.jsp` | 定义新 KPI 指标（公式编辑） |
| `kpi_viewKpi.jsp` | 查看 KPI 定义详情 |
| `kpi_modifyKpi.jsp` | 修改 KPI 定义 |
| `kpi_addGroup.jsp` | 创建 KPI 分组 |
| `kpi_viewGroup.jsp` | 查看分组详情 |
| `kpi_modifyGroup.jsp` | 修改分组 |
| `kpi_addArithmetic.jsp` | 添加公式（衍生 KPI） |

**新系统对应：** Performance → KPI Standard + KPI Station
| 功能 | 原系统 | 新系统 | 差异 |
|------|--------|--------|------|
| KPI 列表浏览 | ✅ | ✅ KPIStandard | — |
| KPI 定义/公式管理 | ✅ (CRUD 4页) | ❌ | **缺失** |
| KPI 分组管理 | ✅ (CRUD 3页) | ❌ | **缺失** |
| KPI 启用/禁用 | ✅ 测量/取消测量 | ❌ | **缺失** |

### 2. Performance Query (性能查询)

**原系统文件：** `pm/perfquery/` — 11 个文件

#### 原系统 kpi_query_temp_add.jsp 表单字段
| 字段 | 说明 |
|------|------|
| tempName | 模板名称 |
| isPublic | 公开/私有 |
| creator | 创建人 |
| description | 描述 |
| reportPeriod | 报告周期 (15分/1小时/1天) |
| week | 周选择 |
| hour | 小时选择 |
| busyTime | 忙时选择 (6/8 小时) |
| selDeviceType | 设备选择方式 (设备组/设备) |
| device_type | 设备类型筛选 (ENB/GSM) |
| indicatorLevel | 指标级别 (device/plmn) |
| relKpi | 关联 KPI |

**其他查询��面：**
| 页面 | 功能 |
|------|------|
| `kpi_query_temp_view.jsp` | 查看模板 |
| `kpi_query_temp_modify.jsp` | 修改模板 |
| `kpi_export.jsp` | 导出 KPI 数据 |
| `kpi_chart_template.jsp` | 图表模板 |

**新系统对应：** Performance → Charts + Extraction + Report 菜单
| 功能 | 原系统 | 新系统 | 差异 |
|------|--------|--------|------|
| 查询模板管理 | ✅ (CRUD) | ❌ | **缺失** |
| KPI 数据导出 | ✅ kpi_export.jsp | ⚠️ Extraction | 需验证 |
| 图表模板 | ✅ kpi_chart_template.jsp | ✅ Charts | 基本对应 |
| 报告周期配置 | ✅ reportPeriod | ❌ | **缺失** |
| 忙时统计 | ✅ busyTime | ❌ | **缺失** |
| PLMN 级指标 | ✅ indicatorLevel | ❌ | **缺失** |

### 3. MR Management (MR 管理)

**原系统文件：** `pm/mrmgmt/` — 3 个文件

#### 原系统 mr.jsp
**表格列：** fileName, modifyTime
**筛选：** 小站编码搜索

**定制 MR 表单：**
| 字段 | 说明 |
|------|------|
| customizeMRStaticPeriod | 统计周期 |
| customizeMRType | MR 类型 (MRS/MRO/MRE) |
| customizeMRSamplePeriod | 采样周期 |
| operation_type | 操作类型 (关闭/开启) |

**操作：** 下载、清除文件、定制

**新系统对应：** MR 菜单
| 功能 | 原系统 | 新系统 | 差异 |
|------|--------|--------|------|
| MR 文件列表 | ✅ mr.jsp | ✅ MRFiles | — |
| MR 定制化 | ✅ 定制表单 | ❌ | **缺失** |
| MR 文件下载 | ✅ | ⚠️ | 需验证 |
| MR 指标 | ❌ | ✅ MRIndicators | **新增** |
| 设备映射 | ❌ | ✅ DeviceMapping | **新增** |
| 变量管理 | ❌ | ✅ Variables | **新增** |
| MR 报表 | ❌ | ✅ MRReports | **新增** |
| MR 任务 | ✅ mr_task.jsp | ✅ MRTasks | — |

## 缺失汇总

| 缺失功能 | 严重度 | 说明 |
|---------|--------|------|
| KPI 定义/公式管理 (CRUD) | 🔴 高 | 无法自定义 KPI 指标 |
| KPI 分组管理 | 🟡 中 | 无法组织 KPI |
| KPI 启用/禁用 | 🔴 高 | 无法控制测量采��� |
| 性能查询模板管理 | 🔴 高 | 无法保存和复用查询条件 |
| 报告周期/忙时配置 | 🟡 中 | 缺少时间维度灵活性 |
| PLMN 级指标 | 🟡 中 | 缺少运营商级统计 |
| MR 定制化采集 | 🟡 中 | 无法配置 MR 类型和周期 |
| 自定义性能指标 | 🟡 中 | 缺少自定义性能 |
| eGW KPI 测量 | 🟡 中 | eGW 设备不支持 |

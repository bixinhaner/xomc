# 暗色主题 (Dark Theme)

## 设计原则

- 侧边栏 **始终为深色**，不受主题切换影响
- 暗色主题影响 Header 和内容区域
- 保持告警等级色和状态色的语义一致性
- 暗色背景需降低对比度，避免刺眼

## 暗色主题 Token 映射

### 背景色

| 亮色 Token | 亮色值 | 暗色值 | 用途 |
|-----------|--------|--------|------|
| `neutral-50` | `#FAFAFA` | `#141414` | 页面背景 |
| `neutral-100` | `#F5F5F5` | `#1F1F1F` | 卡片背景、斑马纹 |
| `neutral-200` | `#F0F0F0` | `#303030` | 分割线、边框 |
| `white` | `#FFFFFF` | `#1F1F1F` | 卡片/表格容器背景 |

### 文字色

| 亮色 Token | 亮色值 | 暗色值 | 用途 |
|-----------|--------|--------|------|
| `neutral-800` | `#262626` | `rgba(255,255,255,0.85)` | 主标题 |
| `neutral-700` | `#434343` | `rgba(255,255,255,0.75)` | 副标题 |
| `neutral-600` | `#595959` | `rgba(255,255,255,0.65)` | 正文 |
| `neutral-500` | `#8C8C8C` | `rgba(255,255,255,0.45)` | 次要文字 |
| `neutral-400` | `#BFBFBF` | `rgba(255,255,255,0.30)` | 禁用文字 |

### 边框色

| 亮色值 | 暗色值 |
|--------|--------|
| `#D9D9D9` | `#434343` |
| `#F0F0F0` | `#303030` |

### 告警色（暗色主题不变）

告警等级色的主色保持不变，但背景色调整为暗色变体：
- Critical bg: `#2A1215`
- Major bg: `#2B1D11`
- Minor bg: `#2B2611`
- Warning bg: `#111D2C`

### 阴影（暗色主题）

暗色主题下阴影使用更深的值：
```css
shadow-sm-dark: 0 1px 2px 0 rgba(0,0,0,0.15), 0 1px 6px -1px rgba(0,0,0,0.12);
shadow-md-dark: 0 3px 6px -4px rgba(0,0,0,0.36), 0 6px 16px 0 rgba(0,0,0,0.24);
shadow-lg-dark: 0 6px 16px -8px rgba(0,0,0,0.24), 0 9px 28px 0 rgba(0,0,0,0.15);
```

## 实现方式

推荐使用 CSS 自定义属性 + `data-theme` 属性切换：

```css
:root { --bg-page: #FAFAFA; }
[data-theme="dark"] { --bg-page: #141414; }
```

# 响应式断点 (Responsive Breakpoints)

## 断点定义

| Token | px | 说明 |
|-------|-----|------|
| `screen-sm` | 576 | 移动端（非主要目标，仅错误页） |
| `screen-md` | 768 | 平板竖屏 |
| `screen-lg` | 992 | 小型笔记本 |
| `screen-xl` | 1200 | **标准桌面（主要目标）** |
| `screen-2xl` | 1600 | 大屏桌面 / 双显示器 |

## 适配策略

OMC 网管系统以 **1200px+ 桌面端**为主要目标。不要求完整移动端适配。

| 视口宽度 | 行为 |
|---------|------|
| ≥ 1600px | 完整布局，Dashboard 可显示更多卡片 |
| 1200-1599px | **标准布局**，侧边栏展开 240px |
| 992-1199px | 侧边栏自动收起为 48px 图标模式 |
| 768-991px | 侧边栏收起，筛选栏字段垂直堆叠 |
| < 768px | 仅显示错误页/登录页，不支持完整功能 |

## 侧边栏响应行为

```
≥ 1200px: 侧边栏展开 (240px)，可手动收起
 992-1199px: 侧边栏自动收起 (48px)，可手动展开（覆盖内容区）
 < 992px: 侧边栏隐藏，通过汉堡菜单触发
```

## 表格响应行为

- ≥ 1200px: 显示所有默认列
- 992-1199px: 隐藏低优先级列，启用水平滚动
- < 992px: 仅显示关键列 + 展开行查看详情

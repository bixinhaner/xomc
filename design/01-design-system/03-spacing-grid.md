# 间距与栅格 (Spacing & Grid)

## 基准单位

**4px** 为基准单位，主要使用 8px 的倍数。

## 间距刻度

| Token | px | 用途 |
|-------|-----|------|
| `space-0` | 0 | 无间距 |
| `space-0.5` | 2 | 微间距：图标与徽标偏移 |
| `space-1` | 4 | 最小间距：图标与文字行内间距、Radio 与标签 |
| `space-2` | 8 | 密集间距：表格单元格水平内边距、紧凑组件内间距 |
| `space-3` | 12 | 默认内边距：输入框垂直内边距、小组件外边距 |
| `space-4` | 16 | **标准间距**：卡片内边距、区段间距、筛选项间距 |
| `space-5` | 20 | 舒适间距：表单字段垂直间距 |
| `space-6` | 24 | 区段间距：内容块间距、页面水平内边距 |
| `space-8` | 32 | 大间距：主要区段分隔 |
| `space-10` | 40 | 超大间距：Dashboard 卡片间距 |
| `space-12` | 48 | Header 高度、侧边栏图标模式宽度 |
| `space-16` | 64 | 页面上下外边距 |

## 24 栏栅格

采用 24 栏流式栅格（与 Ant Design 一致），列间距 `space-4` (16px)。

### 常用栅格分配

| 布局场景 | 左 | 右 | 说明 |
|---------|-----|-----|------|
| 左树 + 右列表 | 6 栏 (25%) | 18 栏 (75%) | 设备管理、配置管理 |
| 左面板 + 右地图 | 8 栏 (33%) | 16 栏 (67%) | 基站监控 |
| Dashboard 6 卡片 | 各 8 栏 (33%) | — | 2 行 × 3 列 |
| Dashboard 2 卡片行 | 各 12 栏 (50%) | — | 宽卡片 |
| MML 三栏 | 6 + 6 + 12 | — | 设备 + 命令 + 执行 |
| 表单两列 | 各 12 栏 (50%) | — | 宽表单字段 |

## 内容区域层叠

```
┌─ 页面区域 ──────────────────────────┐
│ padding: 16px 24px                    │
│                                       │
│ ┌─ 卡片/表格容器 ─────────────────┐  │
│ │ background: #FFFFFF               │  │
│ │ border-radius: 4px                │  │
│ │ padding: 16px                     │  │
│ │ shadow: shadow-sm                 │  │
│ │                                   │  │
│ │ ┌─ 表格内容 ──────────────────┐ │  │
│ │ │ row-height: 40px             │ │  │
│ │ │ cell-padding: 8px 16px       │ │  │
│ │ └─────────────────────────────┘ │  │
│ └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

# Select 选择器

## 概述
从预定义选项中选择一个或多个值。

## 变体

| 变体 | 说明 | 使用场景 |
|------|------|---------|
| 单选 | 选择单个值 | 设备类型、网络制式、告警等级 |
| 多选 | 选择多个值（Tag 展示） | 批量筛选、多选设备类型 |
| 可搜索 | 输入关键词过滤选项 | 选项多时（>10）使用 |
| 远程搜索 | 输入时调用 API 搜索 | 设备名称、SN 联想 |
| 级联选择 | 多级联动选择 | 区域选择（省→市→区） |
| 分组选项 | 选项按组分类 | 参数分类选择 |

## 尺寸
同 Input: Small(24px) / Medium(32px) / Large(40px)

## 功能
- 下拉面板最大高度 256px，超出滚动
- 多选模式显示已选 Tag，超出折叠显示 "+N"
- 支持"全选"操作（多选模式）
- 清除按钮（可选）
- 空选项状态：显示"暂无数据"

## OMC 使用场景
- 筛选栏: 产品类别、厂商、设备型号、网络制式、连接状态
- 表单: 设备类型选择、协议类型、执行模式
- 全局: 设备类型上下文切换（eNB/gNB/CPE/eGW）
- 级联: 区域选择（省→市→区）

# StatisticsPanel 统计面板

## 概述
以标签+数字对的形式展示分组统计数据。

## 结构
```
┌──────────────────────────────────────────┐
│ 总数: 128  在线: 100  离线: 20  异常: 8   │
└──────────────────────────────────────────┘
```

## 变体
- **内联**: 水平排列，用于表格上方
- **卡片**: 每个统计项一个小卡片
- **带图标**: 图标 + 标签 + 数字

## 数字样式
- 数字: `font-xl` (20px)，`font-bold`
- 标签: `font-xs` (12px)，`neutral-500`
- 数字可点击（跳转到对应筛选列表）

## OMC 使用场景
- 设备管理: 总数/在线/离线/6h/12h/24h/7天离线
- 告警管理: 紧急/主要/次要/警告计数
- 配置管理: 总网元/未同步（1/3/7/14/30天）
- 拓扑管理: 设备数/小区数/连接状态

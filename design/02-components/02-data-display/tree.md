# Tree 树

## 概述
展示层级结构数据，支持展开/折叠、选择、搜索。

## 功能
| 功能 | 说明 |
|------|------|
| 展开/折叠 | 点击箭头图标切换 |
| 单选 | 点击节点标签选中 |
| 多选（Checkbox） | 勾选框，父子级联/半选 |
| 搜索 | 顶部搜索框，高亮匹配项，自动展开匹配路径 |
| 懒加载 | 展开节点时异步加载子节点 |
| 右键菜单 | 节点操作（添加、删除、重命名） |
| 拖拽排序 | 拖拽节点调整层级/顺序 |

## 节点结构
```
▶ 📁 节点名称 (计数)  [更多⋯]
  ▼ 📁 子节点
    📄 叶子节点
```

## 样式
- 缩进: 每层级 24px
- 节点高度: 32px
- 选中节点: 背景 `primary-50`，文字 `primary-600`
- 悬浮节点: 背景 `neutral-100`

## OMC 使用场景
- 设备管理: 设备分组树（按区域/类型/厂商）
- 配置管理: 参数分类树、配置目录树
- 性能管理: 报表分类树（NR/LTE 及子类）
- MR 管理: MR 报表分类树
- 文件管理: 设备类型树
- MML: 命令分类树
- 拓扑管理: 管理域树（省→市→区县）
- 报表管理: 统计维度树

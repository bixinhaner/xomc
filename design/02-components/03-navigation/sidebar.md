# Sidebar 侧边栏

## 概述
深色垂直导航菜单，包含设备类型选择器和模块菜单树。

## 结构
```
┌──────────────┐
│ [eNB ▾]      │ ← 设备类型选择器
├──────────────┤
│ 📊 Dashboard │ ← 模块菜单
│ 📱 设备管理 ▾│
│   设备列表    │ ← 子菜单（展开）
│   设备分组    │
│   网元管理    │
│ 🔔 告警管理  │
│ 🗺️ 基站监控  │
│ ⚙️ 配置管理  │
│ ...          │
├──────────────┤
│ [◀ 收起]     │ ← 收起/展开切换
│ v1.0.0       │ ← 版本号
└──────────────┘
```

## 样式
- 背景: `sidebar-bg` (#001529)
- 宽度: 展开 240px / 收起 48px
- 菜单项高度: 40px
- 菜单项文字: `sidebar-text`，14px
- 选中项: 背景 `sidebar-bg-active`，文字白色，左侧 3px 蓝色指示条
- 悬浮项: 背景 `sidebar-bg-hover`
- 子菜单缩进: 48px（图标宽度对齐）
- 子菜单背景: `sidebar-submenu-bg`
- 分组分隔线: `sidebar-divider`

## 收起模式
- 仅显示图标（16px），居中对齐
- 悬浮显示 Tooltip（菜单项名称）
- 子菜单以浮动面板形式显示

## 设备类型选择器
- 位于侧边栏顶部
- 下拉选择: eNB(4G) / gNB(5G) / CPE / eGW / 全部
- 切换后全局数据自动过滤
- 显示当前选中类型图标和名称

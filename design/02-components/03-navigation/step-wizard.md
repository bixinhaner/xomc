# StepWizard 步骤向导

## 概述
引导用户完成多步操作流程。

## 布局
```
┌────────┬─────────────────────────┐
│ ● 第1步│ 当前步骤内容区            │
│ ○ 第2步│                          │
│ ○ 第3步│                          │
│ ○ 第4步│                          │
│        ├─────────────────────────┤
│        │ [上一步]    [下一步] [取消]│
└────────┴─────────────────────────┘
```

## 步骤状态
| 状态 | 图标 | 颜色 |
|------|------|------|
| 已完成 | ✓ 绿色对勾 | `status-success` |
| 当前 | 数字/蓝色实心 | `primary-600` |
| 未来 | 数字/灰色空心 | `neutral-300` |
| 错误 | × 红色 | `status-error` |

## OMC 使用场景
- 性能指标提取: 4 步（选指标→选网元→设时间→查结果）

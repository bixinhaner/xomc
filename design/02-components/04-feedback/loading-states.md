# Loading 加载状态

## 概述
数据加载中的视觉反馈。

## 变体

| 变体 | 说明 | 使用场景 |
|------|------|---------|
| Spinner 旋转图标 | 小型旋转指示 | 按钮内、行内 |
| Skeleton 骨架屏 | 灰色占位块闪烁 | 表格首次加载（5 行） |
| Progress Overlay 进度覆盖 | 半透明遮罩 + 进度 | 文件上传中 |
| Full Page 全页加载 | 居中 Logo + 旋转 | 系统首次加载 |
| Partial 局部加载 | 内容区遮罩 + 旋转 | 表格刷新 |

## 骨架屏规格
- 行数: 5 行
- 每行: 与实际列宽匹配的灰色矩形块
- 动画: 从左到右灰色渐变闪烁，`duration-slower` (400ms) 循环

## OMC 使用场景
- 表格首次加载 → 骨架屏
- 表格翻页/筛选 → 局部加载（半透明遮罩）
- 按钮操作中 → 按钮内 Spinner
- 文件上传 → 进度覆盖
- 系统初始化 → 全页加载

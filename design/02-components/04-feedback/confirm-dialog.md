# ConfirmDialog 确认对话框

## 概述
危险或重要操作前的二次确认。

## 结构
```
┌─ ⚠ 确认删除 ──────────────┐
│                            │
│ 确定要删除选中的 3 台设备吗？ │
│ 此操作不可撤销。             │
│                            │
│          [取消]   [删除]    │
└────────────────────────────┘
```

## 变体
| 变体 | 确认按钮 | 用途 |
|------|---------|------|
| Info | Primary 蓝色 | 常规确认 |
| Danger | Danger 红色 | 删除、清除等破坏性操作 |

## OMC 使用场景
- 删除设备/告警规则/模板
- 批量删除操作
- 清除告警
- 停止/终止正在执行的任务
- 恢复出厂设置

# GISMap GIS 地图

## 概述
基于地理信息系统的设备分布和监控地图。

## 功能

### 地图底图
- 中国行政区划底图
- 推荐: 高德地图(AMap) JS API — 合规、中文支持好

### 设备标记
- 绿色标记: 正常/在线
- 橙色标记: 异常
- 红色标记: 离线/故障
- 图标形态: 设备类型图标
- 密集区域自动聚合（Marker Clustering）
- 聚合标记显示设备总数

### 点击交互
- 点击标记 → 弹出信息窗口:
  ```
  ┌─ 站点名称 ─────────────┐
  │ 经度: 116.397     纬度: 39.908 │
  │ 设备: eNB×3  gNB×2       │
  │ 告警: 紧急 0  主要 1      │
  │ [查看详情]               │
  └──────────────────────────┘
  ```

### 浮动工具栏
```
[⚙ 设置] [📏 测距] [⤡ 全屏] [⟳ 刷新]
```

### 浮动统计面板
```
┌─ 统计 ─────────────┐
│ 站点总数: 128       │
│ 正常: 100  异常: 20 │
│ 离线: 8             │
└─────────────────────┘
```

### 区域着色模式
行政区域按设备密度或告警密度着色（渐变色）。

## OMC 使用场景
- 基站监控: 主 GIS 地图页面
- Dashboard: 嵌入式小地图组件

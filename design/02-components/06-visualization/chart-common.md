# ChartCommon 图表通用规范

## 概述
所有图表共享的通用功能和样式规范。

## 通用元素
| 元素 | 说明 |
|------|------|
| 标题 | 左上角，`font-md` (16px)，`font-semibold` |
| 图例 | 默认底部居中或右侧垂直，点击切换系列显示/隐藏 |
| Tooltip | 悬浮显示数据点详情，半透明深色背景 |
| 坐标轴 | 标签 `font-xs` (12px)，`neutral-500` |
| 网格线 | 虚线，`neutral-200` |

## 交互
- 缩放/平移（可选，适用于折线图）
- 图例切换
- Tooltip 跟随鼠标
- 响应式自适应容器尺寸

## 图表容器卡片
```
┌─ 标题          [时间▾] [⟳] [⤡] [📥] ─┐
│                                        │
│         (图表内容区域)                   │
│                                        │
│    ■ 系列1  ■ 系列2  ■ 系列3           │
└────────────────────────────────────────┘
```
右上角控制: 时间范围选择、刷新、全屏、下载图片。

## 配色
使用 `01-colors.md` 中定义的图表调色板（8 色序列）。

## 推荐实现
ECharts 5.x — 支持中国地图、丰富的图表类型、优秀的移动端适配。

# BatchInput 批量输入

## 概述
大文本域批量输入设备 SN 或其他标识符。

## 结构
```
┌─ 批量输入 ──────────────────────┐
│ Serial Number:                   │
│ ┌─────────────────────────────┐ │
│ │ SN001;SN002;SN003           │ │
│ │ SN004 SN005                 │ │
│ │                             │ │
│ └─────────────────────────────┘ │
│ 提示: 多个设备用分号(;)或空格分隔  │
│                                  │
│              [取消]    [确认]     │
└──────────────────────────────────┘
```

## 分隔符
- 分号 `;`
- 空格
- 换行

## OMC 使用场景
- 备份任务: 批量输入设备 SN
- License 管理: 批量输入设备 SN
- 设备选择: 快速批量添加

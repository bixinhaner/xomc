# TransferBox 穿梭框

## 概述
在两个列表间转移项目的双列选择器。

## 结构
```
┌─ 可选项 (500) ──┐    ┌─ 已选项 (23/500) ─┐
│ [搜索...]       │    │ [搜索...]          │
│ ☐ 全选          │    │ ☐ 全选             │
│ ☐ 指标A         │    │ ☐ 指标X            │
│ ☐ 指标B         │ →  │ ☐ 指标Y            │
│ ☑ 指标C         │ ←  │ ☐ 指标Z            │
│ ☐ 指标D         │    │                    │
│                 │    │ [↑] [↓]            │
└─────────────────┘    └────────────────────┘
```

## 功能
- 左侧: 可选项列表，搜索、多选 Checkbox、全选
- 中间: → 添加 / ← 移除 按钮
- 右侧: 已选项列表，搜索、排序(上移/下移)、全选
- 计数: "已选 23 / 最大 500"

## OMC 使用场景
- 性能指标提取: 选择 Counter/Indicator (最大 500)
- 报表列选择: 选择导出列
- 模板参数选择: 选择要配置的参数

# 拖拽交互 (Drag & Drop)

> OMC 统一网管系统 - 交互设计规范

## 概述

拖拽交互用于文件上传、树节点排序、Dashboard 布局调整和拓扑图操作等场景。本文定义各场景的拖拽行为和视觉反馈。

---

## 1. 文件上传拖放区 (File Upload Drop Zone)

### 1.1 默认状态

```
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
│                                            │
│     ⬆ 点击或拖拽文件到此区域上传             │
│                                            │
│     支持 .xlsx, .csv, .bin 格式             │
│     单个文件不超过 200MB                     │
│                                            │
└─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘

视觉规范:
  - 边框: 2px dashed #D9D9D9 (虚线)
  - 背景: #FAFAFA
  - 图标: InboxOutlined / UploadOutlined, 48px, @primary-color
  - 主文字: 16px, @text-primary
  - 辅助文字: 14px, @text-secondary
  - 圆角: 8px
  - 光标: pointer
```

### 1.2 拖拽悬停状态 (Drag Over)

```
┌─────────────────────────────────────────────┐
│ ┃                                         ┃ │
│ ┃     释放以上传文件                        ┃ │
│ ┃     (Release to upload)                 ┃ │
│ ┃                                         ┃ │
└─────────────────────────────────────────────┘

视觉变化:
  - 边框: 2px solid @primary-color (实线, 蓝色)
  - 背景: @primary-color 5% (#E6F7FF)
  - 文字: "释放以上传文件"
  - 动画: 边框呼吸效果 (opacity 脉冲)
  - 缩放: 轻微放大 (scale 1.01, transition 200ms)
```

### 1.3 文件放入后


### 1.4 文件校验

```
上传前校验:
  - 文件类型: 检查文件扩展名和 MIME type
  - 文件大小: 超出限制 → 提示 "文件大小不能超过 {N}MB"
  - 文件数量: 超出限制 → 提示 "最多上传 {N} 个文件"

校验失败:
  ┌───────────────────────────────────────────┐
  │ ✕ invalid_file.doc                        │
  │   不支持的文件格式，请上传 .xlsx 或 .csv   │
  │                               [移除]      │
  └───────────────────────────────────────────┘
```

## 2. 树节点拖拽排序

### 2.1 交互规范

```
场景: 设备分组管理中，拖拽设备或分组调整层级和顺序

开始拖拽:
  - 鼠标按住节点 150ms → 进入拖拽模式
  - 光标: grab → grabbing
  - 被拖节点: 生成半透明副本跟随鼠标

拖拽中:
  ▼ 广州区域
    ▼ 天河区
    ┄┄┄┄┄┄┄┄┄┄┄  ← 蓝色水平线 (放在此位置)
      ├─ eNodeB-001
    ┌─────────────────┐
    │ eNodeB-003 👆   │  ← 被拖拽的节点 (半透明悬浮)
    └─────────────────┘
      ├─ eNodeB-002
    ▶ 越秀区         ← 蓝色高亮边框 (放入此分组内)

放置指示器:
  - 放在目标上方: 蓝色水平线 (2px, #1890FF) 在目标上方
  - 放在目标下方: 蓝色水平线在目标下方
  - 放入目标内: 目标节点蓝色背景高亮 (#E6F7FF)
  - 不可放置: 红色禁止图标 + cursor: not-allowed
```

### 2.2 拖拽限制

```
规则:
  - 不能将节点拖入自身或自身子节点 (防止循环引用)
  - 叶子节点不可作为容器 (不能放入叶子节点内)
  - 某些系统预设节点不可移动 (如根节点)
  - 跨类型限制: 设备只能拖入分组, 不能拖到其他设备上方
```

## 4. 拓扑画布节点定位

### 4.1 交互规范

```
场景: 拓扑管理中, 拖拽网元节点调整画布位置

画布操作:
  - 拖拽节点: 鼠标按住节点 → 移动到画布任意位置
  - 拖拽画布: 鼠标按住空白区域 → 平移整个画布
  - 缩放: 鼠标滚轮 → 画布缩放 (25% ~ 400%)
  - 框选: Shift + 拖拽空白区域 → 矩形框选多个节点
  - 多节点拖拽: 选中多个节点 → 拖拽其中一个 → 全部跟随移动

节点拖拽中:
  - 节点: 跟随鼠标移动
  - 连线: 实时更新 (贝塞尔曲线重计算)
  - 吸附: 可选对齐辅助线 (与相邻节点对齐)
  - 边界: 拖到画布边缘 → 画布自动扩展或滚动

释放:
  - 节点固定在新位置
  - 连线重新计算路径
  - 位置自动保存 (debounce 1s)
```

## 5. 通用拖拽视觉反馈

### 5.1 拖拽状态光标

| 状态 | 光标 | 说明 |
|------|------|------|
| 可拖拽 (hover) | `grab` | 鼠标悬停在可拖拽元素上 |
| 拖拽中 | `grabbing` | 正在拖拽 |
| 可放置 | `copy` / `move` | 拖拽到有效放置目标上 |
| 不可放置 | `not-allowed` | 拖拽到无效目标上 |

### 5.2 拖拽副本 (Ghost)

```
规范:
  - 跟随鼠标的半透明副本
  - 透明度: 0.6
  - 轻微缩小: scale(0.95)
  - 阴影: 0 8px 24px rgba(0, 0, 0, 0.15)
  - 偏移: 副本中心对准鼠标位置
```

## 6. 触控设备适配

```
规则:
  - 长按 300ms 进入拖拽模式 (移动端)
  - 拖拽过程中禁止页面滚动
  - 放大拖拽手柄的触控热区 (最小 44x44px)
  - 提供非拖拽的替代操作方式 (如上移/下移按钮)

注意: OMC 系统主要面向 PC 端, 触控适配为次要优先级
```

## 7. 实现参考

### 文件上传

```typescript
// Ant Design Upload 组件
<Upload.Dragger
  name="file"
  multiple
  action="/api/upload"
  accept=".xlsx,.csv,.bin"
  maxCount={5}
  beforeUpload={(file) => {
    const isValid = file.size < 200 * 1024 * 1024; // 200MB
    if (!isValid) message.error('文件大小不能超过 200MB');
    return isValid;
  }}
  onChange={handleUploadChange}
>
  <p><InboxOutlined /></p>
  <p>点击或拖拽文件到此区域上传</p>
</Upload.Dragger>
```

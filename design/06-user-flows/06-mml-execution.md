# 用户流程: MML 命令执行 (MML Execution)

> OMC 统一网管系统 - 用户流程

## 概述

MML (Man-Machine Language) 是网管系统中与设备交互的命令语言。本流程包括单条 MML 命令的交互式执行和批量 MML 脚本任务两个子流程。

## 流程 A: 交互式 MML 执行

### 步骤 1: 选择设备

```
页面: MML 管理 > MML 执行
路径: /mml/execute

页面布局: 三栏结构
┌──────────┬──────────────┬──────────────────────────┐
│ 设备面板 │ MML 命令树    │ 命令参数与执行区域        │
│          │              │                          │
│ 🔍搜索.. │              │                          │
│ ▼ 广州   │              │                          │
│   eNB-01 │              │                          │
│  ●eNB-02 │              │                          │
│   eNB-03 │              │                          │
│ ▼ 深圳   │              │                          │
│   eNB-04 │              │                          │
└──────────┴──────────────┴──────────────────────────┘

操作:
  - 左侧面板: 设备树 (按区域/分组组织)
  - 搜索: 支持按设备名称或 IP 搜索
  - 点击设备节点 → 选中设备 (高亮显示)
  - 已选设备: 名称前显示蓝色圆点 ●
  - 设备状态标识: 在线(绿)、离线(红)
  - 只能选择在线设备执行 MML
```

### 步骤 2: 浏览 MML 命令树

```
中间面板: MML 命令分类树

  🔍 搜索命令...
  ▼ 查询类 (DSP)
    ├ DSP CELLINFO     查询小区信息
    ├ DSP RRUINFO      查询RRU信息
    ├ DSP IPRT         查询IP路由
    ├ DSP LICENSE      查询License
    └ ...
  ▼ 修改类 (MOD)
    ├ MOD CELLPARA     修改小区参数
    ├ MOD TXPWR        修改发射功率
    └ ...
  ▼ 添加类 (ADD)
    ├ ADD CELL         添加小区
    ├ ADD ADJCELL      添加邻区
    └ ...
  ▶ 删除类 (RMV)
  ▶ 激活类 (ACT)
  ▶ 去激活类 (DEA)

操作:
  - 展开分类 → 查看命令列表
  - 搜索: 按命令名或描述搜索, 匹配高亮
  - 点击命令 → 右侧显示命令详情和参数
  - 常用命令: 星标收藏, 显示在 "我的收藏" 顶部
```

### 步骤 3: 查看命令详情

```
右侧面板上部: 命令详情

  ┌──────────────────────────────────────────────┐
  │ DSP CELLINFO - 查询小区信息                   │
  ├──────────────────────────────────────────────┤
  │ 命令格式:                                     │
  │   DSP CELLINFO: CELLID=<小区ID>;             │
  │                                              │
  │ 功能描述:                                     │
  │   查询指定小区的基本配置信息和运行状态。        │
  │                                              │
  │ 参数说明:                                     │
  │   CELLID (必选): 小区标识, 范围 0-255         │
  │                                              │
  │ 使用注意:                                     │
  │   该命令为查询类命令, 不影响设备运行。          │
  └──────────────────────────────────────────────┘
```

### 步骤 4: 设置参数

```
右侧面板中部: 参数设置

  ┌──────────────────────────────────────────────┐
  │ 参数设置                                      │
  ├──────────────────────────────────────────────┤
  │                                              │
  │ * CELLID (小区标识):                          │
  │   [0     ▾]   范围: 0-255                    │
  │                                              │
  │ 或者手动输入完整命令:                          │
  │ ┌──────────────────────────────────────────┐ │
  │ │ DSP CELLINFO: CELLID=0;                  │ │
  │ └──────────────────────────────────────────┘ │
  │                                              │
  │ [执行 (DO)]  [收藏]  [清空]                   │
  └──────────────────────────────────────────────┘

参数交互:
  - 必选参数: 红色星号标记
  - 下拉选项: 枚举类型参数用下拉框
  - 输入框: 数值/字符串参数用输入框
  - 参数校验: 输入后即时校验范围/格式
  - 手动模式: 可直接编辑完整命令文本 (高级用户)
```

### 步骤 5: 执行 (DO)

```
操作: 点击 [执行 (DO)] 按钮

执行前检查:
  ✓ 已选择设备且设备在线
  ✓ 参数已填写完整且校验通过
  ✗ 未选择设备 → 提示 "请先选择设备"
  ✗ 设备离线 → 提示 "设备离线, 无法执行"
  ✗ 参数不完整 → 提示具体缺失参数

危险命令确认 (MOD/RMV/DEA 类):
  ┌──────────────────────────────────────────────┐
  │ ⚠ 该命令将修改设备配置, 确定执行吗?            │
  │                                              │
  │ 设备: eNodeB-001                             │
  │ 命令: MOD CELLPARA: CELLID=0, TXPWR=43;     │
  │                                              │
  │                    [取消]    [确认执行]        │
  └──────────────────────────────────────────────┘

执行中:
  [执行 (DO)] 按钮 → Loading 状态: "执行中..."
  超时: 30s (可配置)
```

### 步骤 7: 保存为常用命令 (可选)

```

  ┌──────────────────────────────────────────────┐
  │ 保存为常用命令                          [X] │
  ├──────────────────────────────────────────────┤
  │                                              │

  - 带预设参数, 点击即可快速执行
```

## 流程 B: MML 脚本任务

### 步骤 1: 创建脚本任务

```
页面: MML 管理 > 脚本任务
路径: /mml/script-task

操作: 点击 [新建脚本任务]

  ┌──────────────────────────────────────────────┐
  │ 新建脚本任务                            [X] │
  ├──────────────────────────────────────────────┤
  │                                              │
  │ * 任务名称:   [________________]             │
  │   任务描述:   [________________]             │
  │                                              │
  │ * 执行方式:                                  │
  │   ○ 立即执行                                 │
  │   ● 定时执行  时间: [2024-01-16 02:00]       │
  │   ○ 周期执行  策略: [每天 ▾] [02:00]         │
  │                                              │
  ├──────────────────────────────────────────────┤
  │                    [取消]    [下一步]          │
  └──────────────────────────────────────────────┘
```

### 步骤 2: 添加 MML 命令

```
  ┌──────────────────────────────────────────────────────────┐
  │ 脚本命令列表                                             │
  ├──────────────────────────────────────────────────────────┤
  │                                                          │
  │ 步骤 1: DSP CELLINFO: CELLID=0;        [编辑] [删除]    │
  │ 步骤 2: MOD TXPWR: CELLID=0, TXPWR=43; [编辑] [删除]    │
  │ 步骤 3: DSP TXPWR: CELLID=0;           [编辑] [删除]    │
  │                                                          │
  │ [+ 添加命令]  [从收藏导入]  [从文件导入]                   │
  │                                                          │
  │ 执行设置:                                                │
  │   ☑ 按顺序执行 (上一条成功后才执行下一条)                  │
  │   ☐ 某步失败时继续执行后续步骤                             │
  │   命令间隔: [5 ▾] 秒                                     │
  │                                                          │
  ├──────────────────────────────────────────────────────────┤
  │ [上一步]                                   [下一步]      │
  └──────────────────────────────────────────────────────────┘
```

### 步骤 3: 选择目标设备

```
与流程 A 步骤 1 类似, 但支持多设备选择:
  - 选中多台设备
  - 脚本将在每台设备上依次执行
  - 或并行执行 (可配置)
```

### 步骤 4: 设置执行计划

```
确认执行配置:
  - 命令列表: 3 条命令
  - 目标设备: 5 台
  - 总执行次数: 15 次 (3 命令 x 5 设备)
  - 预计耗时: 约 5 分钟

  [上一步]  [保存任务]  [保存并执行]
```

### 步骤 5: 执行并监控

```
脚本任务在任务面板中跟踪:

  ┌──────────────────────────────────────────────┐
  │ 📜 MML脚本: 修改发射功率 (5台设备)           │
  │ ████████████████░░░░░░  60%                  │
  │ 当前: eNodeB-003 / 步骤2 MOD TXPWR           │
  │                          [暂停]  [终止]      │
  └──────────────────────────────────────────────┘

完成后:
  - 任务详情显示每台设备每条命令的执行结果
  - 可导出完整执行报告 (Excel)
```

## 异常处理汇总

| 步骤 | 可能异常 | 处理方式 |
|------|---------|---------|
| 步骤 1 选择设备 | 设备离线 | 离线设备灰色显示, 不可选 |
| 步骤 5 执行 | 命令执行超时 | 提示 "命令执行超时 (30s)" + [重试] |
| 步骤 5 执行 | 设备拒绝命令 | 显示设备返回的错误信息 |
| 步骤 5 执行 | 权限不足 | "当前用户无权执行此命令" |
| 脚本步骤 5 | 某步骤失败 | 根据配置停止或继续后续步骤 |

# 用户流程: 备份恢复 (Backup & Restore)

> OMC 统一网管系统 - 用户流程

## 概述

备份恢复流程保障设备配置数据安全，支持定期自动备份和按需手动备份。当设备故障或配置错误时，可通过历史备份快速恢复。

## 流程 A: 备份

### 步骤 1: 选择备份设备

```
页面: 备份恢复 > 备份管理
路径: /backup/manage

操作:
  1. 进入备份管理页面
  2. 选择需要备份的设备

  设备选择方式:
    A. 从设备列表选择:
       勾选表格中的设备 Checkbox → [创建备份任务]

    B. 从设备树选择:
       左侧设备树勾选设备/分组 → [创建备份任务]

    C. 全部设备:
       [全网备份] 按钮 (备份所有在线设备)
```

### 步骤 2: 创建备份任务

```
操作: 点击 [创建备份任务] → 弹出配置对话框

  ┌──────────────────────────────────────────────┐
  │ 创建备份任务                            [X] │
  ├──────────────────────────────────────────────┤
  │                                              │
  │ * 任务名称:   [________________]             │
  │                                              │
  │ 备份设备:     eNodeB-001 等 5 台设备         │
  │                                              │
  │ * 备份类型:                                  │
  │   ☑ 配置数据                                 │
  │   ☑ 运行数据                                 │
  │   ☐ 日志数据                                 │
  │                                              │
  │ * 执行方式:                                  │
  │   ○ 立即执行                                 │
  │   ● 定时执行                                 │
  │                                              │
  │   调度策略: [每周 ▾]                          │
  │   执行日:   ☑周一 ☐周二 ☐周三 ☐周四          │
  │            ☐周五 ☐周六 ☐周日                  │
  │   执行时间: [02:00 ▾]                        │
  │   有效期:   [2024-01-15 ~ 2024-12-31]        │
  │                                              │
  │ * 存储方式:                                  │
  │   ● OMC 服务器本地存储                       │
  │   ○ FTP/SFTP 远程存储  [配置FTP...]          │
  │                                              │
  │ 备份保留策略:                                 │
  │   保留最近 [30 ▾] 天的备份                    │
  │   每台设备最多保留 [10 ▾] 份备份              │
  │                                              │

  │                    [取消]    [创建任务]        │
  └──────────────────────────────────────────────┘

调度策略选项:
  - 每天: 每天固定时间执行
  - 每周: 选择星期几执行
  - 每月: 选择每月第几天执行
  - 一次性: 只执行一次
```

### 步骤 4: 任务执行/调度

```
立即执行:
  1. 任务创建后立即开始备份
  2. Toast: "备份任务已启动"
  3. 任务面板显示进度

定时执行:
  1. 任务创建后进入调度队列
  2. 到达执行时间 → 自动触发备份
  3. 执行时通知 (如果用户在线)

任务面板:
  ┌──────────────────────────────────────────────┐
  │ 📦 备份任务: eNodeB-001 等 5 台设备          │
  │ ████████████████░░░░░░  60% (3/5)           │
  │ 当前: 正在备份 eNodeB-003                    │
  └──────────────────────────────────────────────┘
```

```
│          │ 02:00    │         │          │ [删除]       │
│ eNB-001  │ 01-08    │ 2.4MB   │ 本地     │ [恢复][下载] │
│          │ 02:00    │         │          │ [删除]       │
│ eNB-002  │ 01-15    │ 1.8MB   │ FTP      │ [恢复][下载] │
```

## 流程 B: 恢复

### 步骤 1: 选择要恢复的设备

```
入口方式:

A. 从备份文件列表进入:
   备份文件列表 → 找到目标备份 → [恢复]

B. 从设备详情进入:
   设备详情页 → [恢复配置] → 选择备份文件
```

```
  └──────────────────────────────────────────────┘
```

### 步骤 4: 跟踪恢复进度

```
恢复流程:
  1. (可选) 先备份当前配置
  2. 将备份文件传输到设备
  3. 设备执行配置恢复
  4. 设备重启 (如需要)
  5. 验证恢复结果

任务面板:
  ┌──────────────────────────────────────────────┐
  │ 🔄 恢复配置: eNodeB-001                      │
  │ ████████████████████░░░░  80%                │
  │ 当前步骤: 设备正在应用配置...                  │
  └──────────────────────────────────────────────┘

恢复完成:
  Notification: "配置恢复成功: eNodeB-001 已恢复到 2024-01-08 的备份"

恢复失败:
  Notification: "配置恢复失败: {错误原因}  [查看详情]"
  设备状态需手动检查
```

## 异常处理汇总

| 步骤 | 可能异常 | 处理方式 |
|------|---------|---------|
| 备份步骤 2 | 设备离线 | 提示 "以下设备离线, 无法备份" + 列表 |
| 备份步骤 4 | 备份空间不足 | 提示 "存储空间不足, 请清理历史备份" |
| 备份步骤 4 | FTP 连接失败 | 任务失败 + "FTP 连接失败, 请检查配置" |
| 恢复步骤 2 | 备份文件损坏 | "备份文件校验失败, 文件可能已损坏" |
| 恢复步骤 2 | 版本不兼容 | 警告 "备份版本与当前版本不一致, 恢复可能失败" |
| 恢复步骤 4 | 恢复中断 | 设备自动回退到恢复前状态 |

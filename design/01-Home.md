## 1.1 首页仪表板

### 原系统 `home.jsp` — 详细功能清单

原系统首页是一个 **Vue.js + Element UI** 的重量级仪表板，包含 **4 大功能区块**，约 40+ 图表和 20+ API 接口：

#### 区块 A：告警统计卡片（3 张专用告警卡）

| 卡片 | 数据 | 交互 |
|------|------|------|
| 站点离线告警 | 红色大字显示数量 | 点击跳转告警详情 + **导出按钮** |
| 小区离线告警 | 红色大字显示数量 | 点击跳转告警详情 + **导出按钮** |
| 小区不活动告警 | 橙色大字显示数量 | 点击跳转告警详情 + **导出按钮** |

#### 区块 B：设备状态区（按技术制式分 Tab）

**Tab 切换**：Site / eNB / gNB / GSM / CPE — 每个 Tab 包含以下图表：

| 图表类型 | 说明 | 适用制式 |
|---------|------|---------|
| 在线/活动趋势（双折线图） | Total vs Online/Active，7 日时间轴 | 全部 |
| UE 数量趋势（单折线图） | 接入用户数量变化 | eNB/gNB/GSM/CPE |
| MME 连接状态 | MME 连接数变化趋势 | 仅 eNB |
| 产品型号分布（饼图） | Top 10 产品型号占比 | 全部 |
| 设备运行时长分布（柱状图） | 按时长区间统计 | 全部 |

- **每个 Tab 下可通过下拉菜单切换子图表**
- **支持 Day/Week 时间维度切换**
- **7 日时间轴选择器**，点击日期可查看当日详情

#### 区块 C：KPI 性能统计区（按技术制式分 Tab）

**Tab 切换**：eNB / gNB / GSM

| 技术制式 | KPI 指标数量 | 指标分类 |
|---------|------------|---------|
| **eNB (4G)** | **16 项** | 流量 (Traffic)、利用率 (Utilization)、接入性 (Accessibility)、移动性 (Mobility) |
| **gNB (5G)** | **4 项** | 流量 (Traffic)、利用率 (Utilization) |
| **GSM (2G)** | **3 项** | 呼叫相关指标 |

每项 KPI 展示：
- **当前值**（大字体右对齐）
- **同比/环比箭头**（绿色上升、红色下降）
- **折线图趋势**（7 日/当日可切换）

#### 区块 D：SAS 频谱图表区（已禁用但保留代码）

#### 全局特性

| 特性 | 说明 |
|------|------|
| **自动刷新** | 设备状态/KPI 每 10 分钟刷新；告警每 6-10 秒���询 |
| **权限控制** | 按权限码控制区块可见性 (CODE_ENB_MONITOR / CODE_GNB_MONITOR / CODE_ALARM_VIEW 等) |
| **导出功能** | 告警数据导出、统计报表导出 |
| **国际化** | 中英文切换 |

#### 调用 API 列表（20+ 接口）

| API | 用途 |
|-----|------|
| `getDeviceStatisticsDataList.action` | eNB/CPE 设备统计 |
| `getGNBDeviceStatisticsDataList.action` | gNB 设备统计 |
| `getGSMDeviceStatisticsDataList.action` | GSM 设备统计 |
| `getSiteStatisticsInfos.action` | 站点离线数据 |
| 产品统计 API ×4 | 各制式产品型号分布 |
| KPI 性能 API ×3 | eNB/gNB/GSM KPI 数据 |
| 告警数据 + 导出 API | 告警统计和导出 |

## 操作流程完整性：⚠️ 部分完整

新系统 Dashboard 在 **现代化 UI/UX** 方面（GIS 地图、3D 动效、快速入口、响应式设计）显著超越原系统，但在 **电信网管核心业务功能** 方面存在较大差距：

1. **缺少按技术制式（4G/5G/2G）分维度的设备监控** — 这是电信网管的核心需求
2. **完全缺少 KPI 性能统计** — 原系统展示 23 项关键 KPI 指标
3. **缺少自动刷新和实时数据轮询** — 网管系统的基本要求
4. **缺少数据导出能力** — 运维人员常用功能

**建议补全优先级**：KPI 性能统计区 > 分制式设备状态图 > 自动刷新 > 导出 > 专用告警卡

## 五、核查流程说明

```
1. 选择模块 → 在上方"核查进度总览"中找到对应模块
2. 打开对比文档 → 点击"对比文档"链接了解新旧系统差异
3. 参照核查清单 → 打开 17-前端页面迁移核查清单.md 逐项核查
4. 填写核查记录 → 在本文档对应模块的"展开核查记录"中填写结果
5. 更新核查状态 → 核查完成后更新"核查进度总览"表格中的状态和进度
```

### 状态标记规范

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| ✅ | 核查通过 | 新系统与原系统功能完全一致 |
| ⚠️ | 存在差异 | 功能已实现但存在差异，需在"差异说明"中描述 |
| ❌ | 未实现 | 新系统完全缺失该功能 |
| ⏳ | 核查中 | 正在核查，尚未得出结论 |
| — | 不适用 | 该核查维度对此页面不适用 |

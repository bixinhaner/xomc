# 图标系统 (Iconography)

## 图标风格

| 属性 | 值 |
|------|-----|
| 默认风格 | 线性图标 (Outlined) |
| 选中/活跃状态 | 实心图标 (Filled) |
| 线宽 | 1.5px (16px 图标基准) |
| 线帽/连接 | 圆角 (Round) |

## 图标尺寸

| Token | px | 用途 |
|-------|-----|------|
| `icon-xs` | 12 | 表格行内小图标、徽标覆盖 |
| `icon-sm` | 14 | 按钮行内图标、导航次要图标 |
| `icon-base` | 16 | **默认** — 表单图标、列表图标、导航主图标 |
| `icon-md` | 20 | 卡片图标、工具栏图标 |
| `icon-lg` | 24 | 页面区段标题图标、Dashboard 图标 |
| `icon-xl` | 32 | Dashboard 分类图标、空状态次要图标 |
| `icon-2xl` | 48 | Dashboard 主图标、空状态主图标 |

## OMC 专用图标

### 设备类型图标
- eNB (4G 基站) — 天线塔 + "4G" 标记
- gNB (5G 基站) — 天线塔 + "5G" 标记
- CPE (用户终端) — 路由器形态
- eGW (网关) — 服务器 + 网络连接
- Picostation (微站) — 小型天线（家庭/企业/扩展/大功率 4 种变体）
- Wi-Fi AP — 无线信号图标

### 网络元素图标
- BU (基带单元) — 芯片/处理器形态
- EU (扩展单元) — 芯片 + 扩展符号
- RU (射频单元) — 天线 + 射频波
- Slot (板卡) — 插件卡形态
- 近端单元 — 服务器侧图标
- 远端单元 — 天线侧图标

### 核心网图标
- AMF (5G 核心) — 云 + "5GC" 标记
- MME (4G 核心) — 云 + "EPC" 标记
- S-GW / P-GW — 网关形态

### 拓扑图标
- 设备集群(云) — 云形态（全连接/部分断连 2 种状态）
- 连接线 — 实线(已连接)、虚线(Xn/X2)
- Xn 接口线 — 蓝色虚线 + "Xn" 标记
- X2 接口线 — 绿色虚线 + "X2" 标记

### 状态图标
- 在线 — 绿色实心圆点
- 离线 — 红色实心圆点
- 异常 — 橙色实心圆点
- 锁定 — 锁图标 (紫色)
- 关闭中 — 半圆/渐变图标
- 解锁 — 开锁图标

### 告警图标
- 告警铃铛 — 铃铛 + 等级色彩徽标
- 告警静音 — 铃铛 + 斜杠
- 告警已确认 — 铃铛 + 对勾
- 告警已清除 — 铃铛 + 清除标记

### 功能图标
- MML 终端 — 命令行终端
- 备份 — 云 + 上箭头
- 恢复 — 云 + 下箭头
- License — 钥匙
- 固件 — 芯片 + 箭头
- 配置同步 — 循环箭头
- 参数 — 齿轮 + 列表
- 小区 — 六边形蜂窝
- 基线 — 文档 + 对勾
- MR 报告 — 信号 + 文档
- 拓扑 — 网络节点连线
- 域树 — 树状结构
- 模板 — 文档模板
- 脚本 — 代码文件
- 日志 — 文本列表

## 图标与文字间距

- 图标在文字左侧: `space-1` (4px) 间距
- 图标在文字右侧: `space-1` (4px) 间距
- 纯图标按钮: 建议加 Tooltip 说明

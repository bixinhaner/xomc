# 圆角 (Border Radius)

## 圆角刻度

| Token | px | 用途 |
|-------|-----|------|
| `radius-none` | 0 | 全宽元素、表格单元格 |
| `radius-xs` | 2 | 标签(Tag)、小徽标、告警等级点 |
| `radius-sm` | 4 | **默认** — 输入框、按钮、卡片、下拉菜单、表格容器 |
| `radius-md` | 6 | 较大卡片、面板、筛选栏容器 |
| `radius-lg` | 8 | 弹窗(Modal)、Popover |
| `radius-xl` | 12 | Dashboard KPI 卡片、功能卡片 |
| `radius-full` | 9999px | 头像、状态圆点、圆形按钮、Toggle 轨道 |

## 应用映射

| 组件 | 圆角 Token |
|------|-----------|
| Button | `radius-sm` |
| Input / Select | `radius-sm` |
| Card | `radius-sm` |
| Modal | `radius-lg` |
| Tag / Badge | `radius-xs` |
| Tooltip / Popover | `radius-lg` |
| KPI Card | `radius-xl` |
| Avatar | `radius-full` |
| Status Dot | `radius-full` |
| Switch Track | `radius-full` |
| Table Container | `radius-sm` |
| Dropdown Menu | `radius-sm` |

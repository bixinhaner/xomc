# 用户流程: 设备入网 (Device Onboarding)

> OMC 统一网管系统 - 用户流程

## 概述

设备入网是将新设备纳入 OMC 统一网管系统管理的完整流程，包括设备注册、连接建立、参数同步、分组归属、开站调试和交维等步骤。

## 详细步骤

### 步骤 1: 进入设备列表

```
页面: 设备管理 > 设备列表
路径: /device/list

操作:
  - 用户从侧边栏点击 "设备管理" → "设备列表"
  - 页面加载设备列表表格

前置条件:
  - 用户已登录
  - 用户具有设备管理权限
```

### 步骤 2: 点击新建设备

```
操作:
  - 点击表格工具栏中的 [新建设备] 按钮
  - 弹出新建设备 Modal 或导航到新建设备页面

选择入网方式:
  ┌────────────────────────────────────────┐
  │ 新建设备                          [X] │
  ├────────────────────────────────────────┤
  │                                        │
  │ 选择入网方式:                           │
  │   ○ 单台设备注册                       │
  │   ○ 批量导入 (Excel 模板)              │
  │                                        │
  │ [下载批量导入模板]                      │
  │                                        │
  ├────────────────────────────────────────┤
  │                   [取消]    [下一步]    │
  └────────────────────────────────────────┘
```

### 步骤 3: 填写注册信息

**方式 A: 单台设备注册**

```
┌────────────────────────────────────────┐
│ 新建设备 - 基本信息                [X] │
├────────────────────────────────────────┤
│                                        │
│ * 设备名称:   [________________]       │
│ * 设备类型:   [eNodeB ▾]              │
│ * IP 地址:    [________________]       │
│ * 端口号:     [8443         ]          │
│ * 通信协议:   [SNMP ▾]               │
│                                        │
│ ▶ 认证信息 (展开)                      │
│   * 用户名:   [________________]       │
│   * 密码:     [________________]       │
│                                        │
│ ▶ 高级设置 (展开)                      │
│   心跳间隔:   [60s     ▾]             │
│   超时时间:   [30s     ▾]             │
│   描述:       [________________]       │
│                                        │
├────────────────────────────────────────┤
│                   [取消]    [提交]      │
└────────────────────────────────────────┘

校验规则:
  - 设备名称: 必填, 1-64 字符, 不重复
  - IP 地址: 必填, 合法 IPv4/IPv6 格式, 不重复
  - 端口号: 必填, 1-65535
  - 认证信息: 根据协议类型动态变化
```

**方式 B: 批量导入**

```
1. 下载 Excel 模板
2. 填写设备信息 (每行一台设备)
3. 上传填写好的 Excel 文件
4. 系统预览导入数据 (前 5 行)
5. 校验结果:
   - 全部通过 → [确认导入]
   - 部分错误 → 红色标记错误行 + 错误原因, 可选 [跳过错误行并导入]
   - 全部错误 → 提示修正后重新上传
```

### 步骤 4: 提交注册

```
操作:
  - 点击 [提交] 按钮
  - 前端校验 → 通过 → 按钮 Loading → 发送 API 请求

成功:
  - Toast: "设备注册成功"
  - Modal 关闭
  - 设备列表自动刷新
  - 新设备出现在列表顶部, 状态为 "未连接"

失败:
  - Toast: "设备注册失败: {错误原因}"
  - 常见错误:
    - "设备名称已存在"
    - "IP 地址已被注册"
    - "无法连接到设备"
  - Modal 保持打开, 用户修改后可重试

批量导入结果:
  - Toast: "批量导入完成: 成功 48 台, 失败 2 台"
  - [查看详情] → 显示每台设备的导入结果
```

### 步骤 5: 设备上线 (自动)

```
行为:
  - 设备注册后, 系统尝试与设备建立连接
  - 连接过程中: 设备状态为 "连接中" (蓝色 Spinner)
  - 连接成功: 状态自动变为 "在线" (绿色)
  - 连接失败: 状态变为 "离线" (红色)

实时更新:
  - WebSocket 推送设备状态变更
  - 设备列表中对应行状态列实时更新
  - 状态变更伴随高亮闪烁动画

连接超时:
  - 超时时间: 根据设备类型, 30s - 120s
  - 超时后: 状态变为 "未连接", Tooltip 显示 "连接超时"
  - 用户可点击 [重新连接] 手动触发

错误处理:
  - 连接被拒绝: 检查 IP/端口/认证信息
  - 网络不可达: 检查网络配置
  - 认证失败: 检查用户名密码
  - 提示信息显示在设备详情中
```

### 步骤 6: 自动同步参数

```
行为:
  - 设备上线后自动触发参数同步
  - 同步内容: 设备基本信息、小区配置、邻区配置等
  - 同步时间: 根据设备复杂度, 30s - 5min

任务面板:
  ┌────────────────────────────────────────┐
  │ 🔄 参数同步 eNodeB-001    进行中 67%  │
  └────────────────────────────────────────┘

同步完成:
  - 设备详情页可查看完整参数
  - 设备列表中设备信息补全 (如型号、版本等)
```

### 步骤 7: 分配设备分组 (可选)

```
操作:
  - 在设备列表选中设备 → 右键 → "移动到分组..."
  - 或: 设备详情页 → [编辑] → 修改所属分组

分组选择:
  ┌────────────────────────────────────────┐
  │ 选择设备分组                      [X] │
  ├────────────────────────────────────────┤
  │ 🔍 搜索分组...                        │
  ├────────────────────────────────────────┤
  │ ▼ 广东省                               │
  │   ▼ 广州市                             │
  │     ○ 天河区                           │
  │     ● 越秀区                    ← 选中 │
  │     ○ 海珠区                           │
  │   ▶ 深圳市                             │
  │ ▶ 湖南省                               │
  ├────────────────────────────────────────┤
  │ [+ 新建分组]       [取消]    [确定]    │
  └────────────────────────────────────────┘
```

### 步骤 8: 开站 (Commission)

```
操作:
  - 设备在线且参数同步完成后, 可进行开站
  - 设备详情页 → [开站] 按钮
  - 或批量操作: 选中多台设备 → [批量开站]

开站流程:
  1. 检查设备状态 (必须在线)
  2. 检查参数完整性
  3. 执行开站命令
  4. 等待设备响应
  5. 开站成功 → 设备状态变为 "已开站"

错误处理:
  - 设备离线: "设备不在线, 无法开站"
  - 参数不完整: "请先完成参数配置" + 列出缺失项
  - 开站失败: 显示详细错误日志
```

### 步骤 9: 交维 (Handover to Operations)

```
操作:
  - 开站完成后, 将设备正式移交给运维团队
  - 设备详情页 → [交维] 按钮

交维流程:
  1. 填写交维信息 (交维人、运维负责人、交维日期)
  2. 系统自动生成交维报告
  3. 确认交维
  4. 设备状态变为 "已交维" (正常运维状态)

交维后:
  - 设备进入日常运维管理
  - 开始接收告警通知
  - 纳入性能监控
```

## 异常处理汇总

| 步骤 | 可能错误 | 处理方式 |
|------|---------|---------|
| 步骤 3 表单填写 | 字段格式错误 | 行内校验提示 |
| 步骤 4 提交注册 | 名称/IP 重复 | Toast 错误 + 保持表单 |
| 步骤 4 批量导入 | 部分数据格式错误 | 标记错误行, 可选跳过 |
| 步骤 5 设备上线 | 连接超时 | 状态显示 "未连接" + 重连按钮 |
| 步骤 5 设备上线 | 认证失败 | 提示检查认证信息 |
| 步骤 6 参数同步 | 同步失败 | 任务面板显示失败 + 重试 |
| 步骤 8 开站 | 设备忙 | 提示稍后重试 |
| 步骤 8 开站 | 参数不完整 | 列出缺失参数 |

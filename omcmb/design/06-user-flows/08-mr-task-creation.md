# 用户流程: MR 任务创建 (MR Task Creation)

> OMC 统一网管系统 - 用户流程

## 概述

MR (Measurement Report, 测量报告) 任务用于采集无线网络测量数据，用于网络优化分析。流程包括任务创建、配置、下发、数据采集和报表查看。

## 详细步骤

### 步骤 1: 进入 MR 任务列表

```
页面: MR 管理 > MR 任务
路径: /mr/task

页面显示:
  - 已创建的 MR 任务列表
  - 表格列: 任务名称、状态、网元数、采集周期、创建时间、操作
  - 任务状态: 草稿、待下发、已下发、采集中、已停止、已完成

工具栏:
  [新建] [批量启动] [批量停止] [批量删除] [导出]
```

### 步骤 2: 点击新建 MR 任务

```
操作:
  - 点击 [新建] 按钮
  - 打开 MR 任务创建页面 (全页表单, 非弹窗)
  - 或打开步骤向导 Modal

路径: /mr/task/create
```

### 步骤 7: 启动任务

```
操作: 在 MR 任务列表中, 选择已创建的任务 → [启动]

确认对话框:
  ┌──────────────────────────────────────────────┐
  │ 确认启动 MR 任务                              │
  ├──────────────────────────────────────────────┤
  │                                              │
  │ 任务: 广州区域 MR 采集任务                    │
  │ 网元: 5 个                                   │
  │ 采集时间: 2024-01-16 ~ 2024-02-15            │
  │                                              │
  │ 启动后将向所有网元下发 MR 采集配置。            │
  │                                              │
  ├──────────────────────────────────────────────┤
  │                    [取消]    [确认启动]        │
  └──────────────────────────────────────────────┘

启动后:
  - 任务状态变为 "下发中"
  - 开始向网元下发 MR 采集配置
```

### 步骤 8: 同步到网元

```
行为:
  1. MR 任务配置参数下发到各网元
  2. 网元接收配置并开始 MR 数据采集

任务面板:
  ┌──────────────────────────────────────────────┐
  │ 📊 MR 任务下发: 广州区域采集 (5个网元)       │
  │ ████████████████████░░░░  80% (4/5)         │
  │ 当前: 正在下发到 gNodeB-002                  │
  └──────────────────────────────────────────────┘

下发完成:
  - 全部成功: 任务状态变为 "采集中"
  - 部分失败: 任务状态变为 "采集中" + 标记失败网元
  - 全部失败: 任务状态变为 "下发失败" + [重试]

采集中:
  - MR 任务列表显示 "采集中" 状态
  - 网元按配置的周期采集并上传 MR 数据
  - MR 服务器接收并处理数据
```

### 步骤 9: 查看 MR 报表

```
页面: MR 管理 > MR 报表
路径: /mr/report

操作:
  1. 选择 MR 任务
  2. 选择报表类型 (覆盖分析、干扰分析、质量分析等)
  3. 选择时间范围
  4. 查看报表数据 (表格/图表)

报表类型:
  - 覆盖率报表: RSRP 覆盖分布
  - 干扰报表: 干扰电平分布
  - 质量报表: SINR 分布
  - 邻区优化: 基于 MR 数据的邻区建议
  - 弱覆盖分析: 弱覆盖小区识别

报表展示:
  - 表格形式: 小区级 KPI 统计
  - 图表形式: 分布直方图、趋势折线
  - 地图叠加: 覆盖热力图 (未来功能)
```

## 任务生命周期管理

### 任务操作

| 当前状态 | 可执行操作 |
|---------|-----------|
| 草稿 | 编辑、启动、删除 |
| 待下发 | 启动、编辑、删除 |
| 下发中 | 查看进度 |
| 采集中 | 停止、查看报表 |
| 已停止 | 重新启动、删除 |
| 已完成 | 查看报表、删除 |
| 下发失败 | 重试、编辑、删除 |

---

## 异常处理汇总

| 步骤 | 可能异常 | 处理方式 |
|------|---------|---------|
| 步骤 4 MR 服务器 | 连接测试失败 | 红色提示 "连接失败: {原因}" |
| 步骤 5 选择网元 | 网元不在线 | 离线网元标灰, Tooltip "离线" |
| 步骤 6 提交 | 任务名称重复 | "任务名称已存在, 请使用其他名称" |
| 步骤 8 下发 | 部分网元下发失败 | 标记失败网元 + 失败原因 + [重试] |
| 步骤 9 报表 | 无数据 | "所选时间范围内暂无 MR 数据" |

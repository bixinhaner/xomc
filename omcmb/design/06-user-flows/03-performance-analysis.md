# 用户流程: 性能分析 (Performance Analysis)

> OMC 统一网管系统 - 用户流程

## 概述

性能分析流程帮助运维人员通过 KPI 报表监控网络质量、定位性能问题、分析趋势。包括标准报表查询和自定义 KPI 提取两个子流程。

## 流程 A: 标准 KPI 报表查询

### 步骤 1: 选择报表分类

```
页面: 性能管理 > KPI 报表
路径: /performance/kpi-report

页面布局:
┌──────────────┬──────────────────────────────────────┐
│ KPI 分类树   │ 报表内容区域                          │
│              │                                      │
│ ▼ 接入类     │ (选择分类后显示报表)                   │
│   ├ RRC 连接 │                                      │
│   ├ RACH 接入│                                      │
│   └ 寻呼     │                                      │
│ ▼ 移动性     │                                      │
│   ├ 切换     │                                      │
│   └ 重选     │                                      │
│ ▶ 承载类     │                                      │
│ ▶ 流量类     │                                      │
│ ▶ 容量类     │                                      │
│ ▶ 可用性     │                                      │
└──────────────┴──────────────────────────────────────┘

操作:
  - 左侧树: 展开分类 → 点击具体 KPI 分类节点
  - 树支持搜索 (顶部搜索框)
  - 选中节点 → 右侧加载对应报表
```

### 步骤 2: 配置筛选条件

```
筛选栏:
┌────────────────────────────────────────────────────────┐
│ 网元类型: [eNodeB ▾]  粒度: [小时 ▾]                   │
│ 时间范围: [2024-01-14 ~ 2024-01-15]  [近7天] [近30天]  │
│ 网元选择: [已选 5 个网元 ▾]      [查询]  [重置]        │
└────────────────────────────────────────────────────────┘

筛选项说明:
  网元类型: eNodeB / gNodeB / 小区 等
  统计粒度:
    - 15 分钟 (原始)
    - 小时 (按小时聚合)
    - 天 (按天聚合)
  时间范围: 日期选择器 + 快捷预设
  网元选择: 点击打开网元选择对话框 (树+搜索)

点击 [查询] → 发起请求 → 表格 Loading → 数据展示
```

### 步骤 5: 导出数据/图表

```
导出方式:

A. 导出表格数据:
   工具栏 [导出 ▾] → 选择 Excel/CSV
   导出范围: 当前筛选结果

B. 导出图表为图片:
   图表右上角 📸 图标 → 导出 PNG/SVG
   自动包含标题和图例

C. 导出图表原始数据:
   图表右上角 📤 图标 → 导出对应的数据 (Excel)
```

## 异常处理汇总

| 步骤 | 可能异常 | 处理方式 |
|------|---------|---------|
| 步骤 2 筛选查询 | 时间范围过大 | 提示 "时间范围不能超过 90 天" |
| 步骤 2 筛选查询 | 无数据 | 表格空状态: "该时间范围内无数据" |
| 步骤 3 查看数据 | 数据加载超时 | Toast 错误 + [重试] |
| 步骤 5 导出 | 数据量大导出慢 | 转为异步任务, 任务面板跟踪 |
| KPI 提取步骤 3 | 网元不存在 | 手动输入模式下提示 "网元不存在" |
| KPI 提取步骤 4 | 提取超时 | 自动转为后台任务 + 通知 |

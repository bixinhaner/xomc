# 用户流程: 参数配置 (Parameter Configuration)

> OMC 统一网管系统 - 用户流程

## 概述

参数配置流程覆盖设备参数的查看、修改和下发。支持单设备实时配置、按分类批量配置、按模板批量配置和常用配置页面等多种配置方式。

## 方式 A: 实时参数配置 (单设备)

### 步骤 1: 选择设备

```
页面: 配置管理 > 参数配置
路径: /config/parameter

页面布局:
┌──────────────┬──────────────────────────────────────┐
│ 设备/网元树   │ 参数配置区域                          │
│              │                                      │
│ 🔍搜索...    │ (选择网元后显示参数)                   │
│ ▼ 广州       │                                      │
│   ▼ eNB-001  │                                      │
│     Cell-0   │                                      │
│     Cell-1   │                                      │
│     Cell-2   │                                      │
│   ▶ eNB-002  │                                      │
│ ▶ 深圳       │                                      │
└──────────────┴──────────────────────────────────────┘

操作:
  - 左侧树: 展开到具体网元/小区级别
  - 点击网元节点 → 右侧加载该网元的参数数据
  - 加载中: 显示 Skeleton 骨架屏
```

### 步骤 2: 查看和修改参数

```
参数配置区域:

  Tab 分类: [基本参数] [射频参数] [邻区参数] [传输参数] [高级参数]

  ┌────────────────────────────────────────────────────┐
  │ 基本参数                                           │
  │                                                    │
  │ 小区标识 (CELLID):    0           (只读)           │
  │ 小区名称 (CELLNAME):  [Cell-0          ]           │
  │ 频点 (EARFCN):        [38400     ▾]               │
  │ 带宽 (BANDWIDTH):     [20MHz     ▾]               │
  │ PCI:                  [123            ]            │
  │ TAC:                  [12345          ]            │
  │                                                    │
  │ ── 发射功率 ──                                     │
  │ 下行发射功率 (TXPWR):  [43       ] dBm            │
  │ RS 功率 (RSPWR):       [15.2     ] dBm            │
  │                                                    │
  │ 修改标记: ● 2 个参数已修改                          │
  │                                                    │
  │ [还原修改]  [对比差异]  [保存并下发]                 │
  └────────────────────────────────────────────────────┘

交互:
  - 只读参数: 灰色背景, 不可编辑, Tooltip "系统参数, 不可修改"
  - 可编辑参数: 正常输入框
  - 修改后: 输入框左侧出现蓝色标记条
  - [对比差异]: 弹出对话框显示修改前后对比
  - [还原修改]: 恢复为原始值
  - [保存并下发]: 提交修改, 创建同步任务
```

### 步骤 3: 对比差异 (可选)

```
  ┌──────────────────────────────────────────────────┐
  │ 参数修改对比                                [X] │
  ├──────────────────────────────────────────────────┤
  │                                                  │
  │  参数名           修改前        修改后           │
  │  ─────────────    ─────────    ─────────         │
  │  下行发射功率      40 dBm       43 dBm     ← 蓝  │

  │  共 2 项修改                                     │
  │                                                  │
  ├──────────────────────────────────────────────────┤
  │                 [返回编辑]    [确认下发]           │
  └──────────────────────────────────────────────────┘
```

## 方式 B: 按分类批量配置

### 步骤 1: 选择参数分类

```
页面: 配置管理 > 批量配置 > 按分类
路径: /config/batch-by-category

操作:
  1. 选择网元类型 (如 eNodeB)
  2. 选择参数分类 (如 "射频参数 > 发射功率")
  3. 系统加载该分类下所有参数的设备对比表
```

### 步骤 2: 查看多设备参数对比

```
┌──────────────────────────────────────────────────────────┐
│ 射频参数 - 发射功率                                       │
│ 网元类型: eNodeB  参数分类: 射频参数 > 发射功率            │
├──────────────────────────────────────────────────────────┤
│          │ eNB-001  │ eNB-002  │ eNB-003  │ eNB-004    │
│          │ Cell-0   │ Cell-0   │ Cell-0   │ Cell-0     │
├──────────┼──────────┼──────────┼──────────┼────────────┤
│ TXPWR    │ [43]     │ [40]     │ [43]     │ [40]       │
│ RSPWR    │ [15.2]   │ [12.2]   │ [15.2]   │ [12.2]    │
│ MAXPWR   │ [46]     │ [46]     │ [46]     │ [46]       │
└──────────┴──────────┴──────────┴──────────┴────────────┘

功能:
  - 横向对比多设备同类参数
  - 可直接在单元格中修改参数值
  - 修改后单元格高亮标记
  - 支持 "复制到所有" (将一个值应用到同行所有设备)
  - [保存并下发] 批量提交修改
```

## 方式 C: 按模板批量配置

### 步骤 1: 选择或创建模板

```
页面: 配置管理 > 批量配置 > 按模板
路径: /config/batch-by-template

操作:
  1. 从模板列表选择已有模板
  2. 或 [新建模板] 创建配置模板

模板内容:
  - 模板名称: "标准宏站配置模板"
  - 参数集: 一组预定义的参数值
  - 适用设备类型: eNodeB
```

### 步骤 2: 选择目标设备

```
  ┌──────────────────────────────────────────────┐
  │ 应用配置模板                            [X] │
  ├──────────────────────────────────────────────┤
  │                                              │
  │ 模板: 标准宏站配置模板                        │
  │ 参数数量: 15 个                              │
  │                                              │
  │ 选择目标设备:                                │
  │ (3 种选择方式与 MR 任务创建类似)              │
  │                                              │
  │ 已选: 10 台设备                              │
  │                                              │
  │ ☑ 下发前预览参数差异                         │
  │                                              │
  ├──────────────────────────────────────────────┤
  │                   [取消]    [预览并下发]      │
  └──────────────────────────────────────────────┘
```

### 步骤 3: 预览差异并下发

```
差异预览 (勾选预览选项时):
  显示每台设备的参数当前值与模板值的差异
  用户确认后 → 创建批量同步任务
```

## 通用步骤: 提交同步任务

### 提交流程

```
用户点击 [保存并下发] / [确认下发]:

  1. 前端校验参数合法性
  2. 弹出确认对话框:
     ┌──────────────────────────────────────────────┐
     │ 确认下发配置                                  │
     ├──────────────────────────────────────────────┤
     │                                              │
     │ 将向 {N} 台设备下发 {M} 个参数修改。          │
     │                                              │
     │ ⚠ 参数修改可能影响设备正常运行, 请确认!       │
     │                                              │
     ├──────────────────────────────────────────────┤
     │                    [取消]    [确认下发]        │
     └──────────────────────────────────────────────┘

  3. 确认 → 创建同步任务 → Toast "同步任务已创建"
  4. 任务面板显示同步进度
```

## 通用步骤: 监控同步进度

### 任务面板

```
  ┌──────────────────────────────────────────────┐
  │ 🔄 参数同步 (10台设备, 15个参数)             │
  │ ████████████████░░░░░░  60% (6/10)          │
  │ 当前: 正在同步 eNodeB-007                    │
  │                          [暂停]  [终止]      │
  └──────────────────────────────────────────────┘
```

### 同步完成验证

```
验证方式:
  1. 任务面板: 检查同步结果 (成功/失败明细)
  2. 参数查询: 重新加载设备参数, 确认值已更新
  3. 告警检查: 确认无参数修改引起的新告警

同步失败处理:
  - 查看失败原因 (设备离线、参数冲突、权限不足等)
  - [重试] 对失败设备重新同步
  - 或手动回退参数 (恢复修改前的值)
```

## 异常处理汇总

| 步骤 | 可能异常 | 处理方式 |
|------|---------|---------|
| 加载参数 | 设备不在线 | 显示缓存参数 (只读) + 提示 "设备离线, 显示缓存数据" |
| 修改参数 | 参数值超出范围 | 行内校验: "值必须在 {min}-{max} 之间" |
| 同步下发 | 设备离线 | 同步失败 + 提示 "设备离线" |
| 同步下发 | 参数冲突 | 提示具体冲突项 + 建议 |
| 同步下发 | 设备拒绝 | 显示设备返回的拒绝原因 |
| 批量配置 | 部分设备失败 | 结果汇总: 成功 N 台, 失败 M 台 + 明细 |

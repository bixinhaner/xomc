# Wizard Page 向导页

## 线框
```
┌────────┬──────────────────────────────┐
│ Steps  │ Step Content Area             │
│        │                               │
│ ● 选指标│ (当前步骤的表单/选择器/结果)   │
│ ○ 选网元│                               │
│ ○ 设时间│                               │
│ ○ 查结果│                               │
│        ├──────────────────────────────┤
│        │ [上一步]         [下一步] [取消]│
└────────┴──────────────────────────────┘
```

## 规格
- 左侧步骤指示器: 固定宽度 200px
- 步骤间连接线: 垂直虚线
- 底部导航栏: 固定在底部
- 第一步隐藏"上一步"，最后一步"下一步"变"完成"

## 使用模块
性能指标提取（4 步向导）。

# Command Console Page MML 控制台

## 线框
```
┌──────────┬──────────┬───────────────────┐
│ Device   │ Command  │ Execution Panel    │
│ Selector │ Detail   │ (50%)              │
│ (25%)    │ (25%)    │                    │
│          │          │ [控制面板|参数命令]  │
│ [搜索SN] │ 产品类型 │                    │
│ SN 表格  │ 命令功能 │ 操作类型: [LST ▾]  │
│          │ 注意事项 │ 参数路径:           │
│ ──────── │          │ [________] [+][-]  │
│ MML 树   │ 参数卡片:│ [________] [+][-]  │
│ ▶ eNB配置│ · 类型   │                    │
│ ▶ 射频   │ · 范围   │                    │
│ ▶ 自定义 │ · 默认值 │ [执行(DO)] [保存]   │
└──────────┴──────────┴───────────────────┘
```

## 规格
- 三栏: 6 + 6 + 12 栏 (25% + 25% + 50%)
- 左栏分上下: 上=设备选择表格，下=MML 命令树
- 中栏: 命令详情卡片 + 参数卡片列表
- 右栏: 执行面板 + 结果区域

## 使用模块
MML 命令控制台（OMC 专有功能）。

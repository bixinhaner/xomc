# Split Panel Page 上下分屏

## 线框
```
┌──────────────────────────────────────────┐
│ 上方面板 (60%)                            │
│ 主数据表格或设备列表                        │
│                                           │
├═══════════════════════════════════════════┤ ← 可拖拽分隔条
│ 下方面板 (40%)                            │
│ 次要表格、日志或详情                        │
│ [单任务] [批量任务] [导出]                  │
└──────────────────────────────────────────┘
```

## 规格
- 分隔条: 4px 高度，悬浮时显示拖拽光标
- 上方默认 60%，下方 40%
- 上方最小 30%，下方最小 20%
- 下方可折叠（收起为标题栏）

## 使用模块
MML 脚本（任务列表 + 执行结果）、License（设备列表 + 日志）、备份（设备 + 任务）。

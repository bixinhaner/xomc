# Dashboard Page 仪表盘

## 线框
```
┌──────────┬──────────┬──────────┬──────────┐
│ 📱 设备  │ 📡 小区  │ 🔧 EU    │ 📻 RU    │
│ 1,284 ↑  │ 2,568 ↑  │ 640 →    │ 1,280 ↓  │
├──────────┴──────────┴──────────┴──────────┤
│ [紧急: 12] [主要: 45] [次要: 89] [警告: 234]│
├─────────────┬─────────────┬───────────────┤
│ 在线/离线    │ 告警分布     │ 告警趋势      │
│ [柱状图]     │ [饼图]      │ [折线图]      │
├─────────────┼─────────────┼───────────────┤
│ 网格状态     │ 设备地图     │ 历史告警      │
│ [仪表盘]     │ [小地图]     │ [柱状图]      │
└─────────────┴─────────────┴───────────────┘
```

## 规格
- KPI 卡片行: 4 个等宽卡片 (各 6/24 栏)
- 告警摘要行: 全宽条
- 图表区: 2 行 × 3 列 (各 8/24 栏)
- 图表卡片间距: `space-4` (16px)
- 每个图表卡片含: 标题栏 + 图表内容 + 控制按钮

## 使用模块
Dashboard 首页、告警统计页、系统管理首页。

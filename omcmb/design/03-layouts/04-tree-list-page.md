# Tree-List Page 左树右列表

## 线框
```
┌──────────┬────────────────────────────────┐
│ Tree     │ [筛选栏]                        │
│ Panel    ├────────────────────────────────┤
│ (25%)    │ [工具栏]                        │
│          ├────────────────────────────────┤
│ [搜索..] │ ┌──┬──────┬──────┬──────────┐ │
│ ▶ 节点1  │ │☐│ 列1  │ 列2  │ 操作     │ │
│  ▶ 子项  │ │☐│ ...  │ ...  │ 编辑 删除│ │
│ ▶ 节点2  │ └──┴──────┴──────┴──────────┘ │
│ ▶ 节点3  ├────────────────────────────────┤
│          │ [分页]                          │
└──────────┴────────────────────────────────┘
```

## 规格
- 左侧面板: 25% 宽度 (6/24栏)，可拖拽调整
- 右侧面板: 75% 宽度 (18/24栏)
- 中间分隔条: 2px，可拖拽
- 左侧面板最小宽度: 200px
- 左侧面板最大宽度: 400px

设备分组、配置参数、性能报表、MR 分类、文件管理、报表统计、运维工具。

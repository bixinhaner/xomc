# List Page 列表页

## 概述
最常用的页面布局（约 60% 的页面），由筛选栏、工具栏、数据表格和分页组成。

## 线框
```
┌──────────────────────────────────────────┐
│ [Tab Bar] (可选)                          │
├──────────────────────────────────────────┤
│ [名称:___] [SN:___] [状态:▾] [展开][搜索][重置]│
├──────────────────────────────────────────┤
│ [批量操作▾] [导出▾] [新建]    [隐藏列▾] [⟳]│
├──┬────────┬────────┬────────┬───────────┤
│☐ │ 列1 ↕  │ 列2 ↕  │ 列3    │ 操作      │
├──┼────────┼────────┼────────┼───────────┤
│☐ │ ...    │ ...    │ ...    │ 编辑 删除  │
│☐ │ ...    │ ...    │ ...    │ 编辑 删除  │
│☐ │ ...    │ ...    │ ...    │ 编辑 删除  │
├──┴────────┴────────┴────────┴───────────┤
│ 共100条  10条/页  < 1 2 3 ... > 跳至     │
└──────────────────────────────────────────┘
```

## 区域说明
| 区域 | 组件 | 说明 |
|------|------|------|
| Tab Bar | Tabs | 可选，页面内切换视图 |
| 筛选栏 | FilterBar | 1-3 行可展开筛选 |
| 工具栏 | Toolbar | 左: 批量操作；右: 表格控制 |
| 数据表 | DataTable | 核心内容区域 |
| 分页 | Pagination | 底部分页控制 |

## 使用模块
设备列表、告警列表(当前/历史)、小区列表、基线列表、版本列表、文件列表、日志列表、模板列表、任务列表等。

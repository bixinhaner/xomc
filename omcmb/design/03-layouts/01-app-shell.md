# App Shell 应用外壳

## 概述
整个系统的最外层布局容器，包含 Header、Sidebar、内容区和任务面板。

## 线框
```
┌──────────────────────────────────────────────────────────────┐
│  Header (48px, 固定)                                          │
│  [Logo OMC]                    [紧急:12][主要:45] [🔔] [admin▾]│
├─────────┬────────────────────────────────────────────────────┤
│ Sidebar │  [Dashboard ×] [当前告警 ×] [设备列表 ×]            │
│ (240px) ├────────────────────────────────────────────────────┤
│ 固定    │                                                     │
│         │  Content Area                                       │
│ [eNB ▾] │  padding: 16px 24px                                │
│ ────── │  background: #FAFAFA                                │
│ 📊 首页 │                                                     │
│ 📱 设备 │  (各页面内容在此渲染)                                  │
│ 🔔 告警 │                                                     │
│ ...    │                                                     │
│         ├────────────────────────────────────────────────────┤
│ [◀]    │  Task Panel (40px 收起 / 240px 展开)                │
│ v1.0   │  [任务 (3)] [单任务|批量|导出]                        │
└─────────┴────────────────────────────────────────────────────┘
```

## 尺寸规格
| 区域 | 尺寸 | z-index |
|------|------|---------|
| Header | 高 48px, 全宽, 固定顶部 | 100 |
| Sidebar | 宽 240/48px, 全高-48px, 固定左侧 | 100 |
| 二级栏 | 高 40px, 可选 | 10 |
| 内容区 | 流式, padding 16px 24px | 0 |
| 任务面板 | 高 40/240px, 固定底部 | 200 |

## 响应行为
- ≥ 1200px: Sidebar 展开
- 992-1199px: Sidebar 自动收起
- < 992px: Sidebar 隐藏，汉堡菜单触发

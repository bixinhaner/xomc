# 关键设计决策 (Design Decisions)

## 决策 1: 蓝色 (#1677FF) 作为主色调

**决策**: 采用蓝色 `#1677FF` 替代 OMC 的橙色和 Comba 的蓝色渐变。

**理由**:
- 三套系统中有两套使用蓝色系（Comba UMS、广研院），蓝色是电信行业主流色调
- 蓝色传达专业、可靠、技术感，契合 B2B 企业级定位
- 与告警等级色彩（红/橙/黄）不冲突，避免颜色语义混淆
- Ant Design 默认主色即为蓝色，减少定制成本

## 决策 2: 深色侧边栏 + 亮色内容区

**决策**: 侧边栏使用深蓝色 `#001529`，内容区使用浅灰 `#FAFAFA`。

**理由**:
- 深色侧边栏提供稳定的导航锚点，与内容区形成清晰对比
- 是 B2B 后台系统的行业标准模式（Ant Design Pro、飞书管理后台等）
- 深色背景下的白色文字有良好可读性
- 亮色内容区保证数据表格、图表的最佳可读性

## 决策 3: 统一 4 级告警色彩 (YD/T 标准)

**决策**: 采用 紧急(红 `#F5222D`) / 主要(橙 `#FA8C16`) / 次要(黄 `#FAAD14`) / 警告(蓝 `#1890FF`)。

**理由**:
- 遵循中国电信行业 YD/T 标准，运维工程师已形成认知习惯
- 广研院和 Comba UMS 均使用此分级方案
- 红→橙→黄的严重程度渐变直观自然
- 警告级使用蓝色而非绿色，避免与"��线/正常"状态色混淆

## 决策 4: 设备类型作为全局上下文（非导航层级）

**决策**: 将设备类型（eNB/gNB/CPE/eGW）从 OMC 的二级导航降为全局上下文筛选器。

**理由**:
- OMC 的 3 层导航（系统→设备类型→功能）导致层级过深
- 设备类型更像是数据维度而非功能模块
- 放在侧边栏顶部作为全局筛选器，切换后所有模块数据自动过滤
- 简化导航到 2 层（侧边栏模块→子页面），降低认知负担

## 决策 5: 全局持久任务面板

**决策**: 在页面底部设置全局持久的任务跟踪面板，所有模块共享。

**理由**:
- 长时任务（参数同步、软件升级、文件导出、MML 脚本）贯穿多个模块
- Comba UMS 的底部任务栏模式经验证有效
- 用户在操作一个模块时可能需要监控另一个模块的任务进度
- 全局面板避免了在每个模块重复构建任务跟踪 UI

## 决策 6: 多标签页工作空间

**决策**: 支持可关闭的页面标签栏，允许同时打开多个页面。

**理由**:
- 来自 OMC 系统的成功模式
- 运维工程师常需要在多个页面间快速切换（如同时查看告警和设备详情）
- 最多 10 个标签，超出时提供下拉菜单
- 支持关闭单个/关闭其他/关闭所有操作

## 决策 7: 可展开的筛选栏

**决策**: 默认显示 1 行（4-7 个常用筛选项），点击"展开"显示 2-3 行完整筛选项。

**理由**:
- 融合广研院的展开/收起模式和 OMC 的"Add Filter"灵活性
- 默认展示最常用筛选项，减少视觉噪音
- 高级用户可展开查看全部筛选条件
- 搜索和重置按钮始终可见

## 决策 8: 统一数据表格组件

**决策**: 合并三套系统的表格最佳实践为一个统一组件。

**来源融合**:
- OMC: 列筛选功能（Add Filters 按钮）、排序指示器
- Comba UMS: 行状态着色（左侧彩色边框）、列头漏斗图标筛选
- 广研院: 列显示/隐藏下拉、批量操作下拉

## 决策 9: 三模式设备/网元选择器

**决策**: 提供"按网元表格/按分类树/按模板"三种选择模式的统一设备选择器。

**理由**:
- Comba UMS 的三种选择模式覆盖了所有场景
- 按网元: 直接搜索和勾选，适合精确选择
- 按分类: 按区域/类型/厂商等 8 个维度树形筛选，适合批量选择
- 按模板: 使用预定义模板，适合重复操作

## 决策 10: 中文优先双语设计

**决策**: PingFang SC 作为首选字体，所有文本外置支持国际化，布局预留英文展开空间。

**理由**:
- 目标用户以中文为主
- 需支持英文切换（参考 OMC 系统为英文界面）
- 英文文本通常比中文长 50-80%，按钮最小宽度设为 64px
- 侧边栏菜单文本超出时截断+Tooltip

## 决策 11: Ant Design 作为��础组件库

**决策**: 推荐使用 Ant Design 5.x (React) 作为基础 UI 组件库。

**理由**:
- 中文生态最大，社区活跃，文档完善
- 24 栏栅格系统，与我们的布局设计完全匹配
- 表格、表单、树等核心组件功能强大
- 支持 CSS-in-JS 主题定制，可精确匹配设计 Token
- Pro Components 提供高级业务组件

## 决策 12: 1200px 最小视口

**决策**: 系统以 1200px+ 桌面端为主要目标，不要求完整移动端适配。

**理由**:
- 网管系统是纯桌面端应用，运维工程师使用固定工位
- 数据密集型界面在小屏上无法有效展示
- 低于 1200px 时侧边栏自动收起
- 低于 992px 时筛选栏垂直堆叠

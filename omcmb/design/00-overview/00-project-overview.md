# 项目总览 (Project Overview)

## 项目名称

**OMC 统一网管系统** (Unified Network Management System)

## 项目目标

基于对三套现有电信网管系统 UI 的深度分析（427 张截图、17 个功能模块），设计一套全新的、统一的网管系统 UI。融合三套系统的最佳实践，采用现代 B2B 企业级设计语言，为中国电信运维工程师提供高效、专业的操作界面。

## 目标用户

- **角色**: 电信运维工程师（O&M Engineers）
- **职责**: 管理 4G/5G 小基站（Small Cell）、网元（NE）、告警、性能、配置
- **工作环境**: 台式机/笔记本/平板/手机，响应式适配 xs(<576px) ~ xl(≥1200px) 全断点
- **语言**: 中文为主，需支持英文切换
- **技能**: 熟悉电信网管概念、MML 命令、网络拓扑

## 设计原则

### 1. 数据密集但不杂乱 (Data-Dense yet Clean)
- 网管系统天然需要展示大量数据（表格、图表、参数）
- 通过清晰的视觉层级、合理的留白、一致的排版来保持可读性
- 避免不必要的装饰元素，让数据本身成为主角

### 2. 专业 B2B 企业级 (Professional B2B Enterprise)
- 默认蓝色主色调，沉稳专业；支持 7 套视觉主题按需切换
- 深色侧边栏提供导航锚点，支持左/右/顶部三种布局
- 严谨的栅格系统和间距规范
- 一致的组件风格和交互模式

### 3. 高效操作 (Efficient Operations)
- 减少点击次数，支持批量操作
- 全局任务面板跟踪长时操作
- 可定制的筛选条件和列显示
- 键盘快捷键支持

### 4. 容错与引导 (Error-Tolerant & Guided)
- 清晰的操作反馈（成功/失败/进行中）
- 危险操作需二次确认
- 表单实时校验
- 空状态提供操作引导

### 5. 多主题视觉体系 (Multi-Theme Visual System)
- 提供 7 套完整视觉主题（Classic / Tech / Fresh / Cyberpunk / Minions / Tiffany / RMB）
- 每套主题包含独立配色、字体、CSS 特效和 Ant Design 组件覆盖
- 可选 3D 视觉特效系统（粒子动画、动态光源、倾斜卡片、浮动元素），通过设置开关控制
- 尊重 `prefers-reduced-motion` 无障碍设置

### 6. 响应式与多端适配 (Responsive & Multi-Device)
- 5 级断点体系：xs(<576px)、sm(576px)、md(768px)、lg(992px)、xl(≥1200px)
- 移动端抽屉导航、触控目标 ≥ 44×44px
- 平板端侧边栏自动折叠
- 触控设备自动禁用悬浮 3D 变换

## 主题系统

系统内置 7 套完整视觉主题，每套主题包含独立的配色方案、Google Fonts 字体和 CSS 特效：

| 主题 | 风格 | 主色 | 适用场景 |
|------|------|------|---------|
| Classic | 商务蓝 | `#1677FF` | 企业正式环境 |
| Tech | 深色科技 | 蓝色系深色底 | 技术运营中心 |
| Fresh | 清新明亮 | 绿蓝系 | 现代化轻量界面 |
| Cyberpunk | 赛博朋克 | `#00F5FF` | 沉浸式科技体验 |
| Minions | 活泼卡通 | 黄蓝系 | 趣味友好界面 |
| Tiffany | 轻奢优雅 | 蒂芙尼蓝 | 高端精致场景 |
| RMB | 中国红金 | `#F5222D` | 中国市场定制 |

**3D 视觉特效系统**：可选的粒子系统 (ParticleCanvas)、动态光源 (DynamicLightSource)、3D 倾斜卡片 (TiltCard)、浮动动画 (FloatingElement)，按主题配置不同预设，通过 `effects3DEnabled` 开关控制。

## 实现进展

项目前端代码位于 `webcode/` 目录，当前已实现：

- **全模块页面**: 17 个功能模块的页面路由与基础 UI 均已搭建，含 50+ 独立页面
- **Mock 数据体系**: 15+ 个 Mock 服务、30+ 组 Mock 数据集，模拟真实 API 响应（含分页、筛选、延迟）
- **WebSocket 模拟**: 告警实时推送 (alarmWebSocket) 与后台任务进度更新 (taskWebSocket)
- **状态管理**: Zustand 持久化存储（主题、语言、侧边栏、设备类型等），React Query 管理服务端状态
- **国际化**: zh-CN / en-US 完整双语消息文件
- **响应式适配**: 移动端抽屉导航、平板自动折叠侧边栏、触控设备优化
- **7 套视觉主题**: 含主题专属 CSS 特效文件与 Google Fonts 字体预加载
- **3D 特效系统**: 粒子画布 (24fps)、动态光源、倾斜卡片、浮动动画，支持按主题配置预设

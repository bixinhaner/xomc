# 键盘快捷键 (Keyboard Shortcuts)

> OMC 统一网管系统 - 交互设计规范

## 概述

键盘快捷键提高专业用户的操作效率。OMC 系统定义全局快捷键、表格快捷键、表单快捷键和导航快捷键，确保快捷键不与浏览器和操作系统冲突。

---

## 1. 全局快捷键 (Global Shortcuts)

### 1.1 快捷键列表

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + /` | 切换侧边栏 | 展开/折叠侧边栏导航 |
| `Ctrl + K` | 命令面板 (未来) | 全局搜索命令面板 |
| `ESC` | 关闭弹窗/Drawer | 关闭最顶层的 Modal 或 Drawer |
| `F5` / `Ctrl + R` | 刷新数据 | 刷新当前页面数据 (非浏览器刷新) |
| `?` | 显示快捷键帮助 | 弹出快捷键速查面板 (需无输入框聚焦) |

### 1.2 侧边栏切换

```
Ctrl + / (Windows/Linux)
Cmd + / (macOS)

行为:
  - 侧边栏展开 → 折叠为图标模式 (64px)
  - 侧边栏折叠 → 展开为完整模式 (240px)
  - 动画: width transition 200ms ease-out
```

### 1.3 命令面板 (未来功能)

```
Ctrl + K → 打开命令面板:

┌─────────────────────────────────────────────────┐
│ 🔍 输入命令或搜索...                             │
├─────────────────────────────────────────────────┤
│ 最近访问                                         │
│   📄 设备列表                            Ctrl+1  │
│   📄 当前告警                            Ctrl+2  │
│   📄 KPI 报表                                    │
│ ────────────────────────────────────────────── │
│ 操作                                             │
│   ➕ 新建设备                                     │
│   📤 导出当前数据                                 │
│   🔄 刷新数据                            F5      │
└─────────────────────────────────────────────────┘

功能:
  - 快速导航到任何页面
  - 执行常用操作
  - 搜索设备/告警等数据
  - 键盘 ↑↓ 导航, Enter 确认, ESC 关闭
```

## 2. 表格快捷键 (Table Shortcuts)

### 2.1 快捷键列表

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + A` | 全选当前页 | 选中表格当前页所有行 |
| `Delete` / `Backspace` | 删除选中 | 删除选中的行 (需确认对话框) |
| `Ctrl + C` | 复制 | 复制选中行的关键信息 (如设备名称) |
| `Ctrl + E` | 导出 | 打开导出对话框 |
| `Enter` | 查看详情 | 打开选中行的详情 (等同于双击) |

### 2.2 行为规范

```
Ctrl + A:
  - 选中当前页所有行
  - 不选中其他页 (除非之前已勾选"全量选择")
  - 触发已选计数更新

Delete:
  - 无选中 → 无反应
  - 有选中 → 弹出删除确认对话框
  - 确认后 → 执行批量删除

前提: 表格区域获得焦点时才生效
```

## 3. 表单快捷键 (Form Shortcuts)

### 3.1 快捷键列表

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Tab` | 下一个字段 | 焦点移动到下一个输入字段 |
| `Shift + Tab` | 上一个字段 | 焦点移动到上一个输入字段 |
| `Enter` | 提交/下一步 | 在最后字段按 Enter 提交表单 |
| `Ctrl + Enter` | 强制提交 | 在 Textarea 中提交 (Enter 用于换行) |
| `ESC` | 取消/关闭 | 取消表单编辑或关闭弹窗 |
| `Ctrl + S` | 保存 | 保存当前表单 (阻止浏览器默认行为) |
| `Ctrl + Z` | 撤销 | 撤销最后一次修改 (浏览器原生) |

### 3.2 Tab 顺序规范

```
Tab 顺序遵循视觉布局:
  1. 从上到下
  2. 从左到右 (多列布局)
  3. 跳过 disabled 和 readonly 字段
  4. 跳过不可见 (折叠区域内) 的字段

自定义 Tab 顺序: 使用 tabIndex 属性
```

## 5. 键盘焦点指示器 (Focus Indicators)

### 5.1 焦点样式

```
所有可交互元素在获得键盘焦点时必须有可见的焦点指示:

焦点样式:
  outline: 2px solid @primary-color (#1890FF)
  outline-offset: 2px

按钮焦点:
  ┌──────────────────┐
  │ ┌──────────────┐ │  ← 2px 蓝色外框
  │ │   保 存      │ │
  │ └──────────────┘ │
  └──────────────────┘

输入框焦点:
  ┌──────────────────────────────┐
  │ ┌──────────────────────────┐ │  ← 蓝色边框 + 外发光
  │ │ 输入内容                  │ │
  │ └──────────────────────────┘ │
  └──────────────────────────────┘
  box-shadow: 0 0 0 2px rgba(24, 144, 255, 0.2)
```

### 5.2 焦点规范

```
规则:
  - 只在键盘导航时显示焦点指示 (非鼠标点击)
  - 使用 :focus-visible 伪类 (区分键盘焦点和鼠标焦点)
  - 焦点颜色不能与背景色相同 (确保可见)
  - Tab 焦点顺序必须逻辑合理
  - Modal 打开时焦点限制在 Modal 内 (focus trap)
  - Modal 关闭后焦点回到触发元素

CSS 实现:
  /* 只对键盘焦点显示 */
  :focus-visible {
    outline: 2px solid #1890FF;
    outline-offset: 2px;
  }

  /* 鼠标焦点不显示 outline */
  :focus:not(:focus-visible) {
    outline: none;
  }
```

## 7. 快捷键冲突避免

### 7.1 保留快捷键 (不可覆盖)

```
浏览器保留:
  Ctrl + T     新标签页
  Ctrl + W     关闭标签页
  Ctrl + L     地址栏
  Ctrl + F     浏览器搜索
  Ctrl + P     打印
  Ctrl + N     新窗口
  F12          开发者工具

操作系统保留 (macOS):
  Cmd + Q      退出应用
  Cmd + H      隐藏窗口
  Cmd + Tab    切换应用
```

### 7.2 自定义快捷键规则

```
规则:
  - 不覆盖浏览器和系统保留快捷键
  - 使用 Ctrl (Windows) / Cmd (macOS) 作为修饰键
  - 单字母快捷键 (如 ?) 只在无输入框聚焦时生效
  - 快捷键在 Modal 内时, 部分全局快捷键失效 (如 /)
  - 所有快捷键可通过设置面板查看
```

## 8. 实现参考

### 快捷键注册

```typescript
// 推荐: 使用 react-hotkeys-hook
import { useHotkeys } from 'react-hotkeys-hook';

// 全局: 切换侧边栏
useHotkeys('ctrl+/', (e) => {
  e.preventDefault();
  toggleSidebar();
}, { enableOnFormTags: false });

// 表格: 全选
useHotkeys('ctrl+a', (e) => {
  e.preventDefault();
  selectAllRows();
}, { enableOnFormTags: false });

// 表单: 保存
useHotkeys('ctrl+s', (e) => {
  e.preventDefault();
  form.submit();
}, { enableOnFormTags: true });
```

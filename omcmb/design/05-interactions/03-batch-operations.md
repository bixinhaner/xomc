# 批量操作 (Batch Operations)

> OMC 统一网管系统 - 交互设计规范

## 概述

批量操作允许用户一次对多条记录执行相同操作，是网管系统的高频功能。批量操作流程需要清晰的选择反馈、操作确认和结果通知。

---

## 1. 选择模式

### 1.1 Checkbox 选择

```
┌────────────────────────────────────────────────────────────────────┐
│ [☐] 全选  │  设备名称      │  IP 地址        │  状态    │  操作  │
├────────────────────────────────────────────────────────────────────┤
│ [☑]       │  eNodeB-001    │  192.168.1.101  │  在线    │  ...   │
│ [☑]       │  eNodeB-002    │  192.168.1.102  │  在线    │  ...   │
│ [☐]       │  eNodeB-003    │  192.168.1.103  │  离线    │  ...   │
│ [☑]       │  eNodeB-004    │  192.168.1.104  │  在线    │  ...   │
│ [☐]       │  eNodeB-005    │  192.168.1.105  │  在线    │  ...   │
└────────────────────────────────────────────────────────────────────┘
```

### 1.2 选择交互

| 操作 | 行为 |
|------|------|
| 点击单个 Checkbox | 选中/取消选中该行 |
| 点击表头全选 Checkbox | 选中/取消选中当前页所有行 |
| Shift + 点击 Checkbox | 范围选择 (从上次选中到当前点击之间的所有行) |
| Ctrl/Cmd + 点击 Checkbox | 追加/取消选中单行 (不影响其他选中项) |

### 1.3 全选状态

```
表头 Checkbox 三态:
  [☐] 未选中: 当前页无任何选中
  [☑] 全选:   当前页所有行都已选中
  [▣] 半选:   当前页部分行选中 (indeterminate)
```

## 2. 批量操作工具栏

### 2.1 工具栏出现条件

```
选中 0 项: 工具栏隐藏 (或显示但按钮禁用)
选中 ≥ 1 项: 工具栏显示，带选中计数

推荐方案: 工具栏始终可见，选中后激活操作按钮
```

### 2.2 工具栏布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 已选择 3 项  [批量删除] [批量导出] [批量同步] [更多操作 ▾]  [取消选择] │

布局:
  左侧: 选中计数 Badge (蓝色背景 + 白色文字)

  右侧: [更多操作 ▾] Dropdown (低频操作)
```

## 6. 跨页选择

### 6.1 场景说明
用户在分页表格中需要选择跨越多页的数据记录。

### 6.2 交互方案

```
方案: 记忆选择 + 全量选择提示

1. 用户在第 1 页选中 3 项
2. 翻到第 2 页，之前的选中状态保持
3. 在第 2 页继续选中 2 项
4. 工具栏显示: "已选择 5 项 (跨 2 页)"

全量选择:
  当用户点击全选 Checkbox 时:
  ┌─────────────────────────────────────────────────────────┐
  │ 已选中当前页 20 项。 [选择全部 156 项匹配记录]           │
  └─────────────────────────────────────────────────────────┘
```

### 6.3 数据结构

```typescript
interface BatchSelection {
  mode: 'partial' | 'all';       // partial: 按 ID 选择, all: 全量选择
  selectedIds: string[];          // partial 模式下选中的 ID 列表
  excludedIds: string[];          // all 模式下排除的 ID 列表
  filterParams: FilterParams;     // all 模式下的筛选条件
  totalCount: number;             // 当前匹配总数
}
```

## 7. 各模块批量操作汇总

| 模块 | 支持的批量操作 |
|------|--------------|
| 设备管理 | 批量删除、批量同步、批量开站、批量交维、批量导出 |

## 8. 实现参考

### Ant Design Table 批量选择

```typescript
// Table rowSelection 配置
const rowSelection = {
  selectedRowKeys,
  onChange: (keys: React.Key[], rows: DataType[]) => {
    setSelectedRowKeys(keys);
    setSelectedRows(rows);
  },
  // 跨页保持选择
  preserveSelectedRowKeys: true,
  // 选择列宽度
  columnWidth: 48,
  // 禁用某些行的选择
  getCheckboxProps: (record: DataType) => ({
    disabled: record.status === 'syncing',
    name: record.name,
  }),
};
```

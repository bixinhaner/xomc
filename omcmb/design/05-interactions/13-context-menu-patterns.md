# 右键菜单 (Context Menu Patterns)

> OMC 统一网管系统 - 交互设计规范

## 概述

右键菜单 (Context Menu) 为用户提供与当前交互对象相关的快捷操作入口。OMC 系统在表格行、树节点和拓扑节点上支持右键菜单。

---

## 1. 通用菜单结构

### 1.1 菜单项结构

```
┌──────────────────────────────┐
│ 📋 查看详情          Ctrl+O  │  ← 图标 + 文字 + 快捷键
│ ✏️ 编辑                      │
│ 🔄 同步配置                   │
│ ─────────────────────────── │  ← 分隔线 (菜单项分组)
│ 📤 导出                      │
│ 📋 复制名称                   │
│ ─────────────────────────── │
│ 🗑️ 删除              Delete  │  ← 危险操作 (红色文字)
└──────────────────────────────┘
```

### 1.2 视觉规范

```
容器:
  - 背景: #FFFFFF
  - 边框: 1px solid #F0F0F0
  - 圆角: 8px
  - 阴影: 0 6px 16px rgba(0, 0, 0, 0.08),
          0 3px 6px rgba(0, 0, 0, 0.12)
  - 最小宽度: 160px
  - 最大宽度: 280px
  - z-index: 1050 (高于 Modal)

菜单项:
  - 高度: 36px
  - 内边距: 0 16px
  - 字体: 14px, @text-primary
  - 图标: 16px, 与文字间距 8px
  - 快捷键: 14px, @text-secondary, 右对齐

Hover 状态:
  - 背景: #F5F5F5
  - 光标: pointer

禁用状态:
  - 文字颜色: @text-disabled (#D9D9D9)
  - 光标: not-allowed
  - 不可点击

危险操作:
  - 文字颜色: @error-color (#FF4D4F)
  - Hover 背景: #FFF1F0 (浅红)

分隔线:
  - 1px solid #F0F0F0
  - margin: 4px 0
```

## 2. 表格行右键菜单

### 2.1 触发方式

```
触发: 右键点击表格数据行
行为:
  1. 阻止浏览器默认右键菜单 (e.preventDefault())
  2. 高亮被右键点击的行 (选中该行)
  3. 在鼠标位置显示上下文菜单
  4. 菜单内容根据行数据动态生成

关闭:
  - 点击菜单项 → 执行操作 + 关闭菜单
  - 点击菜单外任意位置 → 关闭菜单
  - 按 ESC → 关闭菜单
  - 滚动页面 → 关闭菜单
```

## 5. 菜单项的动态控制

### 5.1 条件显隐

```
根据对象状态动态调整菜单项:

设备在线:
  ✓ 显示 "同步配置"
  ✓ 显示 "MML 操作"

设备离线:
  ✗ "同步配置" 显示但禁用 (灰色 + Tooltip "设备离线")
  ✗ "MML 操作" 显示但禁用

任务进行中:
  ✓ 显示 "暂停任务"
  ✗ 隐藏 "启动任务"

任务已完成:
  ✗ 隐藏 "暂停任务" "终止任务"
  ✓ 显示 "删除任务"
```

### 5.2 权限控制

```
规则:
  - 用户无权限的操作: 不在菜单中显示 (非 disabled)
  - 避免用户看到无法执行的操作
  - 如果隐藏后菜单为空 → 不弹出菜单 (或显示 "无可用操作")
```

## 6. 多选右键菜单

### 6.1 交互规范

```
场景: 用户已选中多行，右键其中一行

行为:
  - 如果右键的行在选中集合内 → 显示批量操作菜单
```

## 7. 实现参考

### 自定义右键菜单组件

```typescript
// 推荐: 使用 Ant Design Dropdown 或自定义组件
import { Dropdown } from 'antd';

// 表格行右键
<Table
  onRow={(record) => ({
    onContextMenu: (e) => {
      e.preventDefault();
      setContextMenuPosition({ x: e.clientX, y: e.clientY });
      setContextRecord(record);
      setContextMenuVisible(true);
    },
  })}
/>

// 菜单组件
<Dropdown
  open={contextMenuVisible}
  menu={{ items: getMenuItems(contextRecord) }}
  trigger={['contextMenu']}
>
  <div style={{
    position: 'fixed',
    left: contextMenuPosition.x,
    top: contextMenuPosition.y,
  }} />
</Dropdown>
```

### 菜单定位

```typescript
// 确保菜单不超出视口
function getMenuPosition(x: number, y: number, menuWidth: number, menuHeight: number) {
  const maxX = window.innerWidth - menuWidth;
  const maxY = window.innerHeight - menuHeight;
  return {
    x: Math.min(x, maxX),
    y: Math.min(y, maxY),
  };
}
```

# 加载状态 (Loading States)

> OMC 统一网管系统 - 交互设计规范

## 概述

加载状态为用户提供系统正在处理请求的视觉反馈，消除不确定性，降低感知等待时间。不同场景应使用不同的加载模式。

---

## 1. Inline Spinner (行内加载指示器)

### 1.1 描述
小型旋转指示器，嵌入在按钮、输入框或文字旁边，表示局部操作正在进行。

### 1.2 视觉规范

```
尺寸:
  - Small: 16x16px (用于按钮内、输入框后缀)
  - Medium: 24x24px (用于卡片内、单元格内)

颜色:
  - 主色 Spinner: @primary-color (#1890FF)
  - 白色 Spinner: #FFFFFF (用于 Primary 按钮内)

动画:
  - 旋转 360deg
  - duration: 800ms
  - timing: linear
  - iteration: infinite
```

### 1.3 使用场景

| 场景 | 示例 | 行为 |
|------|------|------|
| 按钮提交 | [Spinner] 提交中... | 按钮禁用 + Spinner 替换图标 + 文字改为"提交中..." |
| 输入框搜索 | 搜索框右侧 Spinner | 用户输入触发搜索请求时显示 |
| 单元格刷新 | 状态列 Spinner | 单个设备状态查询中 |
| 下拉框加载 | 下拉面板内 Spinner | 异步加载下拉选项时显示 |

### 1.4 按钮 Loading 状态规范

```
正常状态:     [保存]
Loading 状态: [● 保存中...]

规则:
  - 按钮进入 loading 状态时设置 disabled
  - Spinner 放在文字左侧，间距 8px
  - 文字加"中..."后缀 (如: 保存→保存中..., 删除→删除中..., 导出→导出中...)
  - 按钮宽度保持不变 (避免布局跳动)
  - loading 结束后恢复按钮正常状态
```

## 2. Skeleton Screen (骨架屏)

### 2.1 描述
用灰色占位块模拟即将加载的内容结构，让用户预知页面布局，减少感知加载时间。

### 2.2 视觉规范

```
骨架块颜色:
  - 背景色: #F2F2F2
  - 闪烁动画渐变: #F2F2F2 → #E8E8E8 → #F2F2F2

动画 (Shimmer):
  - 类型: 线性渐变从左到右扫过
  - duration: 1.5s
  - timing: ease-in-out
  - iteration: infinite

圆角:
  - 文字行骨架: 4px
  - 头像骨架: 50% (圆形)
  - 图片骨架: 8px
```

### 2.3 表格骨架屏 (Table Skeleton)

```
┌────────────────────────────────────────────────────────┐
│ ████████  ██████████  ████████  ██████  ████████████  │  ← 表头 (实际渲染)
├────────────────────────────────────────────────────────┤
│ ████████  ██████████  ████████  ██████  ████████████  │  ← 骨架行 1
│ ██████    ████████    ██████    ████    ██████████    │  ← 骨架行 2
│ ████████  ██████████  ████████  ██████  ████████████  │  ← 骨架行 3
│ ██████    ████████    ██████    ████    ██████████    │  ← 骨架行 4
│ ████████  ██████████  ████████  ██████  ████████████  │  ← 骨架行 5
└────────────────────────────────────────────────────────┘

默认行数: 5 行
骨架块宽度: 随机 60%-100% (模拟真实数据长度差异)
行高: 与实际表格行高一致 (48px)
```

### 2.4 使用场景

| 场景 | 骨架结构 | 默认行数 |
|------|---------|---------|
| 设备列表 | 表格骨架 | 5 行 |
| 告警列表 | 表格骨架 | 5 行 |
| KPI 报表 | 表格骨架 | 5 行 |
| 卡片列表 | 卡片骨架 (包含标题、描述、操作区) | 4 张卡片 |
| 详情页 | 描述列表骨架 (Label + Value 对) | 8 对 |
| 树形面板 | 树节点骨架 (缩进 + 文字块) | 8 节点 |

### 2.5 何时使用

```
使用骨架屏:
  ✓ 页面首次加载 (内容区域)
  ✓ 切换 Tab 加载新内容
  ✓ 列表/表格数据请求中
  ✓ 可预知内容结构的区域

不使用骨架屏:
  ✗ 按钮操作反馈 → 使用 Inline Spinner
  ✗ 文件上传/下载 → 使用 Progress Bar
  ✗ 全页首次加载 → 使用 Full Page Loading
  ✗ 内容结构不可预知 → 使用 Spinner Overlay
```

## 3. Progress Bar (进度条)

### 3.1 描述
带百分比的水平进度条，用于有明确进度的操作（如文件上传、下载、批量任务）。

### 3.2 视觉规范

```
尺寸:
  - 标准: 高度 8px, 圆角 4px
  - 紧凑: 高度 4px, 圆角 2px (用于顶部全局进度)

颜色:
  - 轨道: #F0F0F0
  - 进度: @primary-color (#1890FF)
  - 成功: @success-color (#52C41A)
  - 失败: @error-color (#FF4D4F)

文字:
  - 百分比显示在进度条右侧: "45%"
  - 字体: 12px, 颜色 @text-secondary
```

### 3.3 进度条变体

```
(a) 标准进度条 (知道具体百分比):
  ┌──────────████████████░░░░░░░░░░░░┐ 45%

(b) 不定进度条 (不知道具体进度):
  ┌░░░░████████░░░░░░░░░░░░░░░░░░░░░┐
  蓝色块来回移动动画

(c) Overlay 进度条 (文件上传):
  ┌─────────────────────────────────────┐
  │  ↑ firmware_v3.2.1.bin              │
  │  ████████████████░░░░░░░░  67%     │
  │  已上传 134MB / 200MB  预计剩余 12s │
  └─────────────────────────────────────┘
```

### 3.4 使用场景

| 场景 | 进度条类型 | 位置 |
|------|-----------|------|
| 文件上传 | Overlay 进度条 | 上传对话框内 |
| 文件下载 | 标准进度条 | 下载通知/任务面板 |
| 批量导出 | 标准进度条 | 任务面板 |
| 软件升级 | 标准进度条 + 步骤指示 | 任务详情 |
| 批量同步 | 标准进度条 | 任务面板 |

## 4. Full Page Loading (全页加载)

### 4.1 描述
系统首次加载时的全屏加载页面，展示品牌标识和加载状态。

### 4.2 视觉规范

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│           [OMC Logo]                │
│                                     │
│       OMC 统一网管系统               │
│                                     │
│        ●●●●○ 加载中...              │
│                                     │
│                                     │
└─────────────────────────────────────┘

背景色: #FFFFFF
Logo 尺寸: 120x120px
系统名称: 20px, @heading-color, font-weight 600
加载指示器: 5 个圆点依次缩放动画
文字: 14px, @text-secondary
```

### 4.3 使用场景

- 系统首次打开 (Cold Start)
- 用户登录后加载用户信息和权限数据
- 系统级配置加载

### 4.4 行为

```
1. 显示 Logo + 系统名称 (立即)
2. 显示加载动画 + "加载中..." (立即)
3. 加载完成 → Fade Out (300ms) → 显示主界面
4. 加载失败 → 显示错误信息 + 重试按钮
5. 加载超时 (15s) → 显示超时提示 + 重试按钮
```

## 5. Partial Area Loading (局部区域加载)

### 5.1 描述
仅覆盖页面中正在加载的区域，其他区域保持可交互。

### 5.2 视觉规范

```
┌─────────────────────────────────────┐
│ [侧边栏]  │  ┌─ 半透明遮罩 ────┐   │
│  可正常    │  │                  │   │
│  交互      │  │    [Spinner]     │   │
│            │  │    加载中...     │   │
│            │  │                  │   │
│            │  └─────────────────┘   │
└─────────────────────────────────────┘

遮罩:
  - 背景色: rgba(255, 255, 255, 0.65)
  - Spinner 居中
  - 可选文字: "加载中..." (14px, @text-secondary)

Spinner:
  - 尺寸: 32x32px
  - 颜色: @primary-color
```

### 5.3 使用场景

| 场景 | 加载区域 | 说明 |
|------|---------|------|
| 切换导航菜单 | 内容区域 | 侧边栏保持可交互 |
| 表格分页 | 表格区域 | 工具栏和筛选栏保持可见 |
| Tab 切换 | Tab 内容区域 | Tab 栏保持可交互 |
| 刷新数据 | 数据区域 | 不影响页面其他部分 |
| 树节点展开 | 树面板 | 其他面板正常 |

## 6. 加载模式选择决策树

```
用户触发操作
    │
    ├── 全系统首次加载?
    │   └── 是 → Full Page Loading (Logo + 加载动画)
    │
    ├── 知道具体进度?
    │   └── 是 → Progress Bar (文件上传/下载/批量任务)
    │
    ├── 加载区域的内容结构可预知?
    │   └── 是 → Skeleton Screen (表格/列表/卡片/详情)
    │
    ├── 加载区域较大 (内容区域)?
    │   └── 是 → Partial Area Loading (半透明遮罩 + Spinner)
    │
    └── 局部小操作 (按钮/输入框)?
        └── 是 → Inline Spinner (按钮内/输入框后缀)
```

## 7. 加载时间阈值

| 加载时间 | 处理方式 |
|---------|---------|
| < 300ms | 不显示任何加载指示 (避免闪烁) |
| 300ms - 1s | 显示 Inline Spinner 或局部 Spinner |
| 1s - 3s | 显示 Skeleton Screen 或 Partial Area Loading |
| 3s - 10s | 显示 Progress Bar (如有进度) 或加载提示文字 |
| > 10s | 显示预计剩余时间 + 可取消操作 |
| > 30s | 建议转为后台任务 (Task Panel) |

### 延迟显示策略

```typescript
// 避免加载指示器闪烁
// 如果请求在 300ms 内完成，不显示加载状态
const LOADING_DELAY = 300; // ms

// 加载指示器最少显示 500ms，避免一闪而过
const MIN_LOADING_DURATION = 500; // ms
```

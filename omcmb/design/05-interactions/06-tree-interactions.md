# 树形交互 (Tree Interactions)

> OMC 统一网管系统 - 交互设计规范

## 概述

树形控件在 OMC 系统中广泛用于网元层级导航、MML 命令浏览、KPI 分类选择、设备分组管理等场景。本文定义树形控件的所有交互行为。

---

## 1. 展开/折叠 (Expand / Collapse)

### 1.1 交互规范

```
树结构示例:
  ▼ 广州区域                  ← 已展开 (▼ 向下箭头)
    ▼ 天河区                  ← 已展开
      ├─ eNodeB-001
      ├─ eNodeB-002
      └─ eNodeB-003
    ▶ 越秀区                  ← 已折叠 (▶ 向右箭头)
    ▶ 海珠区
  ▶ 深圳区域                  ← 已折叠

展开/折叠图标:
  - ▶ (折叠, 向右三角) → 点击 → ▼ (展开, 向下三角)
  - 旋转动画: 90deg, duration 200ms
  - 图标尺寸: 12x12px
  - 图标颜色: @text-secondary (#8C8C8C)
  - 叶子节点: 无展开图标 (空白占位, 保持缩进对齐)

点击区域:
  - 点击展开图标 (▶/▼): 只展开/折叠, 不选中
  - 双击节点文字: 展开/折叠 (可选行为)
```

### 1.2 缩进规范

```
每级缩进: 24px
节点行高: 32px
图标与文字间距: 8px

示例:
  |← 0px →|▼ 一级节点
  |← 24px →|▼ 二级节点
  |← 48px →|├─ 三级节点
```

## 2. 节点选择 (Node Selection)

### 2.1 单选模式

```
点击节点文字/标签区域 → 选中该节点
选中样式:
  背景色: @primary-color 10% (#E6F7FF)
  文字颜色: @primary-color (#1890FF)
  左侧: 2px 蓝色竖线 (可选)

Hover 样式:
  背景色: #F5F5F5

选中行为:
  - 选中节点 → 右侧面板加载对应内容
  - 如: 选中设备节点 → 右侧显示设备详情
  - 如: 选中 KPI 分类节点 → 右侧显示该分类报表
```

### 2.2 多选模式 (Checkbox)

```
  ☑ 广州区域                    ← 全选 (所有子节点选中)
    ☑ 天河区
      ☑ eNodeB-001
      ☑ eNodeB-002
      ☑ eNodeB-003
    ▣ 越秀区                    ← 半选 (indeterminate, 部分子节点选中)
      ☑ eNodeB-004
      ☐ eNodeB-005
    ☐ 海珠区                    ← 未选中

Checkbox 三态:
  ☐ 未选中: 自身和所有子节点都未选中
  ☑ 全选:   自身和所有子节点都已选中
  ▣ 半选:   部分子节点选中 (indeterminate)
```

### 2.3 父子级联规则

```
选中父节点 → 自动选中所有子节点
取消父节点 → 自动取消所有子节点
选中子节点 → 父节点变为 半选(▣) 或 全选(☑)
取消子节点 → 父节点变为 半选(▣) 或 未选中(☐)

联动计算:
  1. 向下级联: 选中/取消父节点 → 递归更新所有子孙节点
  2. 向上级联: 选中/取消子节点 → 递归更新所有祖先节点状态
```

## 3. 树内搜索 (Search within Tree)

### 3.1 交互规范

```
┌──────────────────────┐
│ 🔍 搜索节点...       │  ← 树顶部搜索框
└──────────────────────┘
  ▼ 广州区域
    ▼ 天河区
      ├─ [eNodeB]-001     ← 匹配文字高亮 (黄色背景)
      ├─ [eNodeB]-002
      └─ [eNodeB]-003
    越秀区               ← 无匹配子节点的分支隐藏或折叠
  深圳区域

搜索行为:
  - 实时搜索 (debounce 300ms)
  - 高亮匹配的文字部分 (黄色背景 #FFFBE6)
  - 自动展开包含匹配节点的所有父节点
  - 不匹配的分支:
    方案 A: 隐藏不匹配的节点 (推荐)
    方案 B: 保留但灰色显示
  - 清空搜索: 恢复树的展开/折叠状态
```

### 3.2 搜索匹配计数

```
搜索框下方或右侧显示:
  "找到 5 个匹配节点"

支持 ↑↓ 箭头在匹配节点间跳转 (可选增强)
```

## 4. 懒加载 (Lazy Loading)

### 4.1 交互规范

```
场景: 树层级深、节点多 (如全网设备树可能有上万节点)

行为:
  1. 初始只加载根节点和第一级子节点
  2. 点击展开 ▶ → 发起异步请求加载子节点
  3. 加载中: 展开图标变为 Spinner (旋转动画)
  4. 加载完成: Spinner 恢复为 ▼, 显示子节点
  5. 加载失败: 显示错误提示 + [重试] 链接
  6. 已加载的子节点缓存, 再次折叠/展开无需重新请求

加载中状态:
  ● 广州区域                ← Spinner 替代展开图标
    加载中...               ← 可选加载提示文字
```

## 5. 拖拽排序 (Drag and Drop Reorder)

### 5.1 交互规范

```
触发: 鼠标按住节点拖动
光标: grab (抓手) → grabbing (拖动中)

拖动中:
  - 被拖节点: 半透明浮动效果, 跟随鼠标
  - 放置指示器:
    - 放在节点上方: 蓝色水平线 (在目标节点上方)
    - 放在节点下方: 蓝色水平线 (在目标节点下方)
    - 放入节点内部: 目标节点蓝色高亮边框

释放:
  - 在有效目标上释放 → 节点移动 + 发送排序请求
  - 在无效目标上释放 → 节点回到原位

限制:
  - 不能将父节点拖入其自身子节点内 (防止循环)
  - 某些节点不可拖动 (如根节点)
  - 某些节点不可作为放置目标
```

### 5.2 使用场景

| 场景 | 说明 |
|------|------|
| 设备分组管理 | 拖拽设备到不同分组 |
| MML 命令收藏排序 | 拖拽调整收藏命令的顺序 |
| 导航菜单自定义 | 拖拽调整菜单顺序 (未来) |

### 6.1 交互规范

```
右键点击树节点 → 弹出上下文菜单:

对于分组节点 (非叶子):
┌──────────────────┐
│ 展开全部子节点    │
│ 折叠全部子节点    │

│ 新建子节点       │
│ 重命名           │
│ ──────────────── │
│ 删除             │
└──────────────────┘

对于叶子节点 (如设备):
┌──────────────────┐
│ 查看详情         │
│ 编辑             │
│ ──────────────── │
│ 移动到...        │
│ 复制             │
│ ──────────────── │
│ 删除             │
└──────────────────┘

菜单根据节点类型动态生成
```

## 7. 双击重命名 (Double-click to Rename)

### 7.1 交互规范

```
双击节点文字:
  1. 文字变为可编辑输入框 (inline edit)
  2. 输入框自动全选文字
  3. 用户修改名称

确认:
  - Enter 键 → 保存修改
  - 点击输入框外部 (onBlur) → 保存修改

取消:
  - ESC 键 → 取消修改, 恢复原名

校验:
  - 不能为空
  - 不能与同级节点重名
  - 最大长度限制
  - 不允许特殊字符 (如 / \ : * ? " < > |)
```

## 8. 树的性能优化

```
节点 < 500: 一次性加载, 前端搜索/筛选
节点 500-5000: 懒加载子节点, 虚拟滚动可选
节点 > 5000: 懒加载 + 虚拟滚动 (只渲染可视区域节点)

虚拟滚动:
  - 只渲染视口内的节点 (通常 30-50 个)
  - 展开/折叠触发重新计算可视节点
  - 搜索结果自动滚动到第一个匹配节点
```

## 9. 树的键盘导航 (可选增强)

```
↑ / ↓: 在相邻可见节点间移动焦点
→: 展开当前节点 (如果已展开则移动到第一个子节点)
←: 折叠当前节点 (如果已折叠则移动到父节点)
Enter: 选中当前焦点节点
Space: 切换 Checkbox (多选模式)
Home: 跳到第一个节点
End: 跳到最后一个可见节点
```

## 10. 实现参考

### Ant Design Tree 关键配置

```typescript
<Tree
  // 基础
  treeData={treeData}

  // 选择
  selectedKeys={selectedKeys}
  onSelect={handleSelect}

  // 多选 Checkbox
  checkable
  checkedKeys={checkedKeys}
  onCheck={handleCheck}
  checkStrictly={false}  // false = 父子级联

  // 展开
  expandedKeys={expandedKeys}
  onExpand={handleExpand}

  // 懒加载
  loadData={handleLoadData}

  // 搜索
  filterTreeNode={(node) => matchSearch(node)}

  // 拖拽
  draggable
  onDrop={handleDrop}

  // 虚拟滚动
  virtual
  height={500}

  // 右键菜单
  onRightClick={handleRightClick}
/>
```

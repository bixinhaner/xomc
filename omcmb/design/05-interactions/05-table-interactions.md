# 表格交互 (Table Interactions)

> OMC 统一网管系统 - 交互设计规范

## 概述

表格是 OMC 系统中最核心的数据展示组件。设备列表、告警列表、性能报表、任务列表等几乎所有数据页面都以表格为主。本文定义表格的所有交互行为。

---

## 1. 列排序 (Column Sorting)

### 1.1 交互规范

```
排序循环: 点击表头
  无排序 → 升序 (ASC) → 降序 (DESC) → 无排序

图标状态:
  无排序:  ↕ (灰色双箭头)
  升序:    ↑ (蓝色向上箭头)
  降序:    ↓ (蓝色向下箭头)

图标位置: 表头文字右侧, 间距 4px
```

### 1.2 排序规则

```
- 单列排序: 同时只允许一列排序 (点击其他列排序时清除当前排序)
- 排序触发服务端请求 (后端排序)
- 排序参数: sortField + sortOrder 写入 URL query params
- 默认排序: 由各业务页面定义 (如告警按时间降序)
- 不可排序列: 不显示排序图标 (如操作列)
```

### 1.3 视觉反馈

```
┌──────────────┬──────────────┬──────────────┐
│ 设备名称 ↕   │ IP 地址 ↕   │ 创建时间 ↓    │  ← 创建时间列降序排序中
├──────────────┼──────────────┼──────────────┤
│ eNodeB-005   │ 192.168.1.5 │ 2024-01-15   │
│ eNodeB-003   │ 192.168.1.3 │ 2024-01-14   │
│ eNodeB-001   │ 192.168.1.1 │ 2024-01-13   │
└──────────────┴──────────────┴──────────────┘

排序中的表头: 文字颜色变为 @primary-color
点击表头: 整个表头单元格可点击 (cursor: pointer)
Hover: 表头背景色加深
```

## 2. 列筛选 (Column Filter)

### 2.1 交互规范

```
┌──────────────────┐
│ 状态 ↕  🔽       │  ← 漏斗图标 (FilterOutlined)
├──────────────────┤
      │
      ▼
┌──────────────────┐
│ 🔍 搜索...       │
├──────────────────┤
│ ☑ 全选           │
│ ☑ 在线           │
│ ☑ 离线           │
│ ☐ 未知           │
├──────────────────┤
│ [重置]    [确定]  │
└──────────────────┘

触发: 点击表头中的漏斗图标
漏斗图标: 默认灰色，有筛选条件时变为 @primary-color (蓝色)
面板: Checkbox 列表 + 搜索框 (选项 > 10 时显示搜索)
操作: [确定] 应用筛选, [重置] 清除筛选
```

## 3. 列宽调整 (Column Resizing)

### 3.1 交互规范

```
┌──────────────┬──────────────┬──────────────┐
│ 设备名称     |│ IP 地址      │ 状态         │
│              ↔              │              │
              ↑
        拖拽手柄 (cursor: col-resize)

触发: 鼠标悬停在表头列边界时，光标变为 col-resize
拖拽: 按住鼠标左键拖动，实时预览列宽变化
最小宽度: 80px (防止列被拖到过窄)
最大宽度: 不限制
释放: 松开鼠标，列宽固定
```

### 3.2 列宽持久化

```
- 用户调整的列宽保存在 localStorage
- Key: `omc_table_colWidth_{tableKey}`
- 下次进入页面自动恢复
- [重置列宽] 选项在列设置中提供
```

## 4. 列排序 (Column Reordering)

### 4.1 交互规范

```
触发: 按住表头单元格拖动
视觉反馈:
  - 被拖动列: 半透明悬浮效果
  - 目标位置: 蓝色竖线指示插入位置
  - 其他列: 平滑让位动画

释放: 列顺序更新
不可移动列: 选择列 (Checkbox) 和操作列固定位置
```

## 6. 行选择 (Row Selection)

### 6.1 交互规范

| 操作 | 行为 |
|------|------|
| 点击行 Checkbox | 选中/取消选中该行 |
| 点击表头 Checkbox | 全选/取消全选当前页 |
| Shift + 点击 | 范围选择 (从上次到当前) |
| Ctrl/Cmd + 点击 | 追加/取消单行 |

### 6.2 选中行样式

```
选中行:
  背景色: @primary-color 5% (#E6F7FF)
  左侧边框: 2px solid @primary-color (可选)

Hover 行:
  背景色: #FAFAFA

选中 + Hover:
  背景色: @primary-color 8%
```

## 7. 行展开 (Row Expansion)

### 7.1 交互规范

```
┌───┬──────────────┬──────────────┬──────────────┐
│ ▶ │ eNodeB-001   │ 192.168.1.1 │ 在线         │  ← 点击 ▶ 展开
├───┼──────────────┼──────────────┼──────────────┤
│ ▼ │ eNodeB-002   │ 192.168.1.2 │ 在线         │  ← 已展开
│   │ ┌──────────────────────────────────────┐   │
│   │ │ 详细信息:                             │   │
│   │ │ MAC 地址: AA:BB:CC:DD:EE:FF          │   │
│   │ │ 固件版本: v3.2.1                      │   │
│   │ │ 上线时间: 2024-01-15 08:30:00        │   │
│   │ │ 所属区域: 广州-天河                    │   │
│   │ └──────────────────────────────────────┘   │
├───┼──────────────┼──────────────┼──────────────┤
│ ▶ │ eNodeB-003   │ 192.168.1.3 │ 离线         │
└───┴──────────────┴──────────────┴──────────────┘

展开图标: ▶ (收起) / ▼ (展开)
位置: 首列最左侧
点击 ▶ → 展开该行，显示嵌套内容
点击 ▼ → 收起该行
展开动画: 高度从 0 过渡 (200ms, ease-out)
同时只展开一行 (Accordion 模式) 或允许多行展开 (根据场景)
```

### 7.2 展开内容类型

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| 描述列表 | Key-Value 对 | 设备详细参数 |
| 嵌套表格 | 子表格 | 设备下的小区列表 |
| 自定义内容 | 图表/文本/操作 | 告警关联信息 |

## 10. 行点击动作 (Row Click Action)

### 10.1 交互规范

```
模式 A - 导航到详情页:
  点击行 → 路由跳转到该记录的详情页
  光标: pointer
  视觉: 行 hover 时有点击暗示 (如下划线或箭头)
  例外: 点击操作列按钮不触发行点击

模式 B - 选中行:
  点击行 → 等同于点击该行 Checkbox
  光标: default
  仅当表格配置了 rowSelection 时生效

模式 C - 打开 Drawer:
  点击行 → 右侧打开详情 Drawer (不跳转页面)
  适用于: 告警列表、任务列表等需要快速预览的场景
```

## 11. 水平滚动与固定列 (Horizontal Scroll & Fixed Columns)

### 11.1 交互规范

```
┌────────────────────────────────────────────────────────┐
│固定列 (左)│              可滚动区域              │固定列(右)│
├──────────┼────────────────────────────────────┼─────────┤
│ ☐ 设备名称│ IP地址  类型   状态  区域  版本 ... │  操作    │
│ ☐ eNB-001 │ 192...  eNB   在线  广州  v3.2 ... │ [编辑]  │
│ ☐ eNB-002 │ 192...  eNB   离线  深圳  v3.1 ... │ [编辑]  │
└──────────┴────────────────────────────────────┴─────────┘

固定列:
  - 左侧固定: 选择列 (Checkbox) + 首列 (如设备名称)
  - 右侧固定: 操作列
  - 固定列有阴影效果 (box-shadow) 区分滚动区域

滚动:
  - 水平滚动条: 表格底部
  - 滚动时固定列保持不动
  - 可拖拽表格内容区域进行水平滚动 (可选)
```

## 12. 虚拟滚动 (Virtual Scroll)

### 12.1 触发条件

```
数据量 > 1000 行时启用虚拟滚动
只渲染可视区域内的行 (通常 20-30 行)
```

### 12.2 交互规范

```
行为:
  - 滚动体验与原生滚动一致 (流畅)
  - 支持鼠标滚轮 + 拖拽滚动条
  - 行高固定 (虚拟滚动需要已知行高)
  - 支持行选择、行展开等所有交互

兼容性:
  - 虚拟滚动与行展开: 展开行的高度需要动态计算
  - 虚拟滚动与搜索: 搜索定位到匹配行 (scrollToRow)
  - 虚拟滚动与排序: 排序后保持滚动位置或回到顶部

实现:
  - Ant Design Table: 使用 virtual 属性
  - 或集成 react-window / react-virtuoso
  - 预渲染: 可视区域上下各多渲染 5 行 (buffer)
```

## 13. 表格空状态

```
┌─────────────────────────────────────────────┐
│ 设备名称  │  IP 地址  │  状态  │  操作      │
├─────────────────────────────────────────────┤
│                                             │
│           [空状态插图]                       │
│                                             │
│           暂无数据                           │
│     数据为空或筛选条件无匹配结果              │

│           [清除筛选] (如有筛选)               │
│                                             │
└─────────────────────────────────────────────┘

加载失败: "数据加载失败" + [重试] 按钮
```

## 14. 实现参考

### Ant Design Table 关键配置

```typescript
<Table
  // 基础
  columns={columns}
  dataSource={data}
  rowKey="id"
  loading={loading}

  // 分页
  pagination={{
    current: page,
    pageSize,
    total,
    showSizeChanger: true,
    showQuickJumper: true,
    showTotal: (total) => `共 ${total} 条`,
  }}

  // 行选择
  rowSelection={{
    selectedRowKeys,
    onChange: setSelectedRowKeys,
    preserveSelectedRowKeys: true,
  }}

  // 排序
  onChange={handleTableChange}

  // 固定列
  scroll={{ x: 1500 }}

  // 虚拟滚动 (Ant Design 5.x)
  virtual={data.length > 1000}

  // 行展开
  expandable={{
    expandedRowRender: (record) => <DetailPanel record={record} />,
    expandIcon: customExpandIcon,
  }}

  // 行点击
  onRow={(record) => ({
    onClick: () => handleRowClick(record),
    onContextMenu: (e) => handleContextMenu(e, record),
  })}
/>
```

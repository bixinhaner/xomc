# 导出与下载 (Export & Download)

> OMC 统一网管系统 - 交互设计规范

## 概述

导出和下载是网管系统的常用功能，用于将设备数据、告警记录、性能报表等导出为文件。本文定义导出/下载的交互流程和各种模式。

## 3. 导出进度

### 3.1 小量数据导出 (< 1000 条)

```
行为:
  1. 点击 [确认导出]
  2. 按钮进入 loading: "导出中..."
  3. 请求完成 (通常 < 3s)
  4. 浏览器自动下载文件
  5. Toast: "导出成功, 共 156 条数据"
```

### 3.2 大量数据导出 (> 1000 条)

```
行为:
  1. 点击 [确认导出]
  2. Toast: "导出任务已创建, 可在任务面板中查看进度"
  3. 关闭导出对话框
  4. 任务面板中显示导出任务:
     ┌──────────────────────────────────────────┐
     │ 📤 导出设备列表 (Excel)                   │
     │ ████████████████████░░░░  80%             │
     │ 已处理: 8,000 / 10,000 条                 │
     └──────────────────────────────────────────┘
  5. 完成后:
     - 任务状态变为 "已完成"
     - Notification: "导出已完成 [下载文件]"
     - 点击 [下载文件] → 浏览器下载
  6. 文件保留: 服务器保留导出文件 24h, 之后自动清理
```

## 4. 下载模式

### 4.1 直接下载 (小文件)

```
场景: 文件 < 10MB (如导出的 Excel/CSV, 小型日志文件)

行为:
  1. 点击下载链接/按钮
  2. 浏览器直接开始下载 (使用 <a download> 或 window.open)
  3. 下载完成 → 无额外提示 (浏览器自带下载提示)
```

### 4.2 进度下载 (大文件)

```
场景: 文件 > 10MB (如固件包、批量日志、全量备份)

行为:
  1. 点击下载按钮
  2. 显示下载进度:
     ┌──────────────────────────────────────────┐
     │ ↓ firmware_v3.2.1.bin                    │
     │ ████████████████░░░░░░  67%              │
     │ 已下载 134MB / 200MB  速度: 5.2MB/s      │
     │ 预计剩余: 12s                [取消下载]   │
     └──────────────────────────────────────────┘
  3. 完成 → Toast: "下载完成"
  4. 取消 → 停止下载, 清理临时文件
```

### 4.3 批量下载

```
场景: 同时下载多个文件 (如多个设备的备份文件)

方案 A - ZIP 打包下载 (推荐):
  1. 选择多个文件
  2. 点击 [批量下载]
  3. 后端打包为 ZIP
  4. 下载 ZIP 文件

方案 B - 逐个下载:
  1. 选择多个文件
  2. 点击 [批量下载]
  3. 依次触发浏览器下载 (可能被浏览器拦截)
  → 不推荐, 浏览器可能阻止多文件下载
```

   │  │                                 │    │
   │  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘    │

4. 确认 → 开始导入

## 7. 各模块导出汇总

| 模块 | 可导出内容 | 支持格式 | 备注 |
|------|-----------|---------|------|
| 设备管理 | 设备列表 | Excel, CSV | 支持筛选后导出 |
| 告警管理 | 当前/历史告警 | Excel, CSV | 大量数据走任务 |
| 性能管理 | KPI 报表数据 | Excel, CSV | 支持图表导出为图片 |
| 性能管理 | KPI 图表 | PNG, SVG | 图表右上角导出按钮 |
| 配置管理 | 配置数据 | Excel, CSV | 按设备/分类导出 |
| 软件管理 | 升级计划记录 | Excel | - |
| 备份恢复 | 备份文件 | 原始格式 | 直接下载 |
| MML 管理 | 执行结果 | Excel, TXT | MML 响应数据 |
| MR 管理 | MR 报表 | Excel, CSV | - |
| 日志管理 | 操作日志 | Excel, CSV | 支持时间范围导出 |

## 8. 实现参考

### 前端导出 (小数据量)

```typescript
// 使用 xlsx 库进行前端导出
import * as XLSX from 'xlsx';

function exportToExcel(data: any[], columns: Column[], filename: string) {
  const ws = XLSX.utils.json_to_sheet(data, {
    header: columns.map(c => c.dataIndex),
  });
  const wb = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(wb, ws, 'Sheet1');
  XLSX.writeFile(wb, `${filename}.xlsx`);
}
```

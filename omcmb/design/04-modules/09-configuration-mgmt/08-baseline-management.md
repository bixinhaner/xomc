# 基线管理 (Baseline Management)

## 页面用途

管理厂商基线参数标准，支持基线的创建、编辑、导入/导出、参数查看和开站模板绑定。基线定义了设备出厂参数标准，是配置管理的参数基准。参数查看页面提供左侧基线名称列表 + 参数分类树 + 右侧参数详情表格的三级结构。

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 基线名称 | TextInput | 用户输入 | 空 | 模糊搜索 |
| 版本号 | TextInput | 用户输入 | 空 | 格式 V123.456.789 |

## 弹窗规格

### 新增/编辑厂商基线弹窗

| 字段名称 | 组件类型 | 必填 | 字符限制 | 说明 |
|---------|---------|------|---------|------|

| 所属厂商 | Select | 是(*) | -- | 厂商下拉 |
| 网络制式 | Select | 是(*) | -- | LTE / NR |
| 模型版本 | Select | 是(*) | -- | TR-181 / TR-098 |
| 运营商基线 | Select | 是(*) | -- | 运营商基线选择 |
| 产品分类 | Select | 是(*) | -- | 产品分类 |
| 基线参数类型 | RadioGroup | 是 | -- | 继承运营商基线 / 自行上传（仅新增时） |
| 描述 | Textarea | 否 | 0/255 | 描述信息 |

### 导入确认弹窗

- 警告图标 + "将覆盖现有基线，是否确定导入？"

### 基线参数查看页面（独立页面）

**布局:** 左侧(基线名称列表 + 参数分类树带搜索) + 右侧(筛选栏 + 参数详情表格)

**左侧参数分类树:** 基线参数(512) > 设备信息参数管理(14) / 软件版本参数管理(5) / 基站网管参数管理(19) / ...

**基线信息头部:** 基线名称 / 网络制式 / 版本号 / 模型版本 / 厂商 / 产品分类

**筛选:** 参数名称 / 参数路径 / 中文名称 / 限定性 / 读写性 / 是否为运营商参数

**参数表格列:** 参数名称 / 参数路径 / 中文名称 / 限定性(M/O) / 读写性(R/W/RW) / 参数类型 / 操作(编辑/删除)

**操作按钮:** 导出 / 新增

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 导入覆盖 | 二次确认弹窗，明确提示覆盖风险 |
| 无开站模板 | 模板列表为空时提示 "暂无可用模板" |

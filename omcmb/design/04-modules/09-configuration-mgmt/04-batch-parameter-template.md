# 批量参数模板配置 (Batch Parameter Template Configuration)

## 页面用途

基于预定义模板进行批量参数配置。管理参数模板的创建、编辑、查看和删除，支持模板的启用/共享控制。模板关联设备类型和参数集，可批量应用到选中的网元。

## 布局模板

**Tree-List Page Layout（三栏树形列表页）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 批量参数模板配置
```

## 路由

```
/config/batch-template
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 设备类型 | Select | API: 设备类型列表 | 皮基站 | 设备分类 |

## 数据表规格

### 模板管理表格

| 列名 | 字段 Key | 宽度 | 排序 | 渲染规则 |
|------|----------|------|------|---------|
| (复选框) | _selection | 48px | -- | Checkbox |
| 模板名称 | templateName | 180px | -- | 文本 |
| 是否启用 | enabled | 80px | -- | Toggle: ✅/❌ |
| 是否共享 | shared | 80px | -- | Toggle: ✅/❌ |
| 设备类型 | deviceType | 100px | -- | 文本 |
| 设备子类 | deviceSubType | 100px | -- | 文本 |
| 设备制式 | standard | 80px | -- | 文本 |
| 设备型号 | model | 100px | -- | 文本 |
| 创建用户 | creator | 100px | -- | 文本 |
| 备注 | remarks | flex | -- | 文本 |

## 工具栏操作

| 按钮名称 | 类型 | 条件 | 行为 |
|---------|------|------|------|
| 新建 | Primary | 始终可见 | 打开添加模板弹窗 |
| 编辑 | Default | 选中 1 项 | 打开编辑模板弹窗 |
| 查看 | Default | 选中 1 项 | 打开只读查看 |
| 删除 | Danger | 选中 >= 1 项 | 二次确认后删除 |

## 弹窗规格

### 添加/编辑模板弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 模板名称 | TextInput | 是(*) | 模板名称 |
| 是否启用 | Toggle Switch | -- | 默认开启 |
| 是否共享 | Toggle Switch | -- | 默认关闭 |
| 备注 | Textarea | 否 | 备注信息 |

**参数选择 Tab:**

| 字段名称 | 组件类型 | 说明 |
|---------|---------|------|
| 设备类型 | Select | 设备类型 |
| 设备子类 | Select | 设备子类 |
| 设备制式 | Select | 网络制式 |
| 设备型号 | Select | 设备型号 |
| 参数列表 | Transfer (已选/未选) | 复选框 + 参数标识/名称/路径/描述 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭 |
| Confirm | Primary | 保存模板 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 无模板 | 表格显示 "暂无模板，请新建" |
| 删除共享模板 | 提示 "该模板已被共享，删除后其他用户将无法使用" |

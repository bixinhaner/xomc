# 参数同步 (Parameter Synchronization)

## 页面用途

管理网元设备的参数同步任务。提供三栏布局：左侧菜单树导航、中间设备类型树和网元统计面板、右侧同步数据表格。底部为任务面板，展示同步任务执行进度。支持立即同步和创建定时同步任务。

## 布局模板

**Tree-List Page Layout（三栏树形列表页）**

```
+------------------------------------------------------------------+
| 顶部导航栏                                                         |
+------------------------------------------------------------------+
| 左侧菜单树 | 中间设备树 + 统计面板 | 右侧数据表格                     |
| (15%)       | (25%)               | (60%)                         |
+------------------------------------------------------------------+
| 底部任务面板                                                       |
+------------------------------------------------------------------+
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 设备类型 Tab | TabBar | 类型/子网/站点/区域/模板/群组 | 类型 | 切换设备分类维度 |
| 已选/未选 Tab | TagSwitch | 动态计数 | 未选网元 | 切换显示已选或未选网元 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 排序 | 对齐 | 渲染规则 |
|------|----------|------|------|------|---------|
| (复选框) | _selection | 48px | -- | center | Checkbox |
| Id | id | 80px | -- | left | 网元 ID |
| 设备标识 | deviceId | 180px | -- | left | CWMP 设备标识 |
| 网元名称 | neName | flex | -- | left | 网元名称（含地理信息） |
| 最后同步时间 | lastSyncTime | 160px | 支持 ↕ | left | YYYY-MM-DD HH:mm |
| 监控状态 | monitorStatus | 80px | -- | center | 彩色圆点: 🟢正常 / 🔴失效 |
| 告警级别 | alarmLevel | 100px | -- | left | 文本标签 |
| 工程状态 | engineeringStatus | 100px | -- | left | 文本 |

## 工具栏操作

| 按钮名称 | 类型 | 条件 | 行为 |
|---------|------|------|------|
| 移除 | Default | 已选模式下选中项 | 从已选列表移除 |
| 清空 | Default | 已选列表非空 | 清空所有已选网元 |
| 导入网元 | Default | 始终可见 | 打开导入网元弹窗 |
| 立即同步 | Primary | 已选网元 > 0 | 对已选网元立即执行参数同步 |
| 建立参数同步任务 | Primary | 已选网元 > 0 | 打开创建定时同步任务弹窗 |

## 弹窗规格

### 导入网元模板弹窗

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 操作对象 | Select | 是 | 网元名称下拉选择 |
| 模板下载 | Link | -- | "下载模板" 链接 |
| 上传文件 | FileUpload + Validate | 是 | 点击选择文件 + 校验按钮 |

**提示:** "*仅支持 csv 格式，且须是在网网元"（红色）
**统计:** 通过: 0，未通过: 0

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭 |
| Confirm | Primary | 导入并添加到已选列表 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 统计面板加载中 | 数字显示 `--` |
| 同步任务执行中 | 底部任务面板实时更新进度 |
| 同步失败 | 任务面板状态列显示红色 "失败"，信息内容列显示错误详情 |

# 邻区参数管理 (Neighbor Cell Parameter Management)

## 页面用途

管理邻区参数的导入/导出定时任务。支持创建周期性或一次性任务计划，配置邻区类型和数据同步策略，选择目标网元。任务列表展示所有邻区参数相关的调度任务及其执行状态。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 邻区参数导入/导出任务
```


## 弹窗规格

### 添加邻区参数任务表单

**Section 1: 任务信息设置**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 任务策略名称 | TextInput | 是(*) | 任务名称 |
| 是否启动 | Toggle Switch | -- | 默认开启 |
| 执行方式 | Select | 是 | 立即执行 / 定时执行 |
| 批次完成时间 | Select + NumberInput | 是 | 时间单位(时) + 数值(2) |
| 注释 | Textarea | 否 | 备注 |

**Section 2: 邻区信息设置**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 邻区类型 | Select | 是(*) | 邻区类型选择 |
| 导出前同步数据 | Toggle Switch | -- | 仅导出任务有此字段，默认开启 |
| 上传文件 | FileUpload + Validate | 条件必填 | 仅导入任务有此字段 |

**Section 3: 网元选择（3个Tab）**

| Tab | 说明 |
|-----|------|
| 按网元 | 表格选择: 已选(N)/未选(N) + 移除/清空/导入网元 |
| 按分类 | 左侧分类菜单(按区域/类型/厂家/子网/站点/群组/制式/工程状态) + 右侧搜索+全选/递归选择/反选 |
| 按模板 | 模板树(预置/用户自定义/共享) + 网元总数 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 取消返回列表 |
| Confirm | Primary | 提交创建任务 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 任务执行中 | 状态列显示蓝色 "执行中" |
| 任务已完成 | 状态列显示绿色 "已完成" |
| 任务已停止 | 状态列显示灰色 "已停止" |
| 导入文件校验 | 校验按钮 + 通过/未通过计数 |

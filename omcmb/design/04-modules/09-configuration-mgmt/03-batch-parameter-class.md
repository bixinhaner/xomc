# 批量参数类配置 (Batch Parameter Class Configuration)

## 页面用途

按设备分类进行批量参数配置。左侧提供设备类型下拉筛选、网元选择按钮（带计数徽章）和参数模板树。用户选择目标网元和参数模板后，可批量下发参数配置到多个同类型设备。

## 布局模板

**Tree-List Page Layout（三栏树形列表页）**

## 导航路径

```
OMC 统一网管 > 配置管理 > 网元参数管理 > 批量参数类配置
```

## 路由

```
/config/batch-class
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 制式 | Select | API: 制式列表 | 请选择 | 设备网络制式 |
| 参数模型 | Select | API: 参数模型列表 | 请选择 | 参数模型版本 |
| 设备型号 | Select | API: 设备型号列表 | 请选择 | 设备型号 |
| 设备型号字 | TextInput | 用户输入 | 空 | 设备型号字自由输入 |

## 数据表规格

不适用（使用参数模板树 + 配置面板）

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 选择网元 | Badge Button (红色计数) | 打开网元选择器弹窗 |

## 弹窗规格

### 网元选择器弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 网元选择 |
| 尺寸 | 900px x 600px |

| Tab | 说明 |
|-----|------|
| 已选网元(N) | 显示已选网元列表，支持移除/清空 |
| 未选网元(N) | 显示未选网元列表，支持添加 |

**表格列:** 复选框 / Id / 网元名称 / 设备标识 / 监控状态 / 子网 / 区域 / 站点 / 群组 / 设备型号 / 设备型号字

**操作:** 移除 / 清空 / 导入网元

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗 |
| Confirm | Primary | 确认选择，更新徽章计数 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未选制式 | 参数模板树不可用 |
| 未选网元 | 徽章显示 0，配置操作禁用 |
| 参数导出 Tab | 切换到参数导出子标签，显示搜索框 + 刷新按钮 |

## 跨模块导航

无直接跨模块导航

# 图示系统 (Legend System)

## 页面用途

拓扑画布右侧浮动的图示说明面板，为用户提供拓扑图中所有节点类型、连线类型和状态颜色的视觉参考。支持按分类折叠展示，可独立开关各类图例的可见性。

## 布局模板

**Floating Panel（浮动面板）** — 从拓扑画布工具栏的图例图标触发，显示在画布右侧。

## 导航路径

```
OMC 统一网管 > 拓扑管理 > 拓扑树 > [图例按钮]
```

## 路由

```
/topology/tree  （浮动面板不改变路由）
```

## 弹窗规格

### 图示面板

| 属性 | 值 |
|------|-----|
| 类型 | Floating Panel (非模态浮动面板) |
| 位置 | 画布右侧，垂直居中 |
| 宽度 | 280px |
| 最大高度 | 画布高度 - 40px (超出可滚动) |
| 关闭方式 | X 按钮 / 再次点击图例图标 |

**交互规则:**
- 各分类支持折叠/展开（点击分类标题行的箭头）
- 默认全部展开
- 面板可拖拽调整位置
- 面板不遮挡画布操作，画布交互穿透

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 面板已打开 | 图例图标高亮状态 |
| 面板已关闭 | 图例图标默认状态 |
| 分类折叠 | 箭头旋转 ▶，隐藏子项 |
| 分类展开 | 箭头旋转 ▼，显示子项 |
| 图标已自定义 | 图示面板显示自定义后的图标（与图标设置同步） |

## 跨模块导航

无跨模块导航（纯展示面板）

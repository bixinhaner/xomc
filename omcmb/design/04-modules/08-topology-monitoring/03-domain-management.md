# 域管理 (Domain Management)

## 页面用途

管理行政区划层级结构（省 > 市 > 区/县），为设备和站点提供地理归属的组织框架。左侧展示域列表树形结构，右侧展示选中节点的域详情表单，支持节点的增删改操作。

## 布局模板

**Tree-Detail Layout（树形 + 详情布局）**

```
+------------------------------------------------------------------+
| 顶部导航栏                                                         |
+------------------------------------------------------------------+

```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 关键字过滤 | TextInput | 用户输入 | 空 | "输入关键字进行过滤"，实时过滤树节点高亮匹配 |

## 数据表规格

不适用（本页面使用树形结构 + 表单，无数据表格）

### 域列表树规格

| 层级 | 节点类型 | 图标 | 说明 |
|------|---------|------|------|
| 1 级 | 省 | 文件夹 📂 | 省级行政区划 |
| 2 级 | 市 | 文件夹 📂 | 地级市行政区划 |
| 3 级 | 区/县 | 文档 📄 | 区县级行政区划（叶子节点） |

**树交互:**
- 点击节点: 右侧加载该节点的域详情表单
- 展开/折叠: 点击箭头图标
- 高亮选中: 当前选中节点蓝色背景高亮

## 工具栏操作

| 按钮名称 | 图标 | 类型 | 位置 | 行为 |
|---------|------|------|------|------|
| 添加节点 | plus-circle (绿色) | Link | 右侧面板顶部 | 右侧切换为 "添加节点" 空白表单，上级节点自动填入当前选中节点 |
| 删除节点 | delete (红色) | Link | 右侧面板顶部 | 二次确认后删除当前选中节点及其子节点 |

## 弹窗规格

### 域详情 / 添加节点表单

| 属性 | 值 |
|------|-----|
| 类型 | Inline Form（内嵌表单，非弹窗） |
| 标题 | "域详情"（编辑模式）/ "添加节点"（新增模式） |

| 字段名称 | 组件类型 | 必填 | 字符限制 | 说明 |
|---------|---------|------|---------|------|
| 上级节点名称 | Select (下拉选择) | 是(*) | -- | 父节点选择，添加时自动填入当前选中节点 |
| 域名称 | TextInput | 是(*) | 0/16 | 区域中文名称 |
| 英文名称 | TextInput | 否 | 0/30 | 区域英文名称 |
| 简称 | TextInput | 否 | 0/30 | 区域简称 |
| 行政区划 | TextInput | 是(*) | -- | 行政区划代码（如 6102） |

| 按钮 | 类型 | 行为 |
|------|------|------|
| 保存 | Primary | 保存域信息，刷新左侧树 |

### 删除节点确认弹窗

| 属性 | 值 |
|------|-----|
| 类型 | Confirm Dialog |
| 图标 | ⚠️ 警告 |
| 内容 | "确定删除域节点 '{domainName}' 及其所有子节点？此操作不可撤销。" |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗 |
| Delete | Danger | 执行删除，刷新树，右侧清空 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 树加载中 | 左侧显示 Skeleton 骨架屏 |
| 树为空 | 显示 "暂无域数据，请添加根节点" |
| 未选中节点 | 右侧显示 "请在左侧选择一个域节点" |
| 保存成功 | Success 通知提示，左侧树自动刷新并保持选中状态 |
| 保存失败 | Error 通知提示 + 表单保持当前内容 |
| 删除含子节点的域 | 确认弹窗特别提示 "该节点下包含 N 个子节点" |
| 搜索过滤 | 树仅显示匹配节点及其父链路，自动展开 |

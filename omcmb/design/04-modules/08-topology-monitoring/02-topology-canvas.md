# 拓扑画布 (Topology Canvas)

## 页面用途

以逻辑拓扑图形式展示基站设备间的连接关系和层级结构。左侧面板提供设备列表（按管理域树形结构），用户勾选设备后在右侧画布中生成拓扑结构图。支持节点状态着色、告警角标、连线类型区分、统计面板以及丰富的显示设置。

## 筛选栏配置

### 左侧面板筛选

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 筛选维度 | Dropdown | 字典: 设备名称/区域名称 | 设备名称 | 切换树的过滤维度 |
| 关键字搜索 | TextInput | 用户输入 | 空 | "输入关键字进行过滤"，实时过滤树节点 |

### 画布搜索条件面板（点击 🔽 触发）

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 产品分类 | Select | API: 产品分类列表 | 请选择 | 按产品分类筛选拓扑节点 |
| 厂商 | Select | API: 厂商列表 | 请选择 | 按厂商筛选拓扑节点 |

## 数据表规格

不适用（本页面使用树形结构 + 画布，无传统数据表格）

### 设备树规格

| 层级 | 节点类型 | 图标 | 显示内容 | 交互 |
|------|---------|------|---------|------|
| 1 级 | 省 | 文件夹 📂 | 省名称 (已选数/总数) | 展开/折叠 + 复选框 |
| 2 级 | 市 | 文件夹 📂 | 市名称 (已选数/总数) | 展开/折叠 + 复选框 |
| 3 级 | 设备 | 设备图标 📡 | 设备名称 | 复选框 |

### 统计面板规格

| 统计项 | 子项 | 数据类型 |
|--------|------|---------|
| 设备数(物理) | 总数 / 各类型小站数 | 整数 |
| 设备数(逻辑) | 总数 / 各状态数 | 整数 |
| 小区数 | 总数 / 5G小区数 / 4G小区数 | 整数 |
| 入网状态 | 已激活 / 交维中 / 已开站 / 未激活(允许开站) / 未激活(拒绝开站) | 整数 |
| BU(5G) | 已连接 / 未连接 / -(未激活) | 整数 |
| BU(4G) | 已连接 / 未连接 / -(未激活) | 整数 |

## 工具栏操作

### 画布工具栏图标

| 按钮名称 | 图标 | 行为 |
|---------|------|------|
| 下载 | download | 导出拓扑图为 PNG/SVG |
| 统计图表 | bar-chart | 显示/隐藏统计面板 |
| 搜索 | search | 打开 SN 号搜索框，高亮匹配节点 |
| 筛选 | filter | 打开搜索条件面板（产品分类/厂商） |
| 设置 | settings | 打开拓扑显示设置弹窗 |
| 图例 | legend | 打开图示说明面板 |

### 画布控件

| 按钮名称 | 图标 | 行为 |
|---------|------|------|
| 撤销 | undo | 撤销上一步画布操作 |
| 放大 | zoom-in | 放大画布 |
| 缩小 | zoom-out | 缩小画布 |
| 适应屏幕 | fit-screen | 自适应缩放至全部可见 |
| 刷新 | refresh | 重新请求并渲染拓扑数据 |

### 左侧面板按钮

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 刷新 | Default | 刷新设备树列表 |
| 全选 | Default | 全选所有设备节点 |
| 反选 | Default | 反选当前勾选状态 |
| 查看拓扑 | Primary | 将已选设备加载到右侧拓扑画布 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 初始空状态 | 画布显示空状态插图 + "拓扑结构内容为空，请勾选后点击'查看拓扑'" |
| 加载拓扑中 | 画布中心显示加载动画 |
| 拓扑加载完成 | 自动 fit-screen 适应屏幕，显示统计面板 |
| 节点告警 | 节点右上角红色角标数字，表示告警数量 |
| 设备断连 | 对应连线变为红色虚线，节点图标加警告标识 |
| 搜索 SN | 匹配节点高亮闪烁，画布自动平移居中 |

### 拓扑节点类型

| 节点类型 | 图标 | 说明 |
|---------|------|------|
| 设备集(全连接) | 云图标 ☁️ | 所有下属设备均已连接 |
| 设备集(存在断开) | 云图标 + 警告 ⚠️☁️ | 部分设备断开连接 |
| 核心网 AMF | AMF 信号图标 | 5G 核心网 |
| 核心网 MME | MME 信号图标 | 4G 核心网 |
| 基站(4G一体化) | 基站图标 📡 | 4G 一体化小站 |
| BU/EU/RU | 各自专用图标 | 基带/射频单元 |

### 连线类型

| 连线类型 | 样式 | 说明 |
|---------|------|------|
| 设备连接 | 实线 | 正常连接关系 |
| Xn/X2 连接 | 虚线 | 基站间接口连接 |

### 节点状态着色

| 管理状态 | 颜色 | 说明 |
|---------|------|------|
| Unlocked | 绿色 | 正常解锁状态 |
| ShuttingDown | 黄色 | 关闭中 |
| Locked | 红色 | 锁定状态 |

# 快捷访问面板 (Quick Access Panel)

## 页面用途

Dashboard Row 4 右侧卡片，提供常用功能的快捷入口，包括最近访问页面、收藏页面和常用操作按钮。减少用户在多层导航中查找常用功能的时间成本。

## 布局模板

内嵌于 Dashboard 页面 Row 4 第三列，`Col span={8}`。

## Tab 1: 最近访问

展示用户最近访问过的页面列表，按时间倒序排列。

### 列表规格

| 属性          | 值                              |
|-------------|--------------------------------|
| 最大条数      | 8 条                           |
| 行高          | 36px                          |
| 布局          | 左: 图标 + 页面名称, 右: 相对时间 |

### 列表项样式

| 元素         | 样式                                    |
|-------------|----------------------------------------|
| 图标         | 16px, 取自导航菜单配置, color: #8C8C8C  |
| 页面名称     | 14px, color: #262626, 最大宽度 ellipsis |
| 相对时间     | 12px, color: #BFBFBF, 右对齐           |
| Hover 效果   | 背景色 #F5F5F5, 名称变 #1890FF         |
| 点击行为     | 跳转到对应页面                           |
| 无数据       | "暂无访问记录"                           |

### 时间格式

| 时间差            | 显示格式       |
|------------------|---------------|
| < 1 分钟          | "刚刚"        |
| 1-59 分钟         | "X 分钟前"    |
| 1-23 小时         | "X 小时前"    |
| 1-6 天            | "X 天前"      |
| > 7 天            | "MM-DD"       |

## Tab 2: 收藏页面

展示用户手动收藏的页面列表。

### 列表规格

| 属性          | 值                               |
|-------------|----------------------------------|
| 最大条数      | 10 条                           |
| 行高          | 36px                            |
| 布局          | 左: 星标 + 页面名称, 右: 取消收藏  |
| 排序方式      | 收藏时间倒序                      |

### 收藏操作

| 操作          | 触发方式                                     |
|-------------|----------------------------------------------|
| 添加收藏     | 在任何页面的 Tab 栏右键菜单中选择 "收藏此页面"    |
| 取消收藏     | 点击列表项右侧的取消收藏图标                     |
| 最大收藏数   | 20 个, 超出提示 "收藏已满, 请先取消部分收藏"      |

### 列表项样式

| 元素         | 样式                                       |
|-------------|-------------------------------------------|
| 星标         | `StarFilled`, 16px, color: #FAAD14        |
| 页面名称     | 14px, color: #262626                      |
| 取消收藏     | `StarOutlined`, Hover 时显示, color: #BFBFBF |
| Hover 效果   | 背景色 #F5F5F5                             |
| 点击行为     | 跳转到对应页面                               |
| 无数据       | "暂无收藏页面, 右键标签可添加收藏"              |

## 数据存储

```typescript
// 最近访问 - 存储在 localStorage
interface RecentVisit {
  key: string;            // 路由 path
  title: string;          // 页面名称
  icon: string;           // 图标名称
  timestamp: number;      // 访问时间戳
}

// 收藏页面 - 存储在后端 + localStorage 缓存
interface FavoritePage {
  key: string;            // 路由 path
  title: string;          // 页面名称
  icon: string;           // 图标名称
  createdAt: string;      // 收藏时间
}

// API
GET /api/user/favorites
POST /api/user/favorites  { key, title }
DELETE /api/user/favorites/{key}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 最近访问为空   | 显示空状态 "暂无访问记录"                 |
| 收藏为空       | 显示空状态 + 引导文字                    |
| 收藏加载失败   | 显示 "加载失败" + 重试按钮               |
| 收藏已满       | 添加时 Toast 提示 "收藏已满"             |

## 跨模块导航

| 来源            | 目标              | 触发方式      |
|----------------|-------------------|--------------|
| 最近访问列表项   | 对应页面           | 点击列表项    |
| 收藏页面列表项   | 对应页面           | 点击列表项    |
| 常用操作按钮     | 对应模块/弹窗      | 点击按钮      |

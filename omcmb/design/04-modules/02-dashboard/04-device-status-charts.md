# 设备在线/离线状态图表 (Device Status Charts)

## 页面用途

Dashboard Row 3 左侧图表卡片，以分组柱状图展示各设备类型的在线/离线数量分布，帮助运维人员快速识别设备连接健康状况。

## 布局模板

内嵌于 Dashboard 页面 Row 3 第一列，`Col span={8}`。

## 数据接口

```typescript
GET /api/dashboard/device-status?deviceType={deviceType}&period={day|week|month}

interface DeviceStatusChart {
  categories: string[];  // ['eNB', 'gNB', 'CPE', 'eGW']
  series: {
    online: number[];    // [200, 50, 100, 28]
    offline: number[];   // [56, 14, 28, 4]
  };
  total: number;         // 480
}
```

## 交互行为

| 操作              | 行为                                       |
|------------------|---------------------------------------------|
| 点击柱体          | 跳转到设备管理 > 在线监控, 携带设备类型和状态参数 |
| 时间选择器切换     | 重新请求对应时间段数据, 图表渐变过渡            |
| 点击刷新按钮       | 重新请求数据, 按钮旋转动画                     |
| 图例点击          | 切换对应系列显示/隐藏                          |
| 全局设备类型切换   | 如选 ALL, 显示全部; 如选具体类型, 仅显示该类型   |

## 状态处理

| 状态           | 处理方式                                  |
|---------------|------------------------------------------|
| 加载中         | 图表区域显示 Skeleton (矩形条纹骨架)         |
| 数据为空       | 显示 Empty 组件 "暂无设备数据"              |
| 加载失败       | 显示 "加载失败" + 重试按钮                  |
| 所有设备在线    | 离线柱体不显示 (值为 0)                     |
| 所有设备离线    | 在线柱体不显示 (值为 0), 整体红色警示底色     |

## 跨模块导航

| 来源          | 目标                    | 触发方式              |
|--------------|------------------------|-----------------------|
| 在线柱体      | 设备管理 > 在线监控      | 点击, status=online    |
| 离线柱体      | 设备管理 > 在线监控      | 点击, status=offline   |
| 设备类型标签   | 设备管理 > 设备列表      | 点击 X 轴类型标签       |

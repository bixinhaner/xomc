# 告警摘要组件 (Alarm Summary Widgets)

## 页面用途

Dashboard 第二行的告警摘要栏，提供当前系统告警的快速概览。包含四级告警计数条、告警分布环形图和最新告警滚动条三个子组件，帮助运维人员快速感知告警态势。

## 布局模板

内嵌于 Dashboard 页面 Row 2，通栏布局 `Col span={24}`。

## 子组件 3: 最新告警滚动条 (Ticker)

### 布局

```
┌──────────────────────────────┐
│  最新告警               暂停 ⏸ │
│  ─────────────────────────── │
│  ▶ [紧急] eNB-001 光模块故障   │ ← 当前显示条目

```

### 滚动规格

| 属性          | 值                              |
|--------------|---------------------------------|
| 滚动方向      | 垂直向上滚动                      |
| 滚动间隔      | 每 5 秒切换一条                   |
| 过渡动画      | slideUp, 300ms ease              |
| 数据条数      | 最近 20 条告警循环播放             |
| 暂停按钮      | 右上角, hover 显示, 点击暂停滚动   |
| 鼠标悬停      | 自动暂停滚动                      |
| 实时更新      | WebSocket 推送新告警时自动插入头部  |

### 单条告警格式

```
[等级标签] 设备名称 告警内容 (截断至40字符)

```

| 元素         | 样式                                          |
|-------------|-----------------------------------------------|
| 等级标签     | 与告警等级颜色一致, mini badge                   |
| 设备名称     | font-weight: 500, color: #262626               |
| 告警内容     | color: #595959, 超出截断 ellipsis               |
| 时间         | font-size: 11px, color: #BFBFBF                |
| 点击行为     | 跳转到对应告警详情                               |

## 数据接口

```typescript
// 告警摘要数据
GET /api/dashboard/alarm-summary?deviceType={deviceType}

interface AlarmSummary {
  counts: {
    critical: number;
    major: number;
    minor: number;
    warning: number;
    total: number;
  };
  recentAlarms: RecentAlarm[];  // 最近 20 条
}

interface RecentAlarm {
  alarmId: string;
  severity: 'critical' | 'major' | 'minor' | 'warning';
  deviceName: string;
  content: string;
  timestamp: string;
}
```

## 状态处理

| 状态              | 处理方式                                |
|------------------|-----------------------------------------|
| 加载中            | Skeleton 占位: 3 段矩形骨架              |
| 告警数据为空       | 显示 "当前无活跃告警" + 绿色对勾图标       |
| 滚动条无数据       | 显示 "暂无最新告警"                       |
| WebSocket 断连    | 滚动条暂停, 显示 "实时数据连接中断" 提示     |
| 环形图数据为 0     | 显示空心圆环 + 中心 "0"                   |

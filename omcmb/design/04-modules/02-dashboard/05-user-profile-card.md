# 用户信息卡片 (User Profile Card)

## 页面用途

Dashboard Row 4 左侧卡片，展示当前登录用户的基本信息（姓名、角色、登录时间），以及常用快捷操作链接。帮助用户快速确认身份信息并访问个人相关功能。

## 布局模板

内嵌于 Dashboard 页面 Row 4 第一列，`Col span={8}`。

## 信息列表

| 字段       | 数据来源             | 格式                        |
|-----------|---------------------|----------------------------|
| 登录时间   | session.loginTime   | YYYY-MM-DD HH:mm:ss       |
| 登录 IP   | session.loginIp     | IPv4/IPv6                  |
| 在线时长   | 实时计算             | X 小时 Y 分 (每分钟更新)     |
| 最后操作   | session.lastAction  | 操作描述文字                 |

## 数据接口

```typescript
GET /api/user/session-info

interface UserSessionInfo {
  username: string;          // 用户名
  displayName: string;       // 显示名称
  role: string;              // 角色名称
  roleLevel: 'admin' | 'operator' | 'readonly';
  loginTime: string;         // ISO 8601
  loginIp: string;           // IP 地址
  lastAction: string;        // 最后操作描述
  avatar?: string;           // 自定义头像 URL (可选)
}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 加载中         | 头像 + 文字行 Skeleton 骨架              |
| 加载失败       | 显示默认头像 + "用户信息加载失败"          |
| 会话过期       | 卡片显示 "会话已过期, 请重新登录" + 登录按钮 |
| 在线时长更新   | 每 60 秒自动更新一次, 无刷新闪烁          |

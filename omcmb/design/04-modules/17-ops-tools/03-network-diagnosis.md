# 任务管理 Task Management

> 模块路径：`/ops-tools/tasks`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 任务管理页 — 常用配置任务 + 批量参数配置任务

---

## 1. 页面概述

任务管理页面统一管理运维工具创建的配置任务。包含两类任务：常用配置任务（预定义的快捷操作）和批量参数配置任务（从配置管理模块创建的批量任务）。采用双 Tab 布局。

---

## 3. Tab 1 — 常用配置任务

### 3.1 筛选栏

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| 任务名称 | Input | 模糊搜索 |
| 配置类型 | Select | 开站配置/参数修改/基线恢复/邻区配置 |
| 配置模式 | Select | 全部/立即执行/定时执行 |
| 执行状态 | Select | 全部/待执行/执行中/成功/部分成功/失败 |

### 3.2 工具栏

[新建任务] [删除] [刷新]

### 3.3 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 任务名称 | `taskName` | 200px | |
| 配置类型 | `configType` | 120px | Tag |
| 配置模式 | `configMode` | 100px | 立即/定时 |
| 设备网络制式 | `networkStandard` | 120px | |
| 执行时间 | `executionTime` | 160px | |
| 执行结果 | `executionResult` | 120px | 成功/部分成功/失败 Tag |
| 创建时间 | `createTime` | 160px | |
| 创建人 | `creator` | 100px | |

### 执行结果颜色

| 状态 | Tag 颜色 | 说明 |
|------|---------|------|
| 待执行 | `default` | |
| 执行中 | `processing` | 蓝色 + 动画 |
| 成功 | `success` | 全部设备配置成功 |
| 部分成功 | `warning` | 部分设备失败 |
| 失败 | `error` | 全部失败 |

## 6. 新建常用配置任务

> 模态对话框 → 全页表单（复杂任务）

### 简单任务对话框（宽度 560px）

| 字段 | 组件 | 必填 |
|------|------|------|
| 任务名称 | Input | ✅ |
| 配置类型 | Select | ✅ |
| 网络制式 | Select | ✅ |
| 配置模式 | Radio（立即/定时） | ✅ |
| 定时时间 | DateTimePicker | 定时时必填 |
| 选择设备 | Device Selector | ✅ |
| 配置模板 | Select（从模板库选择）| — |
| 备注 | TextArea | — |

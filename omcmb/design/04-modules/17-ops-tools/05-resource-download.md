# 下载任务 Download Tasks

> 模块路径：`/ops-tools/downloads`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 下载任务页 — 资源下载 + 报表下载

---

## 1. 页面概述

下载任务页面统一管理系统中所有异步导出/下载任务。包含两个 Tab：资源下载（配置文件、日志文件、固件等设备资源的下载任务）和报表下载（性能报表、告警报表、统计报表等的导出任务）。

## 5. 通用交互

### 5.1 批量删除

1. 勾选多条记录
2. 点击 [批量删除]
3. 确认对话框："确认删除选中的 N 条下载任务？已完成的文件将被永久删除。"
4. 确认后删除，Toast 通知

### 5.2 下载交互

| 状态 | 操作按钮 | 行为 |
|------|---------|------|
| 待处理 | 无 | 等待 |
| 处理中 | 无 | 等待 |
| 已完成 | [下载] | 浏览器下载文件 |
| 失败 | [重试] | 重新创建下载任务 |
| 已过期 | 无 | 文件已清理，需重新导出 |

### 5.3 文件保留策略

- 已完成文件保留 **7 天**
- 超过 7 天自动标记为"已过期"并清理文件
- 每日 03:00 执行清理任务

### 5.4 实时更新

- 处理中的任务通过 WebSocket 推送状态变更
- 完成后自动刷新状态为"已完成"

---

## 6. 与全局任务面板的关系

下载任务同时在全局任务面板的"导出"Tab 中展示。两处数据同步，任一位置点击"下载"均可触发文件下载。

---

## 7. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看下载任务 | `ops:download:view` |
| 下载文件 | `ops:download:execute` |
| 删除下载任务 | `ops:download:delete` |

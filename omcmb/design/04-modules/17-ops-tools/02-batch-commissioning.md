# 指令管理 Command Management

> 模块路径：`/ops-tools/commands`
> 布局模板：列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 指令管理页

---

## 1. 页面概述

指令管理页面跟踪网管系统向设备下发的各类操作指令的执行状态。包括配置下发、版本升级、参数同步等设备操作指令。提供指令查询和状态监控。

---

## 3. 筛选栏

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| ID | Input | 精确/模糊搜索 |
| 设备名称 | Input | 模糊搜索 |
| 设备序列号 | Input | 精确搜索 |
| 执行状态 | Select | 全部/待执行/执行中/成功/失败/超时/已取消 |
| 操作类型 | Select | 全部/配置下发/版本升级/参数同步/重启/其他 |

---

## 4. 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| ID | `commandId` | 80px | |
| 设备名称 | `deviceName` | 140px | |
| 设备序列号 | `deviceSn` | 180px | 等宽字体 |
| 厂商 | `vendor` | 100px | |
| 创建人 | `creator` | 100px | |
| 创建时间 | `createTime` | 160px | 支持排序 |
| 完成时间 | `completeTime` | 160px | 未完成显示 `—` |
| 操作类型 | `operationType` | 120px | Tag |
| 执行状态 | `status` | 100px | Tag + 颜色 |

### 执行状态颜色

| 状态 | Tag 颜色 |
|------|---------|
| 待执行 | `default` (灰) |
| 执行中 | `processing` (蓝色 + 动画) |
| 成功 | `success` (绿) |
| 失败 | `error` (红) |
| 超时 | `warning` (橙) |
| 已取消 | `default` (灰) |

### 操作类型

| 类型 | Tag 颜色 |
|------|---------|
| 配置下发 | `blue` |
| 版本升级 | `purple` |
| 参数同步 | `cyan` |
| 设备重启 | `orange` |
| 日志获取 | `green` |
| 其他 | `default` |

## 5. 指令详情

点击表格行展开 Expandable Row 或打开侧滑抽屉，展示指令详细信息：

```
┌───────────────────────────────────┐
│ 指令详情 — CMD-001                │
├───────────────────────────────────┤
│ 基本信息                           │
│ ID：CMD-001                       │
│ 设备：NE-001 (SN-12345678)        │
│ 操作类型：配置下发                  │
│ 创建人：admin                      │
│ 创建时间：2024-01-15 14:30:00     │
│ 完成时间：2024-01-15 14:30:25     │
│ 耗时：25 秒                        │
│ 状态：✅ 成功                       │
│                                   │
│ 指令内容                           │
│ ┌─ JSON ─────────────────────┐   │
│ │ { "action": "setParam",   │   │
│ │   "params": {...}          │   │
│ │ }                          │   │
│ └────────────────────────────┘   │
│                                   │
│ 执行结果                           │
│ ┌─ JSON ─────────────────────┐   │
│ │ { "code": 200, ... }      │   │
│ └────────────────────────────┘   │
└───────────────────────────────────┘
```

# 网络连通性诊断 Network Connectivity Diagnosis

> 模块路径：`/ops-tools/network-diagnosis`
> 布局模板：工具页（输入 + 结果分屏）— 参考 `03-layouts/06-split-panel-page.md`
> 数据来源：基于网管系统通用网络诊断工具设计

---

## 1. 页面概述

网络连通性诊断工具提供 Ping 和 Traceroute 两种诊断能力，用于检测网管系统与网元设备之间的网络连通性和路由路径。运维工程师常用工具，支持从网管服务器发起或从指定设备发起诊断。

## 3. Ping 参数

| 字段 | 组件 | 默认值 | 说明 |
|------|------|--------|------|
| 诊断源 | Radio | 网管服务器 | 从哪里发起 Ping |
| 源设备 | Device Selector | — | 选择"指定设备"时显示 |
| 目标地址 | Input | — | IP 地址或域名 |
| Ping 次数 | InputNumber | 4 | 1-100 |
| 超时时间 | InputNumber | 3 秒 | 1-30 秒 |
| 包大小 | InputNumber | 64 字节 | 32-65535（展开高级选项） |

---

## 4. Traceroute 参数

| 字段 | 组件 | 默认值 | 说明 |
|------|------|--------|------|
| 诊断源 | Radio | 网管服务器 | |
| 源设备 | Device Selector | — | |
| 目标地址 | Input | — | IP 地址或域名 |
| 最大跳数 | InputNumber | 30 | 1-64 |
| 超时时间 | InputNumber | 3 秒 | |

### Traceroute 结果展示

```
> traceroute 10.0.1.100

 跳数  │ 地址              │ 延迟1    │ 延迟2    │ 延迟3
 ──────┼───────────────────┼─────────┼─────────┼─────────
  1    │ 192.168.1.1       │ 1.2 ms  │ 0.8 ms  │ 1.0 ms
  2    │ 10.0.0.1          │ 3.5 ms  │ 3.2 ms  │ 3.8 ms
  3    │ 10.0.0.5          │ 5.1 ms  │ 4.9 ms  │ 5.3 ms
  4    │ 10.0.1.100        │ 6.7 ms  │ 6.5 ms  │ 6.9 ms
```

结果同时以终端风格文本和结构化表格两种方式展示。

## 5. 结果区域

| 属性 | 值 |
|------|-----|
| 样式 | 终端风格，黑色背景 `#1A1A1A`，绿色文字 `#52C41A` |
| 字体 | 等宽字体 `SFMono-Regular` 13px |
| 实时输出 | 结果逐行实时追加（WebSocket 推送） |
| 可滚动 | 超出自动滚动到底部 |
| 复制 | 右上角 [复制结果] 按钮 |
| 清除 | [清除] 按钮 |

### 统计概要卡片

Ping 完成后底部展示统计卡片：

| 指标 | 展示 |
|------|------|
| 发送/接收/丢失 | 数字 + 丢包率百分比 |
| 最小/平均/最大延迟 | ms 数值 |
| 连通状态 | 0% 丢包 = 🟢 正常，>0% = 🟡 部分丢包，100% = 🔴 不通 |

## 6. 历史记录

页面底部可选展示最近 20 条诊断历史记录（折叠区域）：

| 列名 | 说明 |
|------|------|
| 时间 | 诊断执行时间 |
| 类型 | Ping / Traceroute |
| 目标 | 目标地址 |
| 结果 | 成功/丢包率 |
| 操作 | [重新执行] [查看详情] |

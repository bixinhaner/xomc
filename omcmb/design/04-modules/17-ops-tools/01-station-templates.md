# 模板管理 Template Management

> 模块路径：`/ops-tools/templates`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 模板管理页 — 开站模板 + 通用模板

---

## 1. 页面概述

模板管理页面提供两类模板的统一管理：开站模板（用于新基站开通流程）和通用模板（系统各模块使用的 Excel 导入导出模板）。采用双 Tab 布局。

---

## 2. 页面结构

```
┌─────────────────────────────────────────────────────┐
│ 面包屑：运维工具 / 模板管理                             │
├─────────────────────────────────────────────────────┤
│ Tab：[开站模板 (9)] [通用模板 (79)]                    │
├─────────────────────────────────────────────────────┤
│ (Tab 内容区)                                         │
└─────────────────────────────────────────────────────┘
```

## 3. Tab 1 — 开站模板

### 3.1 筛选栏

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| 模板名称 | Input | 模糊搜索 |
| 型号版本 | Select | 设备型号版本 |
| 开站模板类型 | Select | 室外宏站/室内分布/微站 等 |
| 网络制式 | Select | LTE-FDD/LTE-TDD/NR 等 |

### 3.2 工具栏

[新增模板] [刷新]

### 3.3 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 模板名称 | `templateName` | 240px | |
| 开站类型 | `stationType` | 120px | 室外宏站/室内分布/微站 |
| 网络制式 | `networkStandard` | 120px | |
| 型号版本 | `modelVersion` | 140px | |
| 创建人 | `creator` | 100px | |
| 创建时间 | `createTime` | 160px | 支持排序（默认降序） |
| 操作 | — | 140px | [下载](蓝) [删除](红) |

### 3.4 新增开站模板对话框

> 模态对话框，宽度 560px

```
┌─────────────────────────────────────┐
│ 新增开站模板                          │

│                                     │

│                                     │
│ ┌─────────────────────────────────┐ │
│ │                                 │ │
```

| 字段 | 组件 | 必填 | 说明 |

| 模板文件 | Upload 拖拽区域 | ✅ | .xlsx .xls .csv |

## 4. Tab 2 — 通用模板

### 4.1 筛选栏

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| 所属模块 | Select | 设备管理/基础配置/配置管理/系统管理 等 |
| 模板类型 | Select | 导入模板/导出模板/报表模板 |
| 模板名称 | Input | 模糊搜索 |

### 4.2 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 所属模块 | `module` | 140px | Tag 组件 |
| 模板类型 | `templateType` | 120px | |
| 模板名称 | `templateName` | 300px | 文件名（.xlsx） |
| 操作 | — | 80px | [下载] |

### 4.3 模块分类

| 模块 | 典型模板 |
|------|---------|
| 设备管理 | 设备导入模板、设备分组导入模板 |
| 基础配置 | 基站参数导入模板 |
| 配置管理 | 批量参数配置模板、邻区配置模板 |
| 系统管理 | 用户导入模板、角色导入模板 |
| 性能管理 | KPI 导出报表模板 |
| 告警管理 | 告警规则导入模板 |

- 通用模板为只读下载，不可删除/上传（由系统管理员统一维护）
- 数据量：79 条记录，单页展示（分页 10 条/页）

---

## 5. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看模板 | `ops:template:view` |
| 新增开站模板 | `ops:template:create` |
| 删除开站模板 | `ops:template:delete` |
| 下载模板 | `ops:template:download` |

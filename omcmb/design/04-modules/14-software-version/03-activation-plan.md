# 激活软件计划 Software Activation Plan

> 模块路径：`/software/activation-plan`
> 布局模板：列表页 + 全页表单 — 同升级计划
> 数据来源：Comba UMS 激活软件计划

---

## 1. 页面概述

管理软件激活计划。当升级计划设置为"手动激活"时，需通过激活计划来切换设备运行版本。页面结构与升级计划高度相似，区别在于操作对象是已下载但未激活的固件版本。

---

## 2. 计划列表页

结构同 `02-upgrade-plan.md` 列表页，以下为差异列：

| 列名 | 字段 | 说明 |
|------|------|------|
| 软件切换版本 | `switchVersion` | 替代"固件名称"列，展示目标激活版本 |
| 激活方式 | `activationType` | 热激活/冷激活（需重启） |

其余列（计划ID、名称、调度状态、下次执行、调度类型等）与升级计划一致。

### 工具栏按钮

与升级计划一致：[新建] [编辑] [查看] [删除] [启动] [执行一次] [停止] [暂停] [恢复] [刷新]

---

## 3. 新建/编辑表单（全页）

三个折叠分区，与升级计划结构一致，以下为差异字段：

### 3.1 任务信息

同升级计划，无差异。

### 3.2 激活信息（替代"升级信息"）

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 设备类别 | Select | ✅ | 联动网络制式 |
| 网络制式 | Select | ✅ | |
| 激活目标 | Radio | ✅ | 主程序/BootLoader/FPGA |
| 切换版本 | Select | ✅ | 从设备已下载版本中选择 |
| 激活方式 | Radio | ✅ | 热激活（不中断）/ 冷激活（需重启） |
| 版本回退 | Switch | — | 激活失败时自动回退到上一版本 |
| 成功条件 | Radio + InputNumber | — | 全部成功/比例达标 |
| 超时时间 | InputNumber | — | 默认 15 分钟 |

### 3.3 网元选择

同升级计划：按网元/按分类/按模板 三种模式。

---

## 4. 激活方式说明

| 方式 | 说明 | 风险 |
|------|------|------|
| 热激活 | 不中断业务，运行中切换 | 低，部分功能可能短暂异常 |
| 冷激活 | 需重启设备 | 高，业务中断 10-30 秒 |

冷激活选择时显示警告：

```
⚠ 冷激活将导致设备重启，业务中断约 10-30 秒。
  建议在维护窗口期执行。
```

---

## 5. 激活进度监控

激活执行后在底部任务面板展示进度：

| 字段 | 说明 |
|------|------|
| 网元名称 | |
| 原版本 | 激活前运行版本 |
| 目标版本 | 即将激活的版本 |
| 激活状态 | 等待/激活中/已激活/失败/已回退 |
| 进度 | 百分比进度条 |
| 耗时 | 秒 |

### 状态流转

```
等待 → 激活中 → 已激活 (成功)
                → 失败 → 已回退 (开启回退)
                       → 失败 (未开启回退)
```

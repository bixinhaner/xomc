# 网元版本查询 NE Version Query

> 模块路径：`/software/version-query`
> 布局模板：列表页 + 底部任务面板 — 参考 `03-layouts/02-list-page.md` + `03-layouts/11-task-panel.md`
> 数据来源：Comba UMS 网元版本查询升级 + 广研院 设备版本管理

---

## 1. 页面概述

网元版本查询页面展示所有网元的当前软件版本信息，支持按网元类型/制式筛选，提供版本查询、升级、激活等快捷操作入口。数据量大（12,520+ 行），需支持高效筛选和批量操作。

---

## 3. 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 复选框 | — | 40px | 多选 |
| ID | `neId` | 80px | |
| 网元名称 | `neName` | 180px | |
| 当前版本 | `currentVersion` | 160px | 等宽字体 |
| 备份版本 | `backupVersion` | 160px | 等宽字体，空则显示 `—` |
| 监控状态 | `monitorStatus` | 100px | 在线/离线 状态指示器 |
| 告警等级 | `alarmLevel` | 100px | 最高告警等级 Tag + 颜色 |
| 设备ID | `deviceId` | 140px | 等宽字体 |
| 工程状态 | `engineeringStatus` | 120px | 已开通/未开通/维护中 |
| 所属子网 | `subnet` | 140px | |
| 产品类别 | `productCategory` | 120px | |
| 厂商 | `vendor` | 100px | |
| 网络制式 | `networkStandard` | 100px | |
| 区域 | `region` | 120px | |
| 连接状态 | `connectionStatus` | 100px | 已连接/未连接 |
| 激活时间 | `activationTime` | 160px | |
| 更新时间 | `updateTime` | 160px | |

### 行操作

| 操作 | 说明 |
|------|------|
| 同步版本 | 从设备同步最新版本信息 |
| 下发升级 | 对单台设备直接下发升级指令 |
| 版本详情 | 打开侧滑抽屉展示详细版本信息 |

### 维度 Tab 说明

| 维度 | 树结构 |
|------|--------|
| 按区域 | 省 → 市 → 区 → 站点 → 网元 |
| 按类型 | 网元类型 → 设备型号 → 网元 |
| 按厂商 | 厂商 → 设备型号 → 网元 |
| 按子网 | 子网 → 网元 |
| 按站点 | 站点 → 网元 |
| 按分组 | 用户自定义分组 → 网元 |
| 按制式 | 网络制式 → 网元 |
| 按工程状态 | 已开通/未开通/维护中 → 网元 |
| 按模板 | 预定义模板 → 匹配的网元集合 |

## 6. 底部任务面板

固定底部，3 个 Tab 视图：

| Tab | 内容 |
|-----|------|
| 任务 | 正在执行的升级/激活/查询任务列表及进度 |
| 计划 | 关联的升级/激活计划列表 |

| 激活软件 | `software:version:activate` |
| 创建计划 | `software:plan:create` |
| 导入网元 | `software:ne:import` |

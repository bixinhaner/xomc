# 告警支持库 (Alarm Support Library)

## 页面用途

告警知识管理中心，包含三个子库：厂商告警支持库（厂商提供的标准告警定义）、系统告警支持库（系统自定义的告警定义）、告警经验库（运维人员贡献的排障经验笔记，支持富文本）。每个子库以表格 + 详情弹窗形式呈现。

## 布局模板

使用 02-list-page 布局，顶部 Tab 切换三个子库。

## 导航路径

告警管理 > 告警支持库

## 路由

`/alarm/support`

## Tab 1: 厂商告警支持库

厂商提供的标准告警定义，通常由系统导入，运维人员只读。

### 筛选栏

| 字段名称   | 英文标识      | 组件类型  | 必填 | 选项/说明               |
|----------|-------------|---------|------|------------------------|
| 告警码    | alarmCode   | Input   | 否   | 精确/模糊搜索            |
| 告警名称  | alarmName   | Input   | 否   | 模糊搜索                |
| 告警等级  | severity    | Select  | 否   | 紧急/主要/次要/警告       |
| 告警类别  | category    | Select  | 否   | 硬件/链路/温度/性能/其他  |
| 产品类别  | productType | Select  | 否   | eNB/gNB/CPE/eGW        |
| 厂商     | vendor      | Select  | 否   | 华为/中兴/爱立信/大唐     |

## Tab 2: 系统告警支持库

系统自定义的告警定义，管理员可编辑。

与厂商告警支持库结构相同，增加 "编辑" 和 "新建" 操作。

### 额外工具栏操作

| 操作名称   | 图标                | 类型     | 说明               |
|---------|--------------------|---------|--------------------|
| 新建定义  | `PlusOutlined`     | Primary | 新建系统告警定义     |
| 导入     | `ImportOutlined`   | Default | 批量导入告警定义     |

## Tab 3: 告警经验库

运维人员贡献的排障经验笔记，支持富文本内容。

### 筛选栏

| 字段名称   | 英文标识      | 组件类型  | 必填 | 选项/说明               |
|----------|-------------|---------|------|------------------------|
| 关键词    | keyword     | Input   | 否   | 搜索标题和内容           |
| 关联告警码 | alarmCode  | Input   | 否   | 搜索关联的告警码         |
| 作者      | author      | Input   | 否   | 模糊搜索                |
| 标签      | tags        | Select  | 否   | 多选标签筛选             |

| 标签         | tags      | Tags      | 否     | 140px  | 自定义标签          |

### 富文本编辑器

| 属性         | 值                                   |
|-------------|--------------------------------------|
| 编辑器类型   | TinyMCE / Quill / Tiptap            |
| 支持功能     | 标题/加粗/列表/代码块/图片/表格/链接   |
| 图片上传     | 支持拖拽和粘贴上传, 最大 5MB          |
| 附件上传     | 支持 pdf/doc/xlsx/jpg/png, 最大 20MB |
| 自动保存     | 每 30 秒自动保存草稿                  |

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 表格加载中     | Skeleton 骨架屏                         |
| 数据为空       | Empty "暂无告警定义/经验"                |
| 详情加载中     | 弹窗内 Skeleton 骨架                    |
| 富文本加载中   | 编辑器区域 Spin 加载                     |
| 图片上传中     | 图片位置显示上传进度                     |
| 保存成功       | Toast "保存成功", 返回列表               |

## 跨模块导航

|---------------|----------------------|-------------------|

| 关联告警码 Tag | 告警管理 > 当前告警   | 点击告警码 Tag     |

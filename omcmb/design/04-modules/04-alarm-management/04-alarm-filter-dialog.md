# 高级告警筛选对话框 (Alarm Filter Dialog)

## 页面用途

复杂的 5-Tab 高级告警筛选对话框。提供比简单筛选栏更精细的告警过滤能力，包括网元选择（3 种模式）、告警码表（2690+ 行搜索）、等级与时间、确认状态、清除状态等多维度联合筛选。支持保存筛选模板以便复用。

## 布局模板

Modal 对话框组件。

## 触发方式

当前告警 / 历史告警页面筛选栏中的 "高级筛选" 按钮。

### 告警码表规格

| 属性          | 值                                  |
|-------------|--------------------------------------|
| 数据量        | 2690+ 行                            |
| 渲染方式      | 虚拟滚动 (Virtual Scroll)            |
| 搜索          | 实时过滤 (debounce 300ms)            |
| 搜索字段      | 告警码 + 告警名称 (任一匹配)          |
| 快捷选择      | 按类别/等级批量选中                   |
| 表格高度      | 320px (固定, 内部滚动)              |

## 筛选模板功能

### 保存模板

| 属性     | 值                           |
|---------|------------------------------|
| 触发     | 点击 "保存当前为模板"          |
| 弹窗     | 输入模板名称 (2-32 字符)       |
| 存储     | 后端存储, 关联当前用户         |
| 最大数量  | 20 个模板                    |

### 加载模板

| 属性     | 值                            |
|---------|-------------------------------|
| 触发     | 从下拉框选择已保存模板          |
| 行为     | 自动填充所有 Tab 的筛选条件     |
| 管理     | 支持删除已保存模板              |

## 数据接口

```typescript
// 保存筛选模板
POST /api/alarm/filter-template
{
  name: string;
  conditions: AlarmFilterConditions;
}

interface AlarmFilterConditions {
  // Tab 1: 网元选择
  neSelectionMode: 'tree' | 'condition' | 'manual';
  selectedDeviceSns?: string[];
  neConditions?: { productType?, vendor?, region?, networkType?, connStatus? };
  manualSns?: string[];

  // Tab 2: 告警码
  alarmCodes?: string[];

  // Tab 3: 等级与时间
  severities?: string[];
  timeRange?: { start: string; end: string };
  durationRange?: { min?: number; max?: number };

  // Tab 4: 确认状态
  ackStatus?: 'all' | 'acked' | 'unacked';
  ackUser?: string;
  ackTimeRange?: { start: string; end: string };

  // Tab 5: 清除状态
  clearStatus?: 'all' | 'manual' | 'auto' | 'system';
  clearUser?: string;
  clearTimeRange?: { start: string; end: string };
}
```

## 底部操作栏

| 按钮         | 类型     | 说明                                |
|-------------|---------|-------------------------------------|
| 重置全部     | Default  | 清空所有 Tab 的筛选条件               |
| 取消         | Default  | 关闭对话框, 不应用任何变更             |
| 应用筛选     | Primary  | 关闭对话框, 将筛选条件应用到告警列表    |

## 状态处理

| 状态              | 处理方式                                |
|------------------|-----------------------------------------|
| 告警码加载中      | 表格显示 Skeleton 骨架                   |
| 设备树加载中      | 树组件显示 Skeleton 骨架                  |
| 模板加载失败      | 下拉框显示 "模板加载失败"                  |
| 模板保存成功      | Toast "模板保存成功"                      |
| Tab 有配置指示    | Tab 标签右侧显示蓝色圆点表示该 Tab 已配置  |

## 跨模块导航

本对话框为当前告警/历史告警页面内组件，应用筛选后返回原页面。

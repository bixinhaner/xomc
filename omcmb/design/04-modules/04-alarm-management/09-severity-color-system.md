# 告警等级颜色系统 (Severity Color System)

## 页面用途

本文档是告警等级颜色映射的权威参考规范。定义了系统中四级告警等级的颜色值、使用规则、显示优先级等标准。所有涉及告警等级展示的组件和页面均需遵循本规范。

> **本文档为设计参考文档，不对应具体页面。**

## 四级告警等级定义

| 优先级 | 等级名称 | 英文标识    | 等级代码 | 数值 | 说明               |
|-------|---------|-----------|---------|------|-------------------|
| 1     | 紧急    | Critical  | CRI     | 1    | 最高等级, 业务中断  |
| 2     | 主要    | Major     | MAJ     | 2    | 严重影响, 需立即处理 |
| 3     | 次要    | Minor     | MIN     | 3    | 轻微影响, 需关注    |
| 4     | 警告    | Warning   | WAR     | 4    | 预警性告警          |

**显示顺序：** 始终按照 紧急 → 主要 → 次要 → 警告 的顺序排列（从高到低）。

## 颜色优先级规则

当同一元素需要显示多个等级颜色时（例如设备的最高告警等级），遵循以下优先级规则：

```
紧急 > 主要 > 次要 > 警告 > 正常(无告警)
```

**规则说明：**
- 设备上有紧急告警和次要告警，设备的告警等级显示为 "紧急"（取最高等级）
- 排序默认按等级从高到低：紧急排最前，警告排最后
- 统计图表中，紧急系列始终置于最上层

## 可访问性 (Accessibility)

### 色盲兼容

四种告警颜色在色盲视角下仍需可区分。补充辅助手段：

| 辅助方式      | 说明                                     |
|-------------|------------------------------------------|
| 形状区分     | 紧急(实心圆)/主要(空心圆)/次要(三角)/警告(方块) |
| 文字标签     | 始终附带中文等级名称, 不仅依赖颜色          |
| ARIA 标签   | `aria-label="紧急告警: 5条"`             |
| 图案填充     | 图表中可选开启图案填充模式区分系列          |

### 对比度要求

| 场景             | 最低对比度比 | 说明                    |
|-----------------|------------|------------------------|
| 文字在主色背景上  | 4.5:1      | WCAG AA 标准           |
| 文字在浅色背景上  | 4.5:1      | WCAG AA 标准           |
| 次要等级特殊处理  | 次要用深色文字 | 黄色背景上白色文字不达标 |

```css

  /* 告警等级主色 */

  --alarm-major: #FA8C16;
  --alarm-minor: #FADB14;
  --alarm-warning: #1890FF;
  --alarm-normal: #52C41A;

  --alarm-minor-bg: rgba(250, 219, 20, 0.1);
  --alarm-warning-bg: rgba(24, 144, 255, 0.1);

  /* 告警等级悬停色 */
  --alarm-critical-hover: #FF7875;
  --alarm-major-hover: #FFA940;
  --alarm-minor-hover: #FFEC3D;
  --alarm-warning-hover: #40A9FF;

  /* 告警等级文字色 (在主色背景上) */
  --alarm-critical-text: #FFFFFF;
  --alarm-major-text: #FFFFFF;
  --alarm-minor-text: #333333;
  --alarm-warning-text: #FFFFFF;
}
```

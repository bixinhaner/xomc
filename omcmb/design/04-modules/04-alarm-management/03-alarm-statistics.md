# 告警统计 (Alarm Statistics)

## 页面用途

以 Dashboard 形式展示告警数据的多维度统计分析。包括告警趋势线图、TOP10 告警设备柱状图、告警等级分布饼图、告警类别分布图等。支持快速时间选择器切换统计周期。

## 布局模板

使用 dashboard-page 布局（图表网格）。

## 导航路径

告警管理 > 告警统计

## 路由

`/alarm/statistics`

## 时间选择器

| 选项     | 时间范围                    | 数据粒度    |
|---------|----------------------------|-----------|
| 今天     | 今日 00:00 ~ 当前时间        | 1 小时     |
| 7 天    | 最近 7 天                    | 1 天       |
| 30 天   | 最近 30 天                   | 1 天       |
| 自定义   | 用户自选日期范围, 最长 90 天  | 自动计算    |

### 样式

| 属性         | 值                                |
|-------------|-----------------------------------|
| 组件类型     | Segmented (分段器) + DateRangePicker |
| 位置         | 页面顶部, 内容区左上角               |
| 默认选中     | 7 天                               |

## 统计概要卡片

| 卡片名称     | 图标                    | 计算逻辑                 | 对比文字            |
|------------|------------------------|--------------------------|--------------------|
| 告警总数    | `AlertOutlined`        | 时间段内所有告警数         | 较上一周期 +/- %    |
| 新增告警    | `PlusCircleOutlined`   | 时间段内新产生告警数       | 较上一周期 +/- %    |
| 已清除告警  | `CheckCircleOutlined`  | 时间段内已清除告警数       | 较上一周期 +/- %    |
| 平均持续时长 | `ClockCircleOutlined` | 时间段内告警平均持续时长   | 较上一周期 +/- h    |

## 图表规格

### 告警趋势线图

| 属性          | 值                                    |
|-------------|---------------------------------------|
| 图表类型      | Stacked Area Chart (堆叠面积图)        |
| 高度          | 300px                                |
| X 轴          | 时间轴                                |
| Y 轴          | 告警数量                              |
| 系列          | 4 条线: 紧急/主要/次要/警告            |
| 颜色          | 紧急 #FF4D4F / 主要 #FA8C16 / 次要 #FADB14 / 警告 #1890FF |
| 面积填充      | 对应颜色 opacity 0.1                   |
| 图例          | 底部, 可点击切换系列显示                 |
| Tooltip       | 日期 + 各等级数量 + 合计                |
| 点击行为      | 点击数据点跳转到该日期的告警列表          |

### TOP10 告警设备柱状图

| 属性          | 值                                    |
|-------------|---------------------------------------|
| 图表类型      | Horizontal Bar Chart (水平柱状图)       |
| 高度          | 280px                                |
| X 轴          | 告警数量                               |
| Y 轴          | 设备名称 (TOP10)                       |
| 排序          | 告警数降序                              |
| 柱体颜色      | 渐变色 (数量越多越红)                    |
| Tooltip       | 设备名称 + 各等级告警数                  |
| 点击行为      | 点击柱体跳转到该设备的告警列表             |

### 告警等级分布饼图

| 属性          | 值                                    |
|-------------|---------------------------------------|
| 图表类型      | Donut Chart (环形图)                   |
| 高度          | 280px                                |
| 中心文字      | 告警总数                               |
| 系列          | 4 个扇形: 紧急/主要/次要/警告            |
| 颜色          | 对应告警等级颜色                        |
| 标签          | 等级名 + 数量 + 占比                    |
| 点击行为      | 点击扇形跳转到该等级的告警列表            |

### 告警类别分布图

| 属性          | 值                                    |
|-------------|---------------------------------------|
| 图表类型      | Horizontal Bar Chart (水平柱状图)       |
| 高度          | 280px                                |
| 类别          | 硬件告警/链路告警/温度告警/性能告警/其他   |
| 柱体颜色      | 不同类别不同颜色                        |
| 标签          | 类别名 + 数量 + 占比                    |

## 数据接口

```typescript
GET /api/alarm/statistics?deviceType={type}&period={today|7d|30d|custom}&startDate={}&endDate={}

interface AlarmStatistics {
  summary: {
    total: number;
    totalTrend: number;        // 百分比变化
    newAlarms: number;
    newAlarmsTrend: number;
    clearedAlarms: number;
    clearedAlarmsTrend: number;
    avgDuration: number;       // 分钟
    avgDurationTrend: number;  // 分钟变化
  };
  trend: {
    dates: string[];
    critical: number[];
    major: number[];
    minor: number[];
    warning: number[];
  };
  topDevices: Array<{
    deviceName: string;
    deviceSn: string;
    alarmCount: number;
    critical: number;
    major: number;
    minor: number;
    warning: number;
  }>;
  severityDistribution: Array<{
    severity: string;
    count: number;
    percent: number;
  }>;
  categoryDistribution: Array<{
    category: string;
    count: number;
    percent: number;
  }>;
}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 加载中         | 各图表独立 Skeleton 骨架                 |
| 数据为空       | 图表显示 Empty 状态                     |
| 部分加载失败   | 失败图表显示重试, 其他正常               |
| 时间切换       | 图表渐变过渡动画                        |
| 导出中         | 导出按钮 Loading 态                     |

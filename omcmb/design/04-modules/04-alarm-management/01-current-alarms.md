# 当前告警 (Current Alarms)

## 页面用途

实时展示系统中所有活跃（未清除）的告警信息。支持 WebSocket 实时刷新，行左侧边框按告警等级着色。提供多维度筛选、批量操作（确认/清除/屏蔽）和高级筛选对话框入口。是告警管理的核心页面。

## 布局模板

使用 02-list-page 布局。

## 导航路径

告警管理 > 当前告警

## 路由

`/alarm/current`

## 实时刷新机制

| 属性             | 值                                     |
|-----------------|----------------------------------------|
| 刷新方式         | WebSocket 实时推送                      |
| WebSocket 地址  | `ws://host/ws/alarm/current`            |
| 推送事件类型     | alarm_new (新告警), alarm_clear (清除), alarm_update (状态变更) |
| 连接状态指示器   | 页面右上角 "实时刷新 ●(绿)" / "连接中断 ●(红)" |
| 新告警插入       | 插入到表格顶部，带高亮闪烁动画 (2s)       |
| 告警清除         | 行从表格中渐隐移除 (300ms)               |
| 紧急告警提示     | 新增紧急告警时，浏览器通知 + 声音提醒 (可配置) |

## 行样式特殊处理

### 左侧颜色边框

每行左侧有 4px 宽度的颜色边框，颜色对应告警等级：

| 告警等级 | 左边框颜色 | 行背景色 (悬停)             |
|---------|-----------|---------------------------|
| 紧急     | #FF4D4F   | rgba(255, 77, 79, 0.04)  |
| 主要     | #FA8C16   | rgba(250, 140, 22, 0.04) |
| 次要     | #FADB14   | rgba(250, 219, 20, 0.04) |
| 警告     | #1890FF   | rgba(24, 144, 255, 0.04) |

### 新告警高亮

```css
@keyframes new-alarm-highlight {
  0% { background-color: rgba(24, 144, 255, 0.15); }
  100% { background-color: transparent; }
}
/* animation: new-alarm-highlight 2s ease-out; */
```

## 筛选栏配置

| 字段名称   | 英文标识        | 组件类型         | 必填 | 选项/说明                              |
|----------|---------------|----------------|------|---------------------------------------|
| 告警等级  | severity      | Select (多选)  | 否   | 紧急/主要/次要/警告                      |
| 告警码    | alarmCode     | Input          | 否   | 精确/模糊搜索                           |
| 设备名称  | deviceName    | Input          | 否   | 模糊搜索                               |
| SN       | deviceSn      | Input          | 否   | 精确搜索                               |
| 告警内容  | alarmContent  | Input          | 否   | 模糊搜索                               |
| 产生时间  | startTime     | DateRangePicker| 否   | 时间范围                               |
| 确认状态  | ackStatus     | Select         | 否   | 全部/已确认/未确认                       |
| 高级筛选  | -             | Button         | -    | 打开 5-Tab 高级筛选对话框 (见 04-alarm-filter-dialog.md) |

### 持续时间列特殊处理

持续时间列为实时计算字段，每分钟自动更新显示值。

| 时长范围      | 显示格式     | 颜色     |
|-------------|------------|---------|
| < 1 小时     | "Xm"      | #52C41A |
| 1-24 小时    | "Xh Xm"   | #FAAD14 |
| 1-7 天       | "Xd Xh"   | #FF4D4F |
| > 7 天       | "Xd"      | #FF4D4F |

## 工具栏操作

| 操作名称   | 图标                    | 类型     | 启用条件          | 说明                         |
|---------|------------------------|---------|------------------|------------------------------|
| 批量确认  | `CheckOutlined`        | Primary | 至少选 1 条未确认  | 确认选中的告警                  |
| 批量清除  | `ClearOutlined`        | Default | 至少选中 1 条      | 清除选中的告警 (从当前列表移除)   |
| 批量屏蔽  | `EyeInvisibleOutlined` | Default | 至少选中 1 条      | 对选中告警码创建屏蔽规则         |
| 导出     | `ExportOutlined`       | Default | 始终可用           | 导出当前筛选结果                |

### 行操作按钮

| 操作   | 图标                    | 显示条件       | 说明                  |
|-------|------------------------|--------------|----------------------|
| 确认   | `CheckOutlined`        | 未确认时显示   | 确认该告警             |

## 弹窗规格

### 确认操作

| 属性     | 值                                        |
|---------|-------------------------------------------|
| 类型     | Popconfirm (行内) / Modal.confirm (批量)    |
| 内容     | "确定要确认 {n} 条告警吗？"                  |
| 确认后   | Toast "已确认 {n} 条告警", 状态即时更新      |

### 清除操作

| 属性     | 值                                        |
|---------|-------------------------------------------|
| 类型     | Modal.confirm (warning)                    |
| 内容     | "确定要清除 {n} 条告警吗？清除后将移入历史告警。" |
| 确认后   | 行渐隐消失, Toast "已清除 {n} 条告警"       |

### 屏蔽操作

| 属性     | 值                                          |
|---------|---------------------------------------------|
| 类型     | Modal                                       |
| 标题     | 创建告警屏蔽规则                              |
| 内容     | 屏蔽范围(全局/指定设备), 屏蔽时长(永久/自定义)   |
| 确认后   | Toast "屏蔽规则已创建", 匹配告警从列表隐藏      |

## 声音/通知配置

| 告警等级  | 默认声音  | 浏览器通知  | 可配置项               |
|---------|---------|-----------|------------------------|
| 紧急     | 开启    | 开启       | 声音开关/音量/自定义铃声  |
| 主要     | 开启    | 开启       | 声音开关/音量            |
| 次要     | 关闭    | 关闭       | 声音开关                 |
| 警告     | 关闭    | 关闭       | 声音开关                 |

## 状态处理

| 状态             | 处理方式                                     |
|-----------------|----------------------------------------------|
| 首次加载         | 表格 Skeleton 骨架屏 (5 行)                    |
| 无活跃告警       | Empty "当前无活跃告警" + 绿色对勾图标            |
| WebSocket 断连   | 顶部 Alert 提示 "实时连接中断，正在重连..."      |
| WebSocket 重连成功| Alert 消失, 全量刷新告警数据                    |
| 批量操作中       | 工具栏按钮 Loading 态                          |
| 加载失败         | 错误提示 + 重试按钮                            |

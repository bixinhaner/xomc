# 历史告警 (Historical Alarms)

## 页面用途

查看已清除的历史告警记录。与当前告警页面结构类似，但增加了清除时间、清除方式、清除用户等列。无实时刷新，需要指定查询时间范围。用于告警回溯分析和审计。

## 布局模板

使用 02-list-page 布局。

## 导航路径

告警管理 > 历史告警

## 路由

`/alarm/history`

## 筛选栏配置

| 字段名称    | 英文标识        | 组件类型         | 必填 | 选项/说明                        |
|-----------|---------------|----------------|------|----------------------------------|
| 告警等级   | severity      | Select (多选)  | 否   | 紧急/主要/次要/警告                |
| 告警码     | alarmCode     | Input          | 否   | 精确/模糊搜索                     |
| 设备名称   | deviceName    | Input          | 否   | 模糊搜索                         |
| SN        | deviceSn      | Input          | 否   | 精确搜索                         |
| 告警内容   | alarmContent  | Input          | 否   | 模糊搜索                         |
| 产生时间   | alarmTimeRange| DateRangePicker| **是** | 默认最近 7 天, 最大跨度 90 天     |
| 清除时间   | clearTimeRange| DateRangePicker| 否   | -                                |
| 清除方式   | clearMethod   | Select         | 否   | 全部/手动清除/自动恢复/系统清除     |
| 确认状态   | ackStatus     | Select         | 否   | 全部/已确认/未确认                 |

> 产生时间为必填字段，防止无范围查询导致数据量过大。

## 数据表规格

| 列名称     | 英文标识         | 数据类型    | 可排序 | 宽度    | 说明                    |
|-----------|-----------------|-----------|--------|--------|------------------------|
| 告警等级   | severity        | Severity  | 是     | 90px   | 彩色圆点 + 文字          |
| 告警码     | alarmCode       | String    | 是     | 100px  | -                      |
| 告警名称   | alarmName       | String    | 是     | 140px  | -                      |
| 设备名称   | deviceName      | String    | 是     | 140px  | 蓝色链接                |
| SN        | deviceSn        | String    | 是     | 130px  | 可复制                  |
| 告警内容   | alarmContent    | String    | 否     | 180px  | ellipsis + Tooltip      |
| 产生时间   | alarmTime       | DateTime  | 是     | 160px  | YYYY-MM-DD HH:mm:ss    |
| 清除时间   | clearTime       | DateTime  | 是     | 160px  | YYYY-MM-DD HH:mm:ss    |
| 持续时长   | duration        | Duration  | 是     | 100px  | 静态值 (已结束)          |
| 清除方式   | clearMethod     | Tag       | 是     | 100px  | 手动(蓝)/自动(绿)/系统(灰) |
| 清除用户   | clearUser       | String    | 是     | 100px  | 自动清除时显示 "系统"     |
| 确认状态   | ackStatus       | Tag       | 是     | 90px   | 已确认(绿)/未确认(灰)    |
| 操作       | actions         | Actions   | 否     | 80px   | 详情                    |

### 清除方式说明

| 清除方式   | 说明                         | Tag 颜色   |
|-----------|------------------------------|-----------|
| 手动清除   | 运维人员手动执行清除操作        | blue      |
| 自动恢复   | 告警条件消除, 设备自动上报恢复   | green     |
| 系统清除   | 系统定时清理或规则自动清除       | default   |

## 工具栏操作

| 操作名称   | 图标                | 类型     | 说明                |
|---------|--------------------|---------|--------------------|
| 导出     | `ExportOutlined`   | Default | 导出当前筛选结果      |

> 历史告警不提供批量确认/清除操作（已经是历史记录）。

## 与当前告警的差异

| 特性           | 当前告警                 | 历史告警                  |
|---------------|------------------------|--------------------------|
| 实时刷新       | WebSocket 实时推送      | 无, 手动查询               |
| 行左侧颜色边框  | 有                     | 无 (仅告警等级列着色)       |
| 持续时间       | 实时计算, 动态更新       | 静态值 (已固定)            |
| 批量操作       | 确认/清除/屏蔽           | 仅导出                    |
| 时间范围       | 可选                    | 产生时间必填               |
| 额外列         | -                      | 清除时间/清除方式/清除用户   |
| 声音通知       | 支持                    | 不支持                    |

## 数据接口

```typescript
GET /api/alarm/history?severity={}&alarmCode={}&deviceName={}&deviceSn={}&alarmTimeStart={}&alarmTimeEnd={}&clearTimeStart={}&clearTimeEnd={}&clearMethod={}&ackStatus={}&page={}&size={}

// 产生时间范围为必传参数
```

## 状态处理

| 状态             | 处理方式                                     |
|-----------------|----------------------------------------------|
| 首次进入 (未查询) | 提示 "请选择时间范围后查询"                     |
| 查询中           | 表格 Skeleton 骨架屏                          |
| 无历史告警       | Empty "所选时间范围内无历史告警记录"              |
| 数据量过大       | 提示 "结果超过 10,000 条, 请缩小查询范围"        |
| 导出中           | 导出按钮 Loading 态 + 进度条                   |
| 加载失败         | 错误提示 + 重试按钮                             |

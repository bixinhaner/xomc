# 告警同步 (Alarm Sync)

## 页面用途

提供从设备侧同步当前告警数据和告警配置的功能。当系统告警数据与设备实际状态不一致时，通过告警同步操作重新获取设备上的实时告警状态。支持单设备同步和批量同步。

## 布局模板

使用 02-list-page 布局。

## 导航路径

告警管理 > 告警同步

## 路由

`/alarm/sync`

## 操作面板

### 同步类型

| 类型         | 说明                                     |
|-------------|------------------------------------------|
| 同步当前告警  | 从设备获取当前所有活跃告警, 与系统数据对齐   |
| 同步告警配置  | 从设备获取告警阈值配置等参数                |

### 设备范围

| 选项         | 说明                                     |
|-------------|------------------------------------------|
| 全部设备     | 对当前设备类型下所有在线设备执行同步          |
| 选择设备     | 显示设备多选表格, 可选择指定设备             |

### 设备选择器

当选择 "选择设备" 时，展开设备选择区域：

```
┌──────────────────────────────────────────────────────┐
│  [搜索设备名称或SN...]                                 │
│  ──────────────────────────────────────────────────  │
│  ☑ eNB-001 (SN001)  ● 在线                          │
│  ☑ eNB-002 (SN002)  ● 在线                          │
│  ☐ eNB-003 (SN003)  ○ 离线  ← 离线设备可选但会警告    │

```

## 同步状态表格

| 列名称     | 英文标识       | 数据类型    | 可排序 | 宽度    | 说明                    |
|-----------|---------------|-----------|--------|--------|------------------------|
| 设备名称   | deviceName    | String    | 是     | 140px  | -                      |
| 设备 SN   | deviceSn      | String    | 是     | 130px  | -                      |
| 产品类别   | productType   | String    | 是     | 100px  | -                      |
| 连接状态   | connStatus    | Status    | 是     | 90px   | ● 在线 / ○ 离线         |
| 同步状态   | syncStatus    | Tag       | 是     | 90px   | 颜色标签                |
| 同步结果   | syncResult    | String    | 否     | 120px  | 成功/失败原因            |
| 告警数     | alarmCount    | Number    | 是     | 80px   | 同步获取到的告警数量      |
| 开始时间   | startTime     | DateTime  | 是     | 140px  | -                      |
| 耗时       | duration      | String    | 是     | 80px   | Xs / Xm                |
| 操作       | actions       | Actions   | 否     | 80px   | 日志/取消/重试           |

### 同步状态标签

| 状态     | Tag 颜色     | 图标                  |
|---------|-------------|----------------------|
| 等待中   | default     | `ClockCircleOutlined`|
| 进行中   | processing  | Spin 动画             |
| 完成     | success     | `CheckCircleOutlined`|
| 失败     | error       | `CloseCircleOutlined`|
| 已取消   | warning     | `MinusCircleOutlined`|

### 行操作

| 同步状态 | 可用操作                    |
|---------|---------------------------|
| 等待中   | 取消                       |
| 进行中   | 取消                       |
| 完成     | 查看日志                    |
| 失败     | 重试 / 查看日志             |
| 已取消   | 重试                       |

## 同步进度条

```
同步进度: ████████░░░░░░░░░░░░ 40%
已完成 2/5, 进行中 1, 等待 2, 失败 0
预计剩余时间: 约 15 秒
```

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Progress + 统计文字              |
| 更新频率     | 每 500ms 更新一次                |
| 进度计算     | 已完成数 / 总数 * 100%           |
| 颜色         | 全部成功: 绿色, 有失败: 橙色      |

## 数据接口

```typescript
// 开始同步
POST /api/alarm/sync/start
{
  syncType: 'current' | 'config';
  scope: 'all' | 'selected';
  deviceSns?: string[];
}

// 查询同步状态
GET /api/alarm/sync/status/{taskId}

// 取消同步
POST /api/alarm/sync/cancel/{taskId}/{deviceSn}

// 重试失败设备
POST /api/alarm/sync/retry/{taskId}/{deviceSn}
```

## 状态处理

| 状态              | 处理方式                                  |
|------------------|--------------------------------------------|
| 未开始同步        | 表格区域显示 "请配置同步参数后开始同步"       |
| 同步中            | 开始按钮变为禁用, 显示进度条                 |
| 全部完成          | 进度条 100%, Alert 成功 "同步完成"           |
| 部分失败          | Alert 警告 "部分设备同步失败, 请检查"         |
| 全部失败          | Alert 错误 "同步失败" + 重试按钮              |
| 离线设备同步      | 直接标记为失败 "设备离线"                     |

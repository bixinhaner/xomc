# 告警规则 (Alarm Rules)

## 页面用途

管理告警处理规则，包括告警屏蔽、告警合并、告警关联、告警升级四种规则类型。每种规则定义匹配条件（告警码、等级、网元范围）和触发动作。

## 布局模板

使用 02-list-page 布局。

## 导航路径

告警管理 > 告警规则

## 路由

`/alarm/rules`

## 筛选栏配置

| 字段名称   | 英文标识    | 组件类型  | 必填 | 选项/说明                     |
|----------|-----------|---------|------|------------------------------|
| 规则名称  | ruleName  | Input   | 否   | 模糊搜索                      |
| 规则类型  | ruleType  | Select  | 否   | 全部/屏蔽/合并/关联/升级        |
| 状态     | status    | Select  | 否   | 全部/启用/禁用                 |

## 数据表规格

| 列名称     | 英文标识       | 数据类型  | 可排序 | 宽度    | 说明                      |
|-----------|---------------|---------|--------|--------|--------------------------|
| 规则名称   | ruleName      | String  | 是     | 160px  | 蓝色链接                   |
| 规则类型   | ruleType      | Tag     | 是     | 100px  | 颜色 Tag (见下方)          |
| 匹配条件   | conditions    | String  | 否     | 200px  | 条件摘要                   |
| 作用范围   | scope         | String  | 是     | 120px  | 全局/指定区域/指定设备       |
| 状态       | status        | Switch  | 是     | 80px   | 启用/禁用开关               |
| 命中次数   | hitCount      | Number  | 是     | 100px  | 该规则被触发的次数           |
| 创建人     | creator       | String  | 是     | 100px  | -                         |
| 创建时间   | createTime    | DateTime| 是     | 160px  | -                         |
| 操作       | actions       | Actions | 否     | 120px  | 编辑/删除                   |

### 规则类型标签

| 类型   | Tag 颜色   | 说明                            |
|-------|-----------|--------------------------------|
| 屏蔽   | orange    | 匹配的告警不在当前告警列表中显示    |
| 合并   | blue      | 相同条件的告警合并为一条显示        |
| 关联   | purple    | 建立告警间的因果关系               |
| 升级   | red       | 满足条件时自动升级告警等级          |

### 表单字段

| 字段名称     | 组件类型        | 必填 | 校验规则                    |
|------------|---------------|------|---------------------------|
| 规则名称    | Input         | 是   | 非空, 2-64 字符             |
| 规则类型    | Select        | 是   | 屏蔽/合并/关联/升级          |
| 作用范围    | Radio + Select| 是   | 全局/区域/设备               |
| 规则描述    | TextArea      | 否   | 最大 256 字符               |
| 告警码匹配  | Checkbox 列表  | 是   | 至少选择 1 个 (或选全部)     |
| 告警等级    | Checkbox 组   | 是   | 至少选择 1 个               |

**规则类型特有字段：**

| 规则类型 | 特有字段                                     |
|---------|---------------------------------------------|
| 屏蔽     | 屏蔽时长 (永久/定时)                           |
| 合并     | 合并窗口 (分钟), 合并维度 (告警码/设备/等级)     |
| 关联     | 主告警码, 从告警码, 关联关系 (因果/并发)         |
| 升级     | 升级条件 (持续时间), 升级路径 (从等级→到等级)     |

## 状态处理

| 状态           | 处理方式                               |
|---------------|----------------------------------------|
| 表格加载中     | Skeleton 骨架屏                         |
| 数据为空       | Empty "暂无告警规则"                     |
| 状态切换       | Switch 切换立即生效                      |
| 删除确认       | "删除后, 该规则将不再生效"                |
| 保存成功       | Toast "规则保存成功", 刷新列表            |

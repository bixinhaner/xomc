# 告警详情 (Alarm Detail)

## 页面用途

展示单条告警的完整详细信息，以抽屉 (Drawer) 形式从右侧滑出。包含基本信息、处理建议（来自告警支持库）、处理历史（时间线）和关联告警（同一设备的其他告警）四个区块。

## 布局模板

Drawer 组件（右侧滑出）。

## 触发方式

当前告警 / 历史告警列表行操作中的 "详情" 按钮。

## Drawer 规格

| 属性         | 值                              |
|-------------|--------------------------------|
| 宽度         | 560px                          |
| 方向         | 右侧滑入                        |
| 关闭方式     | × 按钮 / 点击遮罩 / ESC 键      |
| 遮罩         | 半透明遮罩                       |

## 区块 1: 告警概要头部

| 元素           | 样式                                     |
|---------------|------------------------------------------|
| 等级标签       | 大号 Tag, 对应等级颜色, font-size: 14px    |
| 告警码 + 名称  | font-size: 18px, font-weight: 600        |
| 设备名称       | font-size: 14px, 蓝色链接可点击           |
| 产生时间       | font-size: 13px, color: #8C8C8C          |
| 持续时间       | font-size: 13px, 实时更新, 颜色同告警等级  |
| 确认状态       | Tag 组件                                 |

## 区块 2: 基本信息

Descriptions 描述列表，每行一个字段。

| 字段       | 数据类型    | 说明                  |
|-----------|-----------|----------------------|
| 告警码     | String    | -                    |
| 告警等级   | Severity  | 彩色标识              |
| 告警名称   | String    | -                    |
| 设备名称   | String    | 蓝色链接              |
| 设备 SN   | String    | 可复制                |
| 产品类别   | String    | -                    |
| 告警内容   | String    | 多行显示, 不截断       |
| 产生时间   | DateTime  | 完整时间               |
| 确认状态   | Tag       | 已确认/未确认          |
| 确认人     | String    | 未确认时显示 "-"       |
| 确认时间   | DateTime  | 未确认时显示 "-"       |

## 区块 3: 处理建议

从告警支持库中匹配的处理建议信息。

| 元素           | 说明                                   |
|---------------|----------------------------------------|
| 来源标识       | "厂商告警支持库" / "系统告警支持库" / "经验库" |
| 可能原因       | 编号列表                                |
| 处理步骤       | 编号列表，有序步骤                        |
| 参考文档       | 文档链接，可点击下载                       |
| 无建议时       | 显示 "暂无处理建议" + "前往经验库添加"      |

## 区块 4: 处理历史

时间线组件，展示该告警从产生到当前的所有处理操作。

| 时间线节点类型   | 图标颜色  | 说明                    |
|-------------|---------|------------------------|
| 告警产生     | 红色     | 系统自动记录              |
| 查看详情     | 蓝色     | 用户查看操作              |
| 确认告警     | 绿色     | 用户确认操作              |
| 添加备注     | 蓝色     | 用户添加的处理备注         |
| 告警清除     | 灰色     | 告警清除 (手动/自动)       |

### 添加处理备注

| 属性     | 值                              |
|---------|--------------------------------|
| 触发     | 点击 "添加处理备注" 按钮         |
| 输入方式  | 行内展开 TextArea               |
| 最大字数  | 500 字符                        |
| 提交后   | 新备注追加到时间线, TextArea 收起 |

## 区块 5: 关联告警

列出同一设备上当前活跃的其他告警。

| 元素           | 说明                             |
|---------------|----------------------------------|
| 列表项格式     | 等级标识 + 告警码 + 名称 + 时间 + 持续 |
| 最多显示       | 5 条, 超出显示 "查看全部"          |
| 点击行为       | 切换到该告警的详情                  |
| 无关联告警     | 显示 "该设备当前无其他活跃告警"      |

## 底部操作栏

| 按钮         | 类型     | 显示条件          | 说明              |
|-------------|---------|------------------|-------------------|
| 确认告警     | Primary  | 未确认时显示       | 确认该告警         |
| 清除告警     | Default  | 当前告警时显示     | 手动清除           |
| 屏蔽告警码   | Default  | 始终显示          | 创建屏蔽规则       |

## 数据接口

```typescript
GET /api/alarm/detail/{alarmId}

interface AlarmDetail {
  basic: {
    alarmId: string;
    alarmCode: string;
    severity: string;
    alarmName: string;
    deviceName: string;
    deviceSn: string;
    productType: string;
    content: string;
    alarmTime: string;
    ackStatus: string;
    ackUser?: string;
    ackTime?: string;
    clearTime?: string;
    clearMethod?: string;
    clearUser?: string;
  };
  suggestion: {
    source: string;
    possibleCauses: string[];
    steps: string[];
    referenceDoc?: string;
  } | null;
  history: Array<{
    time: string;
    action: string;
    user: string;
    note?: string;
  }>;
  relatedAlarms: Array<{
    alarmId: string;
    alarmCode: string;
    severity: string;
    alarmName: string;
    alarmTime: string;
    duration: string;
  }>;
}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 加载中         | Drawer 内容区 Skeleton 骨架              |
| 告警不存在     | 显示 "告警不存在或已被删除"               |
| 处理建议为空   | 显示 "暂无处理建议" + 引导链接            |
| 处理历史为空   | 仅显示 "告警产生" 节点                    |
| 备注提交中     | TextArea 禁用 + Spin                    |
| 确认/清除成功  | Toast 提示 + 更新 Drawer 内容 + 刷新列表  |

## 跨模块导航

| 来源              | 目标                  | 触发方式            |
|------------------|----------------------|--------------------|
| 设备名称链接       | 设备管理 > 设备详情   | 点击蓝色链接         |
| 关联告警列表项     | 切换到该告警详情       | 点击列表项           |
| "查看全部" 链接   | 告警管理 > 当前告警    | 携带设备参数筛选      |
| 参考文档链接       | 文件下载              | 点击下载             |
| "前往经验库添加"  | 告警管理 > 告警支持库  | 点击链接             |

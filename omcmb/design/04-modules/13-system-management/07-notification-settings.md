# 告警通知设置 Notification Settings

> 模块路径：`/system/notifications`
> 布局模板：表单页（分区卡片）— 参考 `03-layouts/12-form-page.md`
> 数据来源：综合三套系统告警通知功能设计

---

## 1. 页面概述

配置告警和系统事件的通知方式与规则。支持邮件、短信、站内消息三种通知渠道，可按告警等级、设备类型、时间段灵活配置通知策略。

## 5. 通知渠道配置（Tab 2）

### 5.1 邮件通知

| 配置项 | 说明 |
|--------|------|
| SMTP 服务器 | 引用系统配置中的邮件服务器 |
| 邮件模板 | 告警通知邮件 HTML 模板预览 |
| 测试发送 | 输入邮箱地址，发送测试邮件 |

### 5.2 短信通知

| 配置项 | 说明 |
|--------|------|
| 短信网关 | 短信服务提供商 API 配置 |
| 签名 | 短信签名，如 【OMC网管】 |
| 模板 | 告警短信模板 |
| 测试发送 | 输入手机号，发送测试短信 |

### 5.3 站内消息

| 配置项 | 说明 |
|--------|------|
| 消息保留天数 | 默认 30 天 |
| 弹窗提醒 | 开关：收到消息时浏览器弹窗 |
| 声音提醒 | 开关 + 声音选择 |

## 6. 通知记录（Tab 3）

| 列名 | 字段 | 说明 |
|------|------|------|
| 发送时间 | `sendTime` | `YYYY-MM-DD HH:mm:ss` |
| 规则名称 | `ruleName` | |
| 触发告警 | `alarmInfo` | 告警摘要 |
| 通知渠道 | `channel` | 邮件/短信/站内 |
| 收件人 | `recipients` | |
| 发送状态 | `sendStatus` | 成功/失败/待发送 |
| 失败原因 | `failReason` | 仅失败时显示 |

---

## 7. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看通知设置 | `system:notification:view` |
| 新增/编辑规则 | `system:notification:edit` |
| 删除规则 | `system:notification:delete` |
| 配置通知渠道 | `system:notification:config` |
| 查看通知记录 | `system:notification:log` |

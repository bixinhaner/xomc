# 系统参数配置 System Configuration

> 模块路径：`/system/config`
> 布局模板：表单页（分区卡片）— 参考 `03-layouts/12-form-page.md`
> 数据来源：Comba UMS 系统管理 + 通用 B2B 系统设计

---

## 1. 页面概述

系统参数配置页面集中管理全局系统设置，包括基本参数、安全策略、邮件/短信通知、数据保留策略等。采用分区卡片布局，每个配置分区可独立折叠和保存。

## 3. 配置分区详情

### 3.1 基本参数

| 字段 | 组件 | 默认值 | 说明 |
|------|------|--------|------|
| 系统名称 | Input | OMC 统一网管系统 | 显示在 Header 和浏览器标题 |
| 系统版本 | 只读文本 | — | 后端获取，不可修改 |
| 部署模式 | Radio | 单机 | 影响集群相关配置显示 |
| 数据刷新间隔 | InputNumber | 30 秒 | Dashboard/告警等页面自动刷新间隔 |
| 会话超时 | InputNumber | 30 分钟 | 无操作自动退出 |
| 时区设置 | Select | Asia/Shanghai | 影响所有时间显示 |
| 日期格式 | Select | YYYY-MM-DD HH:mm:ss | 可选：DD/MM/YYYY、MM/DD/YYYY |

### 3.2 安全策略

| 字段 | 组件 | 默认值 |
|------|------|--------|
| 密码最小长度 | InputNumber | 8 |
| 密码复杂度 | Checkbox Group | 大写+小写+数字 |
| 密码有效期 | InputNumber | 90 天 |
| 历史密码限制 | InputNumber | 5 次 |
| 登录失败锁定 | InputNumber × 2 | 5 次 / 30 分钟 |
| 登录验证码 | Radio | 失败3次后开启 |
| IP 白名单 | Switch + TextArea | 关闭 |

### 3.3 邮件服务器

| 字段 | 组件 | 说明 |
|------|------|------|
| SMTP 服务器 | Input | 域名或IP |
| 端口 | InputNumber + Checkbox | 端口 + SSL 开关 |
| 发件人邮箱 | Input | 通知邮件的 From |
| 用户名 | Input | SMTP 认证 |
| 密码 | Input.Password | SMTP 认证 |
| 测试连接 | Button | 发送测试邮件验证配置 |

### 3.4 数据保留策略

| 数据类型 | 默认保留天数 | 范围 |
|---------|-------------|------|
| 告警数据 | 180 天 | 30-365 |
| 性能数据 | 90 天 | 7-365 |
| 操作日志 | 180 天 | 30-365 |
| MR 数据 | 30 天 | 7-180 |
| 任务记录 | 60 天 | 7-180 |

## 4. 交互规则

| 行为 | 说明 |
|------|------|
| 分区独立保存 | 每个卡片有独立的 [保存] 按钮 |
| 未保存提示 | 修改后离开页面弹出确认对话框 |
| 重置默认 | 恢复该分区所有字段为出厂默认值 |
| 测试连接 | 异步执行，按钮显示 Loading 状态 |
| 折叠/展开 | 点击卡片标题栏折叠，记住用户偏好 |

---

## 5. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看系统配置 | `system:config:view` |
| 修改基本参数 | `system:config:edit-basic` |
| 修改安全策略 | `system:config:edit-security` |
| 修改邮件配置 | `system:config:edit-mail` |
| 修改数据保留 | `system:config:edit-retention` |

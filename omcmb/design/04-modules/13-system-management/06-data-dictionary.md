# 数据字典 Data Dictionary

> 模块路径：`/system/data-dictionary`
> 布局模板：列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：Comba UMS 导入/导出分类配置（742 行数据）

---

## 1. 页面概述

数据字典管理系统中的枚举值、分类编码等基础数据。支持查看、导入、导出操作。数据字典为系统全局共享的基础配置，修改影响范围大，需谨慎操作。

## 3. 字典分类树（左侧）

| 元素 | 说明 |
|------|------|
| 树节点 | 字典分类名称 + 子项数量徽章 |
| 搜索 | 树顶部搜索框，过滤分类 |
| 右键菜单 | 新增分类 / 编辑 / 删除 |
| 选中态 | 蓝色背景高亮 |

### 预设分类

| 分类编码 | 分类名称 | 说明 |
|---------|---------|------|
| `device_type` | 设备类型 | RRU/BBU/pRRU 等 |
| `network_standard` | 网络制式 | LTE-FDD/TDD/NR 等 |
| `alarm_severity` | 告警等级 | 紧急/主要/次要/警告 |
| `operation_type` | 操作类型 | 登录/新增/修改/删除 等 |
| `protocol_type` | 协议类型 | TR-069/SNMP/NETCONF |
| `vendor` | 厂商信息 | 华为/中兴/爱立信 等 |
| `region` | 区域 | 省/市/区划分 |
| `ne_status` | 网元状态 | 在线/离线/异常 |

## 4. 字典项列表（右侧）

### 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| ID | `id` | 80px | 自增 |
| 编码 | `code` | 160px | 唯一标识，英文 |
| 名称 | `name` | 200px | 中文显示名 |
| 英文名 | `nameEn` | 200px | 英文显示名 |
| 排序号 | `sortOrder` | 80px | 数字，升序排列 |
| 状态 | `status` | 80px | 启用/禁用 Tag |
| 备注 | `remark` | 200px | 超长截断 |

## 5. 新增/编辑字典项

> 模态对话框，宽度 480px

| 字段 | 组件 | 必填 | 规则 |
|------|------|------|------|
| 所属分类 | Select (只读) | ✅ | 自动填充当前分类 |
| 编码 | Input | ✅ | 英文+数字+下划线+中划线 |
| 名称 | Input | ✅ | 中文名 |
| 英文名 | Input | — | |
| 排序号 | InputNumber | — | 默认 0 |
| 状态 | Switch | — | 默认启用 |
| 备注 | TextArea | — | 最多 200 字 |

| 客户端IP | `clientIp` | 等宽字体 |

## 8. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看数据字典 | `system:dict:view` |
| 新增/编辑字典项 | `system:dict:edit` |
| 删除字典项 | `system:dict:delete` |
| 导入 | `system:dict:import` |
| 导出 | `system:dict:export` |

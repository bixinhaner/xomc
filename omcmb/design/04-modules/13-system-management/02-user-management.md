# 用户管理 User Management

> 模块路径：`/system/users`
> 布局模板：列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：Comba UMS 系统管理模块（用户菜单/密码修改/锁定时间）

---

## 1. 页面概述

用户管理页面提供系统用户的增删改查、密码管理、登录安全设置。页面同时包含从 Header 右上角用户菜单触发的快捷操作（修改密码、锁定时间设置）。

## 3. 新增/编辑用户对话框

> 模态对话框，宽度 640px

| 字段 | 组件 | 必填 | 规则 |
|------|------|------|------|
| 用户名 | Input | ✅ | 4-32 位字母数字下划线，新增后不可改 |
| 姓名 | Input | ✅ | |
| 手机号 | Input | — | 11 位手机号格式 |
| 邮箱 | Input | — | Email 格式校验 |
| 角色 | Select 多选 | ✅ | 从角色列表选择 |
| 初始密码 | Input.Password | ✅ | 仅新增时显示，8-32 位含大小写+数字 |
| 状态 | Switch | — | 默认启用 |
| 备注 | TextArea | — | 最多 200 字 |

### 密码强度指示器

| 强度 | 条件 | 颜色 |
|------|------|------|

| 中 | 满足 3 项规则 | `#FAAD14` 黄色 |
| 强 | 满足全部规则 | `#52C41A` 绿色 |

## 5. 锁定时间设置

> 从 Header 用户菜单触发
> 小型模态对话框，宽度 400px

```
┌───────────────────────────┐
│ 设置自动锁定时间            │
├───────────────────────────┤
│                           │
│ 无操作自动锁屏时间（分钟）：│
│ [  5  ] [-] [+]           │
│                           │
│ 范围：1 ~ 60 分钟          │
│                           │
│      [取消]    [确定]      │
└───────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 组件 | InputNumber + Stepper |
| 默认值 | 5 分钟 |
| 最小值 | 1 分钟 |
| 最大值 | 60 分钟 |
| 步长 | 1 |
| 作用域 | 当前用户个人设置 |

## 7. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看用户列表 | `system:user:view` |
| 新增用户 | `system:user:create` |
| 编辑用户 | `system:user:edit` |
| 删除用户 | `system:user:delete` |
| 重置他人密码 | `system:user:reset-password` |
| 修改自己密码 | 所有登录用户 |
| 设置锁定时间 | 所有登录用户 |

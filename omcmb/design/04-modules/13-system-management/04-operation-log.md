# 操作日志 Operation Log

> 模块路径：`/system/operation-log`
> 布局模板：列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：Comba UMS + 广研院 系统管理/日志管理

---

## 1. 页面概述

记录系统所有用户操作的审计日志，支持多维度筛选查询。操作日志为只读数据，仅支持查看和导出，不可修改或删除（审计安全要求）。

---

## 2. 页面结构

```
┌─────────────────────────────────────────────────────┐
│ 面包屑：系统管理 / 操作日志                             │
├─────────────────────────────────────────────────────┤
│ 时间快捷选择：[今天] [近7天] [近30天] [自定义]          │
├─────────────────────────────────────────────────────┤
│ 筛选栏：                                              │
│ 操作人 [________] 功能菜单 [▼ 全部] 操作类型 [▼ 全部] │

│ 执行结果 [▼ 全部]  [展开更多▼]                        │
│                            [查询] [重置] [导出]       │
├─────────────────────────────────────────────────────┤
│ 表格                                                 │
└─────────────────────────────────────────────────────┘
```

---

## 3. 筛选项

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| 时间范围 | DateRangePicker + 快捷按钮 | 默认"今天" |
| 操作人 | Input | 用户名模糊搜索 |
| 功能菜单 | Select | 所有一级模块菜单 |
| 操作类型 | Select | 登录/登出/新增/修改/删除/导入/导出/执行/其他 |
| 操作对象 | Input | 设备SN、用户名等 |
| 操作内容 | Input | 关键词搜索 |
| 执行结果 | Select | 成功/失败/全部 |
| 客户端IP | Input | "展开更多"区域 |

---

## 4. 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 操作时间 | `operationTime` | 170px | `YYYY-MM-DD HH:mm:ss`，默认降序 |
| 操作人 | `operator` | 120px | 用户名 |
| 客户端IP | `clientIp` | 140px | 等宽字体 |
| 操作对象 | `target` | 160px | 超长截断 |
| 功能菜单 | `module` | 120px | 一级模块名 |
| 操作类型 | `operationType` | 100px | Tag 组件带颜色 |
| 操作内容 | `content` | 300px | 超长截断 + Tooltip |
| 执行结果 | `result` | 100px | 成功(绿Tag) / 失败(红Tag) |
| 消息详情 | `detail` | 80px | 蓝色 [查看] 链接 |

### 操作类型颜色

| 类型 | Tag 颜色 |
|------|---------|
| 登录/登出 | `blue` |
| 新增 | `green` |
| 修改 | `orange` |
| 删除 | `red` |
| 导入/导出 | `purple` |
| 执行 | `cyan` |

## 5. 消息详情弹窗

> 点击 [查看] 打开模态对话框

```
┌─────────────────────────────────────┐
│ 操作详情                              │
├─────────────────────────────────────┤
│                                     │
│ 操作人：admin                        │
│ 时间：2024-01-15 14:30:25           │
│ 类型：修改                           │
│ 模块：配置管理                        │
│                                     │
│ 请求内容：                            │
│ ┌─────────────────────────────────┐ │
│ │ {                               │ │
│ │   "deviceSn": "SN001",         │ │
│ │   "parameters": {              │ │
│ │     "txPower": 23,             │ │
│ │     "bandwidth": "20MHz"       │ │
│ │   }                            │ │
│ │ }                               │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 响应内容：                            │
│ ┌─────────────────────────────────┐ │
│ │ {                               │ │
│ │   "code": 200,                  │ │
│ │   "message": "success"         │ │
│ │ }                               │ │
│ └─────────────────────────────────┘ │
│                                     │
│           [复制] [关闭]              │
└─────────────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 宽度 | 640px |
| JSON 展示 | 树形缩进格式化，语法高亮 |
| 字体 | 等宽字体 `SFMono-Regular` 13px |
| 复制按钮 | 复制完整 JSON 到剪贴板 |
| 长文本 | 内容区最大高度 400px，超出滚动 |

---

## 6. 导出

- 格式：Excel (.xlsx)
- 范围：当前筛选条件匹配的全部记录
- 大数据量异步导出：通过全局任务面板跟踪
- 导出字段：全部表格列 + 完整消息详情

---

## 7. 数据保留策略

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 保留天数 | 180 天 | 可在日志配置页修改 |
| 自动清理 | 开启 | 超出保留期自动清理 |
| 存储空间告警 | 80% | 占用超过阈值发出通知 |

---

## 8. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看操作日志 | `system:oplog:view` |
| 查看消息详情 | `system:oplog:detail` |
| 导出 | `system:oplog:export` |

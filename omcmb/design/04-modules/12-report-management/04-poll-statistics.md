# 轮询统计 (Poll Statistics)

## 页面用途

展示设备轮询采集的统计数据，支持按区域、类型、生产厂家、代理厂家等维度分组查看轮询成功率和相关统计。左侧为分组维度树形导航，中间为分组统计数据表格（支持展开查看子分组），右侧为联动图表面板（柱状图 + 折线图复合图表）。用于监控网管系统对各设备的轮询健康状况。

## 布局模板

**Tree-List-Chart Layout（树形 + 列表 + 图表三栏布局）**

```
+------------------------------------------------------------------+
```

```
+------------------------------------------------------------------+
```

## 筛选栏配置

| 字段名称 | 组件类型 | 默认值 | 必填 | 说明 |
|---------|---------|-------|------|------|
| 启动时间(起) | DatePicker | 7天前 | 是(*) | 统计起始日期 |
| 启动时间(止) | DatePicker | 当前 | 是(*) | 统计结束日期 |

## 左侧分组树

```
轮询统计
  └─ 统计
       └─ 分组统计
            ├─ 按区域        （按省/市/区县行政区域分组）
            ├─ 按类型        （按设备产品类型分组）
            ├─ 按生产厂家    （按设备生产厂家分组）
            └─ 按代理厂家    （按设备代理厂家分组）
```

选择不同的树节点，中间表格的分组维度随之切换，图表面板同步更新。

## 数据表规格

| 列名 | 字段 Key | 宽度 | 渲染规则 |
|------|----------|------|---------|
| 分组 | groupName | 180px | 文本，带展开/折叠箭头（▶/▼），支持层级缩进 |
| 轮询网元数 | polledCount | 100px | 整数 |
| 成功网元数 | successCount | 100px | 整数 |
| 失败网元数 | failedCount | 100px | 整数 |
| 轮询成功率 | successRate | 100px | 百分比 |
| 成功网元总次数 | totalSuccessTimes | 120px | 整数 |
| 失败网元总次数 | totalFailedTimes | 120px | 整数 |
| 轮询平均成功率 | avgSuccessRate | 120px | 百分比 |

**表格行为:**
- 分组行前有展开/折叠箭头，点击可展开查看下辖子分组明细
- 按区域: 展开后显示下辖区县（如成都市→市辖区/锦江区/青羊区/...）
- 按生产厂家: 展开后显示该厂家下的子分类数据
- 点击某一行时，右侧图表面板联动展示该分组的子项统计图���

## 右侧图表面板

| 属性 | 值 |
|------|------|
| 触发方式 | 点击表格行后在右侧联动展示 |
| 图表类型 | 柱状图 + 折线图复合（双Y轴） |
| 图表标题 | "{分组名称} - 轮询统计" |

**图例:**

| 图例名称 | 图表类型 | 颜色 | Y轴 |
|---------|---------|------|-----|
| 成功网元数 | 柱状图 | 蓝色 | 左Y轴（数量） |
| 失败网元数 | 柱状图 | 红色 | 左Y轴（数量） |
| 轮询成功率 | 折线图 | 绿色 | 右Y轴（百分比） |

**坐标轴:**
- X轴: 子分组名称（如子区域名称、子厂家名称等）
- Y轴左: 数量刻度（0 至最大值）
- Y轴右: 百分比刻度（0% 至 100%）

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 导出 | Default | 导出当前表格数据为文件 |
| 刷新 | Icon | 刷新当前统计数据 |

## 弹窗规格

无独立弹窗

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未选择时间 | 查询区域提示 "请选择启动时间" |
| 查询中 | 表格和图表区域显示加载动画 |
| 无数据 | 表格显示 "查询无结果" |
| 图表未触发 | 右侧图表面板显示 "请点击左侧表格行查看统计图表" |
| 子分组为空 | 展开后显示 "无子分组数据" |
| 分组维度切换 | 切换左侧树节点时重新查询并刷新表格和图表 |
| 大量子分组 | 图表X轴标签自动旋转45度，超出部分截断显示 |

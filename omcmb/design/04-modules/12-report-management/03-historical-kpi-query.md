# 历史指标查询 (Historical KPI Query)

## 页面用途

查询历史性能指标数据，支持按时间范围、多指标组合、设备维度进行灵活查询。用户可选择多个 KPI 指标进行组合查询，查看指定时间段内的历史趋势数据，并支持结果导出。适用于性能回溯分析和趋势对比场景。

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| 查询类型 | Select | 网元/小区/业务区/厂商/站点 | 网元 | 统计维度 |
| 时间粒度 | Select | 分钟/小时/天/周/月 | 天 | 时间粒度 |
| 查询条件 | Select | 网元名称/设备标识/SN/区域 | 网元名称 | 过滤字段 |
| 匹配方式 | Select | 包含/不包含/等于/不等于 | 包含 | 匹配逻辑 |
| 过滤值 | TextInput | 用户输入 | 空 | 过滤关键词 |
| 开始时间 | DateTimePicker | -- | 7天前 | 查询起始时间(必填) |
| 结束时间 | DateTimePicker | -- | 当前 | 查询结束时间(必填) |
| 指标选择 | TransferList | KPI指标列表 | 空 | 左右穿梭框多选 |

**特殊交互:**
- 过滤条件支持通过 [+] 按钮添加多组
- 指标选择使用穿梭框（Transfer）组件，左侧为可选指标，右侧为已选指标
- 穿梭框支持关键字搜索过滤、全选、批量移入/移出
- 时间范围为必填字段，标记 * 号

## 数据表规格

| 列名 | 字段 Key | 宽度 | 渲染规则 |
|------|----------|------|---------|
| 网元名称/小区名称 | entityName | 200px | 文本，统计维度对应的实体名称 |
| 日期 | date | 120px | 日期时间 |
| (动态KPI列) | kpi_xxx | 120px | 根据已选指标动态生成，每个选中KPI一列 |

**说明:** 表格列完全由用户在"已选指标"中的选择决定，支持百分比、数量、流量等多种数据类型的混合展示。

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 查询 | Primary | 执行历史指标查询 |
| 重置 | Default | 清空所有筛选条件和已选指标 |
| 导出 | Dropdown | 导出格式: CSV / Excel |

| 按钮名称 | 类型 | 行为 |
|---------|------|------|

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 未查询 | 结果区域为空，提示 "请��置查询条件并选择指标后点击查询" |
| 未选择指标 | 查询按钮禁用，提示 "请至少选择一个指标" |
| 时间范围未填 | 查询按钮禁用，提示 "请选择查询时间范围" |
| 查询中 | 表格显示加载动画 |
| 无数据 | 显示 "查询无结果" |
| 大量指标已选 | 表格支持横向滚动，固定前两列（网元名称、日期） |
| 趋势图多网元 | 不同网元使用不同颜色的线条/柱状，图例显示网元名称 |

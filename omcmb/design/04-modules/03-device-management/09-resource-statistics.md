# 资源统计 (Resource Statistics)

## 页面用途

提供设备资源的多层级统计分析页面。按产品类别、厂商、设备型号、网络制式等维度层层下钻，以图表和表格形式展示设备资源分布情况，帮助管理者掌握资源全貌。

## 布局模板

使用 dashboard-page 布局（统计图表 + 表格混合）。

## 导航路径

设备管理 > 资源统计

## 路由

`/device/statistics`

## 维度下钻路径

```
Level 1: 产品类别 (eNB / gNB / CPE / eGW)
    ↓ 点击某产品类别
Level 2: 厂商 (华为 / 中兴 / 爱立信 / 大唐)
    ↓ 点击某厂商
Level 3: 设备型号 (BTS3900 / BTS5900 / ...)
    ↓ 点击某型号
Level 4: 网络制式 (LTE-FDD / LTE-TDD / NR / ...)
```

### 面包屑导航

```
全部 > eNB > 华为 > BTS3900
  ↑ 每级可点击回退到对应层级
```

## 图表区域

### Treemap 矩形树图

| 属性          | 值                                  |
|-------------|--------------------------------------|
| 图表类型      | Treemap (矩形树图)                   |
| 图表库        | ECharts treemap / AntV G2           |
| 高度          | 280px                               |
| 颜色方案      | 按产品类别/维度分色                    |
| 标签          | 维度名称 + 数量, 面积过小时隐藏        |
| 点击行为      | 下钻到下一层级                        |
| Tooltip       | 维度名称, 数量, 占比, 在线率          |
| 动画          | 下钻时缩放过渡动画 (400ms)            |

### 分组柱状图

| 属性          | 值                                  |
|-------------|--------------------------------------|
| 图表类型      | Grouped Bar Chart                   |
| X 轴          | 当前维度的分类值                      |
| Y 轴          | 设备数量                             |
| 系列          | 按下一级维度分组 (如按产品类别分色)     |
| Tooltip       | 维度名称, 各系列数量, 合计            |
| 点击行为      | 下钻到下一层级                        |

## 统计表格

### 多级表头

当前维度为行维度，产品类别为列维度。

| 列名称   | 数据类型  | 说明                |
|---------|---------|---------------------|
| 维度名称  | String  | 当前下钻层级的维度值  |
| eNB     | Number  | eNB 类型设备数       |
| gNB     | Number  | gNB 类型设备数       |
| CPE     | Number  | CPE 类型设备数       |
| eGW     | Number  | eGW 类型设备数       |
| 合计     | Number  | 行合计, font-weight: 600 |
| 占比     | Percent | 占总设备数百分比      |
| 在线率   | Percent | 在线设备占比          |

### 表格行样式

| 行类型     | 样式                              |
|-----------|----------------------------------|
| 普通行     | 默认样式                          |
| 合计行     | 背景色 #FAFAFA, font-weight: 600  |
| 在线率低   | 在线率 < 70% 时红色字体            |
| Hover 行  | 背景色 #E6F7FF, 可点击下钻         |

## 工具栏操作

| 操作名称   | 图标                  | 说明                             |
|---------|----------------------|----------------------------------|
| 导出报表  | `ExportOutlined`     | 导出当前统计数据为 Excel            |
| 刷新     | `ReloadOutlined`     | 重新加载统计数据                    |

## 数据接口

```typescript
GET /api/device/statistics?deviceType={type}&dimension={dimension}&parentValue={value}

interface ResourceStatistics {
  dimension: string;           // 当前维度
  breadcrumb: BreadcrumbItem[];// 面包屑路径
  treemapData: TreemapNode[];  // Treemap 数据
  chartData: ChartDataItem[];  // 柱状图数据
  tableData: TableRow[];       // 表格数据
  summary: TableRow;           // 合计行
}

interface TreemapNode {
  name: string;
  value: number;
  children?: TreemapNode[];
}
```

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 加载中         | 图表和表格同时 Skeleton 骨架              |
| 数据为空       | Empty "暂无设备资源数据"                  |
| 下钻加载中     | 面包屑显示加载态, 图表渐变过渡             |
| 导出中         | 导出按钮 Loading 态                      |
| 某维度无子级数据 | 显示 "该维度下无更多明细"                 |

## 跨模块导航

| 来源              | 目标                  | 触发方式               |
|------------------|----------------------|-----------------------|
| 表格行点击        | 下钻到下一维度层级     | 点击行                 |
| Treemap 块点击   | 下钻到下一维度层级     | 点击矩形块             |
| 面包屑回退        | 回退到上级维度        | 点击面包屑层级          |
| 最终层级设备名称   | 设备管理 > 设备详情   | 点击设备名称链接        |

# 设备列表 (Device List)

## 页面用途

设备管理的核心列表页面，展示当前设备类型下的所有设备信息。支持多维度筛选、排序、批量操作和导出功能。是运维人员日常管理设备的主要入口。

## 布局模板

使用 02-list-page 布局。

## 导航路径

设备管理 > 设备列表

## 路由

`/device/list`

## 筛选栏配置

| 字段名称   | 英文标识        | 组件类型       | 必填 | 选项/说明                                    |
|----------|---------------|--------------|------|---------------------------------------------|
| 设备名称  | deviceName    | Input        | 否   | 支持模糊搜索, placeholder "请输入设备名称"      |
| 设备 SN  | deviceSn      | Input        | 否   | 精确/模糊搜索, placeholder "请输入设备SN"       |
| 产品类别  | productType   | Select       | 否   | eNB / gNB / CPE / eGW (跟随全局设备类型)       |
| 厂商      | vendor        | Select       | 否   | 华为 / 中兴 / 爱立信 / 大唐 / 其他             |
| 设备型号  | deviceModel   | Select       | 否   | 联动产品类别和厂商, 动态加载                    |
| 网络制式  | networkType   | Select       | 否   | LTE-FDD / LTE-TDD / NR / NB-IoT            |
| 区域      | region        | TreeSelect   | 否   | 多级区域树选择 (省 > 市 > 区)                  |
| 连接状态  | connStatus    | Select       | 否   | 全部 / 在线 / 离线                            |
| 告警等级  | alarmLevel    | Select       | 否   | 全部 / 紧急 / 主要 / 次要 / 警告 / 正常        |
| 工程状态  | engStatus     | Select       | 否   | 全部 / 待开站 / 开站中 / 已开站 / 待交维 / 已交维 |

**筛选栏行为：**
- 默认展示前 4 个字段 (一行), 点击 "展开" 显示全部
- 查询按钮: 触发表格数据重新加载, 重置翻页到第一页
- 重置按钮: 清空所有筛选条件, 重新加载数据

## 工具栏操作

| 操作名称     | 图标                    | 类型      | 启用条件                  | 说明                    |
|------------|------------------------|----------|--------------------------|------------------------|
| 注册设备     | `PlusOutlined`         | Primary  | 始终可用                  | 打开设备注册弹窗/抽屉     |
| 批量删除     | `DeleteOutlined`       | Danger   | 至少选中 1 项             | 确认弹窗后执行           |
| 批量重启     | `ReloadOutlined`       | Default  | 至少选中 1 项, 选中项在线  | 确认弹窗后执行           |
| 同步配置     | `SyncOutlined`         | Default  | 至少选中 1 项, 选中项在线  | 确认弹窗后下发配置       |
| 导出         | `ExportOutlined`       | Default  | 始终可用                  | 打开导出配置弹窗         |

### 行操作按钮

| 操作   | 图标                  | 类型     | 说明                              |
|-------|-----------------------|---------|-----------------------------------|
| 编辑   | `EditOutlined`        | Link    | 打开编辑弹窗                       |
| 同步   | `SyncOutlined`        | Link    | 同步单台设备配置                    |
| 更多   | `MoreOutlined`        | Dropdown| 子菜单: 重启 / 删除 / 查看详情 / 告警 |

## 弹窗规格

### 删除确认弹窗

| 属性     | 值                                            |
|---------|-----------------------------------------------|
| 触发     | 点击批量删除 / 行操作删除                        |
| 类型     | Modal.confirm (warning)                        |
| 标题     | 确认删除                                       |
| 内容     | "确定要删除选中的 {n} 台设备吗？删除后设备将移入回收站。" |
| 确认按钮  | "确认删除" (danger)                             |
| 取消按钮  | "取消"                                         |

### 重启确认弹窗

| 属性     | 值                                            |
|---------|-----------------------------------------------|
| 触发     | 点击批量重启 / 行操作重启                        |
| 类型     | Modal.confirm (warning)                        |
| 标题     | 确认重启                                       |
| 内容     | "确定要重启选中的 {n} 台设备吗？重启期间设备将暂时不可用。" |
| 确认按钮  | "确认重启" (warning)                            |
| 取消按钮  | "取消"                                         |

## 状态处理

| 状态         | 处理方式                                      |
|-------------|----------------------------------------------|
| 首次加载     | 表格 Skeleton 骨架屏 (5 行)                    |
| 数据为空     | Empty 组件 "暂无设备数据, 请先注册设备" + 注册按钮 |
| 搜索无结果   | Empty 组件 "未找到符合条件的设备" + 重置按钮      |
| 加载失败     | 错误提示 + 重试按钮                             |
| 批量操作中   | 工具栏按钮 Loading 态, 表格行禁用操作             |
| 删除成功     | Toast "删除成功", 自动刷新表格                   |
| 重启成功     | Toast "重启指令已下发", 设备状态短暂变为 "重启中"  |

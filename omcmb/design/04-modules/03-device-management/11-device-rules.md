# 设备规则 (Device Rules)

## 页面用途

配置设备自动分组和自动标签规则。通过条件构建器定义匹配规则（基于设备字段 + 操作符 + 值，支持 AND/OR 逻辑组合），实现设备的自动化管理。

## 布局模板

使用 02-list-page 布局。

## 导航路径

设备管理 > 设备规则

## 路由

`/device/rules`

## 筛选栏配置

| 字段名称   | 英文标识    | 组件类型  | 必填 | 选项/说明              |
|----------|-----------|---------|------|----------------------|
| 规则名称  | ruleName  | Input   | 否   | 模糊搜索              |
| 规则类型  | ruleType  | Select  | 否   | 全部/自动分组/自动标签  |
| 状态     | status    | Select  | 否   | 全部/启用/禁用         |

## 数据表规格

| 列名称       | 英文标识       | 数据类型  | 可排序 | 宽度    | 说明                   |
|-------------|---------------|---------|--------|--------|------------------------|
| 规则名称     | ruleName      | String  | 是     | 160px  | 蓝色链接                |
| 规则类型     | ruleType      | Tag     | 是     | 100px  | 自动分组(蓝)/自动标签(绿) |

| 状态         | status        | Switch  | 是     | 80px   | 启用/禁用开关           |
| 匹配设备数   | matchCount    | Number  | 是     | 100px  | 当前匹配到的设备数量      |
| 创建人       | creator       | String  | 是     | 100px  | -                      |
| 更新时间     | updateTime    | DateTime| 是     | 160px  | -                      |
| 操作         | actions       | Actions | 否     | 160px  | 编辑/执行/删除          |

### 条件构建器

**可用字段：**

| 字段       | 组件类型    | 可用操作符                          |
|-----------|----------|-------------------------------------|
| 设备名称   | Input    | 包含/不包含/开头为/结尾为/等于/不等于  |
| 设备 SN   | Input    | 包含/不包含/开头为/结尾为/等于/不等于  |
| TAC       | Input    | 等于/不等于/包含                     |
| LAC       | Input    | 等于/不等于/包含                     |
| 区域       | Select   | 等于/不等于                          |
| 厂商       | Select   | 等于/不等于                          |
| 产品类别   | Select   | 等于/不等于                          |
| 网络制式   | Select   | 等于/不等于                          |
| 设备型号   | Select   | 等于/不等于                          |
| IP 段     | Input    | 开头为/包含                          |

**操作符说明：**

| 操作符   | 英文标识      | 匹配逻辑                   |
|---------|-------------|---------------------------|
| 包含     | contains    | 字符串包含目标值             |
| 不包含   | notContains | 字符串不包含目标值           |
| 开头为   | startsWith  | 字符串以目标值开头           |
| 结尾为   | endsWith    | 字符串以目标值结尾           |
| 等于     | equals      | 精确匹配                   |
| 不等于   | notEquals   | 不匹配                     |

### 表单校验

| 字段       | 校验规则                              |
|-----------|--------------------------------------|
| 规则名称   | 非空, 2-64 字符, 系统内不重复          |
| 规则类型   | 必选                                  |
| 目标分组   | 分组类型时必选, 分组必须存在            |
| 标签名称   | 标签类型时必填, 2-32 字符              |
| 匹配条件   | 至少一个条件                           |
| 条件值     | 非空                                  |

## 状态处理

| 状态              | 处理方式                               |
|------------------|-----------------------------------------|
| 表格加载中        | Skeleton 骨架屏                         |
| 规则执行中        | 操作列显示 Spin + "执行中"               |
| 规则执行完成      | Toast "规则执行完成, 匹配 {n} 台设备"    |
| 预览加载中        | 预览区域 Spin                           |
| 状态切换          | Switch 切换后立即生效, 禁用时停止自动匹配 |
| 删除确认          | "删除后, 已分配的设备不受影响"            |

# 设备分组 (Device Grouping)

## 页面用途

管理设备分组的树形列表页面。左侧为设备分组树，支持创建、编辑、删除分组；右侧展示选中分组内的设备列表。支持手动分配和自动分组规则（按设备名称、TAC、LAC 等条件匹配）。

## 布局模板

使用 tree-list-page 布局（左树右表）。

## 导航路径

设备管理 > 设备分组

## 路由

`/device/group`

## 左侧分组树

### 树组件规格

| 属性           | 值                              |
|---------------|--------------------------------|
| 组件类型       | Tree (Ant Design)              |
| 宽度           | 280px (可拖拽调整, 最小 200px)   |
| 背景色         | #FAFAFA                        |
| 搜索框         | 顶部搜索, 支持分组名称模糊匹配    |
| 默认展开       | 展开第一级                       |
| 选中样式       | 背景色 #E6F7FF, 左侧 3px 蓝色条  |
| 节点右键菜单    | 新建子分组 / 编辑 / 删除 / 自动规则 |

### 特殊节点

| 节点           | 说明                              |
|---------------|----------------------------------|
| 全部设备       | 根节点, 不可编辑/删除, 显示总设备数  |
| 未分组         | 虚拟节点, 不可编辑/删除, 显示未分组数 |

### 树节点操作

| 操作       | 触发方式            | 说明                           |
|-----------|--------------------|---------------------------------|
| 新建分组   | 顶部 [+] 按钮      | 在根级创建分组                    |
| 新建子分组  | 右键菜单           | 在选中节点下创建子分组             |
| 编辑分组   | 右键菜单 / 双击     | 修改分组名称和描述                |
| 删除分组   | 右键菜单           | 确认后删除, 设备移入 "未分组"      |
| 拖拽排序   | 拖拽节点           | 调整分组层级和顺序                |

## 右侧设备列表

### 头部信息

| 元素           | 说明                    |
|---------------|------------------------|
| 分组名称       | 当前选中分组名称          |
| 设备数量       | 该分组下设备总数          |

### 工具栏

| 操作名称       | 图标                   | 类型      | 启用条件              | 说明                  |
|-------------|------------------------|---------|-----------------------|----------------------|
| 添加设备     | `PlusOutlined`         | Primary | 选中非 "全部" 节点      | 打开设备选择弹窗        |
| 移出分组     | `ExportOutlined`       | Default | 至少选中 1 台设备       | 移至 "未分组"          |
| 自动分组规则  | `SettingOutlined`      | Default | 选中非特殊节点          | 打开规则配置弹窗        |

### 表格列

| 列名称     | 数据类型    | 宽度    | 说明              |
|-----------|-----------|--------|-------------------|
| 复选框     | Checkbox  | 48px   | 全选/单选          |
| 设备名称   | String    | 160px  | 蓝色链接           |
| 设备 SN   | String    | 140px  | -                 |
| 产品类别   | String    | 100px  | -                 |
| 厂商       | String    | 100px  | -                 |
| 连接状态   | Status    | 90px   | ● 在线 / ○ 离线    |
| 告警等级   | Severity  | 90px   | 彩色标识           |
| 操作       | Actions   | 80px   | [移出]             |

## 弹窗规格

### 新建/编辑分组弹窗

| 属性     | 值                           |
|---------|------------------------------|
| 触发     | 新建/编辑分组操作               |
| 标题     | 新建分组 / 编辑分组            |
| 宽度     | 480px                        |

| 字段名称   | 组件类型   | 必填 | 校验规则                          |
|----------|---------|------|----------------------------------|
| 分组名称   | Input   | 是   | 非空, 2-64 字符, 同级不重复        |
| 上级分组   | TreeSelect | 是 | 非空, 默认为当前选中节点           |
| 分组描述   | TextArea | 否  | 最大 256 字符                     |

### 添加设备弹窗

| 属性     | 值                                |
|---------|-----------------------------------|
| 触发     | 点击 "添加设备" 按钮                |
| 标题     | 添加设备到分组: {分组名}            |
| 宽度     | 800px                             |
| 内容     | 左侧可选设备列表 + 右侧已选设备列表  |
| 筛选     | 设备名称/SN 搜索框                  |
| 数据源   | 未分组设备 + 其他分组设备            |

### 自动分组规则弹窗

| 属性     | 值                              |
|---------|--------------------------------|
| 触发     | 点击 "自动分组规则" 按钮           |
| 标题     | 自动分组规则: {分组名}            |
| 宽度     | 640px                          |

**规则条件构建器：**

```
┌──────────────────────────────────────────────────────┐
│  当设备满足以下条件时自动加入本分组:                       │
│                                                      │
│  [AND ▼]                                             │
│  ┌──────────────────────────────────────────────┐    │
│  │ [设备名称 ▼] [包含 ▼]   [北京__________] [×]  │    │
│  │ [TAC     ▼] [等于 ▼]   [12345_________] [×]  │    │
│  │ [LAC     ▼] [开头为 ▼] [001___________] [×]  │    │
│  │                                    [+ 添加条件]│    │
│  └──────────────────────────────────────────────┘    │
│                                                      │
│  逻辑关系: (●) 全部满足 (AND) ( ) 任一满足 (OR)         │
│                                                      │
│  [预览匹配结果: 23 台设备匹配]                          │
│                                                      │
│                             [取消]  [保存并执行]        │
└──────────────────────────────────────────────────────┘
```

**可用条件字段：**

| 字段       | 可用操作符                           |
|-----------|-------------------------------------|
| 设备名称   | 包含 / 不包含 / 开头为 / 结尾为 / 等于 |
| 设备 SN   | 包含 / 不包含 / 开头为 / 结尾为 / 等于 |
| TAC       | 等于 / 不等于 / 包含                  |
| LAC       | 等于 / 不等于 / 包含                  |
| 区域       | 等于 / 包含                          |
| 厂商       | 等于                                |
| 产品类别   | 等于                                |
| 网络制式   | 等于                                |

## 状态处理

| 状态           | 处理方式                                |
|---------------|----------------------------------------|
| 分组树加载中   | 树区域 Skeleton 骨架                    |
| 设备列表加载中  | 表格 Skeleton 骨架                     |
| 分组为空       | 右侧显示 "当前分组无设备, 请添加设备"      |
| 删除分组确认   | "删除后, 该分组下 {n} 台设备将移入未分组"  |
| 自动规则执行中  | 进度提示 "正在匹配设备..."               |
| 拖拽排序中     | 树节点半透明 + 放置指示线                 |

# 设备详情 (Device Detail)

## 页面用途

展示单台设备的完整详细信息，以多 Tab 页形式组织：基本信息、告警、性能、拓扑四个维度。是设备管理的核心详情查看页面。

## 布局模板

使用 detail-page 布局（头部概要 + Tab 内容区）。

## 导航路径

设备管理 > 设备列表 > {设备名称}

## 路由

`/device/detail/:deviceSn`

## 设备概要头部

### 布局

左侧设备图标 + 中间信息区 + 右侧操作区。

| 元素             | 说明                                       |
|-----------------|--------------------------------------------|
| 设备图标         | 64px, 根据产品类别显示不同图标                |
| 设备名称         | font-size: 20px, font-weight: 600           |
| 设备 SN         | font-size: 14px, color: #8C8C8C, 可复制     |
| 连接状态         | ● 在线(绿) / ○ 离线(红), 右上角              |
| 属性标签行       | 厂商 | 产品类别 | 网络制式 | 区域, 用 "|" 分隔 |
| 告警角标行       | 四级告警计数角标 (仅本设备告警数)              |
| 操作按钮         | 编辑 / 同步 / 重启 / 更多                    |

### 操作按钮

| 按钮     | 类型      | 说明                        |
|---------|----------|----------------------------|
| 编辑     | Default  | 打开设备编辑弹窗             |
| 同步     | Default  | 同步设备配置和状态           |
| 重启     | Warning  | 确认弹窗后重启设备           |
| 更多     | Dropdown | 删除 / 导出 / MML 控制台    |

## 状态处理

| 状态            | 处理方式                                 |
|----------------|------------------------------------------|
| 设备不存在      | 显示 404 页面 "设备不存在或已删除"          |
| 基本信息加载中   | Descriptions Skeleton 骨架              |
| 告警 Tab 加载中  | 表格 Skeleton 骨架                      |
| 性能 Tab 加载中  | 图表区域 Skeleton 骨架                   |
| 拓扑 Tab 加载中  | 画布中心 Spin 加载动画                   |
| 设备离线         | 概要头部连接状态红色, 性能图表显示灰色断线  |

## 跨模块导航

| 来源               | 目标                     | 触发方式                |
|-------------------|------------------------|-----------------------|
| 返回设备列表        | 设备管理 > 设备列表       | 点击顶部返回链接        |
| 查看全部告警链接     | 告警管理 > 当前告警       | 携带 deviceSn 参数     |
| 查看完整性能报告链接  | 性能管理 > 设备性能       | 携带 deviceSn 参数     |
| 更多 > MML 控制台   | MML 管理 > 命令控制台    | 携带 deviceSn 预选设备  |
| 告警列表条目        | 告警管理 > 告警详情       | 点击告警条目            |

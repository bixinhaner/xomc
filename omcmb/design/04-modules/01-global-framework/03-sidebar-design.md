# 侧边栏设计 (Sidebar Design)

## 页面用途

系统主导航侧边栏，采用暗色主题，提供模块导航、设备类型上下文切换、版本信息展示等功能。支持展开 (240px) 和折叠 (48px) 两种状态。

## 布局模板

固定左侧定位，高度 100vh，与 Header 等高起始。`position: fixed; left: 0; top: 48px;`

## 折叠状态交互

### Popover 弹出菜单

当侧边栏处于折叠状态时，hover 某个一级模块图标会弹出该模块的二级菜单：

```
+--------+  +--------------------+
|        |  | 设备管理            |
|  [📡]--|→ |  设备列表           |
|        |  |  设备注册           |
|        |  |  设备分组           |
|        |  |  网元管理           |
+--------+  |  在线监控           |
            |  ...               |
            +--------------------+
```

| 属性         | 值                              |
|-------------|--------------------------------|
| 弹出方向     | right (右侧弹出)                |
| 弹出延迟     | 100ms (mouseEnter)             |
| 消失延迟     | 200ms (mouseLeave)             |
| 弹出面板背景  | #001529                        |
| 弹出面板阴影  | 2px 0 8px rgba(0,0,0,0.3)     |
| 弹出面板宽度  | 180px                          |

## 状态管理

```typescript
interface SidebarState {
  collapsed: boolean;          // 折叠状态
  activeModuleKey: string;     // 当前激活的一级模块
  activeSubPageKey: string;    // 当前激活的二级子页面
  expandedKeys: string[];      // 已展开的一级模块列表
  deviceType: DeviceType;      // 设备类型上下文
  deviceCount: {               // 各类型设备数量
    total: number;
    online: number;
  };
}
```

### 持久化策略

| 状态项         | 存储位置           | 恢复策略                  |
|---------------|-------------------|--------------------------|
| collapsed     | localStorage      | 页面刷新后恢复             |
| expandedKeys  | sessionStorage    | 同一会话内保持             |
| deviceType    | localStorage      | 跨会话保持上次选择          |

## 可访问性 (Accessibility)

| 特性          | 实现方式                                  |
|--------------|------------------------------------------|
| 键盘导航      | Tab / Shift+Tab 在菜单项间切换             |
| 展开/折叠     | Enter / Space 触发                        |
| ARIA 属性     | `role="navigation"`, `aria-expanded`      |
| 焦点管理      | 展开模块后焦点移至第一个子项                  |
| 快捷键        | Ctrl+B 切换侧边栏折叠状态                   |

## 跨模块导航

| 操作              | 目标                    |
|------------------|------------------------|
| 点击 Logo         | 导航至 Dashboard         |
| 点击菜单项         | 打开对应页面 + 创建 Tab   |
| 切换设备类型       | 刷新当前页面数据          |

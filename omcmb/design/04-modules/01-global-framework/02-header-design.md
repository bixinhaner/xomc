# Header 设计 (Header Design)

## 页面用途

系统全局顶部栏，固定在视口顶部，高度 48px。包含品牌标识、实时告警状态角标、通知中心、时区选择、用户菜单等全局操作入口。

## 布局模板

固定顶部栏，不随页面滚动。`position: fixed; top: 0; z-index: 1000;`

## 线框描述

```
+-----------------------------------------------------------------------------------+
| [Logo] OMC 统一网管系统  |                    | [紧急 5][主要 12][次要 28][警告 45] |
|                         |                    | [🔔 3] [UTC+8 ▼] [管理员 张三 ▼]  |
+-----------------------------------------------------------------------------------+
|<------ 左区域 -------->|<---- 中间留白 ----->|<----------- 右区域 -------------->|
```

## Header 右区域

从左到右依次排列以下组件，组件间距 16px。

### 1. 告警等级角标组 (Alarm Severity Badges)

四个颜色编码的告警计数角标，实时更新。

| 角标     | 背景色    | 文字色  | 显示格式       | 点击行为                          |
|---------|----------|--------|---------------|----------------------------------|
| 紧急     | #FF4D4F  | #FFFFFF | 紧急 {count}  | 跳转 /alarm/current?severity=critical |
| 主要     | #FA8C16  | #FFFFFF | 主要 {count}  | 跳转 /alarm/current?severity=major    |
| 次要     | #FADB14  | #333333 | 次要 {count}  | 跳转 /alarm/current?severity=minor    |
| 警告     | #1890FF  | #FFFFFF | 警告 {count}  | 跳转 /alarm/current?severity=warning  |

**角标样式规格：**

```
- 高度: 24px
- 圆角: 12px (pill shape)
- 内边距: 0 10px
- 字体: 12px medium
- 排列间距: 8px
- 计数为 0 时: 降低透明度 (opacity: 0.45)
- 计数变化时: 数字缩放动画 (scale 1.2 → 1.0, 300ms)
```

**数据更新：** 通过 WebSocket 实时推送，详见 `04-alert-status-bar.md`。

### 3. 时区选择器 (Timezone Selector)

| 属性         | 值                                    |
|-------------|--------------------------------------|
| 显示格式     | UTC+8 (或选定时区缩写)                  |
| 组件类型     | Select Dropdown                       |
| 选项         | UTC-12 至 UTC+14, 含常用时区名称        |
| 默认值       | 服务器端配置的系统时区                    |
| 变更影响     | 全局所有时间显示立即切换到选定时区          |

**常用时区快捷选项：**

| 显示          | 值              |
|--------------|-----------------|
| UTC+8 北京    | Asia/Shanghai   |
| UTC+0 伦敦    | Europe/London   |
| UTC-5 纽约    | America/New_York|
| UTC+9 东京    | Asia/Tokyo      |

### 4. 用户下拉菜单 (User Dropdown)

| 触发方式     | 点击打开下拉菜单                    |

**下拉菜单项：**

```
+----------------------------+
| 👤 张三                     |
| 角色: 系统管理员             |
+----------------------------+
| 个人设置                     |
| 修改密码                     |
| 语言切换     简体中文 ▶       |
+----------------------------+

+----------------------------+
```

| 菜单项     | 图标                   | 操作                           |
|-----------|----------------------|-------------------------------|
| 个人设置   | `UserOutlined`       | 跳转 /system/profile           |

| 退出登录   | `LogoutOutlined`     | 确认弹窗后退出, 清除 Token       |

## 修改密码弹窗规格

| 属性         | 值                                        |
|-------------|------------------------------------------|
| 触发         | 用户下拉菜单 > 修改密码                     |
| 标题         | 修改密码                                   |
| 宽度         | 480px                                     |

**表单字段：**

| 字段名     | 类型           | 校验规则                                    |
|-----------|---------------|-------------------------------------------|
| 原密码     | Password Input | 必填                                       |
| 新密码     | Password Input | 必填, 8-32 位, 包含大小写字母+数字+特殊字符    |
| 确认密码   | Password Input | 必填, 与新密码一致                            |

**密码强度指示器：** 弱(红) / 中(橙) / 强(绿)

## 响应式行为

| 视口宽度        | Header 适配行为                           |
|----------------|------------------------------------------|
| >= 1440px      | 完整显示所有元素                            |
| 1200-1439px    | 告警角标仅显示图标 + 数字，隐藏中文标签        |
| 992-1199px     | 时区选择器折叠为图标, 通知铃铛保留            |
| < 992px        | 不适用 (本系统最小支持宽度 1200px)           |

## 状态处理

| 状态                | 处理方式                                    |
|--------------------|--------------------------------------------|
| WebSocket 断连     | 告警角标显示 "--", 背景变灰, Tooltip 提示连接中 |
| 告警数据加载中      | 角标显示 Skeleton 加载态                      |
| 用户 Token 过期     | Header 显示 "会话已过期" 提示, 自动跳转登录页   |
| 通知加载失败        | Popover 中显示 "加载失败, 点击重试"            |

## 跨模块导航

| 来源             | 目标                     | 触发方式          |
|-----------------|------------------------|--------------------|
| 告警角标          | 告警管理 > 当前告警       | 点击对应等级角标    |
| 通知 Popover     | 对应模块详情页            | 点击通知条目       |
| 用户菜单 > 个人设置 | 系统管理 > 个人设置      | 点击菜单项         |
| Logo             | Dashboard              | 点击 Logo          |

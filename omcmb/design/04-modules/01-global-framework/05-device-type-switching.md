# 设备类型全局切换 (Device Type Switching)

## 页面用途

提供全局设备类型上下文选择器，位于侧边栏顶部区域。切换设备类型后，系统内所有模块的数据、统计、列表均根据选定类型进行全局过滤。这是一个贯穿整个系统的核心交互机制。

## 布局模板

内嵌于侧边栏 (Sidebar) 组件，位于 Logo 区域下方、导航菜单上方。

## 设备类型选项

| 选项值   | 显示名称    | 图标                 | 描述           |
|---------|-----------|---------------------|---------------|
| `eNB`   | eNB (4G)  | `ApiOutlined`       | 4G 基站设备     |
| `gNB`   | gNB (5G)  | `WifiOutlined`      | 5G 基站设备     |
| `CPE`   | CPE       | `LaptopOutlined`    | 客户终端设备     |
| `eGW`   | eGW       | `GatewayOutlined`   | 网关设备        |
| `ALL`   | 全部设备类型 | `AppstoreOutlined` | 不按类型过滤     |

> 注意：`ALL` 选项是否启用取决于业务需求。某些模块可能不支持"全部类型"模式，此时该选项置灰并显示 Tooltip 说明。

## 全局过滤机制

### 影响范围

切换设备类型后，以下模块的数据将被全局过滤：

| 模块                | 过滤行为                                    |
|--------------------|---------------------------------------------|
| Dashboard          | KPI 卡片数值、图表数据均按设备类型过滤           |
| 设备管理 > 设备列表  | 表格数据只显示对应类型设备                      |
| 设备管理 > 网元管理  | 仅显示对应设备类型的网元                        |
| 告警管理 > 当前告警  | 仅显示对应设备类型产生的告警                     |
| 告警管理 > 历史告警  | 同上                                         |
| 告警管理 > 告警统计  | 统计图表按设备类型过滤                          |
| MML 管理           | 设备选择器仅显示对应类型设备                     |
| 备份恢复            | 设备列表仅显示对应类型设备                      |
| 性能管理            | 性能数据按设备类型过滤                          |
| 配置管理            | 配置数据按设备类型过滤                          |
| Header 告警角标     | 告警计数按当前设备类型过滤                       |

### 切换流程

```
用户选择新设备类型
    ↓
1. 更新全局 State (Context/Store)
    ↓
2. 更新 localStorage 持久化
    ↓
3. 发送 WebSocket 消息切换告警计数订阅频道
    ↓
4. 触发当前页面数据重新加载
    ↓
5. 更新设备统计信息 (在线/总数)
    ↓
6. Header 告警角标数据刷新
    ↓
7. 页面列表重置到第一页
```

### 状态管理

```typescript
// 全局 Context
interface DeviceTypeContext {
  currentType: DeviceType;
  typeStats: Record<DeviceType, {
    total: number;
    online: number;
    offline: number;
  }>;
  setDeviceType: (type: DeviceType) => void;
  isLoading: boolean;  // 切换过程中的加载状态
}

type DeviceType = 'eNB' | 'gNB' | 'CPE' | 'eGW' | 'ALL';

// 各模块消费全局设备类型
const { currentType } = useDeviceTypeContext();

// API 请求自动携带设备类型参数
GET /api/device/list?deviceType=eNB&page=1&size=20
GET /api/alarm/current?deviceType=eNB&severity=critical
```

## 切换动效

| 阶段         | 效果                                       |
|-------------|-------------------------------------------|
| 切换瞬间     | 当前页面内容区域显示轻量 Loading Overlay      |
| 数据加载中   | Skeleton 加载态替代实际数据 (200ms 延迟显示)   |
| 数据就绪     | Loading Overlay 淡出 (150ms)               |
| 统计更新     | 数字使用 countUp 动画过渡到新值 (400ms)       |
| 进度条更新   | 宽度动画过渡 (300ms ease)                    |

## 状态处理

| 状态               | 处理方式                                    |
|-------------------|--------------------------------------------|
| 设备统计加载中      | 显示 "在线 -- / 总数 --" + 骨架进度条          |
| 设备统计加载失败     | 显示 "获取设备统计失败" + 重试图标              |
| 某类型设备数为 0     | 下拉选项中该类型显示 "(0台)", 可选但数据为空     |
| 全局切换数据加载超时  | 5s 后显示超时提示, 保留上一次的数据             |
| 用户快速连续切换     | 防抖处理, 仅最后一次切换生效 (debounce 300ms)  |

## 权限控制

| 场景                | 行为                                      |
|--------------------|--------------------------------------------|
| 用户仅有 eNB 权限    | 下拉选项仅显示 eNB, 其他类型不渲染            |
| 用户有多类型权限     | 显示所有有权限的类型                          |
| 用户无任何设备类型权限 | 选择器区域隐藏, 显示 "暂无设备权限" 提示        |

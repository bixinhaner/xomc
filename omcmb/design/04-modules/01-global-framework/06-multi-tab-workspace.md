# 多标签工作区 (Multi-Tab Workspace)

## 页面用途

在 Header 下方提供可关闭的页面标签栏，允许用户同时打开多个模块页面并在其间快速切换。此设计继承自 OMC 系统原有模式，支持最多 10 个标签，提供溢出下拉、批量关闭等操作。

## 布局模板

位于 Header (48px) 下方，占据独立一行。主内容区域从 Tab Bar 下方开始。

```
+----------------------------------------------------------+
|  Header (48px)                                           |
+----------------------------------------------------------+
|  Tab Bar (36px)                                          |
+----------------------------------------------------------+
|                                                          |
|  主内容区域 (高度 = 100vh - 48px - 36px)                   |
|                                                          |
+----------------------------------------------------------+
```

## 线框描述

## 标签管理规则

### 标签数量限制

| 规则               | 行为                                          |
|-------------------|-----------------------------------------------|
| 最大标签数          | 10 个                                         |
| 超出限制时          | 自动关闭最早打开的非激活标签，为新标签腾出位置       |
| Dashboard 标签     | 始终存在, 不可关闭 (固定标签)                     |
| 最后一个标签        | 关闭后自动跳转到 Dashboard                       |

### 标签打开规则

| 操作                   | 行为                                        |
|-----------------------|---------------------------------------------|
| 点击侧边栏菜单项        | 如已存在该页面 Tab，切换到该 Tab; 否则新建 Tab   |
| 点击页面内导航链接       | 同上                                        |
| 浏览器地址栏直接输入 URL | 新建 Tab (如未存在) 或切换到已存在 Tab          |
| 多次点击同一菜单项      | 不重复创建，切换到已存在 Tab                     |

### 标签关闭操作

| 操作                   | 行为                                         |
|-----------------------|----------------------------------------------|
| 点击标签关闭按钮 (×)    | 关闭该标签，激活相邻标签 (优先右侧，其次左侧)     |
| 鼠标中键点击标签        | 等同于点击关闭按钮                              |
| 右键菜单 > 关闭当前     | 关闭当前标签                                   |
| 右键菜单 > 关闭其他     | 关闭除当前标签和固定标签外的所有标签               |
| 右键菜单 > 关闭左侧     | 关闭当前标签左侧所有非固定标签                    |
| 右键菜单 > 关闭右侧     | 关闭当前标签右侧所有非固定标签                    |
| 右键菜单 > 关闭全部     | 关闭所有非固定标签, 跳转 Dashboard               |

### 右键上下文菜单

```
+-------------------+
| 刷新当前页面       |
| ─────────────────|
| 关闭当前标签       |
| 关闭其他标签       |
| 关闭左侧标签       |
| 关闭右侧标签       |
| 关闭全部标签       |
| ─────────────────|
| 固定标签           |
+-------------------+
```

## 标签状态管理

```typescript
interface Tab {
  key: string;           // 唯一标识 (路由 path)
  title: string;         // 标签显示名称
  icon: ReactNode;       // 标签图标 (取自导航配置)
  path: string;          // 完整路由路径 (含 query params)
  pinned: boolean;       // 是否固定标签
  closable: boolean;     // 是否可关闭
  timestamp: number;     // 打开时间 (用于排序和 LRU 淘汰)
}

interface TabBarState {
  tabs: Tab[];                // 已打开的标签列表
  activeTabKey: string;       // 当前激活标签的 key
  maxTabs: number;            // 最大标签数 (默认 10)
}
```

### 持久化策略

| 状态项     | 存储位置          | 恢复策略                        |
|-----------|------------------|--------------------------------|
| tabs      | sessionStorage   | 刷新页面后恢复所有标签             |
| activeTab | sessionStorage   | 刷新后恢复到上次激活的标签          |
| pinned    | localStorage     | 跨会话保持固定标签设置             |

## 拖拽排序

| 属性         | 值                              |
|-------------|--------------------------------|
| 启用条件     | 标签数量 >= 2                    |
| 拖拽手柄     | 整个标签区域                     |
| 拖拽预览     | 半透明标签副本跟随鼠标            |
| 放置指示     | 目标位置显示蓝色竖线指示器         |
| 固定标签     | 不可拖拽                        |
| 动画         | 其他标签自动让位动画 (200ms)      |

## 标签内页面状态缓存

| 策略             | 说明                                        |
|-----------------|---------------------------------------------|
| Keep-Alive      | 非激活标签的页面组件保持挂载，不销毁             |
| 数据缓存         | 列表页的筛选条件、分页位置、滚动位置在切换后恢复  |
| 缓存清理         | 标签关闭时清理对应页面的缓存数据                |
| 内存限制         | 超过 5 个非激活标签时，最早的标签降级为懒加载模式  |

## 键盘快捷键

| 快捷键                | 操作                    |
|----------------------|------------------------|
| `Ctrl + W`           | 关闭当前标签             |
| `Ctrl + Shift + T`   | 恢复最近关闭的标签        |
| `Ctrl + Tab`         | 切换到下一个标签          |
| `Ctrl + Shift + Tab` | 切换到上一个标签          |
| `Ctrl + 1-9`         | 切换到第 N 个标签        |

## 状态处理

| 状态             | 处理方式                                  |
|-----------------|------------------------------------------|
| 标签正在加载     | 标签名称左侧显示 Spin 加载图标              |
| 页面加载失败     | 标签保留, 内容区显示错误提示 + 重试按钮       |
| 标签过多溢出     | 显示溢出下拉按钮, 列出不可见的标签            |
| 无标签 (全部关闭) | 自动创建 Dashboard 标签并激活              |

## 跨模块导航

| 来源                | 目标                 | Tab 行为                     |
|--------------------|---------------------|------------------------------|
| 侧边栏菜单项        | 对应模块页面          | 新建或切换到已有 Tab           |
| 页面内链接跳转       | 目标页面             | 新建或切换到已有 Tab           |
| Header 告警角标     | 告警管理 > 当前告警   | 新建或切换 + 更新 query params |
| Dashboard 卡片     | 对应模块页面          | 新建或切换到已有 Tab           |

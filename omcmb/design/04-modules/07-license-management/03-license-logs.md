# License 操作日志 (License Operation Logs)

## 页面用途

License 设备列表页下方分割面板中的操作日志区域。记录所有 License 发送、下载、删除操作的执行历史和结果，支持按 SN 搜索和日志导出。用户可实时监控最近的操作进度和执行结果。

## 布局模板

**Sub-Panel Layout（子面板）** — 嵌入在 License 设备列表页的下方分割面板中。

```
+------------------------------------------------------------------+
|  上方面板: License 设备列表（见 01-license-list.md）                 |
+==================================================================+
|  下方面板: Logs 操作日志（本页面）                                   |
+------------------------------------------------------------------+
| Logs                    [Serial Number 🔍]        [📥导出] [🔗]   |
+------------------------------------------------------------------+
| 数据表格                                                           |
+------------------------------------------------------------------+
| 分页器                                                             |
+------------------------------------------------------------------+
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| Serial Number | SearchInput | 用户输入 | 空 | 按设备序列号搜索操作日志，回车或点击搜索图标触发 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 排序 | 对齐 | 渲染规则 |
|------|----------|------|------|------|---------|
| Serial Number | serialNumber | 240px | -- | left | 文本，可点击跳转设备详情 |
| Start Time | startTime | 200px | 支持 ↕ | left | 日期时间格式 YYYY-MM-DD HH:mm:ss |
| Task Progress | taskProgress | 180px | -- | left | 进度条组件: 蓝色填充 + 百分比数字; 100% 时变为绿色 |
| Results | results | 140px | -- | left | 状态标签: Success = 绿色文字 + ✅; Failure = 红色文字 + ❌; 进行中 = 蓝色文字 + ⏳ |

## 工具栏操作

| 按钮名称 | 图标 | 类型 | 条件 | 行为 |
|---------|------|------|------|------|
| 导出日志 | export/download | Icon Button | 有日志数据 | 导出当前筛选条件下的日志为 CSV/Excel 文件 |
| 外部链接 | external-link | Icon Button | 始终可见 | 在新 Tab 中打开完整日志页面（独立页面模式） |

## 弹窗规格

### 导出日志确认

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 导出日志 |
| 尺寸 | 420px x auto |

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 导出格式 | Radio Group | 是 | CSV / Excel (.xlsx) |
| 导出范围 | Radio Group | 是 | 当前页 / 全部数据 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| Cancel | Default | 关闭弹窗 |
| Export | Primary | 开始导出并下载文件 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 加载中 | 表格显示 Skeleton 骨架屏 |
| 空数据 | 居中显示 "暂无操作日志" |
| 搜索无结果 | 显示 "未找到匹配的日志记录" |
| 实时更新 | 发送操作进行中时，Logs 面板每 3 秒自动轮询刷新进度和结果 |
| 进度进行中 | Task Progress 列显���蓝色进度条动画 |
| 操作完成 | 弹出全局通知: 成功/部分失败/全部失败 |

## 跨模块导航

| 触发元素 | 目标页面 | 传递参数 |
|---------|---------|---------|
| Serial Number 点击 | 设备管理 > 设备详情 | deviceSN |
| 外部链接图标 | License 管理 > 完整日志页（独立路由） | 当前筛选条件 |
| Results = Failure 点击 | 弹出失败原因详情 Tooltip | logId |

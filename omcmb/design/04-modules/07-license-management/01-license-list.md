# License 设备列表 (License Device List)

## 页面用途

License 管理模块的主页面，展示所有设备的 License 状态信息。采用上下分割面板布局，上方为设备列表，下方为操作日志。支持按 Basic License 和 1688License 两种类型切换查看，提供 License 的发送、下载、删除等批量操作入口。

## 布局模板

**Split-Panel Layout（上下分割面板）**

```
+------------------------------------------------------------------+
| 顶部导航栏                                                         |
+------------------------------------------------------------------+
| [Device] [Date Model] [Certificate] [License]  ← 功能 Tab         |
+------------------------------------------------------------------+
| [Basic License] | [1688License]     ← License 类型 Tab             |
+------------------------------------------------------------------+
|                    上方面板 — License 设备列表                       |
| 工具栏 + 筛选栏 + 数据表格                                          |
+------------------------------------------------------------------+
|                    下方面板 — 操作日志 (Logs)                        |
| 搜索栏 + 日志表格                                                   |
+------------------------------------------------------------------+
```

## 筛选栏配置

| 字段名称 | 组件类型 | 数据源 | 默认值 | 说明 |
|---------|---------|--------|-------|------|
| Serial Number | SearchInput | 用户输入 | 空 | 设备序列号模糊搜索，回车触发 |
| Online | Select + Tag | 字典: Online/Offline/All | All | 在线状态筛选，支持清除 |
| Status | Select + Tag | 字典: All/Success/Execute failure/Pending | All | License 执行状态筛选 |
| Product Type | Select + Tag | 字典: QRTB/RTD/RTS/QAFA/QAFB | All | 产品类型筛选 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 排序 | 对齐 | 渲染规则 |
|------|----------|------|------|------|---------|
| (复选框) | _selection | 48px | -- | center | Checkbox，联动工具栏计数 |
| (状态图标) | onlineStatus | 32px | -- | center | 圆点: 🟢Online / 🟠Abnormal / 🔴Offline |
| (操作菜单) | _actions | 40px | -- | center | 三点菜单 `...`，含查看详情/编辑 |
| Serial Number | serialNumber | 220px | 支持 ↕ | left | 文本，可点击跳转设备详情 |
| Product Type | productType | 120px | -- | left | 文本标签 |
| License File | licenseFile | 260px | -- | left | 文件名，缺失显示 `--` |
| Upload Time | uploadTime | 180px | 支持 ↕ | left | 日期时间格式 YYYY-MM-DD HH:mm |
| Status | status | 140px | -- | left | Execute failure 显示红色文字 + ❌ 图标; Success 显示绿色; 空值显示 `--` |

## 工具栏操作

| 按钮名称 | 图标 | 类型 | 条件 | 行为 |
|---------|------|------|------|------|
| ☑(N) | checkbox-count | 信息展示 | 始终可见 | 显示当前已选设备数量 |
| Send License | upload | Primary | 至少选中 1 项 | 打开 Send License 流程弹窗 |
| Download | download | Default | 至少选中 1 项 | 下载选中设备的 License 文件 |
| Delete | delete | Danger | 至少选中 1 项 | 二次确认后删除选中 License |
| 批量选择 | batch-select | Icon | 始终可见 | 打开批量输入 SN 弹窗 |
| 导出日志 | export | Icon | 始终可见 | 导出下方 Logs 面板数据 |
| 导出列表 | export-list | Icon | 始终可见 | 导出上方设备列表数据 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 加载中 | 表格区域显示 Skeleton 骨架屏 |
| 空数据 | 居中显示空状态插图 + "暂无 License 数据" |
| 加载失败 | 错误提示 + 重试按钮 |
| 部分执行失败 | Status 列红色 "Execute failure" 标记，Logs 面板同步显示失败详情 |
| License 类型切换 | 切换 Tab 时重新加载对���类型数据，重置筛选条件 |

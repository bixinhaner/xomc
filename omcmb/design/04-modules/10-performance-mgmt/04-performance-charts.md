# 性能图表规格 (Performance Chart Specifications)

## 页面用途

定义性能管理模块中所有图表组件的统一规格，包括柱状图、折线图、饼图以及组合图表。这些图表规格在 KPI 标准报表、基站报表、指标提取向导的统计图视图中复用。

## 布局模板

**Chart Component（图表组件）** — 嵌入在报表页面的统计图 Tab 中

## 导航路径

```
(组件级规格，嵌入在性能管理各报表页面的 [统计图] Tab 中)
```

## 路由

不适用（组件规格）

## 筛选栏配置

### 图表通用控件

| 控件名称 | 组件类型 | 说明 |
|---------|---------|------|
| 选择网元 | Button + Modal | 选择要在图表中展示的网元 |
| 清除 | Icon Button (垃圾桶) | 清除已选网元 |
| 选择图形 | RadioGroup | 柱状图(默认) / 折线图 / 饼图 |
| 导出 | Button | 导出图表为 PNG 图片 |
| 查询 | Button | 执行图表查询 |

## 状态处理

### 图表通用特性

| 特性 | 规格 |
|------|------|
| 标题 | 图表左上角，粗体文本 |
| 图例 | 图表顶部水平排列，支持点击切换显示/隐藏 |
| Tooltip | 鼠标悬停显示详细数值，含指标名称和数值 |
| 坐标轴标签 | X轴: 时间/分类名称; Y轴: 数值+单位 |
| 时间范围控件 | 底部时间刷选条（仅折线图/柱状图） |
| 导出 | 右上角下载按钮，导出 PNG/SVG |
| 空数据 | 居中提示 "暂无数据" |
| 加载中 | 图表区域显示加载动画 |
| 自适应 | 图表容器响应式，随窗口调整大小 |

### 各图表类型适用场景

| 图表类型 | 适用场景 | 说明 |
|---------|---------|------|
| 柱状图 | KPI 值对比、跨网元对比 | 适合离散值的对比分析 |
| 折线图 | KPI 趋势、时间序列 | 适合展示指标随时间的变化趋势 |
| 饼图 | 分布统计、占比分析 | 适合展示某指标的分布比例 |
| 组合图(柱+线) | 数量+比率双轴 | 左Y轴为数量(柱状)，右Y轴为百分比(折线) |

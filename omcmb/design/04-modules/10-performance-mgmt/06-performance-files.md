# 性能文件管理 (Performance File Management)

## 页面用途

管理设备的性能数据采集配置和性能文件。分为两个子标签页: 性能参数配置（配置设备的采集开关、周期、上传地址等）和性能文件（浏览已采集的性能文件列表）。支持批量操作和文件管理。

## 布局模板

**Tab + List Page Layout（标签页 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > 性能管理 > 性能文件
```

## 路由

```
/performance/files          （性能参数配置 Tab）
/performance/files/list     （性能文件 Tab）
```

## 弹窗规格

### 性能参数配置弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | 性能参数配置 |
| 尺寸 | 640px x auto |

**设备SN号:** 只读显示

**采集配置区:**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 实例选择 | Select | 是(*) | OID 实例路径 |
| 采集名称 | TextInput (0/64) | 是(*) | 采集配置名称 |
| 采集开关 | Toggle Switch | 是(*) | 开/关 |
| 采集周期(s) | Select | 是(*) | 如 900 |
| 上传时间 | TimePicker | 是(*) | 上传时间点 |

**文件管理区:**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| URL | TextInput | 是(*) | 性能文件上传地址 |
| 用户名 | PasswordInput | 是(*) | 认证用户名 |
| 密码 | PasswordInput | 是(*) | 认证密码 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| 设为默认值 | Link | 将当前URL/用户名/密码设为默认 |
| Cancel | Default | 关闭 |
| Confirm | Primary | 保存配置 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 采集开关切换 | 行内操作后显示同步中状态 |
| 文件Tab必填未填 | 搜索按钮 disabled，提示 "请填写采集日期和时间范围" |

# FTP 服务器配置 (FTP Configuration)

## 页面用途

定义备份文件上传的 FTP/SFTP 服务器连接参数。作为创建备份任务页面的一个配置区块，提供协议选择、地址端口、认证信息和连接测试功能。

## 布局模板

内嵌于创建备份任务页面的 "FTP 服务器配置" 区块。

## 表单字段

| 字段名称   | 英文标识    | 组件类型       | 必填 | 默认值 | 校验规则                         |
|----------|-----------|--------------|------|-------|----------------------------------|
| 启用 FTP | ftpEnabled| Switch       | -    | 禁用   | -                                |
| 传输协议  | protocol  | Radio Group  | 是   | SFTP  | SFTP / FTP                       |
| IP 地址  | host      | Input        | 是   | -     | IPv4/IPv6/域名 格式校验            |
| 端口     | port      | InputNumber  | 是   | 22    | 1-65535                          |
| 用户名   | username  | Input        | 是   | -     | 非空, 最大 64 字符                |
| 密码     | password  | Password     | 是   | -     | 非空, 最大 128 字符               |
| 上传路径  | uploadPath| Input        | 否   | /backup/{deviceType}/{date}/ | 以 "/" 开头的合法路径 |

### 字段联动

| 触发       | 联动效果                              |
|-----------|---------------------------------------|
| 启用开关关闭 | 所有下方字段变为禁用 (灰色, 不可编辑)    |
| 选择 SFTP  | 端口默认值设为 22                      |
| 选择 FTP   | 端口默认值设为 21                      |
| 协议切换   | 如端口为上一个协议默认值, 自动更新为新默认值 |

## 组件样式

### 启用开关

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Switch (Ant Design)            |
| 开启文字     | 启用                            |
| 关闭文字     | 禁用                            |
| 开启颜色     | #1890FF                        |

### 协议选择

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Radio Group (按钮样式)          |
| 选项         | SFTP / FTP                     |
| 推荐标识     | SFTP 选项右侧显示 "(推荐)" 标签 |

### 密码输入框

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Input.Password (Ant Design)    |
| 显示/隐藏   | 右侧眼睛图标切换                 |
| 自动填充     | autocomplete="new-password"    |

### 上传路径

| 属性         | 值                                           |
|-------------|----------------------------------------------|
| Placeholder  | /backup/{deviceType}/{date}/                 |
| 说明文字     | 支持变量: {deviceType}, {date}, {time}, {sn}  |

**路径变量说明：**

| 变量           | 说明                  | 示例值          |
|---------------|----------------------|----------------|
| {deviceType}  | 当前设备类型          | eNB            |
| {date}        | 执行日期              | 20240115       |
| {time}        | 执行时间              | 020000         |
| {sn}          | 设备 SN              | SN20240001     |

## 测试连接

### 测试按钮

| 属性         | 值                                |
|-------------|-----------------------------------|
| 按钮文字     | "测试连接"                         |
| 图标         | `ApiOutlined`                     |
| 类型         | Default                           |
| 启用条件     | FTP 启用 + 所有必填字段已填写       |
| 超时时间     | 10 秒                             |

### 测试流程

```
点击 "测试连接"
  ↓
1. 前端校验必填字段
  ↓ (通过)
2. 按钮变为 Loading + "连接中..."
  ↓
3. 发送测试请求
  ↓
4a. 连接成功 → 显示 "✓ 连接成功 (延迟: Xms)"
4b. 连接失败 → 显示 "✗ 连接失败: {原因}"
4c. 连接超时 → 显示 "⏱ 连接超时 (10s)"
```

### 连接状态显示

| 状态       | 图标                    | 颜色     | 文字                          |
|-----------|------------------------|---------|-------------------------------|
| 未测试     | -                      | -       | -                             |
| 测试中     | Spin 动画              | #1890FF | "连接中..."                   |
| 连接成功   | `CheckCircleOutlined`  | #52C41A | "连接成功 (延迟: {X}ms)"       |
| 连接失败   | `CloseCircleOutlined`  | #FF4D4F | "连接失败: {原因}"             |
| 连接超时   | `ClockCircleOutlined`  | #FA8C16 | "连接超时 (10s)"              |

### 常见失败原因

| 原因                  | 显示文字                          |
|----------------------|-----------------------------------|
| 网络不可达            | "无法连接到 {host}:{port}"         |
| 认证失败             | "用户名或密码错误"                  |
| 端口拒绝             | "端口 {port} 连接被拒绝"           |
| 路径不存在           | "上传路径 {path} 不存在"           |
| 权限不足             | "用户无上传路径写入权限"            |
| 协议不匹配           | "服务器不支持 {protocol} 协议"      |

## 数据接口

```typescript
// 测试 FTP 连接
POST /api/backup/ftp/test
{
  protocol: 'sftp' | 'ftp';
  host: string;
  port: number;
  username: string;
  password: string;
  uploadPath?: string;
}

interface FTPTestResult {
  success: boolean;
  latency?: number;       // ms
  errorMessage?: string;
  errorCode?: string;
}
```

## 安全提示

```
┌──────────────────────────────────────────────────────┐
│ 🔒 安全提示:                                          │
│ - 推荐使用 SFTP 协议，数据传输经过加密                  │
│ - FTP 协议传输数据不加密，不建议在公网环境使用           │
│ - 密码将加密存储在系统中                                │
└──────────────────────────────────────────────────────┘
```

当选择 FTP (非 SFTP) 时，显示上方安全提示（黄色 Alert）。

## 状态处理

| 状态               | 处理方式                                |
|-------------------|-----------------------------------------|
| FTP 禁用           | 所有字段灰色不可编辑                      |
| FTP 启用           | 字段变为可编辑, 必填字段标红               |
| 测试中             | 测试按钮 Loading, 其他字段可编辑          |
| 必填字段未填写      | 测试按钮禁用, Tooltip "请先填写必填字段"   |
| 密码已保存 (编辑模式)| 密码显示为 "••••••", 可清空重新输入       |

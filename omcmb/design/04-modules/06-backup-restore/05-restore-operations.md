# 恢复操作 Restore Operations

> 模块路径：`/backup-restore/restore`
> 布局模板：Split Panel（上下分屏）— 参考 `03-layouts/06-split-panel-page.md`
> 数据来源：Cloudcore OMC 备份恢复模块

---

## 1. 页面概述

恢复操作页面用于将之前备份的配置文件恢复到目标设备。上半区选择设备与备份文件，下半区展示恢复任务执行状态。恢复为高危操作，需二次确认。

## 3. 设备列表表格

### 3.1 列定义

| 列名 | 字段 | 宽度 | 对齐 | 功能 |
|------|------|------|------|------|
| 复选框 | — | 40px | 居中 | 多选，表头全选 |
| 序列号 | `serialNumber` | 180px | 左对齐 | 等宽字体，点击复制 |
| 小区名称 | `cellName` | 160px | 左对齐 | 超长截断 + Tooltip |
| 产品类型 | `productType` | 140px | 左对齐 | 如 RRU-4T4R、pRRU |
| 最新备份文件 | `latestBackupFile` | 200px | 左对齐 | 文件名 + 文件大小 |
| 备份时间 | `backupTime` | 160px | 左对齐 | `YYYY-MM-DD HH:mm` |
| 操作 | — | 120px | 居中 | [备份历史] [恢复] |

### 3.2 行操作

- **备份历史**：打开侧滑抽屉，展示该设备所有备份版本列表
- **恢复**：直接触发单设备恢复确认对话框

## 7. 恢复任务列表（下半区）

### 7.1 状态计数栏

与备份任务页保持一致的四状态计数徽章：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 等待 Waiting | `#8C8C8C` neutral | 排队中 |
| 执行中 In Progress | `#1677FF` primary | 正在恢复 |
| 已完成 Completed | `#52C41A` success | 恢复成功 |
| 失败 Failed | `#F5222D` error | 恢复失败 |

### 7.2 任务表格列定义

| 列名 | 字段 | 宽度 | 功能 |
|------|------|------|------|
| 任务名称 | `taskName` | 200px | 自动生成：`恢复_SN_时间戳` |
| 设备序列号 | `deviceSn` | 160px | 等宽字体 |
| 备份版本 | `backupVersion` | 120px | 如 v3 |
| 操作人 | `operator` | 100px | 当前用户 |
| 开始时间 | `startTime` | 160px | `YYYY-MM-DD HH:mm:ss` |
| 结束时间 | `endTime` | 160px | 进行中显示 `—` |
| 状态 | `status` | 100px | Tag 组件 + 颜色 |
| 进度 | `progress` | 120px | Progress Bar 0-100% |
| 结果 | `result` | 140px | 成功/失败原因摘要 |
| 操作 | — | 100px | [详情] [重试] |

### 7.3 实时更新

- 恢复任务通过 **WebSocket** 推送进度更新
- 进度条实时递增，状态自动切换
- 失败任务显示 [重试] 按钮，支持单任务重试

## 8. 批量恢复流程

```
选择设备（勾选多台）
    ↓
点击 [恢复配置]
    ↓
弹出确认对话框（展示设备列表 + 版本选择）
    ↓
勾选风险确认 → 点击 [确认恢复]
    ↓
创建恢复任务（每设备一条任务记录）
    ↓
任务列表实时更新进度
    ↓
全部完成 → Toast 通知 "N 台设备恢复完成"
部分失败 → Alert Banner "M 台设备恢复失败，请检查"
```

## 9. 版本对比功能

选择两个备份版本进行 Diff 对比，以高亮显示配置差异：

| 属性 | 值 |
|------|-----|
| 展示方式 | 左右分栏 Side-by-Side |
| 差异高亮 | 新增行绿色背景 `#F6FFED`，删除行红色背景 `#FFF1F0`，修改行黄色背景 `#FFFBE6` |
| 文件类型 | XML 配置文件，代码高亮 |
| 字体 | 等宽字体 `SFMono-Regular` 13px |

# 执行计划配置 (Schedule Configuration)

## 页面用途

定义备份任务执行计划的可视化日程选择器规格。支持三种模式：按天（仅选择时间）、按周（多选星期几 + 时间）、按月（多选月份 + 多选日期 + 时间）。每种模式提供直观的可视化选择界面。

## 布局模板

内嵌于创建备份任务页面的 "执行计划" 区块。

## 组件规格

### 模式选择器

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Select                         |
| 宽度         | 200px                          |
| 默认值       | Day (按天)                      |
| 切换行为     | 切换模式后, 重置该模式下的字段    |

### 星期选择器 (Week 模式)

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Checkbox Group (按钮样式)       |
| 布局         | 横排 7 个, 等宽                  |
| 选项         | 周一(1) ~ 周日(7)               |
| 选中样式     | 背景 #1890FF, 文字白色           |
| 默认样式     | 背景 #F5F5F5, 文字 #262626      |
| 校验         | 至少选择 1 天                    |

**单个选项尺寸：**

```css
.week-day-btn {
  width: 56px;
  height: 36px;
  border-radius: 4px;
  text-align: center;
  cursor: pointer;
  transition: all 0.2s;
}
```

| 布局         | 6 列 × 2 行                    |

| 选中样式     | 背景 #1890FF, 文字白色          |
| 默认样式     | 背景 #F5F5F5, 文字 #262626     |
| 快捷操作     | [全选] [全不选]                 |

**单个选项尺寸：**

```css
.month-btn {

```

### 日期选择器 (Month 模式)

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Checkbox Group (日历网格样式)   |
| 布局         | 10 列 × 3.1 行 (1-31)          |
| 选项         | 1 日 ~ 31 日                    |
| 选中样式     | 背景 #1890FF, 文字白色          |
| 默认样式     | 背景 #F5F5F5, 文字 #262626     |
| 快捷操作     | [全选] [全不选]                 |
| 校验         | 至少选择 1 天                    |
| 特殊日提示   | 29/30/31 日 hover 时提示 "部分月份无此日" |

**单个选项尺寸：**

```css
.day-btn {
  width: 36px;
  height: 32px;
  border-radius: 4px;
  font-size: 13px;
}
```

### 时间选择器

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | TimePicker (Ant Design)        |
| 格式         | HH:mm (24 小时制)              |
| 默认值       | 02:00                          |
| 分钟步进     | 30 分钟                        |
| 建议         | 建议选择业务低峰时段 (00:00-06:00) |

### 执行预览

| 属性         | 值                              |
|-------------|--------------------------------|
| 位置         | 时间选择器下方                   |
| 字体         | 13px, color: #8C8C8C           |
| 图标         | `ClockCircleOutlined`          |
| 内容格式     | "每{模式描述} {时间} 执行备份"   |
| 下次执行     | 自动计算并显示下次执行的具体日期时间 |

## 预览文字生成规则

| 模式   | 预览文字格式                                    |
|-------|------------------------------------------------|
| 按天   | "每天 {HH:mm} 执行备份"                        |
| 按周   | "每{周X、周X} {HH:mm} 执行备份"                |
| 按月   | "每年{X月、X月} 的 {X日、X日} {HH:mm} 执行备份" |

## 校验规则

| 模式   | 字段         | 校验规则                        |
|-------|-------------|--------------------------------|
| Day   | 执行时间     | 必填                            |
| Week  | 执行日       | 至少选 1 天                     |
| Week  | 执行时间     | 必填                            |
| Month | 执行月份     | 至少选 1 个月                   |
| Month | 执行日       | 至少选 1 天                     |
| Month | 执行时间     | 必填                            |
| Month | 29/30/31 日  | 警告提示, 不阻止选择             |

## 状态处理

| 状态              | 处理方式                               |
|------------------|-----------------------------------------|
| 模式切换          | 重置该模式下的选择, 保留时间选择          |
| 全选/全不选       | 立即更新所有选项状态                      |
| 无效日期组合      | 底部橙色提示 (如选了 2 月 30 日)          |
| 预览计算错误      | 显示 "无法计算下次执行时间"               |

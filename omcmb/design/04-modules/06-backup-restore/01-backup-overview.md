# 备份恢复总览 (Backup Overview)

## 页面用途

备份恢复模块的主页面，采用上下分栏布局：上方为设备备份文件信息表格，下方为备份/恢复任务列表（含 Tab 切换）。提供设备备份状态查看、任务管理等功能。

## 布局模板

使用 split-panel-page 布局（上下分栏，可拖拽调整比例）。

## 导航路径

备份恢复

## 路由

`/backup`

## 上栏: 设备备份信息

### 筛选栏

| 字段名称   | 英文标识      | 组件类型  | 必填 | 选项/说明           |
|----------|-------------|---------|------|---------------------|
| 设备 SN  | deviceSn    | Input   | 否   | 精确/模糊搜索        |
| 小区名称  | cellName    | Input   | 否   | 模糊搜索             |
| 产品类别  | productType | Select  | 否   | eNB/gNB/CPE/eGW     |

### 表格列

| 列名称       | 英文标识         | 数据类型   | 可排序 | 宽度    | 说明                    |
|-------------|-----------------|-----------|--------|--------|------------------------|
| SN          | deviceSn        | String    | 是     | 130px  | -                      |
| 小区名称     | cellName        | String    | 是     | 140px  | -                      |
| 产品类别     | productType     | String    | 是     | 100px  | -                      |
| 厂商         | vendor          | String    | 是     | 100px  | -                      |
| 最新备份文件  | latestBackup    | String    | 否     | 160px  | 文件名, 蓝色链接可下载   |
| 最新备份时间  | latestBackupTime| DateTime  | 是     | 140px  | -                      |
| 备份大小     | backupSize      | FileSize  | 是     | 90px   | KB/MB 格式              |
| 备份状态     | backupStatus    | Tag       | 是     | 90px   | 最新/过期/无             |
| 操作         | actions         | Actions   | 否     | 120px  | 备份/恢复               |

### 备份状态标签

| 状态   | Tag 颜色   | 条件                          |
|-------|-----------|-------------------------------|
| 最新   | success   | 最近 7 天内有成功备份          |
| 过期   | warning   | 最近 7 天内无备份, 但历史有     |
| 无     | error     | 从未备份过                     |

### 行操作

| 操作   | 图标                    | 说明                     |
|-------|------------------------|--------------------------|
| 备份   | `CloudUploadOutlined`  | 立即对该设备执行一次备份    |
| 恢复   | `CloudDownloadOutlined`| 打开恢复操作弹窗           |

## 下栏: 任务列表

### Tab 切换

| Tab         | 说明                        |
|------------|------------------------------|
| Task List  | 备份/恢复任务列表             |
| Device List| 按设备维度查看备份恢复记录     |

### 状态筛选 Chip

```
[全部(12)] [Waiting(2)] [InProgress(1)] [Suspend(0)] [End(9)]
```

| Chip 状态     | 颜色              | 说明                |
|-------------|-------------------|---------------------|
| 全部         | default           | 不筛选              |
| Waiting     | blue              | 等待执行             |
| InProgress  | blue + 呼吸动画   | 正在执行             |
| Suspend     | orange            | 已暂停              |
| End         | default (灰)      | 已结束              |

### 工具栏

| 操作名称       | 图标                    | 类型     | 说明                  |
|-------------|------------------------|---------|----------------------|
| 新建备份任务  | `CloudUploadOutlined`  | Primary | 打开创建备份任务页面    |
| 新建恢复任务  | `CloudDownloadOutlined`| Default | 打开恢复操作弹窗       |

## 数据接口

```typescript
// 设备备份信息
GET /api/backup/devices?deviceType={type}&page={page}&size={size}

// 任务列表
GET /api/backup/tasks?status={status}&page={page}&size={size}

// 立即备份
POST /api/backup/instant
{ deviceSns: string[] }

interface BackupTask {
  taskId: string;
  taskName: string;
  user: string;
  createTime: string;
  taskType: 'restore_factory' | 'recurring_backup' | 'restore' | 'backup';
  status: 'waiting' | 'in_progress' | 'suspend' | 'end';
  progress: number;
  successCount: number;
  failCount: number;
  totalCount: number;
}
```

## 状态处理

| 状态             | 处理方式                                |
|-----------------|----------------------------------------|
| 上栏加载中       | 表格 Skeleton 骨架                      |
| 下栏加载中       | 表格 Skeleton 骨架                      |
| 设备无备份       | 备份状态显示 "无" (红色), 备份文件显示 "-" |
| 任务执行中       | 进度条实时更新 (轮询 5s)                  |
| 立即备份成功     | Toast "备份任务已创建", 自动切换到下栏     |
| 立即备份失败     | 错误提示 + 原因                          |

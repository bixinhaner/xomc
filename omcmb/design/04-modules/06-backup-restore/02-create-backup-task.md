# 创建备份任务 (Create Backup Task)

## 页面用途

创建定时周期备份任务的表单页面。配置备份任务的启用状态、设备范围、执行计划（按日/周/月）、时间安排和 FTP 服务器参数。

## 布局模板

使用 form-page 布局（垂直表单分区）。

## 导航路径

备份恢复 > 新建备份任务

## 路由

`/backup/create`

## 表单区块

### 区块 1: 基本信息

| 字段名称   | 英文标识      | 组件类型   | 必填 | 校验规则                   |
|----------|-------------|---------|------|---------------------------|
| 任务名称  | taskName    | Input   | 是   | 非空, 2-64 字符, 系统不重复 |
| 启用状态  | enabled     | Switch  | -    | 默认启用                   |
| 任务描述  | description | TextArea | 否  | 最大 256 字符              |

### 区块 2: 设备选择

| 字段名称   | 英文标识         | 组件类型    | 必填 | 校验规则/说明                    |
|----------|----------------|-----------|------|--------------------------------|
| 设备范围  | deviceScope    | Radio     | 是   | 全部设备 (ALL) / 选择设备 (SELECT) |
| SN 输入  | deviceSns      | TextArea  | 条件 | 选择设备时必填, 至少 1 个有效 SN   |

**设备选择交互：**

| 操作                | 说明                                |
|--------------------|------------------------------------|
| 选择 "全部设备"     | 对当前设备类型下所有设备执行备份       |
| 选择 "选择设备"     | 展开 SN 输入区域                    |
| 批量输入 SN         | TextArea, 逗号或换行分隔            |
| "从设备列表选择" 按钮| 弹出设备选择弹窗 (复选表格)          |
| SN 校验             | 实时校验输入的 SN 是否存在系统中     |

### 区块 3: 执行计划

详见 `03-schedule-config.md`。

| 字段名称   | 英文标识      | 组件类型   | 必填 | 说明                   |
|----------|-------------|---------|------|------------------------|
| 执行模式  | scheduleMode| Select  | 是   | Day (按天) / Week (按周) / Month (按月) |
| 执行时间  | executeTime | TimePicker | 是 | 24 小时制, 默认 02:00  |
| 执行日 (周)| weekDays   | Checkbox | 条件 | 按周模式时必填, 至少选 1 天 |
| 执行月份  | months      | Checkbox | 条件 | 按月模式时必填, 至少选 1 月 |
| 执行日 (月)| monthDays  | Checkbox | 条件 | 按月模式时必填, 至少选 1 日 |

### 区块 4: FTP 服务器配置

详见 `04-ftp-config.md`。

## 底部操作栏

| 按钮         | 类型     | 说明                              |
|-------------|---------|-----------------------------------|
| 取消         | Default  | 返回备份恢复总览页面               |
| 仅保存       | Default  | 保存任务但不启用 (状态为 Waiting)   |
| 保存并启用   | Primary  | 保存并立即启用任务                  |

## 数据接口

```typescript
POST /api/backup/tasks
{
  taskName: string;
  enabled: boolean;
  description?: string;
  deviceScope: 'all' | 'selected';
  deviceSns?: string[];
  scheduleMode: 'day' | 'week' | 'month';
  executeTime: string;           // HH:mm
  weekDays?: number[];           // 1-7 (周一到周日)
  months?: number[];             // 1-12
  monthDays?: number[];          // 1-31
  ftpConfig?: FTPConfig;
}
```

## 状态处理

| 状态              | 处理方式                                |
|------------------|-----------------------------------------|
| 设备列表弹窗加载中 | 弹窗内 Skeleton 骨架                    |
| SN 校验中         | 输入框右侧 Spin                        |
| SN 无效           | 红色标记无效 SN + 错误提示              |
| 表单提交中        | 保存按钮 Loading 态                     |
| 保存成功          | Toast "备份任务创建成功" + 跳转总览页面  |
| 保存失败          | 错误提示 (如任务名重复)                  |
| FTP 测试连接中    | 测试按钮 Loading                       |

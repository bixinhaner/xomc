# 执行面板 (Execution Panel)

## 页面用途

MML 命令控制台右栏的执行面板详细规格。包含 Tab 切换（Control Panel / Parameter Command）、操作类型选择、参数路径输入、执行按钮和结果显示区域。是 MML 命令实际下发和结果查看的操作区。

## 布局模板

内嵌于 MML 命令控制台右栏 (360px)。

### Parameter Command Tab

参数化命令执行面板。

## 操作类型选择器

```
操作类型: [LST (查询) ▼]
```

| 选项   | 标签           | 说明                    |
|-------|---------------|------------------------|
| LST   | LST (查询)     | 查询当前参数值           |
| MOD   | MOD (修改)     | 修改参数值              |
| ADD   | ADD (添加)     | 添加新配置条目           |
| DEL   | DEL (删除)     | 删除配置条目             |

| 属性         | 值                              |
|-------------|--------------------------------|
| 组件类型     | Select                         |
| 宽度         | 100%                           |
| 默认值       | LST                            |
| 切换行为     | 切换后更新参数列表 (不同操作类型可能参数不同) |

### 危险操作警告

当选择 MOD/ADD/DEL 时，显示警告提示：

```
⚠ 注意: 修改操作将直接影响设备配置，请确认参数正确后再执行。
```

## 参数路径输入区

### 参数行结构

```
参数名:  [输入值________]  [+]  [-]
```

| 元素         | 说明                                  |
|-------------|---------------------------------------|
| 参数名标签   | 取自命令参数定义, font-weight: 500     |
| 输入组件     | 根据参数类型动态渲染                    |
| [+] 按钮    | 添加该参数的多值行 (支持多个值)          |
| [-] 按钮    | 移除当前参数值行                        |

### 输入组件类型映射

| 参数类型    | 渲染组件        | 说明                       |
|-----------|----------------|---------------------------|
| INTEGER   | InputNumber    | 步进器, 可输入整数           |
| DECIMAL   | InputNumber    | 步进器, 支持小数            |
| STRING    | Input          | 文本输入                    |
| ENUM      | Select         | 下拉选择, 选项来自参数定义    |
| BOOLEAN   | Switch         | 开关                       |
| IP        | Input          | IP 地址格式校验             |

### 参数校验

| 校验类型      | 触发时机       | 提示方式                   |
|-------------|---------------|---------------------------|
| 必填校验     | 点击 DO 时    | 红色边框 + 错误提示文字      |
| 范围校验     | 输入时 (实时) | 红色边框 + "超出范围"        |
| 类型校验     | 输入时        | 红色边框 + "请输入有效的数字" |
| 自定义规则   | 点击 DO 时    | 红色边框 + 规则定义的提示    |

### 添加可选参数

```
[+ 添加可选参数]  →  下拉选择未添加的可选参数
```

点击后显示下拉菜单，列出当前命令中尚未添加的可选参数。

## 执行按钮

| 按钮         | 类型     | 快捷键    | 说明                        |
|-------------|---------|----------|-----------------------------|
| DO (执行)    | Primary | Ctrl+Enter | 校验参数 → 发送命令 → 显示结果 |
| Save (保存)  | Default | Ctrl+S   | 保存当前参数配置为模板          |

### 执行流程

```
点击 DO
  ↓
1. 前端参数校验
  ↓ (校验通过)
2. MOD/ADD/DEL 操作: 弹出确认对话框
  ↓ (确认)
3. 发送 API 请求
  ↓
4. 显示 Loading (DO 按钮变为 Spin + "执行中...")
  ↓
5. 收到响应
  ↓
6. 渲染执行结果
```

## 执行结果区

### 结果头部

```
执行时间: 2024-01-15 10:35:00    耗时: 1.2s    状态: ✓ 成功 (RETCODE = 0)
```

| 状态     | 显示样式                           |
|---------|-------------------------------------|
| 成功     | ✓ 成功, 绿色, RETCODE = 0          |
| 失败     | ✗ 失败, 红色, RETCODE + 错误信息    |
| 超时     | ⏱ 超时, 橙色, "设备响应超时"         |

### 结果内容

| 结果类型      | 渲染方式                              |
|-------------|---------------------------------------|
| 表格型结果   | 自动解析为 Table 组件 (列头 + 数据行)    |
| 文本型结果   | monospace 字体的 pre 标签格式化显示      |
| 空结果       | "命令执行成功, 无返回数据"               |

### 结果操作

| 操作     | 图标                  | 说明                  |
|---------|----------------------|-----------------------|
| 复制     | `CopyOutlined`       | 复制完整结果到剪贴板    |
| 导出     | `ExportOutlined`     | 导出为 CSV/TXT 文件    |
| 清空     | `ClearOutlined`      | 清空结果区域           |

## 数据接口

```typescript
// 执行 MML 命令 (与控制台主页面共享)
POST /api/mml/execute
{
  deviceSn: string;
  commandCode: string;
  operationType: 'LST' | 'MOD' | 'ADD' | 'DEL';
  parameters: Record<string, string | number>;
}

// 保存参数模板
POST /api/mml/templates
{
  commandCode: string;
  templateName: string;
  operationType: string;
  parameters: Record<string, string | number>;
}
```

## 状态处理

| 状态              | 处理方式                                   |
|------------------|--------------------------------------------|
| 未选择设备/命令   | 面板整体灰色, 提示 "请先选择设备和命令"       |
| 参数加载中        | 参数区域 Skeleton 骨架                      |
| 命令执行中        | DO 按钮 Loading, 结果区 "执行中..." + Spin  |
| 执行超时          | 30s 后超时, 显示超时提示                    |
| 执行成功          | 结果区绿色状态 + 数据展示                    |
| 执行失败          | 结果区红色错误信息                          |
| 保存成功          | Toast "模板保存成功"                        |
| 确认弹窗 (MOD/DEL)| "即将对设备 {deviceName} 执行 {操作}, 请确认" |

## 跨模块导航

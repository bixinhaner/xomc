# 新建 MML 脚本任务对话框 (New Task Dialog)

## 页面用途

创建 MML 脚本批量执行任务的对话框。定义任务名称、执行模式（立即/等待/定时/周期）、执行策略（离线重试）、设备选择和 MML 脚本内容。

## 布局模板

Modal 对话框组件。

## 触发方式

MML 脚本任务页面 > 工具栏 > [+ 新建任务] 按钮。

## 对话框规格

| 属性         | 值                           |
|-------------|------------------------------|
| 宽度         | 800px                        |
| 最大高度     | 85vh (内容超出可滚动)         |
| 关闭方式     | × 按钮 / ESC 键              |
| 关闭确认     | 有内容时 "是否保存为草稿?"     |

## 表单字段

### 基本信息

| 字段名称   | 英文标识    | 组件类型 | 必填 | 校验规则                  |
|----------|-----------|--------|------|--------------------------|
| 任务名称  | taskName  | Input  | 是   | 非空, 2-64 字符, 不重复    |

### 执行模式

| 字段名称   | 英文标识      | 组件类型        | 必填 | 校验规则/说明                         |
|----------|-------------|----------------|------|--------------------------------------|
| 执行方式  | executeMode | Radio Group    | 是   | Immediately/AwaitingStart/Schedule/Recurring |
| 执行时间  | scheduleTime| DateTimePicker | 条件 | 选择 Schedule 时必填, 不早于当前时间    |
| 重复方式  | repeatType  | Select         | 条件 | 选择 Recurring 时必填: 每天/每周/每月   |
| 重复时间  | repeatTime  | TimePicker     | 条件 | 选择 Recurring 时必填                 |
| 结束日期  | endDate     | DatePicker     | 条件 | 选择 Recurring 时可选                 |

### 执行策略

| 字段名称      | 英文标识        | 组件类型     | 必填 | 默认值 | 说明                |
|-------------|----------------|------------|------|-------|---------------------|
| 启用离线重试  | retryEnabled   | Checkbox   | 否   | 启用   | -                   |
| 重试次数     | retryCount     | InputNumber| 条件  | 3     | 1-10 次             |
| 重试间隔     | retryInterval  | InputNumber| 条件  | 300   | 60-3600 秒          |
| 超时时间     | timeout        | InputNumber| 否   | 60    | 10-600 秒           |

### 设备选择

| 字段名称   | 英文标识         | 组件类型     | 必填 | 说明                     |
|----------|----------------|------------|------|--------------------------|
| 选择模式  | selectionMode  | Radio      | 是   | 选择设备 / 批量输入 SN    |
| 设备列表  | selectedDevices| Transfer   | 条件  | 选择设备模式时, 至少选 1 台 |
| SN 输入  | snInput        | TextArea   | 条件  | 批量输入模式时, 至少 1 个   |

### MML 脚本

| 字段名称   | 英文标识      | 组件类型          | 必填 | 说明                      |
|----------|-------------|------------------|------|---------------------------|
| 脚本内容  | scriptContent| Code Editor      | 是   | MML 命令脚本, 多行          |

## 代码编辑器规格

| 属性           | 值                                  |
|---------------|--------------------------------------|
| 编辑器类型     | CodeMirror / Monaco Editor (轻量版)  |
| 语言模式       | 自定义 MML 语法高亮                   |
| 显示行号       | 是                                   |
| 字体           | monospace, 13px                     |
| 高度           | 200px (可拖拽调整)                   |
| 最小高度       | 120px                               |
| 最大高度       | 400px                               |
| 自动完成       | 支持 MML 命令关键字补全               |
| 语法高亮规则    | 命令码(蓝色)/参数名(绿色)/值(橙色)/注释(灰色) |

### MML 语法格式

```
命令码 [参数名=值[, 参数名=值]...];
```

示例：

```
LST CELLPARA: CellId=0, SubId=ALL;
MOD POWERPARA: CellId=0, DlTxPower=43;
LST ENODEB;
```

### 脚本校验

点击 [校验脚本] 按钮执行：

| 校验项        | 说明                            |
|-------------|--------------------------------|
| 语法检查     | 命令格式是否正确                  |
| 命令存在性   | 命令码是否在系统命令库中           |
| 参数检查     | 参数名是否合法, 值是否在范围内     |
| 重复检查     | 是否有重复命令行                  |

校验结果在编辑器下方显示：

```
✓ 脚本校验通过, 共 3 条命令
```

或

```
✗ 第 2 行: 未知命令 "MOD POWRPARA", 是否指 "MOD POWERPARA"?
✗ 第 3 行: 参数 "CellId" 值超出范围 (0-255)
```

### 模板加载

| 属性     | 值                               |
|---------|----------------------------------|
| 触发     | 点击 [从模板加载] 下拉按钮         |
| 内容     | 列出用户保存的脚本模板             |
| 行为     | 选择模板后填充脚本内容 (覆盖当前)   |
| 确认     | 有现有内容时 "是否覆盖当前脚本?"    |

## 底部操作栏

| 按钮       | 类型     | 说明                           |
|-----------|---------|--------------------------------|
| 取消       | Default | 关闭对话框                      |
| 保存草稿   | Default | 保存为草稿, 不创建任务           |
| 创建       | Primary | 校验 → 创建任务                 |

### 创建流程

```
点击 "创建"
  ↓
1. 前端表单校验
  ↓ (通过)
2. 脚本语法校验 (如未手动校验)
  ↓ (通过)
3. 发送创建请求
  ↓
4. 创建按钮 Loading
  ↓
5. 创建成功 → Toast "任务创建成功"
  ↓
6. 如为 "立即执行" → 自动启动任务
7. 关闭对话框, 刷新任务列表
```

## 数据接口

```typescript
POST /api/mml/tasks
{
  taskName: string;
  executeMode: 'immediately' | 'awaitingStart' | 'schedule' | 'recurring';
  scheduleTime?: string;
  repeatType?: 'daily' | 'weekly' | 'monthly';
  repeatTime?: string;
  endDate?: string;
  retryEnabled: boolean;
  retryCount?: number;
  retryInterval?: number;
  timeout: number;
  deviceSns: string[];
  scriptContent: string;
}

// 校验脚本
POST /api/mml/validate-script
{
  scriptContent: string;
}
```

## 状态处理

| 状态              | 处理方式                                |
|------------------|-----------------------------------------|
| 设备列表加载中    | 设备选择区 Skeleton 骨架                  |
| 脚本校验中       | 校验按钮 Loading + "校验中..."            |
| 校验通过         | 绿色 "✓ 校验通过" 提示                    |
| 校验失败         | 红色错误列表, 编辑器中标记错误行            |
| 创建中           | 创建按钮 Loading                         |
| 创建成功         | Toast + 关闭对话框 + 刷新任务列表          |
| 创建失败         | 错误提示 (如任务名重复)                    |
| 关闭前有内容未保存 | 确认弹窗 "是否保存为草稿？"                |

## 跨模块导航

本对话框为 MML 脚本任务页面的内嵌弹窗组件，创建成功后关闭对话框回到任务列表。

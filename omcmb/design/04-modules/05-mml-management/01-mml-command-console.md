# MML 命令控制台 (MML Command Console)

## 页面用途

MML (Man-Machine Language) 命令操作的核心页面，采用三栏布局：左栏设备选择器 + MML 命令树，中栏命令详情卡片（含参数规格），右栏执行面板（含参数输入和结果展示）。用于向设备下发 MML 命令进行配置查询和修改。

## 布局模板

使用 command-console-page 布局（三栏布局）。

## 导航路径

MML 管理 > 命令控制台

## 路由

`/mml/console`

## 左栏: 设备选择器 + 命令树

### 设备选择器

```
┌──────────────────────┐
│ 🔍 搜索设备名称或SN... │
│ ──────────────────── │
│ ┌──────────────────┐ │
│ │ 设备名称 │ SN    │ │
│ │──────── ┼──────│ │
│ │ eNB-001 │SN001 │ │ ← 选中行高亮
│ │ eNB-002 │SN002 │ │
│ │ gNB-001 │SN003 │ │
│ │ ...     │      │ │
│ └──────────────────┘ │
│ 共 128 台在线设备      │
└──────────────────────┘
```

| 属性         | 值                              |
|-------------|--------------------------------|
| 搜索方式     | 按设备名称或 SN 即时筛选         |
| 列表内容     | 仅显示在线设备                   |
| 选择模式     | 单选                            |
| 选中样式     | 背景色 #E6F7FF, 左侧蓝色边框    |
| 表格高度     | 200px (内部滚动)                |
| 跟随全局类型  | 只显示当前设备类型的设备          |

### MML 命令树

```
┌──────────────────────┐
│ 🔍 搜索命令码或名称... │
│ ──────────────────── │
│ ▼ eNB Configuration  │
│   LST CELLPARA       │ ← 选中高亮
│   MOD CELLPARA       │
│   ADD CELLPARA       │
│   DEL CELLPARA       │
│   LST ENODEB         │
│   MOD ENODEB         │
│ ▶ Radio Configuration│
│ ▶ Customized         │
│ ──────────────────── │
│ [+ 添加自定义命令]     │
│ [- 删除自定义命令]     │
└──────────────────────┘
```

| 属性          | 值                                       |
|--------------|-----------------------------------------|
| 树节点类别    | eNB Configuration / Radio Configuration / Customized |
| 叶节点格式    | 命令码 + 命令名称 (如 "LST CELLPARA")     |
| 搜索          | 按命令码或名称即时过滤                     |
| 选中行为      | 选中命令后, 中栏展示该命令详情              |
| 自定义命令     | 在 Customized 分类下, 支持添加/删除        |
| 树区域高度     | flex: 1 (填充剩余空间)                    |

详见 `03-command-tree.md`。

## 右栏: 执行面板

详见 `04-execution-panel.md`。

### Tab 切换

| Tab             | 说明                      |
|----------------|--------------------------|
| Control Panel  | 快捷操作面板 (常用操作按钮) |
| Parameter Command | 参数化命令执行           |

### 操作类型选择

| 操作类型 | 英文标识 | 说明                |
|---------|---------|---------------------|
| 查询     | LST     | 查询当前配置参数值    |
| 修改     | MOD     | 修改配置参数         |
| 添加     | ADD     | 添加新的配置条目      |
| 删除     | DEL     | 删除配置条目         |

### 参数路径输入

```
┌────────────────────────────────────┐
│ CellId:  [0_______]   [+] [-]     │
│ SubId:   [0_______]   [+] [-]     │
│ Freq:    [2600____]   [+] [-]     │
│ Power:   [43______]   [+] [-]     │
│                                    │
│ [+ 添加参数行]                      │
└────────────────────────────────────┘
```

| 元素           | 说明                          |
|---------------|-------------------------------|
| 参数标签       | 取自命令参数定义的参数名        |
| 输入框         | 根据参数类型渲染不同输入组件     |
| [+] 按钮       | 添加该参数的额外值行           |
| [-] 按钮       | 移除该参数值行                 |
| 添加参数行按钮  | 添加新的可选参数               |

### 执行按钮

| 按钮     | 类型     | 说明                              |
|---------|---------|-----------------------------------|
| DO 执行  | Primary | 向选中设备下发 MML 命令             |
| Save 保存 | Default | 保存当前参数配置为模板             |

| 属性           | 值                              |

## 三栏布局规格

| 栏位   | 宽度       | 背景色    | 边框                    |
|-------|-----------|----------|------------------------|
| 左栏   | 260px (固定) | #FAFAFA | 右侧 1px solid #E8E8E8 |
| 中栏   | flex: 1    | #FFFFFF  | 右侧 1px solid #E8E8E8 |

## 数据接口

```typescript
// 获取命令列表
GET /api/mml/commands?productType={type}

// 获取命令详情 (参数定义)
GET /api/mml/commands/{commandCode}/detail

// 执行 MML 命令
POST /api/mml/execute
{
  deviceSn: string;
  commandCode: string;
  operationType: 'LST' | 'MOD' | 'ADD' | 'DEL';
  parameters: Record<string, string | number>;
}

interface MMLExecuteResult {
  retcode: number;
  message: string;
  executeTime: string;
  duration: number;       // ms
  columns?: string[];     // 结果表格列名
  rows?: any[][];         // 结果表格数据
  rawText?: string;       // 原始文本结果
}
```

## 状态处理

| 状态              | 处理方式                                |
|------------------|-----------------------------------------|
| 未选择设备        | 右栏提示 "请先选择设备"                   |
| 未选择命令        | 中栏显示 "请从左侧命令树选择命令"          |
| 命令详情加载中     | 中栏 Skeleton 骨架                      |
| 命令执行中        | DO 按钮 Loading + 结果区显示 "执行中..."  |
| 执行成功          | 结果区绿色 "成功" + 数据展示              |
| 执行失败          | 结果区红色错误信息                        |
| 设备离线          | 设备列表项灰色 + 不可选择 + Tooltip       |
| 参数校验失败      | 输入框红色边框 + 错误提示                  |

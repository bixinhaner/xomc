# 操作日志查询 Operation Log Query

> 模块路径：`/log/query` Tab 3
> 布局模板：同日志查询页通用结构
> 数据来源：广研院 日志查询页 — 操作日志 Tab

---

## 1. 页面概述

操作日志记录所有用户在网管系统中的操作行为，是系统审计的核心数据。支持多维度筛选，可展开查看完整的请求/响应 JSON 消息内容。共享日志查询页的 4-Tab 结构。

---

## 2. 筛选栏

```
┌─────────────────────────────────────────────────────┐
│ 操作人 [________] 功能菜单 [▼ 全部] 操作类型 [▼ 全部]│
│ 操作对象 [________] 操作内容 [________]               │
│ 执行结果 [▼ 全部]                                    │
│ [展开更多 ▼]                                         │
│                            [重置] [查询] [导出]       │
└─────────────────────────────────────────────────────┘
```

### 基本筛选项

| 筛选项 | 组件 | 说明 |
|--------|------|------|
| 操作人 | Input | 用户名模糊搜索 |
| 功能菜单 | Select | 一级模块（设备管理/告警管理/配置管理 等） |
| 操作类型 | Select | 登录/登出/新增/修改/删除/查询/导入/导出/执行 |
| 操作对象 | Input | 设备 SN、用户名、规则名等 |
| 操作内容 | Input | 关键词搜索 |
| 执行结果 | Select | 全部/成功/失败 |

### 展开更多

| 筛选项 | 组件 |
|--------|------|
| 客户端 IP | Input |
| 请求方法 | Select（GET/POST/PUT/DELETE） |

## 3. 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 操作时间 | `operationTime` | 170px | `YYYY-MM-DD HH:mm:ss`，默认降序 |
| 操作人 | `operator` | 100px | |
| 客户端 IP | `clientIp` | 130px | 等宽字体 |
| 操作对象 | `target` | 140px | 超长截断 |
| 功能菜单 | `module` | 120px | |
| 操作类型 | `operationType` | 100px | Tag + 颜色 |
| 操作内容 | `content` | 280px | 超长截断 + Tooltip |
| 执行结果 | `result` | 80px | 成功(绿)/失败(红) |
| 消息内容 | — | 80px | 蓝色 [查看] 链接 |

## 4. 消息内容弹窗

> 点击 [查看] 打开模态对话框
> 宽度 720px

```
┌─────────────────────────────────────────┐
│ 消息内容                                  │
├─────────────────────────────────────────┤
│                                         │
│ ┌─ 请求/响应内容 ─────────────────────┐ │
│ │ {                                   │ │
│ │   "action": "modifyParameter",     │ │
│ │   "deviceSn": "SN-12345678",       │ │
│ │   "parameters": {                  │ │
│ │     "txPower": {                   │ │
│ │       "old": 20,                   │ │
│ │       "new": 23                    │ │
│ │     },                             │ │
│ │     "bandwidth": {                 │ │
│ │       "old": "10MHz",             │ │
│ │       "new": "20MHz"              │ │
│ │     }                              │ │
│ │   },                               │ │
│ │   "result": {                      │ │
│ │     "code": 200,                   │ │
│ │     "message": "success"          │ │
│ │   }                                │ │
│ │ }                                   │ │
│ └─────────────────────────────────────┘ │
│                                         │
│              [复制]    [关闭]            │
└─────────────────────────────────────────┘
```

### 弹窗规格

| 属性 | 值 |
|------|-----|
| 宽度 | 720px |
| 内容区最大高度 | 500px（超出滚动） |
| 渲染方式 | JSON 树形缩进格式化 |
| 语法高亮 | key 蓝色、string 绿色、number 橙色、boolean 紫色 |
| 字体 | 等宽字体 `SFMono-Regular` / `Consolas` 13px |
| 行号 | 左侧显示行号 |
| 复制 | 复制完整 JSON 文本到剪贴板 |
| 折叠 | 支持 JSON 节点折叠/展开 |

## 5. 日志统计视图

> 对应日志统计页 `/log/statistics` Tab 3

### 5.1 筛选

| 筛选项 | 组件 |
|--------|------|
| 统计粒度 | Toggle：按小时 / 按天 |
| 操作类型 | Select |

### 5.2 图表

**图表 1 — 操作次数趋势**

| 属性 | 值 |
|------|-----|
| 类型 | 多系列折线图 |
| X 轴 | 时间（小时/天） |
| Y 轴 | 操作次数 |
| 系列 | 按操作类型分组，图例可切换 |
| 分页 | 图例超过 5 个时分页显示（1/5 翻页） |

**图表 2 — 操作类型分布**

| 属性 | 值 |
|------|-----|
| 类型 | 饼图/环形图 |
| 数据 | 按操作类型统计占比 |
| 颜色 | 使用标准图表调色板 |
| 交互 | 点击扇区筛选列表 |

## 6. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看操作日志 | `log:operation:view` |
| 查看消息详情 | `log:operation:detail` |
| 导出 | `log:operation:export` |
| 查看统计 | `log:operation:statistics` |

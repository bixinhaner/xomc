# 网元消息日志 NE Message Log

> 模块路径：`/log/query` Tab 1
> 布局模板：Tab 切换列表页 + 时间快捷选择 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 日志查询页 — 网元消息日志 Tab

---

## 1. 页面概述

日志查询页面采用统一的 4-Tab 布局（网元消息日志、网元心跳日志、操作日志、系统日志），共享顶部时间快捷选择器。网元消息日志记录网管与设备之间的通信消息，包括指令下发和设备响应。

---

## 2. 日志查询页面通用结构

```
┌─────────────────────────────────────────────────────┐
│ 面包屑：日志管理 / 日志查询                             │
├─────────────────────────────────────────────────────┤
│ 时间快捷选择：[今天] [近7天] [近30天] [自定义]          │
│ 自定义：[2024-01-01] ~ [2024-01-15]                  │
├─────────────────────────────────────────────────────┤
│ Tab：[网元消息日志] [网元心跳日志] [操作日志] [系统日志] │
├─────────────────────────────────────────────────────┤
│ (筛选栏 — 各 Tab 不同)                                │
│                            [重置] [查询] [导出]       │
├─────────────────────────────────────────────────────┤
│ (表格 — 各 Tab 不同)                                  │
│                                                     │
│ 加载更多…                                            │
└─────────────────────────────────────────────────────┘
```

### 时间快捷选择器

| 按钮 | 时间范围 |
|------|---------|
| 今天 | 当天 00:00 至当前时间 |
| 近 7 天 | 7 天前 00:00 至当前 |
| 近 30 天 | 30 天前 00:00 至当前 |
| 自定义 | DateRangePicker，展开后可精确选择 |

### 分页方式

采用 **"加载更多"** 模式（非传统分页），每次加载 50 条，滚动到底部点击加载更多。

## 3. 网元消息日志 — 筛选栏

| 筛选项 | 组件 | 必填 | 说明 |
|--------|------|------|------|
| 选择设备 | Device Selector 按钮 | ✅ | **必填**，点击弹出设备选择器 |
| 设备搜索 | Input | — | 快捷搜索已选设备 |
| 消息类型 | Select | — | 全部/指令下发/设备响应/心跳/告警上报 |
| 日志内容 | Input | — | 关键词搜索 |

### 设备未选择状态

未选择设备时，表格区域显示空状态占位：

```
┌─────────────────────────────────────┐
│                                     │
│       📋 请先选择设备                │
│       选择一台设备以查看其消息日志     │
│                                     │
│       [选择设备]                     │
│                                     │
└─────────────────────────────────────┘
```

## 4. 网元消息日志 — 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 事件时间 | `eventTime` | 180px | `YYYY-MM-DD HH:mm:ss.SSS` 毫秒级 |
| 消息类型 | `messageType` | 120px | Tag 组件，不同类型不同颜色 |
| 设备序列号 | `deviceSn` | 160px | 等宽字体 |
| 设备名称 | `deviceName` | 140px | |
| 请求 IP | `requestIp` | 140px | 等宽字体 |
| 请求内容 | `requestContent` | 300px | 截断 + [展开] 链接 |
| 响应内容 | `responseContent` | 300px | 截断 + [展开] 链接 |

### 消息类型颜色

| 类型 | Tag 颜色 |
|------|---------|
| 指令下发 | `blue` |
| 设备响应 | `green` |
| 心跳 | `default` (灰) |
| 告警上报 | `red` |
| 配置变更 | `orange` |

### 内容展开

点击 [展开] 展开该行为全宽内容显示区，以 JSON 树格式渲染请求/响应内容（同操作日志的消息详情弹窗样式）。

---

## 5. 导出

- [导出] 按钮导出当前筛选结果
- 格式：Excel (.xlsx)
- 大数据量异步导出，通过任务面板跟踪

---

## 6. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看网元消息日志 | `log:ne-message:view` |
| 导出 | `log:ne-message:export` |

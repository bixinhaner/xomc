# MR 文件管理 (MR File Management)

## 页面用途

管理设备的 MR 数据采集配置和 MR 文件。分为两个子标签页: MR 参数配置（配置设备的 MR 开关、测量类型、采集参数等）和 MR 文件（浏览已采集的 MR 文件列表）。与性能文件管理结构类似，但增加了 MR 特有的测量类型、采样周期、PRB 和子帧数等配置。

## 布局模板

**Tab + List Page Layout（标签页 + 列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 文件
```

## 路由

```
/mr/files/config     （MR 参数配置 Tab）
/mr/files/list       （MR 文件 Tab）
```

## 弹窗规格

### MR 参数配置弹窗

| 属性 | 值 |
|------|-----|
| 弹窗标题 | MR 参数配置 |
| 尺寸 | 680px x auto |

**设备SN号:** 只读显示

**采集配置区:**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| 实例选择 | Select | 是(*) | OID 实例路径 |
| MR开关 | Toggle Switch | 是(*) | 开/关 |
| 测量类型 | CheckboxGroup | 是(*) | MRO/MRE/MRS (可多选) |
| 采集周期 | NumberInput + 单位(min) | 是(*) | 如 3600 |
| 采样周期 | Select (ms) | 是(*) | 如 5120 |
| 采样时间范围 | TimeRangePicker | 是(*) | 开始至结束 |
| PRB | TextInput (0/256, 带提示) | 否 | PRB 配置 |
| 子帧数 | TextInput (0/256, 带提示) | 否 | 子帧数配置 |

**文件管理区:**

| 字段名称 | 组件类型 | 必填 | 说明 |
|---------|---------|------|------|
| URL | TextInput (0/256) | 是(*) | MR 文件上报地址 |
| 用户名 | PasswordInput | 是(*) | 认证用户名 |
| 密码 | PasswordInput | 是(*) | 认证密码 |

| 按钮 | 类型 | 行为 |
|------|------|------|
| 设为默认值 | Link | 将当前配置设为默认 |
| Cancel | Default | 关闭 |
| Confirm | Primary | 保存配置 |

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| MR开关切换 | 行内操作，同步中显示加载状态 |
| 批量下载 | 打包为 ZIP 文件下载 |
| 测量类型多选 | CheckboxGroup 支持多选(MRO+MRE+MRS) |

# MR 变量管理 (MR Variables Management)

## 页面用途

管理 MR 报表计算中使用的变量定义，包括变量名称、说明、类型和取值范围。变量用于 MR 指标的参数化计算和报表生成。

## 布局模板

**List Page Layout（列表页布局）**

## 导航路径

```
OMC 统一网管 > MR 管理 > MR 指标 > 变量
```

## 路由

```
/mr/indicators/variables
```

## 筛选栏配置

| 字段名称 | 组件类型 | 默认值 | 说明 |
|---------|---------|-------|------|
| 变量名称 | TextInput | 空 | 按变量名称搜索 |
| 变量说明 | TextInput | 空 | 按变量说明搜索 |

## 数据表规格

| 列名 | 字段 Key | 宽度 | 渲染规则 |
|------|----------|------|---------|
| 变量名称 | variableName | 120px | 文本 |
| 变量说明 | description | flex | 文本 |
| 变量类型 | variableType | 80px | 整型/字符串 |
| 变量取值 | variableValues | 100px | 范围表示 |
| 操作 | _actions | 120px | [编辑] [删除] |

## 工具栏操作

| 按钮名称 | 类型 | 行为 |
|---------|------|------|
| 新增 | Primary | 打开新增弹窗 |

## 弹窗规格

### 新增变量弹窗

| 字段名称 | 组件类型 | 必填 | 字符限制 | 说明 |
|---------|---------|------|---------|------|
| 变量名称 | TextInput | 是(*) | 0/64 | 变量标识名 |
| 变量说明 | TextInput | 是(*) | 0/64 | 变量描述 |
| 变量类型 | Select | 是(*) | -- | 整型/字符串 |
| 变量取值 | TextInput (带提示) | 否 | 0/64 | 取值范围 |

### 编辑变量弹窗

与新增弹窗相同，但 **变量名称** 为灰色不可编辑状态。

## 状态处理

| 状态 | 处理方式 |
|------|---------|
| 空数据 | "暂无变量定义" |
| 变量名称不可改 | 编辑时灰色 disabled |

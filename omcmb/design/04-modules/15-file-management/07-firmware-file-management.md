# 设备配置与日志文件管理 Device Config & Log File Management

> 模块路径：`/file-mgmt/device-files`
> 布局模板：Tab 切换列表页 — 参考 `03-layouts/02-list-page.md`
> 数据来源：广研院 设备配置文件（三 Tab）+ 设备日志文件（双 Tab）

---

## 1. 页面概述

广研院侧的设备文件管理，管理设备自动上传和用户手动上传的配置文件，以及网管下发的配置记录。同时管理设备日志文件的周期上传配置和日志文件查看。采用两大分区 + 多 Tab 布局。

---

## 8. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看设备文件 | `file:device-files:view` |
| 上传配置文件 | `file:device-files:upload` |
| 下发配置 | `file:device-files:distribute` |
| 配置日志上传参数 | `file:device-log:config` |
| 下载日志文件 | `file:device-log:download` |

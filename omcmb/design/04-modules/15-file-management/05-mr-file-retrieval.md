# MR 文件获取 MR File Retrieval

> 模块路径：`/file-mgmt/mr-retrieval`
> 布局模板：树-列表 + 上下分屏（同获取配置文件）
> 数据来源：基于 Comba UMS 文件管理模式扩展

---

## 1. 页面概述

从网元设备获取 MR（Measurement Report，测量报告）原始数据文件。MR 文件包含终端上报的无线环境测量数据，是 MR 管理模块分析的数据源。页面布局复用文件管理通用模板。

---

## 2. 与通用布局的差异

### 2.1 工具栏

| 按钮 | 说明 |
|------|------|
| 移除 / 清空 / 导入网元 | 标准按钮 |
| **获取 MR 文件** | Primary 按钮 |

### 2.2 获取 MR 文件对话框

```
┌─────────────────────────────────────┐
│ 获取 MR 文件                         │
├─────────────────────────────────────┤
│                                     │
│ 目标网元：已选择 15 台                 │
│                                     │
│ MR 类型   ☑ MRO (周期测量)            │
│           ☑ MRE (事件测量)            │
│           ☐ MRS (信令测量)            │
│                                     │
│ 时间范围  [2024-01-14] ~ [2024-01-15]│
│                                     │
│          [取消]    [开始获取]          │
└─────────────────────────────────────┘
```

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| MR 类型 | Checkbox Group | ✅ | MRO/MRE/MRS |
| 时间范围 | DateRangePicker | ✅ | 最大跨度 3 天（MR 文件量大） |

---

## 4. 注意事项

- MR 文件数据量通常很大，单文件可达数十 MB
- 建议配合任务面板异步获取
- 获取时间范围限制为 3 天，避免一次获取过多数据
- 获取完成后的文件会自动关联到 MR 管理模块

## 5. 权限控制

| 操作 | 所需权限 |
|------|---------|

| 获取 MR 文件 | `file:mr-retrieval:retrieve` |
| 下载文件 | `file:mr-retrieval:download` |

# 下发脚本/配置文件 Configuration File Distribution

> 模块路径：`/file-mgmt/config-distribution`
> 布局模板：树-列表 + 上下分屏（同获取配置文件）+ 列表页（批量计划）
> 数据来源：Comba UMS 下发脚本文件 + 批量文件下发计划

---

## 1. 页面概述

将配置文件或脚本文件下发（推送）到网元设备。包含两个子页面：即时下发（手动选择网元并立即下发）和批量下发计划（定时/周期自动下发）。

---

## 2. 即时下发页面

布局与获取配置文件页面一致（左树 + 右上网元列表 + 右下结果 + 底部任务面板），差异如下：

### 2.1 工具栏

| 按钮 | 说明 |
|------|------|
| 移除 | 移除选中网元 |
| 清空 | 清空列表 |
| 导入网元 | 导入对话框 |
| **下发文件** | Primary，对选中网元下发文件 |
| 下载模板 ▼ | 下拉菜单：脚本模板/配置模板 |

### 2.2 下发文件对话框

> 模态对话框，宽度 560px

```
┌─────────────────────────────────────┐
│ 下发文件                              │
├─────────────────────────────────────┤

│                                     │

│           或从文件库选择：[打开文件库]  │
│                                     │
│ 执行方式  ○ 立即执行                   │
│           ● 下发后手动执行              │
│                                     │

│          [取消]    [确认下发]          │
```

### 2.3 操作结果表格（差异列）

| 列名 | 字段 | 说明 |
|------|------|------|
| 命令触发类型 | `triggerType` | 手动/自动/计划 |
| 操作人 | `operator` | 执行下发的用户 |
| 下发状态 | `status` | 成功/失败/进行中 |

## 3. 批量文件下发计划

> 路径：`/file-mgmt/distribution-plan`

独立列表页，管理定时/周期下发计划。

### 3.1 表格列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 计划ID | `planId` | 80px | |
| 计划名称 | `planName` | 200px | |
| 任务类型 | `taskType` | 120px | 脚本下发/配置下发 |
| 调度状态 | `scheduleStatus` | 120px | 未启动/运行中/已暂停/已停止 |
| 下次执行 | `nextExecution` | 160px | |
| 调度类型 | `scheduleType` | 120px | 一次/每天/每周/每月 |
| 执行间隔 | `interval` | 120px | |
| 开始时间 | `startTime` | 160px | |
| 结束时间 | `endTime` | 160px | |

### 3.2 工具栏

[新建] [编辑] [查看] [删除] [启动] [执行一次] [暂停] [刷新]

### 3.3 新建/编辑计划对话框

> 模态对话框，宽度 640px

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 计划名称 | Input | ✅ | |
| 任务类型 | Select | ✅ | 脚本下发/配置下发 |
| 下发文件 | Upload / 文件库选择 | ✅ | |
| 调度类型 | Radio | ✅ | 一次/每天/每周/每月 |
| 调度配置 | Schedule Picker | ✅ | 根据调度类型动态展示 |
| 目标网元 | 网元选择器 | ✅ | |
| 执行方式 | Radio | ✅ | 立即执行/下发后手动 |

# 性能文件获取 Performance File Retrieval

> 模块路径：`/file-mgmt/perf-retrieval`
> 布局模板：树-列表 + 上下分屏（同获取配置文件）
> 数据来源：基于 Comba UMS 文件管理模式扩展

---

## 1. 页面概述

从网元设备获取性能统计数据文件（PM 文件）。页面布局复用文件管理通用模板（左树 + 右上网元列表 + 右下结果 + 底部任务面板）。性能文件通常为 XML/CSV 格式，包含 KPI 计数器原始数据。

---

## 2. 与通用布局的差异

### 2.1 工具栏

| 按钮 | 说明 |
|------|------|
| 移除 / 清空 / 导入网元 | 标准按钮 |
| **获取性能文件** | Primary 按钮 |
| 导出结果 | 导出操作结果表 |

### 2.2 获取性能文件对话框

```
┌─────────────────────────────────────┐
│ 获取性能文件                          │
├─────────────────────────────────────┤
│                                     │
│ 目标网元：已选择 25 台                 │
│                                     │
│ 统计类型  ☑ 15分钟粒度                 │
│           ☑ 1小时粒度                  │
│           ☐ 24小时粒度                 │
│                                     │
│ 时间范围  [2024-01-14] ~ [2024-01-15]│
│                                     │
│ 文件格式  ○ XML  ● CSV               │
│                                     │
│          [取消]    [开始获取]          │
└─────────────────────────────────────┘
```

| 字段 | 组件 | 必填 | 说明 |
|------|------|------|------|
| 统计类型 | Checkbox Group | ✅ | 性能统计粒度 |
| 时间范围 | DateRangePicker | ✅ | 最大跨度 7 天 |
| 文件格式 | Radio | — | 默认 CSV |

## 3. 操作结果表格

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 网元名称 | `neName` | 140px | |
| 序列号 | `sn` | 160px | |
| 统计粒度 | `granularity` | 100px | 15min/1h/24h |
| 文件名 | `fileName` | 200px | |
| 文件大小 | `fileSize` | 100px | |
| 记录数 | `recordCount` | 80px | 文件中的数据记录条数 |
| 获取状态 | `status` | 100px | 成功/失败/进行中 |
| 获取时间 | `retrieveTime` | 160px | |
| 操作 | — | 100px | [下载] [预览] |

### 预览功能

点击 [预览] 在侧滑抽屉中展示文件前 100 行数据预览（表格格式），便于确认数据正确性。

## 4. 权限控制

| 操作 | 所需权限 |
|------|---------|
| 查看页面 | `file:perf-retrieval:view` |
| 获取性能文件 | `file:perf-retrieval:retrieve` |
| 下载文件 | `file:perf-retrieval:download` |

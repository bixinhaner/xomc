# Input 输入框

## 概述
文本输入组件，支持多种输入类型。

## 类型

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| Text | 单行文本 | 设备名称、SN 搜索 |
| Password | 密码输入（显示/隐藏切换） | FTP 密码、登录 |
| Number | 数字输入（+/- 按钮） | 端口号、超时时间 |
| Textarea | 多行文本 | MML 脚本、批量 SN 输入、备注 |

## 尺寸

| 尺寸 | 高度 | 字号 | 用途 |
|------|------|------|------|
| Small | 24px | 12px | 表格内联编辑 |
| Medium | 32px | 14px | **默认**，筛选栏、表单 |
| Large | 40px | 14px | 突出的搜索框 |

## 功能
- **前缀图标**: 搜索图标、用户图标等
- **后缀图标**: 清除按钮(×)、密码显示/隐藏(眼睛)
- **字符计数**: 显示已输入/最大字符数
- **可清除**: 输入内容后显示 × 清除按钮

## 状态
- Default: 边框 `neutral-300`
- Hover: 边框 `primary-600`
- Focus: 边框 `primary-600` + 蓝色外发光
- Error: 边框 `status-error` + 红色外发光
- Disabled: 背景 `neutral-100`，文字 `neutral-400`
- ReadOnly: 背景 `neutral-50`，无边框变化

## OMC 使用场景
- 筛选栏: 设备名称、SN、IP 地址搜索
- 表单: 设备注册信息、FTP 配置、任务名称
- MML: 参数路径输入（等宽字体）
- 批量输入: Textarea 模式，分号/空格/换行分隔

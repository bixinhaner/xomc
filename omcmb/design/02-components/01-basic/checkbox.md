# Checkbox 复选框

## 概述
允许用户从多个选项中选择零个或多个。

## 变体
- **单个复选框**: 独立的开/关选择
- **复选框组**: 一组互不排斥的选项
- **半选状态 (Indeterminate)**: 子项部分选中时的父级状态

## 状态
| 状态 | 外观 |
|------|------|
| Unchecked | 白色方框 + 灰色边框 |
| Checked | 蓝色填充 + 白色对勾 |
| Indeterminate | 蓝色填充 + 白色横线 |
| Disabled Unchecked | 灰色背景 + 灰色边框 |
| Disabled Checked | 浅蓝填充 + 灰色对勾 |

## OMC 使用场景
- **表格全选**: 表头的全选 Checkbox（含 Indeterminate 状态）
- **表格行选**: 每行前的选择 Checkbox
- **筛选面板**: 告警等级多选（紧急/主要/次要/警告）
- **列显示控制**: 选择要显示的表格列
- **树节点选择**: 拓扑树、设备分组树的节点多选

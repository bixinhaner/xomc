# Link 链接

## 概述
文字形式的导航或操作链接。

## 变体
| 变体 | 颜色 | 用途 |
|------|------|------|
| 默认链接 | `primary-600` | 表格行内操作、导航跳转 |
| 危险链接 | `status-error` | 删除操作 |
| 次要链接 | `neutral-500` | 低优先级操作 |

## 状态
- Default: 蓝色文字
- Hover: 下划线 + `primary-400`
- Active: `primary-700`
- Disabled: `neutral-400`

## OMC 使用场景
- 表格操作列: 编辑(蓝) / 同步(蓝) / 删除(红) / 查看(蓝)
- 筛选栏: "展开" / "收起" 链接
- 日志表格: "查看" 消息内容链接
- 面包屑: 路径中的可点击祖先节点

# Tabs 标签页

## 概述
在同一区域切换不同视图或内容。

## 变体

| 变体 | 说明 | 使用场景 |
|------|------|---------|
| 线条式 | 底部边框指示选中 | 页面内内容切换 |
| 卡片式 | 带边框的卡片标签 | 独立区域切换 |
| 可关闭式 | 带 × 关闭按钮 | 多标签工作空间 |

## 多标签工作空间（二级栏）
```
┌─[Dashboard ×]─[当前告警 ×]─[设备列表 ×]─ ... ─[+]──┐
```
- 最多 10 个标签
- 超出时最右显示 "更多▾" 下拉
- 右键菜单: 关闭 / 关闭其他 / 关闭所有
- 选中标签: 底部 `primary-600` 指示线

## OMC 使用场景
- 工作空间: 顶部多页签切换
- 性能报表: 表格 / 统计图 / KPI 说明 Tab
- 设备详情: 基本信息 / 告警 / 性能 / 拓扑 Tab
- 文件管理: 设备上传 / 用户上传 / 网管下发 Tab
- License: Basic License / 1688License Tab

# Header 顶栏

## 概述
全局固定顶栏，提供品牌标识、告警状态和用户操作。

## 结构 (48px 高度)
```
┌────────────────────────────────────────────────────────────┐
│ [Logo] OMC 统一网管    [紧急:12][主要:45][次要:89][警告:234] │
│                        [🔔] [UTC▾] [Welcome, admin ▾]      │
└────────────────────────────────────────────────────────────┘
```

## 左侧
- Logo 图标 (24×24px) + 系统名称 (`font-md`, `font-semibold`, white)

## 右侧
| 元素 | 说明 |
|------|------|
| 告警等级徽标 | 4 个彩色徽标，显示各等级实时计数，点击跳转告警列表 |
| 通知铃铛 | 铃铛图标 + 未读计数红点 |
| 时区选择器 | 下拉: UTC / 本地时区，显示当前时间 |
| 用户菜单 | 用户名 + 下拉箭头 → 修改密码 / 切换语言 / 退出登录 |

## 样式
- 背景: `#001529` (与侧边栏同色) 或 `#FFFFFF` (亮色变体)
- 高度: 48px
- z-index: 100
- 阴影: `shadow-sm` (底边)

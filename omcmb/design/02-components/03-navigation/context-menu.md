# ContextMenu 右键菜单

## 概述
右键点击触发的上下文操作菜单。

## 结构
与 MenuDropdown 结构一致: 图标 + 文字 + 分隔线。

## 触发位置
| 位置 | 菜单项 |
|------|--------|
| 表格行 | 查看详情 / 编辑 / 删除 / 复制 SN |
| 树节点 | 添加子节点 / 重命名 / 删除 |
| 拓扑节点 | 查看详情 / 告警信息 / 配置 |
| MML 任务 | 启动 / 终止 / 删除 |

## 样式
- 背景: `#FFFFFF`
- 阴影: `shadow-md`
- 圆角: `radius-sm`
- 出现位置: 鼠标右键点击处
- 自动避免溢出屏幕边缘

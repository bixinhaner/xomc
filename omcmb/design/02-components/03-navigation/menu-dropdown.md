# MenuDropdown 下拉菜单

## 概述
点击触发的多级下拉操作菜单。

## 结构
```
┌──────────────────┐
│ 🔄 同步配置       │
│ 📤 导出数据       │
├──────────────────┤
│ ✎ 编辑           │
│ 🗑 删除     (红色) │
└──────────────────┘
```

## 菜单项
- 图标(可选) + 文字 + 快捷键(可选)
- 分隔线区分功能组
- 危险操作文字使用 `status-error` 红色
- 禁用项灰色 + 不可点击

## OMC 使用场景
- 工具栏 "批量操作" 下拉
- 工具栏 "导出" 下拉 (Excel / CSV)
- 表格行 "更多" 按钮下拉
- 用户菜单下拉

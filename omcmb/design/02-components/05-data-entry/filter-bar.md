# FilterBar 筛选栏

## 概述
列表页顶部的多条件筛选组件，支持展开/收起。

## 结构
```
收起状态（1行）:
┌──────────────────────────────────────────────────────┐
│ [设备名称: ___] [SN: ___] [状态: 全部▾] [展开] [搜索][重置]│
└──────────────────────────────────────────────────────┘

展开状态（2-3行）:
┌──────────────────────────────────────────────────────┐
│ [设备名称: ___] [SN: ___] [状态: 全部▾] [产品类别:▾]     │
│ [厂商: ▾] [设备型号: ▾] [网络制式: ▾] [区域: ▾]         │
│ [创建时间: 从___至___]                    [收起][搜索][重置]│
└──────────────────────────────────────────────────────┘
```

## 筛选控件类型
| 类型 | 控件 | 示例 |
|------|------|------|
| 文本搜索 | Input | 设备名称、SN |
| 下拉选择 | Select | 产品类别、厂商、状态 |
| 日期范围 | DateRangePicker | 创建时间、告警时间 |
| 树选择 | TreeSelect | 区域（省市区）|
| 级联选择 | Cascader | 设备分类层级 |

## 行为
- 默认显示 1 行（4-7 个最常用筛选项）
- "展开/收起" 链接切换显示完整筛选项
- "搜索" 按钮触发查询（Primary 按钮）
- "重置" 按钮清空所有筛选条件
- 筛选状态会话级持久化
- URL 参数同步（可分享筛选状态）

## OMC 使用场景
几乎所有列表页的顶部，是使用频率最高的组件之一。

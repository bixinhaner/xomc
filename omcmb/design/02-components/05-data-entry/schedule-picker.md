# SchedulePicker 调度选择器

## 概述
配置定时任务的执行周期（按天/周/月）。

## 结构

### 按天执行
```
周期: [天 ▾]
时间: [16:00:00]
```

### 按周执行
```
周期: [周 ▾]
星期: [一 ✓] [二 ✓] [三 ✓] [四] [五] [六] [日]
时间: [16:00:00]
```
多选星期几（日历格子样式）。

### 按月执行
```
周期: [月 ▾]
月份: [1 ✓] [2] [3 ✓] [4] ... [12 ✓]
日期: [1 ✓] [2] [3] [4 ✓] [5 ✓] ... [31]
时间: [16:00:00]
```
多选月份 + 多选日期（日历格子样式）。

## OMC 使用场景
- 备份任务: 创建周期备份（按天/周/月）
- 升级计划: 定时升级
- MR 任务: 定期采集
- 配置同步: 定时同步任务

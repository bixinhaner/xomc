# AlarmFilterDialog 告警高级筛选对话框

## 概述
OMC 系统中最复杂的弹窗组件，5 个标签页的告警高级筛选。

## 结构 (Extra Large: 1000px)
```
┌─ 高级筛选 ──────────────────────────── [×] ─┐
│ [告警网元] [告警码] [告警信息] [告警确认] [告警清除]│
├──────────────────────────────────────────────┤
│                                               │
│ (当前 Tab 内容)                                │
│                                               │
├──────────────────────────────────────────────┤
│ [另存模板]  [重置]           [取消]    [确认]  │
└──────────────────────────────────────────────┘
```

## Tab 1: 告警网元
内嵌 DeviceSelector 组件（3 种选择模式）。

## Tab 2: 告警码
- 告警码表格（2690+ 行）
- 搜索框过滤
- Checkbox 多选
- 列: 告警码、告警名称、告警等级

## Tab 3: 告警信息
- 告警方式: Radio 选择
- 时间范围: DateRangePicker
- 告警等级: Checkbox 多选（紧急/主要/次要/警告）

## Tab 4: 告警确认
- 确认状态筛选
- 确认方式筛选
- 确认时间范围

## Tab 5: 告警清除（仅历史告警）
- 清除方式筛选
- 清除用户筛选
- 清除时间范围

## 底部操作
- **另存模板**: 将当前筛选条件保存为模板
- **重置**: 清空所有标签页的筛选条件
- **取消**: 关闭不应用
- **确认**: 应用筛选条件

## OMC 使用场景
- 当前告警列表: "高级筛选" 按钮触发
- 历史告警列表: "高级筛选" 按钮触发（显示第 5 个 Tab）

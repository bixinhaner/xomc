# NESelector 网元选择器

## 概述
简化版网元选择器，仅提供搜索 + 表格选择模式。

## 结构
```
┌─ 选择网元 ─────────────────────┐
│ [搜索网元名称/SN...]            │
│ ┌──┬────────┬────────┬──────┐ │
│ │☐ │ 网元名称│ 设备SN  │ 状态 │ │
│ │☐ │ BU-001 │ SN12345│ ● 在线│ │
│ │☑ │ BU-002 │ SN12346│ ● 在线│ │
│ └──┴────────┴────────┴──────┘ │
│ 已选: 1                        │
│              [取消]    [确认]   │
└────────────────────────────────┘
```

## 与 DeviceSelector 的区别
- 仅单一表格选择模式（无分类/模板）
- 更简洁，用于简单场景
- 弹窗 Medium 尺寸（640px）

## OMC 使用场景
- 配置管理命令模式: 选择单个网元
- 日志查询: 选择设备
- 性能报表: 选择查看的网元

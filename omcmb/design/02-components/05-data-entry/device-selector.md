# DeviceSelector 设备选择器

## 概述
OMC 系统中最复杂的数据录入组件，提供三种模式选择设备/网元。

## 结构
```
┌─ 选择设备 ───────────────────────────────────┐
│ [按网元] [按分类] [按模板]   已选: 23 | 未选: 12496│
├──────────────────────────────────────────────┤
│                                               │
│ (当前模式的内容区域)                             │
│                                               │
├──────────────────────────────────────────────┤
│                    [取消]    [确认]            │
└──────────────────────────────────────────────┘
```

## 模式 1: 按网元 (By Element)
标准表格选择:
- 搜索框 + 数据表格 + Checkbox 多选
- 列: Id, 网元名称, 设备标识, 监控状态, 告警等级, 区域, 站点
- Tab 切换: 已选网元(23) / 未选网元(12496)
- 操作: 添加 / 全选 / 移除 / 清空

## 模式 2: 按分类 (By Classification)
8 维度树形筛选:
- 左侧维度选择: 按区域 / 按类型 / 按厂商 / 按子网 / 按站点 / 按分组 / 按制式 / 按工程状态
- 中间: 选中维度的树 + 搜索 + Checkbox
- 右侧: 匹配的网元列表 + 总数

## 模式 3: 按模板 (By Template)
预定义模板选择:
- 模板列表: 预设模板 / 用户模板 / 共享模板
- 选择模板后加载对应设备列表

## 公共功能
- 顶部已选/未选计数 Tab 带徽标
- 批量导入按钮（触发 BatchInput 组件）
- 确认后返回选中的设备 ID 列表

## OMC 使用场景
- 配置管理: 参数批量配置选择目标设备
- 性能管理: KPI 提取选择网元
- 软件版本: 升级计划选择目标设备
- 文件管理: 文件操作选择目标设备
- MR 管理: MR 任务选择网元
- 备份恢复: 备份任务选择设备

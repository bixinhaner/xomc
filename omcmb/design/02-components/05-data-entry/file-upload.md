# FileUpload 文件上传

## 概述
支持点击和拖拽上传文件。

## 变体

### 点击上传
```
[选择文件] 未选择文件
```
标准文件选择按钮。

### 拖拽上传
```
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
│  📤 点击或拖拽文件到此区域    │
│  支持 .xlsx, .csv 格式      │
│  [下载模板]                  │
└─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘
```
- 虚线边框，拖入时高亮
- 文件类型/大小限制说明
- 模板下载链接

## 上传后文件列表
```
📄 devices.xlsx  2.3MB  [✓ 100%]  [🗑]
📄 config.csv    456KB  [── 45%]  [×]
```

## OMC 使用场景
- 设备批量注册: CSV/Excel 上传 + 模板下载
- 软件版本: 固件文件上传
- 运维模板: 站点模板上传
- 配置管理: 参数批量导入
- MR 指标: 指标数据导入
- 文件管理: 用户文件上传

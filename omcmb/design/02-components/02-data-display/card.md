# Card 卡片

## 概述
信息分组容器，包含头部、内容和可选底部。

## 结构
```
┌─ 标题          [操作按钮] ─┐
├───────────────────────────┤
│ 内容区域                    │
│                            │
├───────────────────────────┤
│ 底部（可选）                │
└───────────────────────────┘
```

## 样式
- 背景: `#FFFFFF`
- 圆角: `radius-sm` (4px)
- 阴影: `shadow-sm`
- 内边距: `space-4` (16px)

## OMC 使用场景
- Dashboard: 图表容器卡片
- 表单: 可折叠的区段卡片
- 详情页: 信息分组卡片

# DescriptionList 描述列表

## 概述
以键值对形式展示详细信息。

## 布局
| 布局 | 说明 | 使用场景 |
|------|------|---------|
| 水平 | 标签在左，值在右 | 设备详情、告警详情基本信息区 |
| 垂直 | 标签在上，值在下 | 弹窗中的信息展示 |
| 行内 | 标签和值同行排列 | 紧凑的信息展示 |

## 列数
- 1 列: 弹窗/抽屉中
- 2 列: 标准宽度内容区
- 3 列: 宽屏详情页
- 4 列: 超宽内容区

## OMC 使用场景
- 设备详情: 设备名称、SN、型号、IP、状态等
- 告警详情: 告警码、等级、设备、时间、内容
- MML 命令详情: 产品类型、命令功能、注意事项
- 任务详情: 任务名称、类型、创建人、执行状态

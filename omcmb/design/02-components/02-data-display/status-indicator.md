# StatusIndicator 状态指示器

## 概述
以视觉元素表示实体的当前状态。

## 变体

### 圆点 + 文字
```
● 在线    ● 离线    ● 异常    ○ 未知
```
- 圆点直径: 8px
- 圆点与文字间距: `space-1` (4px)
- 颜色映射见 `01-colors.md` 状态色

### 彩色标签 (Tag)
```
[在线]  [离线]  [异常]
```
使用 Tag 组件的状态色变体。

### 左侧彩色边框（表格行）
```
┃ 紧急告警行内容...    (左边框 3px 红色)
┃ 主要告警行内容...    (左边框 3px 橙色)
```
用于告警表格行的等级着色。

## OMC 使用场景
- 设备列表: 连接状态（在线/离线）
- 告警列表: 告警等级（4 级色彩）
- 任务列表: 执行状态（等待/进行/暂停/完成/失败）
- 拓扑节点: 管理状态（锁定/关闭中/解锁）
- 小区管理: 阻断状态、管理状态、运行状态

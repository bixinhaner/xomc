# Pagination 分页

## 概述
数据表格的分页控制。

## 结构
```
共 1,234 条  [10条/页 ▾]  < 1 2 3 ... 124 >  跳至 [   ] 页  [⟳]
```

## 元素
| 元素 | 说明 | 可选 |
|------|------|------|
| 总条数 | "共 X 条" | 必选 |
| 每页条数 | 下拉选择 10/25/50/100 | 必选 |
| 页码导航 | 首页/上页/页码/下页/末页 | 必选 |
| 跳转输入 | "跳至 [ ] 页" | 可选 |
| 刷新按钮 | 刷新当前页 | 可选 |

## 页码显示规则
- 总页数 ≤ 7: 显示所有页码
- 总页数 > 7: 显示 1 ... 当前±1 ... 末页
- 当前页高亮 `primary-600` 背景

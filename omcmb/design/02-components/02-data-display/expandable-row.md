# ExpandableRow 展开行

## 概述
表格行点击展开后显示嵌套的详细信息。

## 交互
- 行首展开图标: ▶(收起) / ▼(展开)
- 点击图标或整行（可配置）触发展开
- 展开内容在当前行下方，跨越所有列
- 默认同时只展开一行

## 展开内容类型
| 类型 | 说明 | 使用场景 |
|------|------|---------|
| 描述列表 | 键值对详情 | 告警详情、设备详情 |
| 子表格 | 嵌套数据表格 | 网元子设备列表 |
| 自定义内容 | 图表/地图/表单 | 设备性能快照 |

## 样式
- 展开区域背景: `neutral-50`
- 左侧缩进与父行内容对齐
- 底部分割线与普通行一致

## OMC 使用场景
- 告警列表: 展开查看告警详细信息和处理建议
- 设备列表: 展开查看设备关键参数
- MML 脚本: 展开查看执行结果
- 升级任务: 展开查看关联设备列表

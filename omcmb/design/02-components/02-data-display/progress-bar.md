# ProgressBar 进度条

## 概述
显示操作完成百分比。

## 变体
| 变体 | 说明 | 使用场景 |
|------|------|---------|
| 线性 | 水平进度条 | 文件上传、任务进度 |
| 环形 | 圆环进度 | Dashboard 统计 |
| 步骤进度 | 分段进度 | 升级任务步骤 |

## 状态色
- 正常: `primary-600`
- 成功: `status-success`
- 异常: `status-error`
- 活跃: 条纹动画

## OMC 使用场景
- 文件上传/下载进度
- 软件升级进度
- 备份任务进度
- 导出任务进度
- MML 脚本执行进度

# Timeline 时间线

## 概述
垂直时间线，按时间顺序展示事件序列。

## 结构
```
● 2024-01-15 10:30  告警确认
│  操作员: admin，确认告警 #1234
│
● 2024-01-15 09:00  告警产生
│  设备 BU-001 产生紧急告警
│
○ 2024-01-14 18:00  设备注册
   设备首次注册入网
```

## 节点样式
- 已完成: 实心蓝色圆点 `primary-600`
- 当前/进行中: 蓝色圆点 + 动画脉冲
- 未来/待处理: 空心灰色圆点 `neutral-300`
- 错误: 红色圆点 `status-error`

## OMC 使用场景
- 告警详情: 告警处理历史（产生→确认→处理→清除）
- 设备详情: 设备生命周期事件
- 任务详情: 任务执行步骤

# DataTable 数据表格

**系统中最核心的组件**，约 60% 的页面以数据表格为主体。

## 概述
高功能数据表格，支持排序、筛选、分页、批量选择、行展开等企业级特性。融合三套系统的最佳实践。

## 列功能

### 列排序
- **三态循环**: 点击列头 → 升序(↑) → 降序(↓) → 无序(↕) → 升序...
- 同一时间只支持单列排序
- 排序图标在列名右侧

### 列筛选
- 列头右侧漏斗图标(🔽)，点击弹出筛选面板
- 文本列: 包含/不包含/等于/开头是/结尾是 + 输入框
- 数字列: 大于/小于/等于/范围 + 输入框
- 枚举列: 多选 Checkbox 列表
- 日期列: 日期范围选择器

### 列显示/隐藏
- 工具栏 "隐藏列" 下拉: Checkbox 列表，搜���框，保存
- 来源: 广研院系统的列控制模式

### 列宽调整
- 拖拽列头右边框调整宽度
- 双击列头右边框自适应内容宽度
- 最小列宽: 80px

## 行功能

### 行选择
- 左侧固定 Checkbox 列
- 表头全选 Checkbox（含 Indeterminate 半选状态）
- 支持 Shift+Click 范围选择
- 支持 Ctrl+Click 追加选择
- **跨���选择**: 翻页后保持之前选择

### 行展开
- 行首展开图标(▶/▼)
- 展开后显示嵌套内容区域（详情表格、描述列表等）
- 同时只展开一行（可配置为多行）

### 行状态着色
- **告警等级行**: 左侧 3px 彩色边框（紧急红/主要橙/次要黄/警告蓝）
- **选中行**: 背景 `primary-50`
- **悬浮行**: 背景 `neutral-100`
- **斑马纹**: 偶数行背景 `neutral-50`

### 行右键菜单
- 右键点击行弹出上下文菜单
- 菜单项: 查看详情 / 编辑 / 删除 / 复制 SN 等

### 行内编辑
- 双击单元格进入编辑模式
- 编辑完成后 Enter 确认 / Esc 取消
- 仅用于特定场景（日志配置存储天数等）

## 固定列
- 左侧固定: Checkbox 列
- 右侧固定: 操作列
- 中间区域水平滚动

## 分页
统一分页组件:

```
共 1,234 条  [10条/页 ▾]  < 1 2 3 ... 124 >  跳至 [   ] 页
```

- 总条数显示
- 每页条数选择: 10 / 25 / 50 / 100
- 页码导航: 首页 / 上一页 / 页码 / 下一页 / 末页
- 跳转输入框
- 可选: 刷新按钮

## 工具栏

左侧（选择相关）:
- 已选计数徽标: "已选 3 项"
- 批量操作下拉: 批量删除 / 批量导出 / 批量同步 等
- 操作完成后自动清除选择

右侧（表格控制）:
- 隐藏列下拉
- 刷新按钮
- 导出按钮/下拉（Excel / CSV）
- 密度切换（紧凑/默认/舒适）

## 加载状态
- **骨架屏**: 5 行骨架占位，灰色闪烁动画
- **覆盖加载**: 半透明遮罩 + 中央旋转图标

## 空状态
- 插图 + "暂无数据" 文字
- 如有筛选条件: "未找到匹配数据，请调整筛选条件"
- 操作引导按钮（如 "新建设备"）

## 表格尺寸

| 密度 | 行高 | 字号 | 单元格内边距 |
|------|------|------|------------|
| 紧凑 | 32px | 13px | 4px 8px |
| 默认 | 40px | 14px | 8px 16px |
| 舒适 | 48px | 14px | 12px 16px |

## OMC 使用场景
- 设备管理: 设备列表（15+ 列，批量操作）
- 告警管理: 当前告警（实时刷新，等级着色）
- 性能管理: KPI 报表（多 KPI 列）
- 配置管理: 参数列表、基线参数
- 所有列表页的主体

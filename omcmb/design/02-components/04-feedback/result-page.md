# ResultPage 结果页

## 概述
操作完成后的全页或区域结果反馈。

## 变体
| 变体 | 图标 | 颜色 | 用途 |
|------|------|------|------|
| Success | ✓ 大图标 | `status-success` | 操作成功 |
| Error | × 大图标 | `status-error` | 操作失败 |
| Info | ℹ 大图标 | `primary-600` | 信息提示 |

## 结构
```
        ✓
   操作成功

  已成功创建 3 个备份任务

  [返回列表]  [继续创建]
```

## OMC 使用场景
- 批量操作完成后的结果汇总
- 导入完成后的成功/失败统计

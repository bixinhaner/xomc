# Modal 弹窗

## 概述
覆盖层弹窗，用于需要用户关注的操作（表单、确认、详情查看）。

## 尺寸
| 尺寸 | 宽度 | 使用场景 |
|------|------|---------|
| Small | 480px | 简单确认、单字段输入 |
| Medium | 640px | 标准表单（5-10 个字段） |
| Large | 800px | 复杂表单、带选择器 |
| Extra Large | 1000px | 告警筛选对话框、设备选择器 |

## 结构
```
┌─ 标题                    [×] ─┐
├───────────────────────────────┤
│ 内容区域（可滚动）              │
│                               │
│                               │
├───────────────────────────────┤
│              [取消]    [确认]  │
└───────────────────────────────┘
```

## 关闭方式
- × 按钮（右上角）
- ESC 键
- 点击遮罩层（可配置禁用）
- 取消按钮

## 遮罩层
- 背景: `rgba(0,0,0,0.45)`
- 点击关闭（表单弹窗中建议禁用）

## OMC 使用场景
- 设备注册表单 (Medium)
- 告警高级筛选 (Extra Large)
- 备份任务创建 (Large)
- 版本上传 (Medium)
- 参数编辑 (Medium)
- 确认删除 (Small)

# AlertBanner 内联警告横幅

## 概述
页面内联的提示信息条。

## 类型
| 类型 | 背景 | 图标 | 用途 |
|------|------|------|------|
| Info | `#E6F7FF` | ℹ | 说明信息 |
| Success | `#F6FFED` | ✓ | 成功提示 |
| Warning | `#FFF7E6` | ⚠ | 注意事项 |
| Error | `#FFF1F0` | × | 错误/失败 |

## 结构
```
┌─ ℹ 提示信息内容 ─────────── [操作链接] [×] ─┐
└──────────────────────────────────────────────┘
```

## OMC 使用场景
- 日志配置页: 存储策略说明卡片
- 设备注册: 批量导入格式说明
- 连接断开: 顶部红色横幅 "网络连接已断开，正在重连..."

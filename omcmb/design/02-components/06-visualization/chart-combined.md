# CombinedChart 组合图

## 概述
柱状图 + 折线图双轴组合，左轴为计数，右轴为百分比。

## 结构
```
计数 │ ██                    ● ─ ─ ● │ 百分比
     │ ██ ██      ●─ ─ ●           │
     │ ██ ██ ██ ●                   │
     └──────────────────────────────┘
     图例: ■ 成功数  ■ 失败数  ● 成功率
```

## OMC 使用场景
- 报表管理: 轮询统计（成功数柱/失败数柱 + 成功率折线）
- 日志统计: 日志数量柱 + 趋势折线

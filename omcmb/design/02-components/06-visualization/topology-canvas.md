# TopologyCanvas 拓扑画布

## 概述
网络拓扑可视化画布，展示设备间连接关系。

## 节点类型
| 类型 | 图标 | 说明 |
|------|------|------|
| 设备集群(云) | 云形态 | 全连接/部分断连 2 种状态 |
| AMF/MME | 核心网图标 | 5G/4G 核心网元 |
| 基站 | 天线塔图标 | eNB/gNB |
| BU | 芯片图标 | 基带单元 |
| EU | 扩展图标 | 扩展单元 |
| RU | 射频图标 | 射频单元 |

## 连线类型
| 类型 | 样式 | 说明 |
|------|------|------|
| 已连接 | 实线 | 正常连接 |
| Xn 接口 | 蓝色虚线 | 5G 基站间接口 |
| X2 接口 | 绿色虚线 | 4G 基站间接口 |
| 断连 | 红色虚线 | 连接异常 |

## 节点状态着色
- 锁定(Locked): 绿色
- 关闭中(ShuttingDown): 橙色
- 解锁(Unlocked): 灰色

## 告警徽标
节点右上角红色圆形徽标，显示告警数量。

## 画布控制
| 操作 | 控件 |
|------|------|
| 缩放 | 滚轮 / +/- 按钮 |
| 平移 | 拖拽画布 |
| 适配屏幕 | "适配" 按钮 |
| 全屏 | 全屏按钮 |
| 撤销 | 撤销按钮 |
| 导出图片 | 下载按钮 |

## 辅助面板
- 统计面板: 设备数、小区数、服务状态分布
- 图例面板: 所有节点/连线类型的说明
- 搜索面板: 搜索并定位节点
- 设置面板: 告警等级显示开关、线型设置、图标定制

## 推荐实现
AntV G6 — 图可视化引擎，支持自定义节点/边/布局。

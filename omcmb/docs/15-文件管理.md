# 文件管理

## 概述
文件管理模块提供网元文件和用户文件的管理功能，包括配置文件获取/下发、日志文件获取、脚本文件下发、用户上传文件及设备固件文件管理。
- 涉及系统：jx / 广研院

---

## 五、系统对比

### 5.1 文件管理功能对比

| 特性 | Comba UMS (jx) | 广研院统一网管 |
|------|---------------|--------------|
| 配置文件获取 | 获取配置文件(从网元拉取) | 设备上传(设备自动上传) |
| 配置文件上传 | 用户上传文件(通用文件上传) | 用户上传(配置文件专用上传) |
| 配置文件下发 | 下发脚本文件 + 批量文件下发计划 | 网管下发(含下发状态/异常信息) |
| 日志文件获取 | 获取日志文件(从网元拉取) | 日志文件(设备周期/手动上传) |
| 日志周期配置 | 无独立配置(由网元侧配置) | 周期上传配置(开关/周期/URL/凭证) |
| 固件文件管理 | 设备固件文件(用户文件管理子菜单) | 无独立固件文件管理(在设备版本管理中) |
| 上传记录 | 网元文件上传记录(6411条日志) | 无独立上传记录页面 |
| 文件审核 | 支持文件审核状态 | 无文件审核机制 |

### 5.2 交互模式对比

| 维度 | Comba UMS (jx) | 广研院统一网管 |
|------|---------------|--------------|
| 页面结构 | 左侧菜单展开子页面，每个子功能独立页面 | Tab切换(设备上传/用户上传/网管下发) |
| 网元选择 | 设备类型树 + 网元列表(按类型/子网/站点/区域/模板/群组分类) | 筛选条件直接搜索(无设备树) |
| 文件上传方式 | "打开"按钮(系统文件选择器) | 拖拽上传区域 + 点击上传 |
| 批量操作 | 批量文件下发计划(支持调度/定时) | 批量操作下拉菜单 + 批量下载 |
| 任务面板 | 底部固定任务面板(任务/批任务/导出三视图) | 无底部任务面板 |
| 筛选展开 | 列头内联筛选 + 分类Tab | 独立筛选区 + 展开/收起 |
| 计划管理 | 新建/编辑/查看/删除/启动/停止/暂停/继续执行/立即执行一次/刷新 | 无独立计划管理 |

### 5.3 配置文件管理流程对比

| 流程 | Comba UMS (jx) | 广研院统一网管 |
|------|---------------|--------------|
| 上传到网管 | 选择网元 > 获取配置文件 > 结果表格显示 | 设备自动上传 / 用户手动新增(含拖拽上传) |
| 下发到设备 | 选择网元 > 下发脚本文件 / 批量文件下发计划 | 用户上传时勾选"下发到设备" / 网管下发记录 |

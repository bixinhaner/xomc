# OMC UI 截图分析文档索引

## 项目概述

本文档集合对三套网管系统的 UI 截图进行了逐张分析，提取了所有界面元素（页面布局、导航、表格、表单、按钮、筛选条件、弹窗等），按功能模块组织输出。共分析 **427 张截图**，生成 **17 个模块文档**。

## 通用 UI 组件对比

| 组件 | Cloudcore OMC | Comba UMS (jx) | 广研院统一网管 |
|------|:---:|:---:|:---:|
| 分页器 | `50/page` + 页码 + 跳转 + 刷新 | `共N条` + 页码 + `25条/页` | `共N条` + `10条/页` + 页码 |
| 表格列筛选 | Add Filters 按钮 | 列头漏斗图标 + 匹配模式 | 隐藏列下拉 |
| 表格排序 | ↕ 列头点击 | 升降序切换 | 列头点击 |
| 批量操作 | 复选框 + 工具栏按钮 | 复选框 + 上方按钮 | 复选框 + 批量操作下拉 |
| 弹窗/对话框 | 橙色主题，右上×关闭 | 居中弹窗 | 居中弹窗，蓝色主题 |
| 搜索框 | 文本 + 搜索图标 | 文本 + 搜索图标 | 文本 + 搜索/重置按钮 |
| 状态标识 | 彩色圆点 + 文本 | 彩色行 + 文本 | 彩色标签 Tag |
| 导出 | 右上角图标 + 进度条 | 底部导出Tab | 导出下拉按钮 |
| 树形导航 | 左侧图标侧边栏 | 左侧展开/折叠树 | 左侧展开/折叠树 |
| 文件上传 | 文件选择按钮 | 文件选择按钮 | 拖拽上传区域 |
| 时间选择 | HH:MM:SS 选择器 | 日期范围选择器 | 日期范围选择器 |

## 使用说明

1. 每个模块文档按 **系统** 分节，每节包含：来源截图、页面布局、导航元素、数据表格列、筛选条件、操作按钮、表单/弹窗
2. 模块文档末尾有 **系统对比表**，方便横向对比三套系统的同类功能
3. 截图文件名在文档中以相对路径引用（如 `OMC/告警.png`、`jx/告警/当前告警/*.jpg`）
4. 后续可基于这些文档进行 OMC 系统的 UI 重新设计

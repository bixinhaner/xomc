# 设备管理

## 概述
设备管理模块负责基站设备的注册、监控、分组、规则配置等全生命周期管理，是网管系统的核心功能。
- 涉及系统：OMC / jx / 广研院

| 字段 | 类型 | 说明 |

#### Matching Rules 匹配规则配置
- **规则类型切换**: `eNB Name`（橙色选中）| `TAC` | `LAC` — 单选按钮
- **条件列表**（多行，可动态添加/删除）:
  | 逻辑运算 | 匹配方式 | 值 | 操作 |
  |---------|---------|-----|------|
  | (首行无) | Contain ∨ | Default | |
  | AND ∨ | Contain ∨ | ABC | × 删除 |
  | AND ∨ | Not Contain ∨ | GEF | × 删除 |
  | OR ∨ | Start With ∨ | admin | × 删除 |
  | OR ∨ | End With ∨ | ABC | × 删除 |
- **添加按钮**: `+ Add Condition`（橙色边框按钮）
- **规则说明文本**: 自动生成，如 `Must (contain "Default" AND contain "ABC") OR (not contain "GEF") OR (start with "admin").`
- **Description**: 文本输入框（描述）

#### eNB List 设备预览
- `☑(2)` 选中计数
- 筛选: `Device Group ∨` | `Serial Number` 搜索框
- 表格列: 复选框 | Serial Number | GroupName

#### 弹窗按钮
- `OK`（橙色按钮）| `Cancel`（灰色按钮）

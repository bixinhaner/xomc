# 备份恢复

## 概述
备份恢复模块提供对基站设备配置的定期备份和恢复功能，支持按天/周/月的周期执行策略，以及 FTP/SFTP 上传。
- 涉及系统：仅 OMC

---

## 二、创建备份任务 — 按天执行

### 来源
- 截图文件：OMC/创建备份任务按天执行.png

### 弹窗/表单: Update Periodic Backup Task
- **关闭按钮**: 右上角 ×（橙色）

#### Enable 开关
- Toggle 开关（橙色 = 启用）

#### Select Devices 选择设备区
- **Equipment Specified**: `ALL`(单选) | `Select`(橙色选中)
- **搜索框**: `Serial Number/Cell Name` + 搜索图标
- **筛选**: `Product Type ∨` | `Clear Filter`
- **Batch Input**: 橙色边框按钮（批量输入）

##### 设备表格列
| 列名 | 说明 |
|------|------|
| (复选框) | 多选 |
| (状态图标) | 设备状态圆点 |
| Serial Number ↕ | 设备序列号 |
| Cell Name ↕ | 小区名称 |
| Product Type ↕ | 产品类型 |
| Latest Update File | 最新备份文件 |
| Latest Update Time ↕ | 最新更新时间 |

- **分页器**: `50/page ∨` | `< 1 2 ... 6 >` | `Total 20`

#### Execute Mode 执行模式
| 字段 | 类型 | 值 |
|------|------|-----|
| *Periodic Execute | 下拉选择 | `Day` |
| *Time | 时间选择器 | `16:00:00` |

#### FTP Server 配置
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Enable | Toggle 开关 | - | 默认关闭，描述"默认关闭" |
| *FTP protocol | 下拉选择 | 是 | `SFTP` |
| *Upload path | 文本输入框 | 是 | 上传路径 |
| *IP Address | 文本输入框 | 是 | FTP 服务器 IP |
| *Port | 文本输入框 | 是 | 端口号 |
| *User Name | 文本输入框 | 是 | 用户名 |
| *Password | 密码输入框（带显示/隐藏图标） | 是 | 密码 |

#### 操作按钮
- `OK`（橙色按钮）| `Cancel`（灰色按钮）

## 六、执行模式汇总

| 执行模式 | 配置字段 | 说明 |
|---------|---------|------|
| Day | Time | 每天固定时间执行 |
| Week | Week(多选星期) + Time | 每周指定日期时间执行 |
| Month | Month(多选月份) + Day(多选日期) + Time | 每月指定日期时间执行 |

## 七、通用组件汇总

| 组件 | 说明 |
|------|------|
| 设备选择器 | ALL/Select 切换 + 表格多选 + Batch Input |
| FTP Server 配置 | Enable开关 + 协议/路径/IP/端口/用户名/密码 |
| 时间选择器 | HH:MM:SS 格式，带时钟图标 |
| 周/月/日选择器 | 日历多选组件 |
| 密码输入框 | 带显示/隐藏切换图标 |
| 密码长度限制 | `Length:6-20` 提示 |

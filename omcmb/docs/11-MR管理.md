# MR 管理

## 概述
MR (Measurement Report) 管理模块提供测量报告的指标查询、统计报表和文件管理功能。MR 数据是无线网络优化的核心依据，包含 MRO（周期性测量）、MRE（事件触发测量）、MRS（统计测量）等类型，用于评估覆盖质量、干扰水平和切换性能。
- 涉及系统：jx / 广研院

---

## 五、系统对比

### 5.1 功能覆盖对比

| 功能维度 | Comba UMS (jx) | 广研院 |
|----------|---------------|--------|
| **MR 指标管理** | 无独立指标管理模块 | 支持基础指标 / 设备指标关联 / 变量三级管理 |
| **MR 报表** | 无独立 MR 报表功能 | 支持 4G/5G 的 MRO 和 MRE 报表查询 |
| **MR 任务管理** | 支持 MR 测量任务的创建、同步、停止、删除 | 无独立 MR 任务管理概念 |
| **MR 参数配置** | 在创建任务时配置采集参数 | 独立的设备级 MR 参数配置页面 |
| **MR 文件管理** | 左侧菜单含 MR 文件管理；通过网元文件上传记录查看 | 独立的 MR 文件列表页，支持批量下载 |
| **MR 下载任务** | 无 | 支持资源下载和报表下载两类任务管理 |

### 5.2 MR 数据模型对比

| 维度 | Comba UMS (jx) | 广研院 |
|------|---------------|--------|
| **指标分类体系** | 无指标分类树 | NR(36 条) / LTE(133 条)，下分 MRO / MRE / MRS |
| **指标层级** | 无分层 | 基础指标 -> 设备指标关联 -> 变量 三级结构 |
| **设备映射** | 无 | 支持指标到具体设备型号/厂商的映射关联 |
| **报表类型** | 无 | 5G-MRO / 5G-MRE / 4G-MRO / 4G-MRE |
| **测量类型** | 在任务中配置 | MRO(周期性) / MRE(事件触发) / MRS(统计) |

### 5.3 MR 任务/配置方式对比

| 维度 | Comba UMS (jx) | 广研院 |
|------|---------------|--------|
| **配置入口** | 配置 > MR管理 > MR任务管理 | MR管理 > MR文件 > MR参数配置 |
| **配置粒度** | 任务级（一次任务绑定多个网元） | 设备级（每台设备单独配置） |
| **采集参数** | MR服务器地址/用户名/密码、文件类型、OMC-R名称、采样/采集周期、测量开始时间 | 实例选择、MR开关、测量类型(MRO/MRE/MRS)、采集/采样周期、采样时间范围、PRB、子帧数、URL/用户名/密码 |
| **同步策略** | 新增 / 覆盖 / 去重覆盖（单选） | 同步按钮（逐设备同步） |
| **批量操作** | 网元选择支持按网元/按分类/按模板 | 批量开启 / 批量关闭 / 批量配置 / 批量同步 |
| **任务调度** | 支持立即下发/立即执行、批次完成时间 | 无任务调度概念，直接配置到设备 |

### 5.4 UI 风格对比

| 维度 | Comba UMS (jx) | 广研院 |
|------|---------------|--------|
| **布局风格** | 传统三栏（左侧菜单树 + 中间内容 + 底部任务面板） | 左侧分类/设备树 + 右侧内容表格 |
| **导航方式** | 顶部主导航 + 面包屑 Tab 栏 + 左侧菜单树 | 顶部一级菜单 + 二级 Tab + 左侧树 |
| **弹窗风格** | 整页表单（折叠区块式） | 模态弹窗（轻量级） |
| **筛选方式** | 列头内联筛选（文本/下拉） | 表格上方独立筛选区（支持展开/收起） |
| **操作按钮** | 按钮组在表格上方横排 | 按钮组在筛选区右侧 + 每行操作列 |
| **任务面板** | 页面底部固定任务面板（任务/批任务/导出 Tab） | 无底部任务面板 |
| **分页样式** | "共N条 / 页码 / N条/页 / 前往" | "共N条 / N条/页 / 共N页" |
| **数据导入** | 弹窗式导入网元（按分类/按模板树形选择） | 弹窗式文件上传（拖拽/点击 + 模板下载） |

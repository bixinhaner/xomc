# 日志管理

## 概述
日志管理模块提供系统操作日志的查询、统计和配置功能，支持网元消息日志、网元心跳日志、操作日志、系统日志的多维度查看与分析。
- 涉及系统：广研院

### 表单/弹窗: 行内编辑模式
- **编辑方式**: 点击「编辑」后，该行的「存储天数(天)」列变为可编辑的文本输入框（当前值为30）
- **操作变化**: 该行操作列从「编辑」变为「保存」（蓝色按钮）
- **其他行**: 仍保持只读状态，操作列继续显示「编辑」
- **说明**: 不使用弹窗，采用表格行内编辑模式

### 帮助卡片
- **标题**: 「帮助卡」
- **内容说明**:
  - 日志存储时间定义收集的原始日志将保留在数据库中的时间。
  - 日志存储时间最多可保存180天，最少保存1天（仅可设置整数）。
  - 日志存储超出设定存储上限将删除20%，超过设定时间的日志将直接全部删除。
  - 查询即将删除的日志，可能会将其删除的时间推迟。

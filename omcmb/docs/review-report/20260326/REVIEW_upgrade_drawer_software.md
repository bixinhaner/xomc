## 变更详情

### 新增功能

1. **时间范围筛选** - 单一日期范围选择器，筛选开始/结束时间有交集的记录
2. **导出功能** - 页面右上角导出按钮，支持CSV格式导出
3. **重新执行** - 操作列仅对失败记录显示"重新执行"按钮，带二次确认
4. **批量升级抽屉**:
   - 产品类型选择（切换时自动过滤不匹配设备）
   - 升级类型：软件升级/PATCH升级/FPGA升级
   - 设备列表管理（支持删除和添加）
   - 添加设备弹窗（从同产品类型设备中勾选）
   - 升级文件选择（根据产品类型和升级类型过滤）
   - 保留配置选项
   - 执行方式：立即执行/挂起/定时执行
   - 任务配置：离线重试、批量数量

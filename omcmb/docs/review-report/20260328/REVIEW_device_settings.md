## 2. 变更详情

### 2.1 布局重组
从 3 个 Card 改为 8 个独立 Card：
1. **设备Inform周期** - 独立 Card
2. **设备名称同步** - 独立 Card
3. **设备接入控制** - 独立 Card
4. **CPE信号强度** - 独立 Card（纯展示）
5. **UE信号强度** - 独立 Card（纯展示）
6. **基站文件上传协议** - 独立 Card
7. **回收站** - 独立 Card
8. **eNB位置移动检测** - 独立 Card

### 2.2 默认值调整
| 字段 | 旧值 | 新值 |
|------|------|------|
| `enbInformPeriodAdjustEnable` | false | true |
| `enbTimeout` | '' | 100 |
| `cpeTimeout` | '' | 300 |
| `nameSettingEnable` | false | true |
| `deviceOfflineSaveDay` | '' | 90 |
| `locationDetection` | false | true |
| `latitudeToleranceRange` | '' | 1000 |

### 2.3 文案更新（与旧版 JSP 对齐）
- "设备启动ENB Inform周期不符合" → "OMC在设备启动时，检测eNB Inform周期不符合"
- "规定时间无响应 X 秒设备将会关机" → "如果系统在 X 秒内没有收到设备心跳消息，则显示设备状态为离线"
- "检查和设置相同设备名称的LMT" → "检查并设置网管上的设备名称与LMT上设备名称一致。"
- "通知我是否手动同步" → "提示我人工处理同步"
- "只允许符合规则" → "只允许符合接入控制"
- "启用设备经纬度检测" → "如果eNB位置移动超过"

### 2.4 移除的功能
- 移除了 CPE/UE 信号强度的输入框，改为纯展示规则（弱< -100 正常< -80 强）
- 移除了未使用的样式定义（subSettingStyle, signalIndicatorStyle）

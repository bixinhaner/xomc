## 变更详情

### 1. 新增功能 - 添加菜单

**新增类型定义：**
- `ShowStatus`: 显示状态 ('show' | 'hide')
- `IsExternal`: 是否外链 ('yes' | 'no')
- `ApiPermission`: API权限 ('required' | 'none')

**扩展 MenuItem 接口：**
- `icon`: 菜单图标
- `isExternal`: 是否外链
- `routePath`: 路由地址
- `routeParams`: 路由参数
- `showStatus`: 显示状态
- `apiPermission`: API权限

**新增组件和状态：**
- `addVisible`: 新增抽屉可见状态
- `addForm`: 新增表单实例
- `menuTreeData`: 树形菜单选择数据
- `handleAdd`: 打开新增弹窗
- `handleAddSave`: 保存新增菜单

### 2. 表单字段动态显示

根据菜单类型显示不同字段：

**目录类型：**
- 显示排序、菜单名称、菜单图标（默认勾选）
- 是否外链、路由地址、显示状态、菜单状态、API权限

**菜单类型：**
- 显示排序、菜单名称、是否外链、路由地址
- 组件路径、权限字符、路由参数、显示状态、菜单状态

**按钮类型：**
- 显示排序、菜单名称、权限字符、菜单状态、API权限

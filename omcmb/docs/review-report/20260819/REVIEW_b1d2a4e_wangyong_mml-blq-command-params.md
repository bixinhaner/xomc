## 变更目标

修复 BLQ 基站“修改 FAP 载波能力集”命令被错误保留但没有可编辑参数的问题，并优化从“指定参数”切换到“命令参数”时的操作路径，使用户直接进入 MML 命令列表。

## 审查范围

- MML 分组命令树按产品参数模型过滤时，结合命令操作类型与参数访问权限计算可用子字段。
- 参数配置弹框在未选择命令时，从原始路径模式切换到标准命令模式的导航行为。
- 后端只读参数过滤与前端页签直达行为的回归测试。

## 审查结果

未发现 CRITICAL、WARNING 或 INFO 级问题。

关键行为符合预期：

1. `MOD` 命令只统计 `READ_WRITE` 子字段，没有可写字段的命令不会作为空命令显示。
2. `LST` 命令排除 `WRITE_ONLY` 子字段，保持可读参数查询能力。
3. BLQ 参数模型中的 FAP 载波能力字段保持只读语义，不通过放宽模型权限制造无效修改入口。
4. 未选择命令时切换到“命令参数”会调用既有 `onGotoCommand` 导航，直接打开命令选择弹框。
5. 已选择命令或切换到其他模式时仍沿用原有页签状态更新逻辑。

## 风险与边界

- 过滤规则仅影响已经按产品型号解析、且具有子字段定义的 `MOD`/`LST` 命令树；其他操作类型保持原行为。
- 不涉及数据库迁移、接口字段变更或参数模型数据修改。
- 前端交互修改位于现有 MML Console 页面，不涉及其他皮肤的独立实现。

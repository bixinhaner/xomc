## 二、新系统新增菜单��原系统无对应）

| 新系统菜单 | 二级菜单项 | 说明 |
|-----------|----------|------|

## 三、操作流程完整性总览

### ✅ 完整的操作流程（14 个）
1. 用户登录/登出
2. Dashboard 仪表板概览（KPI 卡片 + 图表 + GIS 地图）
3. 设备注册（多步骤向导：基础信息 → 网络配置 → 确认）
4. 设备列表查询（筛选 + 分页 + 批量操作 + 导出）
5. 设备分组管理（树形结构 + CRUD + 设备关联）
6. 当前告警管理（列表 + 确认 + 清除 + 批量操作）
7. 告警统计（多维度图表 + TOP10 + 趋势分析）
8. 告警规则 CRUD
9. MML 控制台（设备选择 → 命令执行 → 终端输出）
10. 用户管理（CRUD + 锁定/解锁 + 密码重置）
11. 角色权限管理（角色列表 + 权限树 + 保存）
12. 操作日志查看（筛选 + 详情 JSON 查看器）
13. 许可证列表（详情面板 + 撤销操作）
14. 固件上传（拖拽上传 + 进度追踪）

### ⚠️ 部分完整的操作流程（8 个）
1. 设备监控 — 有在线监控页面，缺少设备级详细监控面板
2. 性能图表 — 图表展示完整，缺少 KPI 定义/公式管理
3. 拓扑画布 — 图形渲染完整，缺少设备右键操作菜单
4. 备份任务 — 任务列表和策略有，缺少设备级选择和进度追踪
5. 升级计划 — 有计划创建和进度条，缺少多设备类型支持（CPE/UPS/FPGA）
6. 配置参数列表 — 有参数列表展示，缺少参数编辑和设备级修改
7. MR 报表 — 有报表列表，缺少 MR 定制化采集和文件下载
8. 文件管理 — 有多类型文件展示，缺少文件版本管理和 MD5 校验

### ❌ 缺失的关键操作流程（18 个）
1. 设备重启全流程（选设备 → 设定时间 → 执行 → 监控进度）
2. 工厂复位
3. 配置备份/恢复全流程（选设备 → 创建任务 → 执行 → 下载备份）
4. 信令追踪（eNB/EPC/UE/gNB 信令抓取和分析）
5. SON PCI 优化（冲突检测 → 自动分配 → 进度监控）
6. SON 自配置（即插即用 + 自配置策略）
7. 设备自启动（零接触配置）
8. EPC 核心网管理（APN/IMSI/设备策略/信令追踪）
9. 运营商管理（运营商 CRUD + 设备分配）
10. 证书管理（SSL/TLS/CA 证书生命周期）
11. 资源监控（CPU/内存/磁盘/数据库实时监控）
12. 设备迁移
13. DHCP 管理
14. SAS 频谱管理
15. UPS 电源管理
16. eGW/NewEGW 网关管理
17. GSM 设备管理
18. 告警通知设置（声音 + 邮件 + 自定义模板）

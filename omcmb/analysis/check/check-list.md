# 前端页面功能迁移核查清单

> 本文档用于逐页面/逐模块核查，确保从原系统（JSP + jQuery EasyUI）迁移至新系统（React + Ant Design）时不遗漏任何前端细节。

---

## 一、数据字段核查

| 核查项 | 说明 | 核查方式 |
|--------|------|---------|
| 字段完整性 | 原系统页面所有可见字段是否在新系统中全部保留 | 逐字段对照原 JSP 页面与新 React 页面 |
| 字段命名 | 字段中英文 label 是否与原系统一致（含 i18n） | 对比 `zh-CN/index.ts` 和 `en-US/index.ts` |
| 字段顺序 | 表单/表格字段排列顺序是否与原系统一致 | 截图对比 |
| 隐藏字段 | 原系统中存在但不直接展示的字段（hidden input）是否在新系统中正确携带 | 检查接口请求参数 |
| 只读字段 | 某些场景下只读的字段（如编辑时 ID 不可改）是否正确设置 `disabled / readOnly` | 逐场景验证 |
| 条件显隐字段 | 根据其他字段值动态显示/隐藏���字段逻辑是否一致 | 对照原 JS 逻辑 |

## 二、数据类型核查

| 核查项 | 说明 | 常见问题 |
|--------|------|---------|
| 字符串 (string) | 文本输入框、文本域 | 原系统 `<input type="text">` → 新系统 `<Input>` / `<Input.TextArea>` |
| 数值 (number) | 整数、浮点数 | 原系统允许手动输入 → 新系统 `<InputNumber>` 是否限制了步长/精度 |
| 布尔 (boolean) | 开关、复选框 | 原系统 checkbox → 新系统 `<Switch>` / `<Checkbox>`，提交值是否一致（0/1 vs true/false） |
| 枚举 (enum) | 下拉选择框 | 选项列表是否完整、选项值是否与后端一致 |
| 日期/时间 | 日期选择器、时间范围 | 格式是否一致（`YYYY-MM-DD` vs `MM/DD/YYYY`），时区处理 |
| IP 地址 | IPv4 / IPv6 输入 | 原系统自定义 IP 输入组件 → 新系统实现方式 |
| 文件 (file) | 文件上传 | 文件类型限制、大小限制、多文件支持是否一致 |
| 复合类型 | 嵌套对象、数组 | JSON 序列化/反序列化方式是否兼容 |

## 三、字段长度/范围限制核查

| 核查项 | 说明 | 示例 |
|--------|------|------|
| 最大长度 (maxLength) | 文本输入最大字符数 | 设备名称 ≤ 64 字符 |
| 最小长度 (minLength) | 文本输入最小字符数 | 密码 ≥ 8 字符 |
| 数值范围 (min/max) | 数值输入上下限 | 端口号 1~65535、EARFCN 0~262143 |
| 精度 (precision) | 小数位数限制 | 经纬度精度 6 位小数 |
| 文件大小限制 | 上传文件大小上限 | 固件文件 ≤ 500MB |
| 列表条数限制 | 批量操作最大选择数 | 批量删除 ≤ 100 条 |

## 四、默认值核查

| 核查项 | 说明 | 核查方式 |
|--------|------|---------|
| 新建表单默认值 | 打开新建弹窗/页面时各字段的初始值 | 对比原系统新建操作 |

| 搜索条件默认值 | 列表页搜索区域的默认筛选条件 | 某些状态筛选器默认选中"全部" |
| 分页默认值 | 默认页码、每页条数 | 原系统默认 20 条/页 → 新系统是否一致 |

## 八、校验规则核查

### 8.1 格式校验

| 校验类型 | 说明 | 示例 |
|---------|------|------|
| 正则校验 | 特定格式的输入校验 | IP 地址、MAC 地址、邮箱、手机号 |
| 字符类型限制 | 仅字母 / 仅数字 / 字母数字组合 | 设备序列号：仅大写字母和数字 |
| 特殊字符限制 | 禁止输入的特殊字符 | 设备名不允许 `< > & " '` |
| 中文支持 | 是否允许中文输入，字符长度计算方式 | 中文算 1 字符还是 2/3 字节 |

### 8.2 业务校验

| 校验类型 | 说明 | 示例 |
|---------|------|------|
| 唯一性校验 | 字段值是否需要唯一（前端/后端） | 设备名称不可重复 |
| 关联校验 | 多字段之间的逻辑关系校验 | 结束时间 > 开始时间 |
| 范围校验 | 数值/日期范围的上下限 | 查询时间跨度 ≤ 30 天 |
| 依赖校验 | 字段 A 的值约束字段 B 的可选范围 | 选择频段后限制 EARFCN 范围 |
| 状态校验 | 某些操作仅在特定状态下可执行 | 仅"在线"设备可下发配置 |

### 8.3 校验时机

| 时机 | 说明 |
|------|------|
| 实时校验 (onChange) | 输入时即时校验 |
| 失焦校验 (onBlur) | 输入框失去焦点时校验 |
| 提交校验 (onSubmit) | 点击提交按钮时统一校验 |
| 异步校验 | 需调用后端接口验证（如用户名是否已存在） |

## 十一、会话与认证核查

| 核查项 | 说明 | 原系统特征 |
|--------|------|-----------|
| Token 管理 | JWT access_token + refresh_token 双令牌机制 | 原系统 JSP Session → 新系统 Zustand + localStorage |
| 静默刷新 | 401 时自动刷新 token 并重发请求队列 | 原系统无此机制，新系统 `http.ts` 拦截器实现 |
| 会话超时 | 长时间无操作后自动登出的提示和跳转 | 原系统 Session timeout → 新系统 token 过期检查（30s 宽限期） |
| 登录状态持久化 | 刷新页面后是否保持登录态 | 原系统依赖 Cookie → 新系统 localStorage 持久化 |
| 多 Tab 同步 | 多浏览器 Tab 间登录/登出状态是否同步 | 新系统通过 localStorage 事件可感知 |
| 请求头携带 | 所有 API 请求是否正确携带 `Authorization: Bearer` | 检查 http 拦截器 |

# 用户管理功能设计文档

## 1. 页面概述

用户管理页面用于管理系统中的用户信息，包括用户的创建、编辑、删除、锁定、密码重置等操作。

## 2. 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| 操作 | - | 100px | 操作按钮列（放在最前面） |
| 在线状态 | online_status | 100px | 显示"在线"或"不在线" |
| 锁定状态 | lock_status | 100px | 解锁/有效期锁定 |
| 用户名称 | user_name | 130px | 登录用户名 |
| 邮箱 | email | 自适应 | - |
| 用户组 | group_name | 150px | 支持多个用户组，悬浮显示全部 |
| 上次登录时间 | last_login_time | 160px | - |
| 来源 | source | 80px | 本地/LDAP |

## 3. 搜索条件

| 字段名 | 字段标识 | 类型 | 说明 |
|--------|----------|------|------|
| 用户名称 | userName | 输入框 | 模糊搜索，支持回车查询 |

## 4. 工具栏按钮

## 7. 添加/编辑用户

通过抽屉（Drawer）滑出面板进行用户信息的添加和编辑。抽屉宽度520px。

### 表单字段

| 字段名 | 字段标识 | 必填 | 类型 | 校验规则 | 说明 |
|--------|----------|------|------|----------|------|
| 用户名称 | userName | 是 | Input | 3-32字符，仅字母数字下划线 | 修改时不可编辑 |
| 密码 | password | 是（新增） | Input.Password | 最少8位，需包含两种类型 | - |
| 确认密码 | confirmPassword | 是（新增） | Input.Password | 需与密码一致 | - |
| 邮箱 | email | 否 | Input | 邮箱格式，最大50字符 | - |
| 手机号 | phone | 是 | Input | 手机号格式(11位)或固话格式 | 短信验证模式下必填 |
| 用户组 | groupNames | 是 | Select[mode=multiple] | 至少选择一个 | 支持多选 |
| 锁定状态 | lockStatus | 否 | Radio | 0=解锁，1=有效期锁定 | 默认解锁 |
| 到期时间 | expireTime | 条件 | DatePicker | 需大于当前时间 | 不勾选"不限制时间"时必填 |
| 不限制时间 | limitTime | 否 | Checkbox | - | 默认勾选 |
| 描述 | description | 否 | TextArea | 最大500字符 | - |

### 用户组选择说明

用户组分为三种预设类型：
- **Super Admin**：超级管理员组（内置组，ID=1）
- **Default Group**：默认组（内置组，ID=100000）
- **Customize**：自定义用户组（多选）

### 表单校验规则详情

#### 用户名校验
- 必填
- 不能包含中文
- 只能包含字母(a-z, A-Z)、数字(0-9)、下划线(_)、减号(-)、破折号(—)
- 长度：3-32字符
- 不能与已存在用户名重复

#### 密码校验
- 必填
- 长度：8-20字符
- 允许字符：字母、数字、特殊字符(_!@#$%^&*?)
- 必须包含至少两种类型（大写字母、小写字母、数字、特殊字符）

#### 邮箱校验
- 格式：标准邮箱格式
- 最大长度：50字符

#### 手机号校验
- 短信验证模式：必填，11位手机号(1开头)
- 非短信模式：可选，固话格式(数字、-、+、()、空格)

### 导入入口
- 点击工具栏"导入"按钮
- 右侧滑出导入面板（Drawer，宽度350px）

### 导入面板内容

| 元素 | 说明 |
|------|------|
| 标题 | 导入 |
| 文件选择 | 支持拖拽或点击选择 |
| 文件格式 | .xlsx, .xls |
| 下载模板链接 | 点击下载导入模板 |
| 确定按钮 | 开始导入 |
| 取消按钮 | 关闭面板 |

### 导入流程
1. 点击"导入"按钮，右侧滑出导入面板
2. 点击选择Excel文件（仅支持.xlsx/.xls格式）
3. 选择文件后，文件名显示在输入框中
4. 点击"确定"按钮开始导入
5. 导入成功后自动关闭面板并刷新列表
6. 导入失败显示错误信息

### 导入API

```
POST /api/v1/users/import
Content-Type: multipart/form-data
```

请求参数：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | Excel文件(.xlsx/.xls) |

响应：
```json
{
  "success": true,
  "message": "导入成功",
  "data": {
    "total": 100,
    "success": 98,
    "failed": 2,
    "errors": [
      {"row": 5, "reason": "用户名已存在"},
      {"row": 12, "reason": "邮箱格式错误"}
    ]
  }
}
```

### 下载模板API

```

```

返回：Excel文件下载

## 19. 特殊规则

### 内置用户
- `admin` 用户为超级管理员，不可删除
- `build_in = 1` 的用户为内置用户，部分操作受限
- 运营商管理员 `build_in = 9`，有特殊权限限制

### LDAP用户
- 来源为 LDAP 的用户，密码相关操作不可用
- 密码由LDAP服务器管理，OMC不可修改

### 短信验证模式
- 系统配置项，影响手机号校验规则
- 开启时手机号必填且需为11位手机号
- 关闭时手机号可选且支持固话格式

### 密码规则配置
- 最小长度：系统配置 `min_password_length`
- 最大长度：系统配置 `max_password_length`
- 密码强度：是否要求包含多种字符类型

### 用户名规则配置
- 最小长度：系统配置 `min_username_length`
- 是否检查特殊字符：系统配置 `check_username_chars`

## 7. 添加/编辑角色

通过抽屉（Drawer）滑出面板进行角色信息的添加和编辑。抽屉宽度520px。

### 表单字段

| 字段名 | 字段标识 | 必填 | 类型 | 校验规则 | 说明 |
|--------|----------|------|------|----------|------|
| 角色名称 | roleName | 是 | Input | 最大200字符，不能重复 | 编辑时只读 |
| 描述 | description | 否 | TextArea | 最大500字符 | - |
| 菜单权限 | permissions | 是 | Tree | 至少选择一个操作权限 | 三级树形结构 |
| 数据权限 | deviceGroupIds | 是 | Tree | 至少选择一个设备组 | 二级树形结构 |

### 菜单权限配置

菜单权限为三级树形结构：
- **一级**：功能模块（设备管理、告警管理、性能管理等）
- **二级**：子菜单（设备列表、设备分组、活动告警等）
- **三级**：操作权限（查询、新增、修改、删除、导出、批量）

#### 操作权限说明

| 操作 | Key | 说明 |
|------|-----|------|
| 查询 | query | 查看数据权限 |
| 新增 | add | 创建数据权限 |
| 修改 | edit | 编辑数据权限 |
| 删除 | delete | 删除数据权限 |
| 导出 | export | 导出数据权限 |
| 批量 | batch | 批量操作权限 |

#### 菜单权限树顶部操作

| 操作 | 说明 |
|------|------|
| 展开/折叠 | 展开 or 折叠所有节点 |
| 全选/全不选 | 选中或取消所有权限 |
| 父子联动 | 勾选时是否自动选中父/子节点 |

### 数据权限配置

数据权限基于设备组树形结构：
- **一级**：设备组分类
- **二级**：具体设备组

#### 筛选功能

| 筛选项 | 说明 |
|--------|------|
| 基站类型 | 按基站类型筛选（eNB/gNB/GSM等） |
| 产品类型 | 按产品类型筛选（宏基站/小基站/皮基站） |
| 全选 | 选中当前筛选结果 |

# 菜单管理功能设计文档

## 1. 页面概述

菜单管理页面用于管理系统中的菜单配置，支持树形结构展示，可创建目录、菜单、按钮三种类型的菜单项。

## 2. 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| 操作 | - | 100px | 操作按钮列（放在最前面） |
| 菜单名称 | name | 200px | 树形展示，支持展开/折叠 |
| 类型 | type | 100px | 目录/菜单/按钮 |
| 排序 | sort | 100px | 可编辑的排序值（上下箭头调整） |
| 权限标识 | permissionKey | 200px | 权限标识码 |
| 组件路径 | componentPath | 200px | 前端组件路径 |
| 状态 | status | 100px | 正常/停用 |

## 3. 搜索条件

| 字段名 | 字段标识 | 类型 | 说明 |
|--------|----------|------|------|
| 菜单名称 | name | 输入框 | 模糊搜索 |
| 状态 | status | 下拉选择 | 正常/停用 |

## 4. 工具栏按钮

| 按钮名称 | 图标 | 权限控制 | 说明 |
|----------|------|----------|------|
| 新增 | PlusOutlined | CODE_SYSTEM_MENUS | 新增菜单（顶级菜单） |

## 5. 树形结构

菜单采用三级树形结构：

| 层级 | 类型 | 说明 |
|------|------|------|
| 一级 | 目录 | 功能模块分类（如：设备管理、系统管理） |
| 二级 | 菜单 | 具体页面（如：设备列表、角色管理） |
| 三级 | 按钮 | 操作权限（如：查询、新增、删除） |

### 展开折叠

- 点击节点前的箭头图标展开/折叠子节点
- 树形数据默认展开所有节点

## 6. 排序功能

排序列使用 InputNumber 组件，支持上下箭头调整：

| 操作 | 说明 |
|------|------|
| 上箭头 | 排序值 +1 |
| 下箭头 | 排序值 -1 |
| 直接输入 | 修改为指定值（1-999） |

**注意**：修改排序值不会实时调整显示顺序，仅更新排序字段值。

## 7. 添加/编辑菜单

通过抽屉（Drawer）滑出面板进行菜单的添加和编辑。抽屉宽度520px。

### 表单字段

| 字段名 | 字段标识 | 必填 | 类型 | 说明 |
|--------|----------|------|------|------|
| 菜单名称 | name | 是 | Input | 菜单显示名称 |
| 类型 | type | 是 | Radio | 目录/菜单/按钮 |
| 权限标识 | permissionKey | 是 | Input | 权限标识码 |
| 上级菜单 | parentId | 否 | TreeSelect | 选择父级菜单 |
| 路由路径 | routePath | 条件 | Input | 类型为目录/菜单时显示 |
| 组件路径 | componentPath | 条件 | Input | 类型为菜单时显示 |
| 路由参数 | routeParams | 否 | Input | 类型为菜单时显示 |
| 是否外链 | isExternal | 条件 | Radio | 类型为菜单时显示 |
| 菜单图标 | icon | 条件 | Input | 类型为目录/菜单时显示 |
| 显示状态 | showStatus | 条件 | Radio | 类型为菜单时显示 |
| 排序 | sort | 是 | InputNumber | 1-999 |
| 状态 | status | 是 | Radio | 正常/停用 |
| API权限 | apiPermission | 条件 | Radio | 类型为菜单时显示 |
| 描述 | description | 否 | TextArea | 备注信息 |

### 根据类型显示不同字段

#### 类型 = 目录
显示：菜单名称、类型、权限标识、上级菜单、路由路径、菜单图标、排序、状态、描述

#### 类型 = 菜单
显示：菜单名称、类型、权限标识、上级菜单、路由路径、组件路径、路由参数、是否外链、菜单图标、显示状态、排序、状态、API权限、描述

#### 类型 = 按钮
显示：菜单名称、类型、权限标识、上级菜单、排序、状态、描述

## 8. 菜单类型说明

| 类型 | 值 | 说明 |
|------|-----|------|
| 目录 | directory | 一级分类，包含子菜单 |
| 菜单 | menu | 具体页面，可配置路由 |
| 按钮 | button | 操作权限，不可展开 |

## 9. 状态说明

| 状态值 | 显示文本 | 标签颜色 |
|--------|----------|----------|
| normal | 正常 | green |
| disabled | 停用 | default |

## 10. 权限控制

| 权限码 | 说明 |
|--------|------|
| CODE_SYSTEM_MENUS | 菜单管理权限 |

# MML 脚本任务管理页面

> 原始文件：`omcmb/original-omc/OMCWebServer/src/main/webapp/WEB-INF/content/cell/task/MMLScript/task_list.jsp`

## 1. 页面概述

MML 脚本任务管理页面用于创建、执行和管理 MML 脚本任务，支持批量向基站设备下发 MML 命令。

## 2. 页面布局

页面分为上下两个区域：

```
┌─────────────────────────────────────────────────────────────────┐
│                        工具栏                                    │
│  [添加] [搜索框] [日期范围选择器]                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│                     MML 脚本任务列表                              │
│                                                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│                     任务执行结果列表                              │
│                   (点击查看结果后显示)                            │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 任务列表

### 3.1 工具栏

| 功能 | 说明 |
|------|------|
| 添加按钮 | 打开新建任务侧边栏 |
| 搜索框 | 按任务名称模糊搜索 |
| 日期范围选择器 | 按创建时间范围筛选（开始时间 ~ 结束时间） |

### 3.2 搜索字段

| 搜索类型 | 字段代码 | 搜索方式 | 说明 |
|----------|----------|----------|------|
| 任务名称 | task_name | 模糊搜索 (LIKE) | 支持部分匹配 |
| 创建时间范围 | create_time | 范围筛选 | 日期时间范围选择器 |

**搜索参数说明：**
- `likeFields`: 'task_name' - 指定模糊搜索字段
- `searchText`: 搜索关键词
- `startTime`: 开始时间
- `endTime`: 结束时间

### 3.3 列表字段

| 序号 | 字段名 | 字段代码 | 宽度 | 格式化 | 说明 |
|------|--------|----------|------|--------|------|
| 1 | 操作 | - | 70px | - | 结果查看图标、更多操作菜单 |
| 2 | 任务名称 | TASK_NAME | 自适应 | - | 任务的名称标识，支持模糊搜索 |
| 3 | 创建者 | CREATE_USER | 自适应 | - | 创建任务的用户名 |
| 4 | 创建时间 | CREATE_TIME | 自适应 | - | 任务创建的时间 |
| 5 | 类型 | CREATE_STATUS | 自适应 | typeFmt | 任务执行类型 |
| 6 | 状态 | TASK_STATUS | 自适应 | tastStatusFmt | 任务当前状态（带颜色） |
| 7 | 进度 | TASK_PROGRESS | 自适应 | - | 任务执行进度百分比 |
| 8 | 结果 | TASK_RESULT | 自适应 | taskResultFmt | 任务执行结果 |
| 9 | 开始时间 | START_TIME | 140px | - | 任务开始执行时间 |
| 10 | 结束时间 | END_TIME | 140px | - | 任务结束时间 |

### 3.4 操作列

**操作列包含两个图标按钮：**

| 图标 | 类名 | 点击事件 | 说明 |
|------|------|----------|------|
| 结果图标 | el-icon-operation-result | showResult(row) | 查看任务执行结果 |

### 3.5 操作菜单

点击"更多操作"图标显示以下菜单项：

| 序号 | 操作 | 图标类名 | 操作代码 | 说明 | 权限控制 | 可用状态 |
|------|------|----------|----------|------|----------|----------|
| 1 | 信息 | el-icon-operation-info | info | 查看任务详情 | 所有人可见 | 所有状态 |
| 2 | 开始 | el-icon-operation-start | start | 启动暂停的任务 | CODE_ENB_MML | 挂起状态 |
| 3 | 暂停 | el-icon-operation-awaiting | wait | 暂停执行中的任务 | CODE_ENB_MML | 执行中状态 |
| 4 | 终止任务 | el-icon-operation-terminate | end | 终止任务执行 | CODE_ENB_MML | 执行中/等待状态 |
| 5 | 删除 | el-icon-operation-delete | del | 删除任务 | CODE_ENB_MML | 非执行中状态 |

**菜单显示逻辑：**
- 无写权限时只显示"信息"菜单
- 有写权限时显示完整菜单

### 3.7 状态枚举 (TASK_STATUS)

| 状态 | 说明 |

| 执行中 | 任务正在执行 |

| 已完成 | 任务执行完成 |
| 已终止 | 任务被终止 |

### 3.8 结果枚举 (TASK_RESULT)

| 结果 | 说明 |
|------|------|
| 成功 | 所有命令执行成功 |

## 5. 新建任务页面

通过"添加"按钮打开新建任务页面，包含以下配置项：

### 5.1 基本信息

| 序号 | 字段名 | 字段代码 | 类型 | 必填 | 输入限制 | 默认值 | 说明 |
|------|--------|----------|------|------|----------|--------|------|
| 1 | 任务名称 | taskName | 文本输入 | ✓ | 最大50字符 | - | 任务的名称标识 |
| 2 | 选择脚本 | fileName | 文件上传 | ✓ | .txt 格式 | - | MML 脚本文件 |

**脚本文件说明：**
- 文件格式：仅支持 .txt 文件
- 可上传多个文件
- 提供模板下载功能（导出模板按钮）
- 使用模板导入提示：支持使用模板导入

### 5.2 选择执行方式

| 序号 | 执行方式 | 字段值 | 附加字段 | 说明 |
|------|----------|--------|----------|------|
| 1 | 立即执行 | active | - | 创建后立即开始执行 |
| 2 | 挂起 | suspend | - | 创建后处于挂起状态，需手动启动 |
| 3 | 定时执行 | timing | time（日期时间选择器） | 按指定时间执行 |
| 4 | 周期任务 | period | periodStartTime + periodEndTime（日期范围）<br>periodTime（时间选择器） | 按周期重复执行 |

**执行方式交互说明：**
- 选择"定时执行"时，显示日期时间选择器
- 选择"周期任务"时，显示日期范围选择器和时间选择器
- 日期选择器禁止选择过去时间（可以选择今天）
- 定时执行和周期任务的默认时间必须大于当前时间

### 5.3 执行策略

#### 5.3.1 离线设备策略

| 字段 | 字段代码 | 类型 | 输入限制 | 默认值 | 说明 |
|------|----------|------|----------|--------|------|
| 离线设备重试开关 | offlineRetryEnable | 复选框 | on/off | off | 离线设备是否等待上线重试 |
| 等待设备上线重试时间 | offlineRetryWaitTime | 数字输入 | 最小:20, 最大:10080 | 60 | 等待设备上线重试的时间（分钟） |

**说明：**
- 勾选后，离线设备会在设备上线后自动重试
- 等待时间范围：20~10080 分钟（最多 7 天）

#### 5.3.2 在线设备策略

| 字段 | 字段代码 | 类型 | 输入限制 | 默认值 | 说明 |
|------|----------|------|----------|--------|------|
| 配置失败重试开关 | failedRetryEnable | 复选框 | on/off | off | 在线设备配置失败是否重试 |
| 重试次数 | failedRetryCount | 数字输入 | - | 3 | 配置失败重试次数 |
| 间隔重试时间 | failedRetryWaitTime | 数字输入 | - | 5 | 每次重试的间隔时间（分钟） |

**说明：**
- 勾选后，在线设备配置失败会自动重试
- 重试次数和间隔时间可自定义配置

### 5.4 表单验证规则

| 字段 | 验证规则 |
|------|----------|
| 任务名称 | 必填，不能为空格 |
| 选择脚本 | 必填，必须先选择文件 |
| 定时执行时间 | 当执行方式为"定时执行"时必填 |
| 周期日期范围 | 当执行方式为"周期任务"时必填 |
| 周期执行时间 | 当执行方式为"周期任务"时必填 |
| 离线等待时间 | 必填，数字类型 |
| 失败重试次数 | 必填，数字类型 |
| 失败重试间隔 | 必填，数字类型 |

### 5.5 错误处理

当上传的 MML 脚本存在错误时：
1. 弹出确认对话框显示错误列表
2. 错误列表包含：行号、错误信息
3. 用户可选择"继续"保存或"取消"
4. 支持导出错误信息

**错误对话框字段：**

| 字段 | 字段代码 | 说明 |
|------|----------|------|
| MML 结果行标题 | line | 错误所在行号 |
| MML 结果标题 | msg | 错误信息描述 |

### 5.6 页面按钮

| 按钮 | 操作 | 说明 |
|------|------|------|
| 确定 | saveTask() | 保存任务并关闭页面 |
| 取消 | closePage() | 取消并关闭页面 |
| 导出模板 | downloadTpl() | 下载 MML 脚本模板文件 |
| Continue | continueSave() | 脚本有错误时继续保存 |

### 5.7 查看任务详情

当查看任务详情时（isView=true）：
- 所有表单字段为只读/禁用状态
- 不显示底部按钮（确定/取消）
- 通过 sessionStorage 存储查看模式标识

## 6. API 接口

### 6.1 任务列表

```
GET /task/MMLScript/getMMLScriptTaskList.action
```

**请求参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| timeZone | string | 时区 |
| likeFields | string | 模糊搜索字段 |
| searchText | string | 搜索关键词 |
| startTime | string | 开始时间 |
| endTime | string | 结束时间 |

### 6.2 任务结果列表

```
GET /task/MMLScript/getMMLScriptTaskProgress.action
```

**请求参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| task_id | string | 任务 ID |
| timeZone | string | 时区 |
| searchText | string | 搜索关键词 |

### 6.3 导出结果

```
POST /task/MMLScript/exportMMLProgResultToCSV.action
```

**请求参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| taskId | string | 任务 ID |
| timeZone | string | 时区 |
| searchText | string | 搜索关键词 |

### 6.4 任务操作

| 操作 | 接口 | 参数 |
|------|------|------|
| 启动任务 | POST /task/MMLScript/activeTask.action | taskId |
| 暂停任务 | POST /task/MMLScript/suspendTask.action | taskId |
| 终止任务 | POST /task/MMLScript/terminateMMLScriptTask.action | taskId |
| 删除任务 | POST /task/MMLScript/delMMLScriptTask.action | taskId |

## 7. 权限控制

| 权限代码 | 说明 |
|----------|------|
| CODE_ENB_MML | MML 脚本任务写权限（添加、开始、暂停、终止、删除） |

## 8. 交互说明

### 8.1 查看结果

1. 点击任务行的"结果"图标
2. 下方展开任务结果列表
3. 结果列表显示该任务下所有设备的执行详情
4. 可通过搜索框筛选特定设备

### 8.2 查看详情

1. 点击结果行的"详情"链接
2. 弹出对话框显示格式化的 JSON 详情
3. 支持嵌套结构的层级展示

### 8.3 删除确认

1. 点击"删除"菜单项
2. 弹出确认对话框
3. 确认后执行删除操作

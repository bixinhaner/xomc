## 1. 功能概述

### 1.1 功能定位

字典功能是系统管理模块的核心基础功能之一，为整个系统提供统一的枚举值管理服务。它是连接业务数据与用户展示的关键桥梁，确保前后端对枚举值的理解保持一致。

### 1.2 设计理念

| 设计原则 | 说明 |
|----------|------|
| **数据与展示分离** | 通过字典将业务数据值（如 `1`、`0`）与用户展示文本（如 "启用"、"禁用"）分离，便于国际化和UI调整 |
| **集中管理** | 所有枚举值集中在字典表中统一管理，避免硬编码散落在各处 |
| **动态配置** | 字典可在运行时动态增删改，无需修改代码和重启服务 |
| **前后端一致** | 通过相同的字典类型（Type）获取相同的选项列表，确保前后端数据一致性 |
| **缓存优化** | 前端缓存字典数据，减少重复请求 |

### 1.3 适用场景

- **枚举字段管理**：性别（男/女）、状态（启用/禁用）、审核状态等
- **分类管理**：商品分类、文章分类、问题类型等
- **级别定义**：会员等级、优先级、紧急程度等
- **类型分类**：文件类型、消息类型、操作类型等
- **代码配置**：数据库类型映射、系统配置项等

## 2. 功能需求

### 2.1 字典管理

#### 2.1.1 功能需求

- 支持字典的创建、查询、修改、删除操作
- 支持按字典类型查询单个字典及其所有字典项
- 支持获取所有字典列表（不含详情）

#### 2.1.2 字典字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 主键ID，系统自动生成 |
| name | string | 是 | 字典名称（中文），如"性别" |
| type | string | 是 | 字典类型（英文标识），如"gender"，全局唯一 |
| status | bool | 否 | 启用状态，默认启用 |
| desc | string | 否 | 字典描述说明 |
| created_at | datetime | 是 | 创建时间 |
| updated_at | datetime | 是 | 更新时间 |

#### 2.1.3 业务规则

- **类型唯一性**：字典 Type 字段在全局范围内必须唯一，创建和更新时都需要进行唯一性校验
- **级联删除**：删除字典时，自动删除其关联的所有字典项
- **软删除**：删除操作采用软删除机制，保留数据可追溯
- **状态控制**：禁用的字典在前端不再展示，但其字典项仍可被关联查询

### 2.2 字典项管理

#### 2.2.1 功能需求

- 支持字典项的创建、查询、修改、删除操作
- 支持分页获取字典项列表
- 支持按字典ID、展示值、字典值、状态等字段筛选

#### 2.2.2 字典项字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 主键ID，系统自动生成 |
| label | string | 是 | 展示值，如"男" |
| value | string | 是 | 字典值，如"1" |
| extend | string | 否 | 扩展值，用于存储额外信息 |
| status | bool | 否 | 启用状态，默认启用 |
| sort | int | 否 | 排序标记，值越小越靠前，默认0 |
| sys_dictionary_id | int | 是 | 所属字典ID |
| created_at | datetime | 是 | 创建时间 |
| updated_at | datetime | 是 | 更新时间 |

#### 2.2.3 业务规则

- **排序规则**：字典项通过 sort 字段控制展示顺序，数值越小排序越靠前
- **状态过滤**：禁用的字典项在查询字典详情时不返回
- **分页支持**：列表查询支持分页，默认每页10条

### 2.3 字典使用（消费端需求）

#### 2.3.1 按类型获取字典选项列表

- 支持通过字典类型（Type）获取该字典下所有启用的字典项
- 返回结果按 sort 字段升序排列
- 只返回 status=true 的字典项

#### 2.3.2 字典值到展示文本的转换

- 支持根据字典值查找对应的展示文本（label）
- 支持根据字典类型和字典值直接查询单个字典项详情

#### 2.3.3 缓存需求

- 前端首次获取字典后应缓存数据
- 后续相同类型的请求优先返回缓存数据
- 字典数据修改后需支持手动刷新缓存
- 页面刷新后缓存清空，重新加载

## 3. 数据模型

### 3.1 字典主表

存储字典的基本信息，一个字典对应一类枚举值。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | uint | 主键，自增 | 主键ID |
| created_at | datetime | 非空 | 创建时间 |
| updated_at | datetime | 非空 | 更新时间 |
| deleted_at | datetime | 索引 | 删除时间（软删除） |
| name | varchar(255) | 非空 | 字典名称（中文） |
| type | varchar(255) | 唯一，非空 | 字典类型（英文标识） |
| status | tinyint(1) | 默认1 | 启用状态：1-启用，0-禁用 |
| desc | varchar(255) | | 字典描述说明 |

### 3.2 字典详情表

存储字典的具体选项值，与字典主表一对多关联。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | uint | 主键，自增 | 主键ID |
| created_at | datetime | 非空 | 创建时间 |
| updated_at | datetime | 非空 | 更新时间 |
| deleted_at | datetime | 索引 | 删除时间（软删除） |
| label | varchar(255) | 非空 | 展示值 |
| value | varchar(255) | 非空 | 字典值 |
| extend | varchar(255) | | 扩展值 |
| status | tinyint(1) | 默认1 | 启用状态：1-启用，0-禁用 |
| sort | int | 默认0 | 排序标记 |
| sys_dictionary_id | int | 外键，索引 | 关联字典主表ID |

### 3.3 关联关系与约束

#### ER 图

```
┌─────────────────────┐         ┌─────────────────────────┐
│   SysDictionary     │         │   SysDictionaryDetail   │
├─────────────────────┤         ├─────────────────────────┤
│ PK  id              │◄───────│ FK  sys_dictionary_id   │
│     created_at      │   1:N   │     created_at          │
│     updated_at      │         │     updated_at          │
│     deleted_at      │         │     deleted_at          │
│     name            │         │     label               │
│ UQ  type            │         │     value               │
│     status          │         │     extend              │
│     desc            │         │     status              │
│                     │         │     sort                │
└─────────────────────┘         └─────────────────────────┘
```

#### 索引设计

| 表名 | 索引名 | 字段 | 类型 | 说明 |
|------|--------|------|------|------|
| sys_dictionaries | PRIMARY | id | 主键 | |
| sys_dictionaries | idx_deleted_at | deleted_at | 普通索引 | 软删除查询优化 |
| sys_dictionaries | type | type | 唯一索引 | 字典类型唯一性 |
| sys_dictionary_details | PRIMARY | id | 主键 | |
| sys_dictionary_details | idx_deleted_at | deleted_at | 普通索引 | 软删除查询优化 |
| sys_dictionary_details | idx_sys_dictionary_id | sys_dictionary_id | 普通索引 | 外键关联查询优化 |

#### 关联关系

- **一对多关系**：一个字典可以包含多个字典项
- **级联删除**：删除字典时，自动删除其关联的所有字典项
- **软删除**：采用软删除机制，保留数据可追溯

## 4. 接口契约

### 4.1 通用规范

#### 认证方式

- JWT Token 认证
- 请求头：`Authorization: Bearer {token}`

#### 响应格式

统一 JSON 格式：

```json
{
  "code": 0,
  "data": {},
  "msg": "操作成功"
}
```

#### 错误码定义

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 7 | 参数错误 |
| 10001 | 数据库错误 |
| 10002 | 记录已存在 |
| 10003 | 记录不存在 |

### 4.2 字典管理接口

#### 4.2.1 创建字典

| 项目 | 内容 |
|------|------|
| 端点 | `/sysDictionary/createSysDictionary` |
| 方法 | POST |
| 权限 | 需认证 + 操作记录 |

**请求参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 字典名称 |
| type | string | 是 | 字典类型（英文，全局唯一） |
| status | bool | 否 | 启用状态，默认true |
| desc | string | 否 | 描述 |

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "name": "性别",
    "type": "gender",
    "status": true,
    "desc": "用户性别字典"
  },
  "msg": "创建成功"
}
```

**业务规则：**
- Type 字段全局唯一，重复时返回错误

#### 4.2.2 删除字典

| 项目 | 内容 |
|------|------|

### 5.2 字典项管理页面

用于更详细的字典项管理，支持完整的数据操作和筛选功能。

#### 5.2.1 功能需求

- 展示字典项列表，支持分页
- 支持按展示值、字典值、状态、所属字典等字段筛选
- 支持字典项的增删改查操作

#### 5.2.2 交互需求

- 列表按排序字段升序展示
- 提供新增、编辑、删除按钮
- 编辑时支持修改所有字段

### 5.3 字典消费端使用方式

#### 5.3.1 下拉选择使用

在表单中使用字典作为下拉选项：

- 通过字典类型获取选项列表
- 选项展示为 label，提交值为 value
- 支持下拉搜索（当选项较多时）

#### 5.3.2 数据展示使用

在表格或详情页中展示字典值对应的文本：

- 根据字典值查找对应的展示文本
- 支持自定义值字段名和标签字段名

#### 5.3.3 缓存使用策略

- 首次获取字典后缓存到内存
- 后续相同类型的请求优先使用缓存
- 提供刷新机制，支持手动刷新指定字典
- 页面刷新后缓存清空

| 字段 | 说明 |

| 操作人 | 当前登录用户 |

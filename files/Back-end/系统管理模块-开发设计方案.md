## 一、概述

### 1.1 模块定位

系统管理模块是 OMC 平台的核心基础模块，负责用户认证、授权、权限控制、组织架构管理、日志审计等核心功能。

### 1.2 功能域

| 子模块 | 功能说明 | 优先级 |
|--------|---------|--------|
| **用户管理** | 用户 CRUD、密码重置、状态管理、导入导出 | P0 |
| **角色管理** | 角色 CRUD、权限分配、数据权限配置 | P0 |
| **菜单管理** | 菜单树、权限标识、前端路由配置 | P0 |
| **字典管理** | 数据字典、枚举值管理 | P1 |
| **参数管理** | 系统参数配置 | P1 |
| **日志管理** | 登录日志、操作日志、任务日志 | P0 |
| **国际化** | 多语言配置管理 | P2 |

### 1.3 与现有代码的差异

| 功能 | 现有实现 | 需要调整 |
|------|---------|---------|
| 用户/角色/权限 | ✅ 已有 (users/roles/permissions) | 对接现有表结构 |
| 设备组 | ✅ 已有 (topology 模块) | 关联 sys_device_group |
| 数据权限 | ❌ 无 | 新增网络类型+设备组组合权限 |
| 字典/参数 | ❌ 无 | 新增 |
| 日志 | ✅ 已有 (audit_logs) | 扩展登录日志、任务日志 |

### 5.2 数据权限实现

```go
// internal/admin/data_permission.go
package admin

import (
	"context"
	"github.com/google/uuid"
	"github.com/omcgo/omcgo/internal/core/model"
)

// DataPermissionFilter 数据权限过滤器
type DataPermissionFilter struct {
	DeviceIDs   []uuid.UUID       `json:"device_ids,omitempty"`
	Technologies []string          `json:"technologies,omitempty"`
	Carrier     *model.CarrierCode `json:"carrier,omitempty"`
}

// DataPermissionChecker 数据权限检查器
type DataPermissionChecker struct {
	userRepo    UserRepository
	roleRepo    RoleRepository
	groupRepo   DeviceGroupRepository // 复用 topology 模块
}

// GetDataPermissions 获取用户数据权限
func (c *DataPermissionChecker) GetDataPermissions(
	ctx context.Context,
	userID uuid.UUID,
) (*DataPermissionFilter, error) {
	user, err := c.userRepo.GetByID(ctx, userID)
	if err != nil {
		return nil, err
	}

	// 超级管理员不受限制
	if c.isSuperAdmin(user) {
		return &DataPermissionFilter{}, nil
	}

	filter := &DataPermissionFilter{}

	// 获取用户角色
	roles, err := c.userRepo.GetRoles(ctx, userID)
	if err != nil {
		return nil, err
	}

	// 收集设备组权限
	for _, role := range roles {
		for _, groupID := range role.DeviceGroups {
			members, err := c.groupRepo.ListDeviceIDs(ctx, groupID)
			if err != nil {
				continue
			}
			filter.DeviceIDs = append(filter.DeviceIDs, members...)
		}
		// 收集网络类型权限
		filter.Technologies = append(filter.Technologies, role.Technologies...)
	}

	// 用户绑定的运营商
	if user.Carrier != nil {
		filter.Carrier = user.Carrier
	}

	return filter, nil
}

func (c *DataPermissionChecker) isSuperAdmin(user *User) bool {
	for _, role := range user.Roles {
		if role.Name == "admin" || role.Name == "super_admin" {
			return true
		}
	}
	return false
}
```

### 5.3 权限检查中间件

```go
// internal/admin/middleware.go

// RequirePermission 功能权限检查
func RequirePermission(permCode string) gin.HandlerFunc {
	return func(c *gin.Context) {
		userID := c.GetUint("user_id")
		if userID == 0 {
			c.AbortWithStatusJSON(401, gin.H{"message": "未登录"})
			return
		}

		// 从缓存或数据库获取用户权限
		permissions, err := getUserPermissions(c.Request.Context(), userID)
		if err != nil {
			c.AbortWithStatusJSON(500, gin.H{"message": "权限查询失败"})
			return
		}

		if !hasPermission(permissions, permCode) {
			c.AbortWithStatusJSON(403, gin.H{"message": "权限不足"})
			return
		}

		c.Next()
	}
}

// RequireDataPermission 数据权限检查
func RequireDataPermission(checker *DataPermissionChecker) gin.HandlerFunc {
	return func(c *gin.Context) {
		userID := c.GetUint("user_id")
		if userID == 0 {
			c.AbortWithStatusJSON(401, gin.H{"message": "未登录"})
			return
		}

		filter, err := checker.GetDataPermissions(c.Request.Context(), userID)
		if err != nil {
			c.AbortWithStatusJSON(500, gin.H{"message": "数据权限查询失败"})
			return
		}

		// 将数据权限存入上下文，供业务逻辑使用
		c.Set("data_permission_filter", filter)
		c.Next()
	}
}
```

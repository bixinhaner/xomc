# Issue 152 私网传输提示文案修复设计

## 目标

让系统配置中的 ACS 传输地址帮助文案与 #152 修复后的真实业务规则一致：生产环境允许基站网络可达的私网地址。

## 方案

- 保留现有后端校验和 URL 构建逻辑，不回滚系统配置 MR。
- 仅修改 `system.transfer.deviceReachabilityHelp` 的中英文文案。
- 文案明确：地址必须能从设备网络访问；生产环境允许运营商网络可达的私网地址；localhost、回环、链路本地和未指定地址仍不可用。
- 在 `TransferSettings.test.tsx` 增加回归断言，锁定用户可见业务语义。

## 验证

- 先增加期望新文案的测试并确认旧代码失败。
- 修改中英文资源后确认定向测试通过。
- 运行 `npm run typecheck`，确认前端类型检查通过。

## 非目标

- 不调整私网地址的后端放行规则。
- 不修改 ACS、日志收集或 KPI 文件上报链路。
- 不回滚昨天系统配置 MR 的其他改动。

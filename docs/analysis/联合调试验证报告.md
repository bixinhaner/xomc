## 2. 发现并修复的 Bug

### Bug 1: 设备状态映射错误 (Critical)

| 项目 | 详情 |
|------|------|
| **位置** | `omcmb/webcode/src/services/api/deviceApi.ts:40-53` |
| **现象** | 所有 active 设备在前端显示为 "offline" |
| **根因** | 后端 `DeviceStatus` 使用 `"active"` 表示在线,但前端 `mapStatus()` 只匹配 `'online'`,`"active"` 走 `default` 返回 `'offline'` |
| **修复** | 在 switch 中增加 `case 'active':` → `return 'online'`,并补充所有后端状态枚举值 |

### Bug 2: 告警空列表返回 null (Moderate)

| 项目 | 详情 |
|------|------|
| **位置** | `omcgo/internal/alarm/pg_store.go` ListActive / ListHistory |
| **现象** | 无告警时 JSON 响应 `"items": null` 而非 `"items": []`,前端 `.map()` 报错 |
| **根因** | Go `var items []model.Alarm` 未初始化时为 nil,`json.Marshal` 输出 `null` |
| **修复** | return 前加 `if items == nil { items = []model.Alarm{} }` |

### Bug 3: 管理员密码哈希错误 (Critical)

| 项目 | 详情 |
|------|------|
| **位置** | `omcgo/migrations/000015_create_audit_logs.up.sql` |
| **现象** | `POST /api/v1/auth/login` 使用 admin/admin123 返回 401 |
| **根因** | 种子数据中的 bcrypt 哈希值不是 `admin123` 的正确哈希 |
| **修复** | 用 Go `bcrypt.GenerateFromPassword` 生成正确哈希并更新迁移文件 |

### Bug 4: PostgreSQL inet 类型扫描失败 (Critical)

| 项目 | 详情 |
|------|------|
| **位置** | `omcgo/internal/omcr/device/pg_repository.go` deviceColumns() |
| **现象** | 设备列表接口返回 500,日志: `cannot scan inet (OID 869) in binary format into **string` |
| **根因** | `ip_address` 列类型为 `inet`,pgx 无法直接扫描到 Go `*string` |
| **修复** | SELECT 列从 `"ip_address"` 改为 `"host(ip_address) as ip_address"`,提取主机地址为文本 |

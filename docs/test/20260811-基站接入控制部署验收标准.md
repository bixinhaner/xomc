# 基站接入控制部署验收标准

## 1. 适用范围

本标准用于 MR 556 在测试或正式环境的部署后验收，覆盖 Redmine #31672、#51449、#45094、#31732、#31675、#21156、#21155。

验收遵循一个原则：接入决定、OMC 任务和设备实际动作分别取证，不能用页面状态替代 CWMP 回执或 GPV 回读。

## 2. 前置条件

- 核对部署分支、提交、镜像摘要、容器启动时间和健康端点；
- schema/seed 执行成功；
- App、ACS、Worker、Web、NATS、Redis、PostgreSQL 正常；
- 选择一台用户明确授权的测试基站；
- 记录设备 SN、IP、ProductClass、运营商、在线、RF、激活、TAC、ECGI、GPS 和现有任务；
- 记录操作时间和执行人，确认操作结束后恢复设备原状态。

接入控制不再要求三进程 `device_access` YAML 配置，也不要求 Basic/Digest 新账号、双人审批或维护窗口。唯一业务总开关在页面操作。

## 3. 验收顺序

### 3.1 部署与权限

- 管理员可见“设备 > 接入控制”菜单；
- 页面包含接入状态、接入策略、接入名单、候选审核、动作状态五个页签；
- 运营商切换后数据作用域正确；
- 受限账号访问页面接口返回 401/403；
- 中文、英文文案完整，无硬编码或缺失 key。

### 3.2 单一业务总开关

1. 初始保持关闭；
2. 在关闭状态下创建策略草稿、发布策略并维护测试名单；
3. 确认关闭时新 Inform 兼容接入、不产生 RF 动作、普通任务不被阻断；
4. 页面开启总开关，确认无需重启服务即刻生效；
5. 验收结束后，除非用户要求保留开启，否则关闭总开关。

### 3.3 决策优先级

逐项证明：

- 黑名单命中优先于白名单和普通规则，结果为拒绝；
- 白名单命中跳过普通规则，结果为接入；
- 单条规则多条件按 AND，多条规则按 OR；
- 无已发布策略、无适用规则或无规则命中时拒绝；
- SN、IP、ProductClass、TAC、ECGI、GPS 条件可判定；
- 多小区 TAC/ECGI 和 GPS 缺失时可由 Inform/GPV 补齐；
- 决定详情展示实际使用的证据、规则版本、原因和时间。

### 3.4 名单与候选

- 新增、停用、重新启用、删除白名单和黑名单记录；
- 校验设备名称/ProductClass 等必要展示信息；
- 未知设备形成候选，可审核进入白名单或黑名单；
- 删除、停用确认信息明确，操作后列表与接口一致；
- 不执行未授权的批量名单或批量重评。

### 3.5 任务保护

- 被拒绝设备创建普通任务时被阻止；
- 已创建但执行前变为拒绝的普通任务在出队时再次被阻止；
- 已接入设备可创建并执行普通任务；
- 接入证据 GPV、RF_OFF/RF_ON 及其回读任务不被普通任务保护反向阻断。

### 3.6 真实 RF 闭环

对唯一授权设备执行：

1. 记录 RF 原值；
2. 通过黑名单或拒绝规则触发拒绝决定；
3. 记录 RF_OFF 动作、任务 ID 和出队状态；
4. 保存 ACS 发出的 SPV 请求及设备响应；
5. 保存随后 GPV 请求、响应和回读值；
6. 确认页面动作状态与设备事实一致；
7. 将设备改为接入，确认只有存在接入控制 RF_OFF 所有权时才触发 RF_ON；
8. 保存 RF_ON 的 SPV、GPV 和最终状态；
9. 再次回读并确认设备恢复到操作前状态。

任一环节没有设备回执或 GPV 回读，只能标记“阻塞/未执行”，不得包装成通过。

### 3.7 可靠性

- 重复 Inform/重复事件不创建重复 RF 动作；
- outbox 失败可幂等重试；
- 进程重启后未完成动作可继续收敛；
- 页面、API、数据库、任务记录和 CWMP 记录可以按 device/decision/action/task ID 关联。

## 5. 证据清单

- 部署提交、镜像摘要、配置摘要、容器和 healthcheck；
- 浏览器页面与 Network 请求；
- API 请求/响应与权限负例；
- 策略、名单、候选、决定、证据、动作、outbox 数据库记录；
- 普通任务创建和出队记录；
- ACS CWMP SPV/GPV 请求与设备响应；
- RF 操作前、关闭后、恢复后的设备回读；
- 清理测试数据和关闭业务总开关的记录。

## 6. 结论规则

- 每项只能标记“通过、失败、阻塞、未执行”；
- 真实 RF 关闭、设备回执、GPV 回读和恢复任一缺失，完整验收不通过；
- 发现失败项时记录现象、证据、影响和修复建议；
- 最终只保留一份与当前部署提交对应的正式 104 验收报告，阶段性报告不进入 MR。

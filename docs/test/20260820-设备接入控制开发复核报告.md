## 1. 复核范围

本轮只复核老项目基站接入控制核心业务及其必要可靠性、安全和审计闭环：

- 运营商开关、身份归属、未知设备候选；
- 黑名单直拒并去激活、白名单直通允许激活、吊销名单；
- 名单多 SN、模板、预检、追加/覆盖、失败明细、原子提交、批次回滚和批量停用；
- 策略草稿、编辑、发布、退役、差异、回滚和规则优先级；
- SN、TAC、ECGI、IP 起止范围、GPS 矩形范围、无邻区/无 GPS 分支；
- 决定、普通任务门禁、RF 动作、回读、重试、离线等待、重启恢复、死信和人工重试；
- 身份/证据/决定/动作/通知/人工操作审计、运营商和设备组隔离；
- 电子围栏 RF 激活门禁。

未扩展邮件/短信供应商、多级审批、高级规则编排、V2/V3 皮肤和 EGW/ECI 接入控制。

## 2. 本轮复核修正

1. 未知但不歧义的 OUI/ProductClass 归属失败不再提前丢弃 Inform，按部署默认运营商进入候选；歧义归属仍拒绝回退。
2. RF 安全任务从“任一合法 RF 路径”收紧为“必须等于动作持久化的目标路径集合”，拒绝空路径、重复路径和跨路径替换。
3. 规则维度 CSV 防公式注入保持导出可安全打开，并修复负经纬度被转义后无法回导的问题，增加 GPS 导出到导入回环测试。
4. 恢复状态详情接口原有的决定、当前证据和动作集合，保留新增分页接口的同时避免破坏旧调用方。
5. 动作完成回调绑定持久化任务 ID、命令和方法，过期或被替代的任务不能完成当前安全动作。
6. 策略历史依赖增加空依赖保护，避免错误配置时空指针崩溃。
7. 未知候选拒绝时不再因缺少正式 `device_id` 跳过 RF 动作；新增受限候选端点，只允许 GPV 基线/回读和 RF 关闭，不允许 RF 开启或普通任务。
8. 候选端点持久化最近 Inform 中的制式和 RF 控制路径，动作继续执行基线回读、精确路径 SPV、结果回读和重试/死信闭环。
9. 已验证隔离所有权不会丢失：候选后续被允许且已建立正式设备时，候选、当前状态和 RF 动作在同一事务内转移到正式设备，仅恢复接入控制已确认关闭的路径。
10. 候选安全动作在 ACS 出队时强制校验已认证会话，并按 SN、OUI、ProductClass、session ID 和 request ID 绑定；身份不一致时拒绝执行。
11. 候选会话断开或任务失败后进入 `retry_wait`，清除旧会话绑定；协调器重新入队后，只能由下一次相同身份且已认证的 Inform 会话继续执行。
12. 型号或运营商没有可用 RF 控制路径时，动作进入 `dead`，稳定记录 `containment_not_supported`，不写入 RF 隔离成功和所有权。
13. 最终差异复核未发现 EGW/ECI、邮件短信供应商、V2/V3 皮肤或普通设备管理扩展；跨模块修改仅保留 Inform 身份、任务门禁、电子围栏激活门禁和动作通知关联。
14. 裁掉候选 RF 控制路径、候选 OUI、绑定 session/request ID 的 API 序列化暴露；这些字段只用于服务端安全执行和审计，不进入管理面响应。
15. 清理 `session.go` 的纯格式变更，并修正未知身份进入候选审核的装配注释，减少无业务意义差异。

# 角色管理功能设计文档

## 1. 页面概述

角色管理页面用于管理系统中的角色信息，角色用于控制用户的操作权限。支持对角色进行创建、编辑、删除、查看等操作。

## 2. 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| 操作 | - | 100px | 操作菜单（查看/修改/删除） |
| 角色名称 | role_name | 200px | 角色名称，内置角色显示蓝色"内置"标签 |
| 支持批量 | batch_operation | 120px | 是/否 |
| 操作人 | user | 150px | 最后修改人 |
| 更新时间 | update_time | 180px | 最后更新时间 |
| 描述 | desc | 自适应 | 角色描述信息 |

## 3. 搜索条件

| 字段名 | 字段标识 | 类型 | 说明 |
|--------|----------|------|------|
| 角色名称 | role_name | 输入框 | 模糊搜索，支持回车查询 |

## 4. 工具栏按钮

| 按钮名称 | 图标 | 权限控制 | 说明 |
|----------|------|----------|------|
| 搜索 | el-icon-common-search | - | 按角色名称搜索 |
| 添加 | PlusOutlined | CODE_SYSTEM_USERS_ROLE | 新增角色 |

## 5. 列表操作

每行数据有一个操作菜单（更多按钮），包含以下操作项：

| 操作名称 | 说明 | 权限控制 | 条件 |
|----------|------|----------|------|
| 查看 | 查看角色详细信息（只读模式） | - | 所有角色可查看 |
| 修改 | 修改角色信息 | CODE_SYSTEM_USERS_ROLE | 有写权限，非内置角色 |
| 删除 | 删除角色 | CODE_SYSTEM_USERS_ROLE | 有写权限，非内置角色 |

## 6. 批量操作

勾选多条记录后，底部显示批量操作栏：

| 操作名称 | 说明 | 条件 |
|----------|------|------|
| 删除 | 批量删除选中角色 | 非内置角色 |
| 取消 | 取消选择 | - |

## 7. 添加/修改角色

通过抽屉（Drawer）进行角色信息的添加和修改，宽度520px。

### 7.1 基本信息

| 字段名 | 必填 | 类型 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| 角色名称 | 是 | Input | 最大200字符，不能重复 | 添加时可编辑，修改时只读 |
| 支持批量 | 否 | Switch | - | 是否支持批量操作，默认否 |
| 描述 | 否 | TextArea | 最大500字符 | 角色描述信息 |
| 设备组 | 否 | Select多选 | - | 选择关联的设备组，支持搜索 |

### 7.2 权限配置

权限配置以树形结构展示，每个功能模块包含以下权限级别：

#### 权限类型

| 权限类型 | 标识 | 说明 |
|----------|------|------|
| 只读 | read | 只能查看数据，不能修改 |
| 读写 | write | 可以查看和修改数据 |

#### 功能模块列表

| 模块名称 | 权限项 | 说明 |
|----------|--------|------|
| 设备管理 | 只读/读写 | 设备列表、设备详情、配置管理 |
| 告警管理 | 只读/读写 | 告警列表、告警确认、告警清除 |
| 性能管理 | 只读/读写 | 性能数据查看、导出、采集配置 |
| 软件版本 | 只读/读写 | 版本列表、上传固件、发起升级 |
| 文件管理 | 只读/读写 | 文件列表、上传、下载、删除 |
| 日志管理 | 只读/读写 | 日志查看、导出、配置 |
| 系统管理 | 只读/读写 | 用户、角色、用户组、系统配置 |
| 报表管理 | 只读/读写 | 报表查看、生成、下载 |
| 运维工具 | 只读/读写 | 模板管理、命令执行、网络诊断 |

#### 权限配置规则

1. **目录级联**：勾选目录时自动勾选所有子项
2. **读写联动**：勾选"读写"时自动勾选"只读"
3. **取消只读**：取消"只读"时同时取消"读写"
4. **必选权限**：首页/Dashboard默认勾选且不可取消

### 7.3 设备组选择

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 设备组 | Select多选 | 选择角色可访问的设备组，支持搜索过滤 |

**数据来源**：设备组树（二级节点）

**交互说明**：
- 多选模式，可选择多个设备组
- 支持按设备组名称搜索
- 必须至少选择一个设备组

## 8. 查看角色

查看角色以只读模式展示角色信息，包含以下内容：

### 8.1 基本信息

| 字段名 | 说明 |
|--------|------|
| 角色名称 | 只读显示 |
| 支持批量 | 标签显示（是/否） |
| 描述 | 只读显示 |
| 设备组 | 以标签形式显示已选设备组 |
| 用户数 | 关联的用户数量 |
| 操作人 | 最后修改人 |
| 更新时间 | 最后更新时间 |

### 8.2 权限配置

以只读树形结构展示已配置的权限，显示只读/读写状态。

## 9. 支持批量字段说明

| 值 | 显示文本 |
|----|----------|
| 1 | 是（绿色标签） |
| 0 | 否（默认标签） |

## 10. 内置角色说明

内置角色的复选框不能勾选，无法批量删除，无法修改。

| 类型 | 说明 | 可操作 |
|------|------|--------|
| 内置角色 | 系统默认角色（built_in=1或2） | 仅可查看 |
| 自定义角色 | 用户创建的角色（built_in=0） | 可修改、可删除 |

## 11. API 接口

### 11.1 获取角色列表

```
GET /sys/role/getRoleSet.action
```

**请求参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 是 | 页码 |
| rows | int | 是 | 每页条数 |
| role_name | string | 否 | 角色名称（模糊搜索） |

### 11.2 获取功能权限树

```
GET /sys/role/getFeature.action
```

**请求参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | string | 是 | add/modify/view |
| role_id | string | 条件 | 角色ID（modify/view时必填） |
| operator_code | string | 是 | 操作员代码 |

### 11.3 获取设备组树

```
GET /sys/role/getDeviceGroup.action
```

**请求参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | string | 是 | add/modify/view |
| role_id | string | 条件 | 角色ID（modify/view时必填） |
| operator_code | string | 是 | 操作员代码 |

### 11.4 保存角色

```
POST /sys/role/save.action
```

**请求参数**（JSON）：
```json
{
  "role_name": "角色名称",
  "role_desc": "描述",
  "menu_ids": [
    {"id": "menu_id_1", "write": true},
    {"id": "menu_id_2", "write": false}
  ],
  "device_group_ids": "group_id_1,group_id_2",
  "operator_code": "operator",
  "type": "add"
}
```

**修改时额外参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| role_id | string | 是 | 角色ID |
| type | string | 是 | 固定为"modify" |

### 11.5 删除角色

```
POST /sys/role/deleteRoleForUI.action
```

**请求参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ids | string | 是 | 角色ID列表，逗号分隔 |

### 11.6 校验角色名称

```
POST /sys/role/checkRoleName.action
```

**请求参数**：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| roleName | string | 是 | 角色名称 |

**返回**：
- success: true - 名称可用
- success: false - 名称已存在

## 12. 权限控制

| 权限码 | 说明 |
|--------|------|
| CODE_SYSTEM_USERS_ROLE | 角色管理权限 |

### 权限级别

| 权限值 | 说明 | 可执行操作 |
|--------|------|------------|
| true | 读写权限 | 查看、修改、删除 |
| false | 只读权限 | 仅查看 |
| 无权限 | 不可访问 | - |

## 13. 交互说明

### 新增角色
1. 点击工具栏"添加"按钮
2. 在抽屉中填写角色名称、描述
3. 选择是否支持批量操作
4. 选择关联的设备组（至少选择一个）
5. 配置功能权限（至少选择一个）
6. 点击"确定"保存
7. 保存成功后显示成功提示，1.5秒后自动关闭抽屉

### 修改角色
1. 点击操作菜单中的"修改"
2. 在抽屉中修改角色信息（角色名称不可修改）
3. 可调整设备组和权限配置
4. 点击"确定"保存

### 删除角色
1. 单个删除：点击操作菜单中的"删除"
2. 批量删除：勾选多个角色后，点击底部"删除"按钮
3. 确认删除提示后执行删除
4. 内置角色无法删除

### 查看角色
1. 点击操作菜单中的"查看"
2. 在抽屉中查看角色详细信息（只读模式）
3. 显示关联的用户数量

## 14. 表单校验

### 角色名称
- 必填
- 最大长度200字符
- 不能与已有角色名称重复

### 功能权限
- 必须至少选择一个权限项

### 设备组
- 必须至少选择一个设备组

## 15. 关联关系

角色与用户组、用户、设备组之间存在以下关联关系：

```
角色 ←→ 用户组 ←→ 用户
角色 ←→ 设备组
```

- 一个角色可以关联多个用户组
- 一个用户组可以关联多个角色
- 一个用户组可以包含多个用户
- 一个用户可以属于多个用户组
- 一个角色可以关联多个设备组

# 报表管理

## 概述
报表管理模块提供网络运维数据的报表查询与导出功能，支持 LTE 标准报表、LTE 基站报表、历史指标查询及轮询统计等维度的数据分析。
- 涉及系统：jx

---

## 一、Comba UMS (jx) — 报表模块总览

### 来源
- 系统：Comba UMS
- 截图文件：jx/Dingtalk_20260228100840.jpg（二级Tab完整展示）

### 导航结构
- **顶部主导航**: `系统` | `配置` | `告警` | `性能` | `报表`（红色下划线高亮）
- **二级Tab页签**: `首页` | `获取配置文件` | `获取日志文件` | `网元版本查询升级` | `升级软件计划` | `激活软件计划` | `告警监控` | `告警同步` | `当前告警统计` | `历史告警查询` | `LTE 标准报表` | `LTE基站报表` | `历史指标查询` | `轮询统计`
- 报表相关Tab共4个：`LTE 标准报表`、`LTE基站报表`、`历史指标查询`、`轮询统计`

## 二、Comba UMS (jx) — 轮询统计

### 2.1 轮询统计 — 分组统计（按区域）

#### 来源
- 截图文件：jx/Dingtalk_20260228100624.jpg, jx/Dingtalk_20260228100636.jpg, jx/Dingtalk_20260228100645.jpg

#### 页面布局
- 左中右三栏布局:
  - 左侧 (约15%): 树形菜单导航
  - 中间 (约50%): 数据表格区域
  - 右侧 (约35%): 图表面板（点击行后弹出）

#### 导航元素
- **顶部主导航**: `系统` | `配置` | `告警` | `性能` | `报表`（高亮）
- **二级Tab页签**: 完整14个Tab，`轮询统计`（绿色高亮，最后一个Tab）
- **左侧树形菜单**:
  - 轮询统计
    - 统计
      - 分组统计（展开）
        - `按区域`（蓝色高亮）
        - `按类型`
        - `按生产厂家`
        - `按代理厂家`

#### 筛选条件
| 筛选项 | 类型 | 说明 |
|--------|------|------|
| * 启动时间 | 日期范围选择器 | 起止时间，如 2026-02-21 至 2026-02-28，必填字段 |

#### 数据表格列
| 列名 | 说明 |
|------|------|
| 分组 | 分组名称（如区域名称：成都市、无区域），带展开/折叠箭头 |
| 轮询网元数 | 参与轮询的网元总数 |
| 成功网元数 | 轮询成功的网元数量 |
| 失败网元数 | 轮询失败的网元数量 |
| 轮询成功率 | 百分比 (如 0%) |
| 成功网元总次数 | 轮询成功的累计次数 |
| 失败网元总次数 | 轮询失败的累计次数 |
| 轮询平均成功率 | 平均成功率百分比 |

#### 操作按钮
| 按钮 | 说明 |
|------|------|
| 导出 | 导出报表数据 |
| 刷新 | 刷新当前数据 |

#### 表格行展开
- 点击分组行前的展开箭头可显示下辖子区域明细
- 示例（"成都市"展开后）：市辖区、锦江区、青羊区、金牛区、武侯区、成华区、龙泉驿区、青白江区、新都区、温江区、双流区、郫都区、金堂县、大邑县、蒲江县、新津县、都江堰市、彭州市、邛崃市、崇州市、简阳市、东部新区、天府新区

#### 右侧图表面板
- **触发方式**: 点击表格行后在右侧弹出
- **图表类型**: 柱状图 + 折线图复合
- **图例**:
  - 成功网元数（红色柱状）
  - 失败网元数（蓝色柱状）
  - 轮询成功率（绿色折线）
- **坐标轴**:
  - X轴：子区域名称（如 市辖区）
  - Y轴左：数量（0-1）
  - Y轴右：百分比（0%-1%）

#### 表单/弹窗
- 无

## 四、通用交互特性

| 特性 | 描述 |
|------|------|
| 日期范围选择 | 轮询统计使用日期范围选择器作为必填筛选条件 |
| 树形分组导航 | 左侧树形菜单支持按区域/类型/生产厂家/代理厂家切换分组维度 |
| 表格行展开 | 分组行支持点击展开查看下辖子分组明细 |
| 图表联动 | 点击表格行后右侧弹出对应的柱状图+折线图复合图表 |
| 数据导出 | 各统计页面均提供导出按钮 |
| 分页器 | 无独立分页器（轮询统计数据量通常直接展示） |

# 即插即用文档

本目录集中维护 OMC 即插即用功能的跨前后端方案和交付模板。

## 目录结构

- `design/`：需求、目标状态、差异分析、编排方案和后续设计决策。
- `templates/`：4G/5G 参数配置模板原件及模板使用说明。
- `references/`：运营商技术要求、XML 样例和 TR 路径等实现参考资料。

## 运行时模板

前端下载入口使用 `omcmb/webcode/public/templates/` 下的运行时副本。修改模板时，应先更新本目录中的归档原件，再同步运行时副本，并确认两份文件 SHA-256 一致。

# LTE 参数配置快速设置对齐处理总结

## 1. 处理范围

- 处理日期：2026-08-05
- 功能范围：即插即用策略编辑页的 LTE（eNB）参数自配置抽屉
- 对齐基准：设备详情页 LTE 快速设置的 BLQ 主体字段定义
- 目标：字段、顺序、三列排版、控件类型及中英文文案与快速设置一致；模板独有字段统一置后

## 2. 最终方案

新增 `enbQuickSettingsFields.ts` 作为 LTE 页面字段的唯一元数据来源，并由 `EnbQuickSettingsCards.tsx` 统一渲染。主体分组顺序固定为：

1. 小区参数（14 个字段）
2. 服务 PLMN 列表
3. MME IP+PLMN 列表
4. 时间与同步（7 个字段）
5. IPSec 配置
6. IPSec 参数（21 个快速设置字段）

小区参数、时间与同步、IPSec 的字段顺序均按快速设置字典固化。带宽、子帧配比、特殊子帧、小区类型、同步源及开关使用对应语义控件；只读的频段支持保持只读；本地时区复用统一时区选项。

联动显示规则与设备快速设置保持一致：IPSec 开关关闭时隐藏 IPSec 参数；同步源不是 PTP（1588）时隐藏 1588 模板参数。隐藏只影响页面展示，不清空已经填写的值。

## 3. 模板扩展与保存

4G Excel 模板独有的以下参数放在快速设置主体之后：小区数量、HaloB、业务/OMC IP、1588 配置。IPSec 模板独有列因属于多实例隧道行，放在每条隧道的“隧道模板扩展参数”区，确保实例关系不丢失。

模板已有字段继续写回 `sheetParameters`；快速设置独有字段（例如频段支持、小区类型、功率等级、同步源及 NTP 服务器 2～5）作为策略直接字段保留。合并表单和模板回填时不会覆盖这些直接字段。

## 4. 国际化与回归约束

中英文资源已补齐全部 LTE 分组、字段、选项及模板扩展标签。测试固定以下规则：

- 6 个主体分组及各组字段顺序；
- 关键字段的选择、开关和只读控件类型；
- 模板扩展字段与快速设置字段分离；
- 所有标签在中英文资源中存在；
- 快速设置独有字段与模板字段合并保存后均不丢失。

## 6. 维护约束

LTE 快速设置字段变化时优先修改 `enbQuickSettingsFields.ts`；新增用户可见字段必须同步补齐中英文资源和字段顺序/i18n 测试。模板新增字段先判断是否属于快速设置，非快速设置字段继续放在主体分组之后。

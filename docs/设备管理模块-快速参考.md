## 🗄️ 数据库表关系

```
┌─────────────────────────────────────────┐
│ devices (分区表: cmcc/ctcc/cucc)        │
├─────────────────────────────────────────┤
│ id (UUID) PK, carrier                   │
│ serial_number UNIQUE(sn, carrier)       │
│ site_name, manufacturer, product_class  │
│ status, firmware_version, ip_address    │
│ latitude, longitude, created_at         │
└──────────────────┬──────────────────────┘
                   │
                   ├─ (1:N) 
                   │
        ┌──────────┴────────────┐
        │                       │
┌───────▼──────────┐  ┌────────▼────────────────┐
│ device_info      │  │ device_group_members   │
├──────────────────┤  ├─────────────────────────┤
│ device_id FK     │  │ group_id FK PK          │
│ up_time          │  │ device_id FK PK        │
│ online_duration  │  │ added_at                │
│ ... 60+ fields   │  │ UNIQUE(device_id)       │
└──────────────────┘  └────────┬────────────────┘
                               │
                               └─ (N:1)
                                  │
                          ┌───────▼──────────────┐
                          │ device_groups       │
                          ├────────────────────┤
                          │ id (UUID) PK        │
                          │ name UNIQUE(name,   │
                          │   coalesce(parent)) │
                          │ parent_id FK        │
                          │ level (1 or 2)      │
                          │ is_default          │
                          │ status, remark      │
                          │ created_by/updated_by
                          │ created_at/updated_at
                          └────────────────────┘
```

### 核心约束

```sql
-- 层级约束
CHECK (level IN (1, 2))

-- 层级与父子一致性
CHECK ((level = 1 AND parent_id IS NULL) 
    OR (level = 2 AND parent_id IS NOT NULL))

-- 同一父节点下名称唯一
UNIQUE INDEX (name, COALESCE(parent_id, '00000000...'))

-- 设备只能在一个分组
UNIQUE (device_id)
```

## 📌 重要提醒

### 命名规范

- **前端:** camelCase (deviceId, siteName, createdAt)
- **后端:** snake_case (device_id, site_name, created_at)
- **自动转换:** HTTP拦截器自动处理转换，无需手动处理

### 分组层级约束

- **L1 (一级):** 
  - parentId = null
  - level = 1
  - 作为分类主节点
  
- **L2 (二级):**
  - parentId = L1的ID
  - level = 2
  - 存储实际设备

- **默认组:**
  - 默认设备组 (ID: 00000000-0000-0000-0000-000000000001) — L1
  - 未分组设备 (ID: 00000000-0000-0000-0000-000000000002) — L2

### 权限管理

- 所有设备查询受用户权限限制
- 用户只能看到其角色有权限的分组内设备
- 后端自动在WHERE子句中注入权限过滤

### 唯一性约束

- **SN唯一:** (serial_number, carrier) 唯一索引
- **分组名称唯一:** 同一父节点下名称唯一
- **设备分组唯一:** 一个设备只能在一个分组中

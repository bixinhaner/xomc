# Milestone: 2026 Q2 — Beta → RC 冲刺

**Codename**：To-RC  
**窗口**：2026-04-20 起，14 周（~2026-07-27 目标达成）  
**目标**：从 Beta 阶段收敛至 RC（Release Candidate），闭合 5 个 P0 短板  
**守护人**：项目经理（`CLAUDE.md §16.11`）

---

## 1. 里程碑目标

用一句话定义：**在 14 周内关闭 5 个 P0 风险，使 OMC 达到运营商试点部署（≤10,000 基站）的商用就绪状态**。

达成后，可用于单运营商的小规模试点：
- 告警全链路可送达运维
- E2E 回归可守门（≥200 用例）
- 数据库迁移可在新环境一键初始化
- 事件总线支持分布式（不受单进程限制）

**未达成项（GA 阶段再解决）**：F08 OSS 协议栈多协议支持、多级聚合、数据分析能力、GA 级可观测性大盘。

## 3. 退出标准（Exit Criteria）

14 周窗口结束时，以下全部满足方视为 RC 达成：

### 3.1 功能闭环
- [ ] 端到端告警场景：CPE 触发 → ACS 接收 → alarm 入库 → 通知渠道送达（邮件+Webhook 必达，短信 Best Effort）
- [ ] F08 SNMP Trap 至少一家运营商 OSS 对接联调通过（staging）
- [ ] 事件总线 NATS JetStream：F04 通知、F08 推送、transfer 三个模块已切换

### 3.2 质量闭环
- [ ] E2E 核心用例 ≥ 200 条全绿
- [ ] 单元测试覆盖率 ≥ 70%
- [ ] 压测基线（10K 设备 / 3K 并发）通过，P95 延迟不回退
- [ ] 所有 P0 风险在 `risk-register.md` 中状态为 Closed

### 3.3 流程闭环
- [ ] `docs/project/dod.md` 在至少 10 个 PR 中被实际使用（勾选率 > 95%）
- [ ] `docs/project/release-gate.md` 至少执行过 1 次完整演练（staging 发布）
- [ ] CI 中迁移编号检查、E2E 阈值、覆盖率阈值均已启用
- [ ] Sprint 承诺完成率平均 > 75%

### 3.4 可观测性闭环
- [ ] Prometheus + Grafana + AlertManager 三件套可一键拉起
- [ ] 关键告警规则至少 10 条（ACS 会话异常/队列积压/通知失败率等）
- [ ] 故障 Runbook 至少覆盖 5 个常见场景

## 4. Sprint 拆解（滚动规划）

Sprint 为 2 周一个周期，编号 01-07 覆盖 14 周。详细承诺见各 `docs/project/sprint/sprint-NN.md`。

| Sprint | 周 | 主题 | 关键交付 |
|--------|---|------|---------|
| 01 | 1-2  | 基建周 | 流程体系落地 + 迁移修复 + R-001 邮件通道 + 监控栈 + E2E 首批 20 用例 |
| 02 | 3-4  | 基础设施 | NATS JetStream 事件总线 + Webhook 通道 + worker 重试 + E2E 累计 40 |
| 03 | 5-6  | 功能收尾 1 | SNMP Trap 骨架 + 短信通道 + License 容量拦截 + 前端 Backup 业务逻辑 + E2E 60 |
| 04 | 7-8  | 功能收尾 2 | SNMP Trap 联调 + Software 灰度策略 + 前端 Software 业务逻辑 + E2E 80 |
| 05 | 9-10 | 功能收尾 3 | F08 推送可靠性 + Software 回滚 + 前端 Topology/Report 补完 + E2E 100 |
| 06 | 11-12 | 收敛周 1 | P0 剩余项扫尾 + 压测基线 + Release Gate 演练 + E2E 150 |
| 07 | 13-14 | 收敛周 2 | RC 冻结 + 冒烟用例集 + Runbook + 发布通告 + E2E 200 |

## 5. 风险与缓解

详见 `docs/project/risk-register.md`。本里程碑特别关注：

| 风险 | 缓解策略 |
|------|---------|
| 运营商 OSS 联调延期 | Sprint-03 启动，预留 Sprint-06 作为 buffer |
| NATS 改造连带影响面过大 | 分模块切换（F04 → transfer → F08），每 sprint 切一块 |
| E2E 用例补齐节奏跟不上 | 每 sprint 强制 +20 为硬指标，不达标则退化下 sprint 新增功能 |
| 短信服务商凭据申请周期不可控 | Sprint-01 立即启动申请，Sprint-03 用不上则降级为 P1 |

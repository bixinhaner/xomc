## 5. 回滚方案

### 5.1 应用层（首版 RC，无前序版本可回滚）

- **首版**：本 RC 是 2026Q2 周期首个 RC tag，**无前序 RC**
- **若严重 bug**：建立下一个 RC（rc-2026Q2-002），不回滚到 Beta（已废弃）
- 二版起：`git checkout rc-2026Q2-{N-1}` + 重新部署

### 5.2 数据库迁移

```bash
# 撤回最新迁移
cd omcgo && make migrate-down  # 单步回滚
# 或指定版本
goose -dir migrations postgres "$DSN" down-to <version>
```

所有 44 个 migration 都有 up/down 配对（W1.4 check-migrations.sh 守门）。

### 5.3 K8s

```bash
kubectl rollout undo deployment/omcgo-app -n omc
kubectl rollout undo deployment/omcgo-acs -n omc
kubectl rollout undo deployment/omcgo-worker -n omc
```

或基于 helm release 回滚（待 helm chart PR 完成）。

### 5.4 RTO 目标

- **应用回滚**：< 5 分钟（K8s rollout undo + readiness check）
- **DB 迁移回滚**：< 1 分钟（goose down 单 ALTER）
- **整体 RTO**：< 1 小时（W3.H.3 DR Runbook 标准）

### 5.5 待 staging 实测

T-0069 W3.I.3 回滚演练（5min 内完成）需 staging 验证，本 RC 暂以 Runbook 规范为准。

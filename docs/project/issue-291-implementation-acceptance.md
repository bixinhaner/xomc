# Issue #291 实施与验收记录

## 当前方案

本轮实现严格限定为：

- 首页新增“关注事项”模块。
- 异常来自当前活跃紧急、重要告警。
- 待办来自接入控制待审核候选设备。
- 点击条目进入原业务模块处理。

不包含 Ops 运维任务审批待办，不包含新的审批流程。

## 开发验收清单

- 后端关注事项接口可返回异常和待办两类 section。
- 异常 section 带用户可见网元组过滤。
- 待办 section 只返回待审核且未过期候选设备。
- 首页每类只展示 1 条预览。
- “查看全部”打开独立分类抽屉。
- 抽屉不出现 tabs，不混合显示另一类数据。
- 异常条目跳当前告警页并打开详情。
- 待办条目跳接入控制候选页并定位候选设备。
- 暗色主题下首页卡片、抽屉卡片、分页、空态文字可读。
- 原首页 KPI、图表、网络制式等板块保持不变。

## 回归边界

- 告警确认、反确认、清除流程不变。
- 接入候选审核流程不变。
- Ops 运维任务页面不变。
- 不新增数据库迁移。

## 本地验收建议

1. 启动前后端。
2. 构造至少 1 条活跃紧急或重要告警。
3. 构造至少 1 条待审核且未过期候选设备。
4. 打开 `/dashboard`。
5. 检查关注事项模块只显示每类 1 条预览。
6. 点击异常预览，确认进入 `/alarm/current?alarmId=...` 并打开告警详情。
7. 返回首页，点击异常“查看全部”，确认抽屉只显示异常。
8. 点击待办预览，确认进入 `/device/access-control?tab=candidates...` 并定位候选设备。
9. 返回首页，点击待办“查看全部”，确认抽屉只显示待办。
10. 清空模拟数据后检查空态。

## 5. ULTRATHINK 决策 5 项

| # | 决策 | 理由 |
|---|---|---|
| ① | InstancePicker GPV 自动探测 = 简化版（indexHelp 提示+手输 fallback）| 完整 SSE 闭环需 ~200 LOC RPC 调用 + SSE 订阅 + 实例 parser；本期 indexHelp 文案已提示用户用 LST 查询实例数；完整 GPV 探测留新任务（需要后端 SSE+前端 SSE 订阅器） |
| ② | Customized 子树用 commandId=undefined Statement | mml_custom_commands 不属 catalog (无 mml_commands.id)；adapter Statement.commandId=undefined 透传到 execute-statements 走 orphan 路径 (T-0119 Sprint B-6 已实现) |
| ③ | buildCustomTreeData private 按 creator 分组 vs 平铺 | PRD §1 老 OMC 实测 PrivateTemplate 含 admin/wangyunqi123 等用户子树；保持老 UX 一致性 |
| ④ | catalog_protected 仅锁 rename/delete 不锁 addChild | 加子节点不修改 protected 自身，语义"受保护资源不可改但可扩展"；P4 batch A 时锁定 |
| ⑤ | supports_delete 🗑 留新任务 | 需要 GPV 实例列表（InstancePicker 完整版）才有地方放 🗑；与 GPV 完整闭环耦合，单独做无意义 |

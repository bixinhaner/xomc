### 2.2 拆分策略

**index.tsx（650 → 303）**：

- 把状态 + handler 拆到 `useGroupActions` / `useDeviceActions` / `useBatchActions` / `useNameFilters` / `useImportExportHandlers` 5 个 hook 文件。
- `useGroupActions` 同时持有 4 个 dialog 的 open/close 状态，让 index 通过 `groupActions.state.addModalOpen` 等访问，避免 index 维护 6 个 useState。
- `handleContextMenu`（原 65 行）压缩为 17 行的 switch dispatcher，调用 `groupActions.open.{addChild,editLevel1,editLevel2,confirmDelete}` / `deviceActions.open.addToGroup`。

**GroupDialogs.tsx（576 → 129）**：

- 4 个 dialog 拆分到独立文件：`AddGroupDrawer` / `EditGroupModal` / `AddChildGroupDrawer` / `EditLevel2GroupDrawer`。
- 共用的"设备名称匹配条件行级编辑器"（约 60 行的内联 JSX × 2）抽取到 `NameFilterEditor.tsx`，AddChild 和 EditLevel2 共用。
- `GroupDialogs.tsx` 保留原 Props 接口（向后兼容），仅作为薄装配容器，转发 props 给 4 个子文件。

**DeviceListPanel.tsx（415 → 155）**：

- 批量导入弹窗（80 行 JSX + 30 行 state/handlers）抽到 `BatchImportModal.tsx`。
- 列定义 + Remark 表头自定义标签的 localStorage state（90 行）抽到 `useDeviceColumns.tsx`。
- 主组件只剩布局壳（toolbar + DataTable + import modal 装配 + CSS）。

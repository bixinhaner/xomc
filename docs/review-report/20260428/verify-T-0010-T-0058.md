### 3.2 重构要点

`wrapHandler` 重构前后对比：

**Before**：所有逻辑（unmarshal、错误判断、deliveries 提取、backoff 计算、Ack/Nak/Term 决策）混在一起，依赖 `*nats.Msg`，无法不开 NATS server 测试。

**After**：
- `decodeEventBytes(data []byte) (Event, error)` — 纯函数，测覆盖 100%
- `decideAck(handlerErr error, deliveries, maxDelivery uint64) ackDecision` — 纯函数，测覆盖 100%
- `wrapHandler` 只负责装配 + Ack/Nak/Term 副作用调用，逻辑下沉到上述两函数

设计原则遵循"接受接口，返回结构"和"小函数 < 50 行"。

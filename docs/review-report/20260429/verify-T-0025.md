#### #18 失败根因（已确认非 smoke 缺陷）

- 本地 docker `docker-app` image 是 T-0012 commit（`0ea736a9`）**之前**的 build
- T-0012 在 commit message 标"未 commit / push / pull"，其 admin/dead-letters 路由代码在 main HEAD 已落地，但 **image 未重新 build**
- `docker restart docker-app-1` 仅重启容器进程，不触发 image rebuild
- 完整修复路径：staging CI 重 build image（go build + COPY → push → pull → up -d），属于运维 deployment lag
- **smoke 设计意图**：404 是 deployment lag 真实信号，运维看到此 fail 应触发 rebuild，**不应放宽 smoke 接受 404**（违背 smoke 严格门槛 D5）

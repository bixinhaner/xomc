# 升级文件管理页面设计文档

> 基于 `fileMgr_enb.jsp` 原始页面整理

---

## 1. 页面结构概览

升级文件管理是 eNB 升级管理页面的子页签之一，主要用于管理各类升级文件的上传、查看、下载和删除。

### 1.1 顶级页签

| 页签名称 | 说明 |
|---------|------|
| 升级&回退 | 设备升级和回退任务管理 |
| **文件** | 升级文件管理（本文档重点）|

---

## 2. 文件页签 - 子分类

文件页签下通过 **Radio Button** 切换四种文件类型：

| 子页签 | 代码值 | 文件类型参数 | 说明 |
|--------|--------|-------------|------|
| IMAGE | `upgrade` | `file_type=0` | 软件镜像升级文件 |
| CA版本 | `ca` | `file_type=1` | CA补丁升级文件（Patch） |
| FPGA升级文件 | `fpga` | `file_type=6` | FPGA固件升级文件 |
| AP升级文件 | `ap` | `file_type=11` | AP无线升级文件 |

---

## 3. 文件列表

### 3.1 列表字段

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 操作 | - | 30px | 更多操作菜单按钮 |
| 版本 | `version` | 400px | 文件版本号，推荐版本显示⭐标识 |
| 产品类型标识 | `product` | 250px | 适用产品型号（AP类型不显示） |
| 文件大小 | `size` | 200px | 文件大小 |
| 版本类型 | `toWho` | 200px | 商用版本/测试版本/Beta版本（仅云核心网环境显示） |
| 上传时间 | `upload_time` | - | 文件上传时间 |

### 3.2 版本推荐标识

推荐版本在版本号后显示星形标识：
```
版本号 ⭐
```

## 6. 导入文件侧边栏

点击"导入文件"按钮后，右侧弹出导入文件表单。

### 6.1 侧边栏布局

```
┌─────────────────────────────────────┐
│ [标题]                      [关闭] │
├─────────────────────────────────────┤
│                                     │
│        表单内容区域                 │
│                                     │
├─────────────────────────────────────┤
│           [确定] [取消]             │
└─────────────────────────────────────┘
```

### 6.2 IMAGE 文件表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 产品类型标识 | 多选下拉 | ✅ | 选择适用的产品型号（支持多选） |
| 文件名 | 文件上传 | ✅ | 支持 tar.gz / IMG / EXT 格式 |
| 版本 | 文本输入 | ✅ | 1-45字符，版本唯一性校验 |
| 版本类型 | 下拉选择 | - | 商用版本(all) / 测试版本(none) / Beta版本(beta) |
| 推荐 | 下拉选择 | - | 是(1) / 否(0) |
| 描述 | 多行文本 | - | 文件描述信息 |

**文件格式提示**：
- tar.gz 格式：`升级支持格式`
- IMG/EXT 格式：`只支持IMG和EXT格式`
- IMG 格式：`支持IMG格式`

## 7. API 接口

### 7.1 文件列表查询

| 接口 | URL |
|------|-----|
| IMAGE | `/cell/version/queryfileInfosList.action?file_type=0&isMultiProductType=true` |
| CA版本 | `/cell/version/queryfileInfosList.action?file_type=1` |
| FPGA | `/cell/version/queryfileInfosList.action?file_type=6` |
| AP | `/cell/version/queryfileInfosList.action?file_type=11` |

### 7.2 版本唯一性校验

```
GET /cell/version/verifyUVExist.action?fileType={type}&version={version}
```

## 10. 交互流程

### 10.1 导入文件流程

```
1. 点击"导入文件"按钮
2. 右侧弹出导入表单
3. 选择产品类型（AP除外）
4. 选择本地文件
5. 填写版本号（实时校验唯一性）
6. 选择版本类型和推荐状态
7. 填写描述（可选）
8. 点击"确定"提交
9. 后台上传文件并刷新列表
```

### 10.2 切换文件类型流程

```
1. 点击文件类型 Radio Button
2. 清空搜索条件
3. 切换文件列表 URL
4. 如果导入侧边栏打开，自动关闭
5. 加载新类型文件列表
```

## 11. 设计要点

### 11.1 文件类型差异

| 文件类型 | 产品类型选择 | 文件格式 |
|---------|-------------|---------|
| IMAGE | 多选 | tar.gz / IMG / EXT |
| CA版本 | 单选 | Patch |
| FPGA | 单选 | IMG |
| AP | 无 | IMG |

### 11.2 表单校验规则

- **版本号**：必填，1-45字符，唯一性校验
- **文件名**：必填，格式校验，文件名不超过100字符
- **产品类型**：必填（AP除外）

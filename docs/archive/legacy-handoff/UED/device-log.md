# 设备上报日志页面功能

## 页面概述

设备上报日志页面用于管理和查看设备日志收集任务，支持立即执行和周期执行两种收集方式。

## Tab 页签

位于"日志管理"菜单下，页签名称：**设备上报日志**

---

## 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| 操作 | - | 30 | 更多操作按钮（下拉菜单） |
| 设备唯一标识 | serial_number | 200 | 设备序列号 |
| 收集状态 | task_status | 220 | 任务状态，见下方状态说明 |
| 类型 | logType | - | 日志类型 |
| 执行方式 | execute_type | 120 | Immediately（立即执行）/ Period（周期执行） |
| 周期 | report_period | 120 | 周期执行时的上报周期 |
| 失败原因 | failureReason | 200 | 任务失败时的原因说明 |
| 更新时间 | update_time | 150 | 任务最后更新时间 |

### 收集状态说明

#### 立即执行任务状态
| 状态值 | 状态名 | 图标颜色 | 可用操作 |
|--------|--------|----------|----------|
| 0 | 等待 | 蓝色 | 终止、删除 |
| 1 | 进行中 | 蓝色 | 终止 |
| 2 | 成功 | 绿色 | 下载、删除 |
| 3 | 失败 | 红色 | 删除 |
| 4 | 终止 | 蓝色 | 删除 |

#### 周期执行任务状态
| 状态值 | 状态名 | 图标颜色 | 可用操作 |
|--------|--------|----------|----------|
| 0 | 等待 | 蓝色 | 终止、删除 |
| 1 | 进行中 | 蓝色 | 终止 |
| 2 | 成功 | 绿色 | 下载、删除 |
| 3 | 失败 | 红色 | 删除 |
| 4 | 终止 | 蓝色 | 删除 |
| 5 | 正在停止上报 | 蓝色 | - |
| 6 | 停止上报成功 | 蓝色 | 删除 |
| 7 | 停止上报失败 | 蓝色 | 终止 |
| 8 | 周期上报设置成功，重启生效 | 蓝色 | 终止 |

---

## 添加功能

### 新建收集任务

点击页面右上角 **添加** 按钮，打开新建收集任务抽屉。

**任务配置字段：**
- 执行方式选择（立即执行 / 周期执行）
- 设备选择（支持多选）
- 日志类型选择
- 周期设置（周期执行时显示）

---

## 列表操作（单行）

点击操作列的"更多"按钮，显示下拉菜单：

| 操作项 | 图标 | 可用条件 | 说明 |
|--------|------|----------|------|
| 结果 | operation-result | 状态为 2（成功） | 查看收集的日志文件列表 |
| 终止任务 | operation-terminate | 状态为 0/1/7/8 | 终止正在进行的收集任务 |
| 下载 | operation-download | 状态为 2（成功） | 下载收集的日志文件 |
| 删除 | operation-delete | 状态为 2/3/4 | 删除任务记录 |

### 查看结果详情

点击"结果"操作后，显示底部抽屉，包含：

| 字段 | 说明 |
|------|------|
| 文件名 | 收集的日志文件名称 |
| 收集时间 | 文件收集完成时间 |
| 操作 | 查看、下载 |

点击"查看"可查看日志文件内容。

---

## 批量操作

### 已选设备区域

- 显示已选数量：`( N )`
- 点击打开批量选择表格，可管理已选设备

### 批量按钮

| 按钮 | 图标 | 可用条件 | 说明 |
|------|------|----------|------|
| 删除 | operation-delete | 已选数量 > 0 | 批量删除选中的任务（进行中的任务不可删除） |
| 下载 | operation-download | 已选数量 > 0 | 批量下载选中任务收集的日志文件 |

---

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 时间范围 | 日期范围 | 按更新时间筛选 |
| 设备标识 | 输入框 | 模糊搜索设备唯一标识 |

---

## 交互说明

1. **状态实时更新**：进行中的任务状态会自动刷新
2. **操作权限控制**：根据任务状态动态显示/禁用操作按钮
3. **批量选择**：支持跨页选择，已选数据在切换页签时保留
4. **删除确认**：删除操作需二次确认

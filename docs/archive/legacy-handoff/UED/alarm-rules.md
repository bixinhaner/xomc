# 告警过滤规则页面

## 一、告警过滤规则列表页面

### 1. 列表字段

| 字段名 | 字段标识 | 说明 |
|--------|----------|------|
| 操作 | - | 更多操作按钮 |
| 状态 | status | 启用(1)/禁用(0)，启用显示绿色图标，禁用显示灰色 |
| 规则名称 | rule_name | 过滤规则的名称 |
| 告警源 | device_type | ENB/UPS/CPE/GNB/WCG/GSM，默认规则显示"ALL" |
| 执行动作 | rule_type | 0:禁止上报, 1:不入库不显示, 2:入库不显示, 3:自动确认 |
| 操作人 | user_code | 创建/修改规则的用户 |
| 更新时间 | operation_time | 规则最后更新时间 |

### 2. 功能

#### 2.1 查询功能
- **搜索框**: 按规则名称模糊搜索

#### 2.2 操作按钮
- **添加按钮**: 新建告警过滤规则

#### 2.3 行操作菜单
| 操作 | 说明 | 条件 |
|------|------|------|
| 信息 | 查看规则详情 | 始终可用 |
| 启用 | 启用禁用状态的规则 | 规则处于禁用状态 |
| 禁用 | 禁用启用状态的规则 | 规则处于启用状态 |
| 修改 | 编辑规则内容 | 规则处于禁用状态且可编辑 |
| 删除 | 删除规则 | 非默认规则且处于禁用状态 |

### 3. 业务规则
- 启用状态的规则禁止修改和删除
- 默认规则（default=1）不可删除
- 规则数量有上限限制

## 二、告警过滤规则添加/编辑页面

### 1. 基本信息

| 字段名 | 字段标识 | 类型 | 必填 | 说明 |
|--------|----------|------|------|------|
| 过滤模板名称 | ruleName | 文本输入 | 是 | 长度限制1~50字符，不可重复 |
| 状态 | status | 单选 | 是 | 启用(1)/禁用(0) |
| 执行动作 | ruleType | 单选 | 是 | 不入库不显示(1)/显示自动确认(3) |

### 2. 条件设置

#### 2.1 告警源选择
| 告警源 | 选项卡名称 | 说明 |
|--------|-----------|------|
| ENB | ENB | 小基站设备 |
| UPS | UPS | 电源设备 |
| CPE | CPE | 客户端设备 |
| GNB | GNB | 5G基站设备 |
| WCG | EGW | 网关设备 |
| GSM | GSM | GSM设备 |

#### 2.2 设备选择方式
| 选项 | 说明 |
|------|------|
| 全选 | 选择该告警源下所有设备 |
| 定制 | 手动选择特定设备或设备组 |

- 定制模式下可选：
  - **KPI设备**: 按设备列表选择
  - **设备组**: 按设备组批量选择

#### 2.3 设备组列表字段
| 字段名 | 说明 |
|--------|------|
| 选择 | 多选框 |
| 设备组名称 | 设备组的名称 |

#### 2.4 设备列表字段
| 字段名 | 说明 |
|--------|------|
| 选择 | 多选框 |
| 连接状态 | 设备连接状态图标 |
| 设备编码 | 设备序列号/编码 |
| 设备名称 | 设备的主机名或名称 |

#### 2.5 告警选择
| 字段名 | 说明 |
|--------|------|
| 选择 | 多选框 |
| 告警源 | 告警来源设备类型 |
| 告警唯一标识 | alarm_identifier |
| 可能原因 | alarm_name |
| 事件类型 | EVENT_TYPE: 通信告警(30000)/服务质量告警(30001)/处理失败告警(30002)/设备告警(30003)/环境告警(30004)/性能溢出告警(30006) |
| 告警级别 | SERVERITY_TYPE: Critical/Major/Minor/Warning |

#### 2.6 告警筛选条件
- **搜索框**: 按告警唯一标识/可能原因搜索
- **事件类型筛选**: 下拉选择事件类型
- **严重程度筛选**: 下拉选择告警级别
- **告警源筛选**: 下拉选择告警源
- **清空筛选**: 重置所有筛选条件

#### 2.7 故障时间范围
| 字段名 | 说明 |
|--------|------|
| 开始时间 | startTime，日期时间选择器 |
| 结束时间 | endTime，日期时间选择器 |

### 3. 执行动作说明

| 动作代码 | 动作名称 | 说明 |
|----------|----------|------|
| 0 | 禁止上报 | 告警不上报到系统 |
| 1 | 不入库不显示 | 告警不入库且不在列表显示 |
| 2 | 入库不显示 | 告警入库但不在列表显示 |
| 3 | 自动确认 | 告警自动确认为已确认状态 |

### 4. 页面模式
- **新增模式**: 新建告警过滤规则
- **编辑模式**: 修改已有的告警过滤规则（需先禁用）
- **查看模式**: 只读查看规则详情

## 三、API接口

### 1. 列表接口
- **URL**: `/cell/fault/queryAlarmRuleInfoList.action`
- **方法**: GET
- **参数**:
  - searchText: 搜索关键字（规则名称）
  - timeZone: 时区

### 2. 保存接口
- **URL**: `/cell/fault/saveAlarmRule.action`
- **方法**: POST
- **参数**:
  - ruleName: 规则名称
  - status: 状态
  - ruleType: 执行动作
  - deviceTypeList: 告警源列表
  - 设备选择相关参数
  - alarmId: 选中的告警ID
  - startTime: 开始时间
  - endTime: 结束时间

### 3. 删除接口
- **URL**: `/cell/fault/deleteRule.action`
- **方法**: POST
- **参数**:
  - ruleId: 规则ID
  - ruleName: 规则名称

### 4. 启用/禁用接口
- **URL**: `/cell/fault/turnAlarmRuleStatus.action`
- **方法**: POST
- **参数**:
  - ruleId: 规则ID
  - status: 目标状态(1启用/0禁用)

### 5. 名称校验接口
- **URL**: `/cell/fault/ruleNameExist.action`
- **方法**: POST
- **参数**:
  - ruleName: 规则名称
  - ruleId: 规则ID（编辑时传入）

# MML 脚本功能需求文档

> **文档版本**: v1.0
> **创建日期**: 2026-04-21
> **基于**: 老 OMC 系统 MML 脚本功能分析
> **目标**: 为新系统 MML 脚本功能开发提供完整需求参考

---

## 1. 功能概述

MML 脚本功能用于批量执行 MML 维护命令任务。用户可以通过上传脚本文件创建批量执行任务，支持多种执行方式（立即执行、挂起、定时执行、周期执行），并提供离线/在线设备的重试机制。系统记录完整的任务执行历史和每台设备的执行结果详情。

### 1.1 页面路由

| 页面 | 路由 | 说明 |
|------|------|------|
| MML 脚本任务 | `/mml/script` | 脚本任务列表管理、新建任务、查看执行结果 |

### 1.2 与 MML 控制台的关系

- **MML 控制台**（`/mml/console`）：三栏布局，用于单设备交互式命令执行
- **MML 脚本任务**（`/mml/script`）：用于批量设备的脚本任务管理，支持调度和重试
- MML 控制台中执行的命令可"保存为脚本"，此时需让用户输入任务名称（原始需求项）

## 2. 脚本任务列表页

### 2.1 页面布局

页面从上到下包含：
1. **筛选栏**：任务名称搜索 + 时间范围筛选
2. **操作栏**：右侧"+"添加任务按钮
3. **任务列表表格**：展示所有脚本任务
4. **分页控件**：底部分页

### 2.2 筛选功能

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 任务名称 | 文本框 + 搜索图标 | 支持模糊查询 |
| 开始时间 | 日期时间选择器 | 时间范围起始 |
| 结束时间 | 日期时间选择器 | 时间范围截止 |

### 2.3 任务列表表格字段

| 序号 | 字段名 | 数据类型 | 说明 |
|------|--------|----------|------|
| 1 | 展开图标 | 图标按钮 | 点击展开/收起该任务的执行结果详情 |
| 2 | 任务名称 | 字符串 | 格式如 `MML Task_admin_2026-04-10 18:05:31` 或自定义名称 |
| 3 | 创建者 | 字符串 | 创建任务的用户名 |
| 4 | 创建时间 | 日期时间 | 格式：`YYYY-MM-DD HH:MM:SS` |
| 5 | 类型 | 枚举 | 执行方式：`立即执行` / `周期执行` / `挂起` / `定时执行` |
| 6 | 状态 | 枚举 | 任务状态：`已结束` / `执行中` / `待执行` / `已挂起` |
| 7 | 进度 | 字符串 | 格式：`已完成数/总数`，如 `16/16`、`3/3` |
| 8 | 结果 | 枚举 | `成功` / `部分成功` / `失败` |
| 9 | 开始时间 | 日期时间 | 任务实际开始执行时间 |
| 10 | 结束时间 | 日期时间 | 任务执行完成时间 |

### 2.4 分页配置

- 默认每页 50 条
- 支持自定义每页条数
- 显示总记录数
- 支持跳转至指定页码

## 3. 任务执行结果详情（展开行）

### 3.1 展开方式

点击任务行最前面的展开图标，在该行下方展开一个子表格，显示该任务中每台设备的执行结果。

### 3.2 详情区域布局

- **标题栏**：显示 `结果（任务名称）`，如 `结果 ( MML Task_admin_2026-04-10 18:05:31 )`
- **搜索框**：支持按基站编码或基站名称搜索
- **操作按钮**：导出按钮（右上角）、关闭按钮（X）
- **详情表格**：每台设备的执行结果
- **分页控件**：详情表格独立分页

### 3.3 详情表格字段

| 序号 | 字段名 | 数据类型 | 说明 |
|------|--------|----------|------|
| 1 | 基站编码 | 字符串 | 设备序列号，如 `1202000240194DP0026` |
| 2 | 基站名称 | 字符串 | 设备名称 |
| 3 | MML 脚本 | 字符串 | 执行的 MML 命令内容，如 `MOD CELL:LTE_CELL_ECI={123456};` |
| 4 | 状态 | 枚举 | `已结束` / `执行中` / `待执行` |
| 5 | 结果 | 枚举 | `成功` / `失败` |
| 6 | 失败原因 | 字符串 | 失败时显示原因，如 `Serial Number在数据库中不存在` |
| 7 | 详情 | 字符串 | 附加详细信息 |
| 8 | 开始时间 | 日期时间 | 该设备命令执行开始时间 |
| 9 | 结束时间 | 日期时间 | 该设备命令执行完成时间 |

### 3.4 导出功能

- 支持将当前任务的执行结果导出
- 导出按钮位于详情区域右上角

## 4. 添加任务功能

### 4.1 入口

点击任务列表右上角的"+"按钮，打开全屏添加任务页面。

### 4.2 表单结构

表单分为三个区块：**基本信息**、**选择执行方式**、**任务配置**。

#### 4.2.1 基本信息

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| 任务名称 | 文本框 | ✅ 是 | `MML任务_用户名_YYYY-MM-DD HH:MM:SS`（自动生成） | 支持手动修改 |
| 选择脚本 | 文件上传 | ✅ 是 | - | 当前支持 `.txt` 格式；提供"模板导出"链接下载脚本格式模板 |

**脚本文件说明**：
- 文件格式：`.txt`
- 需遵循系统提供的示例模板格式
- 脚本文件中包含目标设备信息和要执行的 MML 命令
- 提供"模板导出"功能，用户可下载模板了解格式要求

#### 4.2.2 选择执行方式

| 选项 | 类型 | 关联配置 | 说明 |
|------|------|----------|------|
| 立即执行 | 单选按钮 | 无 | **默认选中**，创建后立即开始执行 |
| 挂起 | 单选按钮 | 无 | 创建后暂不执行，需后续手动启动 |
| 定时执行 | 单选按钮 | 日期时间选择器 | 选中后启用时间选择器，指定一次性执行时间 |
| 周期执行 | 单选按钮 | 日期范围 + 时间选择器 | 选中后启用：周期日期范围（开始日期 - 结束日期）+ 每日执行时间点 |

**动态交互**：
- 定时执行和周期执行的关联输入框默认禁用（灰色）
- 仅当对应的单选按钮被选中时才启用
- 定时执行：显示一个日期时间选择器
- 周期执行：显示日期范围选择器（开始日期 - 结束日期）和每日执行时间点

#### 4.2.3 任务配置（重试策略）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 离线设备重试 | 复选框 + 数值输入框 | 未勾选，等待时间 60 分钟 | 勾选后启用：等待设备上线后重试，最大等待时间 N 分钟 |
| 在线设备重试 | 复选框 + 两个数值输入框 | 未勾选，重试 3 次，间隔 5 分钟 | 勾选后启用：配置失败的情况下重试，最多重试 N 次，每次间隔 M 分钟 |

**离线设备重试**：
- 标签文案：`离线设备：☐ 等待设备上线后重试，最大等待时间 [60] 分钟。`
- 适用场景：目标设备当前不在线，系统在设备上线后自动重试

**在线设备重试**：
- 标签文案：`在线设备：☐ 配置失败的情况下重试，最多重试 [3] 次，每次间隔 [5] 分钟。`
- 适用场景：设备在线但命令执行失败时的自动重试

### 4.3 操作按钮

| 按钮 | 位置 | 说明 |
|------|------|------|
| 确定 | 底部左侧（主按钮） | 提交表单，创建任务 |
| 取消 | 底部（次按钮） | 关闭添加页面，返回任务列表 |
| X | 右上角 | 关闭添加页面 |

## 5. 与新系统的对齐要点

### 5.1 需要保留的核心功能

1. **任务列表管理**：完整的任务 CRUD + 筛选搜索 + 分页
2. **脚本文件上传**：支持 .txt 格式脚本上传 + 模板导出
3. **四种执行方式**：立即执行、挂起、定时执行、周期执行
4. **双重重试策略**：离线设备等待上线重试 + 在线设备失败重试
5. **任务结果详情**：展开行查看每台设备的执行结果，含失败原因
6. **结果导出**：支持导出任务执行结果
7. **任务名称自动生成**：格式 `MML任务_用户名_时间戳`，支持自定义修改

### 5.2 新系统增强项（待规划）

1. **MML 控制台保存为脚本**：在 MML 控制台执行命令后，支持将命令保存为脚本任务，需让用户输入任务名称（原始需求）
2. **任务状态机完善**：支持 pending → running → completed/failed/partial 以及 paused/cancelled 状态流转
3. **任务控制操作**：支持启动挂起任务、暂停运行中任务、终止任务
4. **任务删除**：支持删除历史任务记录
5. **权限控制**：基于 RBAC 的任务操作权限
6. **审计日志**：记录任务创建、执行、修改的审计日志
7. **实时进度更新**：通过 WebSocket 实时推送任务执行进度
8. **脚本在线编辑**：除文件上传外，支持在线编辑脚本内容
9. **设备选择增强**：支持通过设备树/设备分组选择目标设备，而非仅通过脚本文件指定

### 5.3 技术实现参考

- 后端架构参考：`/docs/design/mml-script-task-integration.md`（父子任务架构整合方案）
- 需求设计参考：`/docs/design/mml-requirements-design.md`（MML 完整需求设计文档 v4.0）
- 表结构：`mml_tasks`（父任务）+ `device_tasks`（子任务，通过 parent_task_id 关联）
- 共用服务层：Task Splitter + Task Scheduler + Progress Monitor + Retry Engine

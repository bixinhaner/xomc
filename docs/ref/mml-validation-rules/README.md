# MML 参数校验规则参考

本目录保存从历史 MML 参数配置中整理出的校验规则快照，供排查、规则比对和参数模型迁移时参考。

## 内容

- `*.xml`：按设备或参数版本拆分的规则快照。每个 XML 的根节点 `mmlParameterRules` 均提供版本和参数、参数组、关联关系的汇总数量。
- `MML参数校验规则整理.md`：字段含义、操作必填规则，以及前端和后台校验规则的说明。

## 使用约定

- 参数的唯一标识为 `param_version + path`，其中 `path` 对应 XML 中的 `NAME_PATH`；不能只用 `MIB_DN` 识别参数。
- `V_TYPE` 是数据类型、范围或枚举等后台校验依据；`JS_REGEX` 是前端输入校验。两类规则应分别理解和维护。
- `V_LST`、`V_ADD`、`V_MOD`、`V_RMV` 分别表示查询、新增、修改、删除操作的支持状态；值 `Y*` 表示该操作下参数必填。

## 边界

这些 XML 是参考资料，不是当前系统的运行时参数映射真值源，也不直接决定 MML 命令实际包含的参数路径。系统运行时数据应以相应数据库字典和 `omcgo/data/param-mappings/` 等正式数据源为准。

除非确认了新的权威来源，不应手工改写 XML 中的规则内容；更新时应以完整版本快照替换，并在提交说明中注明来源和适用范围。

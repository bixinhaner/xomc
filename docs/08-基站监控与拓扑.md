# 基站监控与拓扑

## 概述
基站监控与拓扑模块提供基站设备在地图上的可视化定位、网络拓扑结构查看以及管理域的层级化管理。OMC 系统侧重于地图 Site 视图的空间监控，广研院系统侧重于拓扑树的逻辑结构可视化与行政区划域管理。
- 涉及系统：OMC / 广研院

---

## 四、系统对比

### 4.1 功能对比总览

| 对比维度 | Cloudcore OMC (Site 地图监控) | 广研院 (拓扑管理) |
|----------|-------------------------------|-------------------|
| **核心视图** | 地理地图视图（GIS Map） | 逻辑拓扑树视图（画布） |
| **定位方式** | 经纬度地图标点 | 行政区划树形层级 |
| **主要用途** | 站点空间分布监控、状态总览 | 网元拓扑结构可视化、域层级管理 |
| **设备粒度** | Site 站点级（含多设备汇总） | 设备/网元级（BU/EU/RU） |
| **状态展示** | Normal/Abnormal/Offline 三色标记 | 连接状态 + 入网状态 + 告警数量角标 |
| **交互地图** | 支持（缩放/平移/全屏/测距） | 拓扑画布（缩放/平移/适应屏幕） |
| **筛选能力** | 设备类型复选框(eNB/gNB/GSM) | 产品分类/厂商/设备名称/区域/SN号 |
| **统计面板** | Location 面板: 总数+三色分布 | 所选设备数统计: 设备数/小区数/入网状态/BU连接状态 |
| **详情弹窗** | 站点详情(经纬度/设备数/吞吐量) | 拓扑显示设置/图标设置/图示说明 |
| **域/组管理** | Device Group 设备组管理 | 域管理（行政区划树: 省/市/区/县） |
| **界面语言** | 英文 | 中文 |

### 4.2 页面布局对比

| 布局要素 | Cloudcore OMC | 广研院 拓扑树 | 广研院 域管理 |
|----------|---------------|--------------|--------------|
| 分栏方式 | 左侧列表 + 右侧地图 | 左侧设备树 + 右侧拓扑画布 | 左侧域列表树 + 右侧域详情表单 |

### 4.6 独有功能

**Cloudcore OMC 独有**:
- GIS 真实地图底图（支持城市、道路等地理信息）
- 测距工具（Distance）
- 站点吞吐量数据展示（eNB/gNB Throughput）
- 设备数量汇总（eNB Count / gNB Count / GSM Count）
- Site 站点的 CRUD 管理（新增/编辑/删除）

**广研院 独有**:
- 逻辑拓扑结构可视化画布（非GIS地图）
- 设备统计面板（设备数/小区数/入网状态/BU连接状态 多维度）
- 拓扑显示高级设置（告警级别开关、Xn/X2连线显示、线条样式）
- 图标自定义配置（8种网元类型图标可替换）
- 完整图示说明系统（核心网/基站集/基站/网元/管理状态 五类图例）
- 域管理模块（行政区划多级树形管理: 省 > 市 > 区/县）
- 网元同步功能

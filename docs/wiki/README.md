# OMC 知识库

这个目录用于沉淀面向人阅读的项目知识，作为 GitLab Wiki 内容的版本化源文件。

适合放在这里的内容：

- 功能说明
- 真实测试记录
- 操作经验
- 排障复盘
- 业务规则解释
- 常见问题

不适合放在这里的内容：

- 正式设计方案，放 `docs/design/`
- 运维手册，放 `docs/operations/`
- 架构决策，放 `docs/adr/`
- 临时测试过程和草稿，放本地 `tmp/`

维护规则：

- `docs/wiki/` 是知识库源文件，纳入代码仓版本管理。
- GitLab Wiki 不再作为长期内容存放地，避免同一篇文章两处维护。
- 如果后续需要恢复 GitLab Wiki 展示，应从本目录同步生成，而不是在 GitLab Wiki 页面上直接长期编辑。

目录分类：

- `pm/`：PM 数据、指标、保留策略相关知识。
- `system-config/`：系统配置页相关功能说明和真实验证记录。

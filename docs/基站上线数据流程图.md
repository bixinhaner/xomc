# 基站上线全链路数据流程图

> 当 CPE（基站）首次上电或重启后连接 OMC 系统时，系统内部触发的完整事件链路和数据流。

---

## 1. 全局概览

```
┌─────────┐   HTTP POST    ┌──────────────┐   NATS Events   ┌──────────────┐
│   CPE   │ ──────────────→ │   ACS 引擎   │ ──────────────→ │   App 主进程  │
│ (基站)  │ ←────────────── │   (:7547)    │                 │   (:8080)    │
└─────────┘   SOAP/XML      └──────────────┘                 └──────┬───────┘
                                   │                                │
                                   │ NATS Events                    │ NATS Events
                                   ▼                                ▼
                            ┌──────────────┐                 ┌──────────────┐
                            │   Redis      │                 │   Worker     │
                            │ (会话/队列)   │                 │ (后台处理)    │
                            └──────────────┘                 └──────────────┘
```

## 4. 详细阶段拆解

### 阶段一：ACS 接收 Inform

```
┌──────────────────────────────────────────────────────────────────────┐
│ CPE → ACS (:7547)  HTTP POST  Content-Type: text/xml               │
│                                                                      │
│  SOAP Envelope                                                       │
│  ├─ Header: <cwmp:ID>50027</cwmp:ID>                                │
│  └─ Body: <cwmp:Inform>                                             │
│       ├─ DeviceId                                                    │
│       │   ├─ Manufacturer: "COMMON"                                  │
│       │   ├─ OUI: "48BF74"                                          │
│       │   ├─ ProductClass: "FAP/BU1810"                              │
│       │   └─ SerialNumber: "1202000588233HB0039"                     │
│       ├─ Event                                                       │
│       │   ├─ EventCode: "0 BOOTSTRAP"  ← 首次上电                    │
│       │   └─ EventCode: "1 BOOT"       ← 重启                       │
│       ├─ CurrentTime: "2026-03-24T19:13:24"                          │
│       ├─ RetryCount: 0                                               │
│       └─ ParameterList (41-43 个参数)                                 │
│           ├─ Device.DeviceInfo.HardwareVersion                       │
│           ├─ Device.DeviceInfo.SoftwareVersion                       │
│           ├─ Device.ManagementServer.ConnectionRequestURL             │
│           ├─ Device.DeviceInfo.SerialNumber                          │
│           └─ ... (厂商私有参数 X_COM_*)                               │
└──────────────────────────────────────────────────────────────────────┘
                                │
                                ▼
                    ┌───────────────────────┐
                    │  ACS handler 处理流程   │
                    │                       │
                    │  1. parseSOAPEnvelope  │
                    │  2. 速率限制检查        │
                    │  3. 准入控制检查        │
                    │  4. 创建 Redis 会话     │
                    │     · SessionID (UUID) │
                    │     · State: Informed  │
                    │     · TTL: 5 分钟      │
                    │  5. 缓存 ConnReqURL    │
                    │  6. 发送 InformResponse│
                    │  7. 发布事件            │
                    └───────────────────────┘
```

**触发的事件**（根据 Inform 中的 EventCode 分发）：

| EventCode | 发布的 NATS 主题 | 说明 |
|-----------|-----------------|------|
| `0 BOOTSTRAP` | `device.inform.bootstrap` | 首次上电，触发设备注册+开通 |
| `1 BOOT` | `device.inform.bootstrap` | 重启，同样触发注册+开通 |
| `2 PERIODIC` | `device.inform.periodic` | 周期性心跳，更新在线状态 |
| `4 VALUE CHANGE` | `device.inform.value_change` | 参数值变化通知 |
| `6 CONNECTION REQUEST` | `device.inform.connection_request` | 响应网管侧连接请求 |
| `7 TRANSFER COMPLETE` | `device.inform.transfer_complete` | 文件传输完成 |
| `8 DIAGNOSTICS COMPLETE` | `device.inform.periodic` | 诊断完成 |
| Alarm 相关 | `device.inform.alarm` | 告警上报 |

### 阶段二：设备注册

```
device.inform.bootstrap
        │
        ▼
┌───────────────────────────────────────────────────────┐
│  InformHandler.handleBootstrap()                      │
│  订阅队列: device-mgr-bootstrap                       │
│  模块: internal/device/inform_handler.go              │
│                                                       │
│  1. 解码 InformEventPayload                           │
│  2. 通过 OUI 解析运营商                                │
│     CarrierRegistry.ResolveByOUI("48BF74") → CMCC    │
│  3. 调用 DeviceService.RegisterFromInform()           │
│                                                       │
│  ┌─────────────────────────────────────────────┐      │
│  │  RegisterFromInform()                       │      │
│  │                                             │      │
│  │  ┌─ 按 SerialNumber 查询设备                │      │
│  │  │                                          │      │
│  │  ├─ 设备不存在 (BOOTSTRAP):                  │      │
│  │  │   · INSERT INTO devices (...)            │      │
│  │  │   · Status = "online"                    │      │
│  │  │   · Carrier = CMCC                       │      │
│  │  │   · Technology = LTE/NR (从参数推断)      │      │
│  │  │                                          │      │
│  │  ├─ 设备已存在 (BOOT):                       │      │
│  │  │   · UPDATE devices SET status='online'   │      │
│  │  │   · 更新 last_inform_at                  │      │
│  │  │   · 更新 fw_version 等字段               │      │
│  │  │                                          │      │
│  │  └─ 存储 Inform 参数                         │      │
│  │      · UPSERT device_parameters             │      │
│  │      · 41-43 个参数写入                      │      │
│  └─────────────────────────────────────────────┘      │
│                                                       │
│  4. 发布 device.registered 事件                       │
│     Payload: { device_id, serial_number, oui,         │
│               product_class, carrier, technology }    │
└───────────────────────────────────────────────────────┘
```

**数据写入**：

| 存储 | 表/键 | 数据 |
|------|-------|------|
| PostgreSQL | `devices` | 设备基本信息（ID, SN, OUI, 状态, 运营商, 制式） |
| PostgreSQL | `device_parameters` | Inform 携带的 41-43 个初始参数 |
| Redis | `stun:connreq:{sn}` | ConnectionRequestURL 缓存 |

## 5. 完整事件总线链路

```
CPE 上线 (0-BOOTSTRAP / 1-BOOT)
│
├─→ [ACS 发布] device.inform.bootstrap
│   │
│   ├─→ [device 模块订阅] → 设备注册/更新 → [发布] device.registered
│   │                                         │
│   │                                         ├─→ [provision 模块订阅]
│   │                                         │    → HandleBootstrap()
│   │                                         │    → 入队 GPN/GPV 命令
│   │                                         │    → [发布] provision.started
│   │                                         │
│   │                                         └─→ (未来扩展: 拓扑自动发现等)
│   │
│   └─→ [alarm 模块订阅] (仅当 Inform 含告警事件码时)
│        → 告警入库 + 去重 + 关联
│        → [发布] alarm.raised
│             └─→ [northbound 推送] → OSS
│
├─→ [ACS 发布] command.get_names.response (GPN 响应)
│   └─→ [provision 模块订阅]
│        → HandleGPNResult()
│        → 实例发现 + 递归展开
│        → 更新 sync plan
│
├─→ [ACS 发布] command.get_parameters.response (GPV 响应)
│   └─→ [provision 模块订阅]
│        → HandleGPVResult()
│        → 参数值写入 device_parameters
│        → [发布] provision.completed (全部完成时)
│
└─→ 后续周期性 Inform (2-PERIODIC)
    └─→ [ACS 发布] device.inform.periodic
         └─→ [device 模块订阅]
              → 更新 last_inform_at
              → 更新在线状态
```

## 6. 数据持久化汇总

| 阶段 | 存储 | 表/键 | 数据内容 |
|------|------|-------|---------|
| Inform 接收 | Redis | `acs:session:{id}` | 会话状态 (TTL 5min) |
| Inform 接收 | Redis | `stun:connreq:{sn}` | ConnectionRequestURL |
| 设备注册 | PostgreSQL | `devices` | 设备基本信息 |
| 设备注册 | PostgreSQL | `device_parameters` | Inform 参数 (41-43个) |
| 开通任务 | PostgreSQL | `provisioning_tasks` | 任务状态+进度 |
| 命令队列 | Redis | `cmd:{sn}` (Sorted Set) | 待执行的 RPC 命令 |
| 同步计划 | Redis | `provision:sync_plan:{sn}` | GPN/GPV 进度状态 |
| 参数同步 | PostgreSQL | `device_parameters` | 完整参数树 (数百~数千个) |
| 告警 | PostgreSQL | `alarms` | 活动告警 |
| 告警 | TimescaleDB | `alarm_history` | 告警历史 (时序) |

# OMC 基站管理系统 - 文档目录

本目录包含基于规范目录（`规范/`）梳理的系统功能文档。

## 文档清单

| 文件 | 说明 |
|------|------|
| [功能索引.md](功能索引.md) | 系统功能分类总览、详细功能列表、运营商交叉引用矩阵、规范文档目录及映射索引 |

## 数据来源

功能分析基于 `规范/` 目录下三大运营商（中国移动、中国电信、中国联通）的 55 份技术规范文档（移动 19 份、电信 21 份、联通 15 份），涵盖 LTE 和 5G NR 两种制式。

## 功能域速查

- **F01** 南向接口管理（TR069）
- **F02** 数据模型与配置管理
- **F03** 性能管理（PM/KPI）
- **F04** 告警管理
- **F05** 测量报告（MR）
- **F06** OMC-R 核心功能
- **F07** 网元直连接口
- **F08** 北向/OSS 接口
- **F09** 自动开站/自动开通
- **F10** 互操作测试

# F09 自动开站/自动开通

[← 返回目录](../README.md) | [← 功能索引](../功能索引.md)

---

## 功能概述

自动开站是基站设备从上电到投入服务的自动化流程，包括设备自动发现、身份认证、配置下发、参数校验等环节。该功能大幅降低了基站部署的人工成本和出错率。

**覆盖运营商**：移动、电信
**支持制式**：LTE、5G NR
**子功能数**：3

---

## 子功能详细描述

### F09.01 自动开通技术要求

**定义**：一体化皮基站/扩展型皮基站的自动开通流程与技术要求。

**技术要点**：
- **自动发现**：设备上电后通过 DHCP 获取 ACS 地址，发送 Bootstrap Inform
- **身份认证**：基于设备序列号、OUI 等信息的身份验证
- **配置匹配**：根据设备信息匹配预配置的开站参数
- **配置下发**：通过 SetParameterValues 批量下发配置
- **配置校验**：下发后读回验证配置正确性
- **服务激活**：配置完成后激活基站服务
- **状态上报**：开站结果上报与状态跟踪

**自动开站流程**：
```
设备上电
  │
  ├→ DHCP 获取 IP + ACS URL
  │
  ├→ 首次 Inform (0 BOOTSTRAP)
  │
  ├→ ACS 身份认证
  │
  ├→ ACS 读取设备信息 (GetParameterValues)
  │
  ├→ ACS 匹配开站模板
  │
  ├→ ACS 下发配置 (SetParameterValues)
  │
  ├→ ACS 下发固件（如需升级） (Download)
  │
  ├→ 设备重启并重新连接
  │
  ├→ ACS 校验配置 (GetParameterValues)
  │
  └→ 开站完成，设备进入正常运行
```

**运营商差异**：
- **移动独有**：面向一体化皮基站和扩展型皮基站

**关联文档**：#5

---

### F09.02 4G 开站模板

**定义**：4G 皮基站配置开通所需的参数模板。

**技术要点**：
- 基本信息（站名、站号、设备型号）
- 无线参数（频点、PCI、TAC、功率）
- 网络参数（IP 地址、网关、VLAN）
- 核心网参数（MME 地址、S1 配置）
- 回传参数（传输链路配置）

**运营商差异**：
- **电信独有**：V1.0.2 版，文件编号 48BF74

**关联文档**：#27

---

### F09.03 5G 自动开站模板

**定义**：5G 小基站自动开站的配置参数模板。

**技术要点**：
- gNB 基本信息（gNB ID、gNB Name）
- NR 无线参数（SSB 频点、SCS、BWP）
- 5GC 对接参数（AMF 地址、NSSAI、PLMN）
- SA 模式配置
- 切片参数（如适用）
- 自动开站流程参数（超时设置、重试策略）

**运营商差异**：
- **电信独有**：V2.8.7 版（文件编号 20AC9C），版本号高说明多次迭代

**关联文档**：#28

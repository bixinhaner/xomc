## 1. 接口分层总览

OMC 系统涉及三类核心接口：

```
                    ┌───────────────┐
                    │  OSS/上层系统  │
                    └───────┬───────┘
                            │
                   ─────────┴─────────
                   │  北向接口 (F08)  │
                   │  性能/配置/告警   │
                   ─────────┬─────────
                            │
┌───────────────────────────┴───────────────────────────┐
│                     OMC 基站管理系统                      │
│                                                         │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌──────────┐  │
│  │配置管理   │  │性能管理   │  │告警管理   │  │MR 管理   │  │
│  │(F02)     │  │(F03)     │  │(F04)     │  │(F05)     │  │
│  └─────────┘  └─────────┘  └─────────┘  └──────────┘  │
│  ┌─────────┐  ┌─────────┐                               │
│  │自动开站   │  │OMC-R核心 │                               │
│  │(F09)     │  │(F06)     │                               │
│  └─────────┘  └─────────┘                               │
│                                                         │
└──────────┬─────────────────────────────┬────────────────┘
           │                             │
  ─────────┴──────────       ────────────┴───────────
  │ 南向接口 (F01)    │       │ 网元直连接口 (F07)   │
  │ TR069/CWMP        │       │ 非TR069直连通道     │
  ─────────┬──────────       ────────────┬───────────
           │                             │
    ┌──────┴──────┐              ┌───────┴───────┐
    │  基站设备    │              │  网元设备      │
    │  (CPE)      │              │  (直连模式)    │
    └─────────────┘              └───────────────┘
```

## 2. 南向接口（F01）

### 2.1 协议栈

```
┌─────────────────────────────────┐
│         应用层                    │
│   TR069 RPC (GetParameterValues, │
│   SetParameterValues, Inform,    │
│   Download, Upload, etc.)        │
├─────────────────────────────────┤
│         传输层                    │
│   SOAP over HTTP/HTTPS           │
├─────────────────────────────────┤
│         网络层                    │
│   TCP/IP                         │
└─────────────────────────────────┘
```

### 2.2 核心 RPC 方法

| 方向 | RPC 方法 | 功能 | 关联功能域 |
|------|---------|------|-----------|
| ACS → CPE | GetParameterValues | 读取设备参数 | F02 |
| ACS → CPE | SetParameterValues | 设置设备参数 | F02, F09 |
| ACS → CPE | GetParameterNames | 查询参数列表 | F02 |
| ACS → CPE | AddObject / DeleteObject | 增删对象实例 | F02 |
| ACS → CPE | Download | 下发文件（固件/配置） | F09 |
| ACS → CPE | Upload | 上传文件（日志/配置备份） | F06 |
| ACS → CPE | Reboot | 远程重启 | F06 |
| ACS → CPE | FactoryReset | 恢复出厂设置 | F06 |
| ACS → CPE | ScheduleInform | 定时上报调度 | F03 |
| CPE → ACS | Inform | 设备上报（事件通知） | F01, F04, F09 |
| CPE → ACS | TransferComplete | 文件传输完成通知 | F09 |

### 2.3 数据流向

```
基站设备 (CPE)                           OMC (ACS)
    │                                       │
    │──── Inform (0 BOOTSTRAP) ────────────→│  首次上电注册
    │                                       │
    │←─── GetParameterValues ──────────────│  读取设备信息
    │──── GetParameterValuesResponse ─────→│
    │                                       │
    │←─── SetParameterValues ──────────────│  下发配置
    │──── SetParameterValuesResponse ─────→│
    │                                       │
    │──── Inform (2 PERIODIC) ────────────→│  周期性上报
    │                                       │
    │──── Inform (VALUE CHANGE) ──────────→│  参数变化通知
    │                                       │
    │──── Inform (ALARM) ─────────────────→│  告警事件上报
    │                                       │
    │←─── Upload (性能文件) ───────────────│  性能数据采集
    │──── TransferComplete ───────────────→│
    │                                       │
    │←─── Upload (MR文件) ────────────────│  测量报告采集
    │──── TransferComplete ───────────────→│
```

## 3. 北向/OSS 接口（F08）

联通规范中明确定义了 OMC 与上层 OSS 系统之间的北向接口：

### 3.1 接口类型

| 接口 | 数据类型 | 方向 | 协议 |
|------|---------|------|------|
| 性能数据接口 | PM 统计数据 | OMC → OSS | 文件/接口 |
| 配置数据接口 | 设备配置快照 | OMC → OSS | 文件/接口 |
| 告警数据接口 | 实时告警事件 | OMC → OSS | 文件/接口 |

### 3.2 数据流向

```
OMC 基站管理系统                        OSS 上层系统
    │                                       │
    │──── 性能统计文件 ───────────────────→│  周期性推送
    │                                       │
    │──── 配置数据快照 ───────────────────→│  变更时推送
    │                                       │
    │──── 告警事件 ───────────────────────→│  实时转发
    │                                       │
    │←─── 配置下发指令 ──────────────────│  OSS 下发管理指令
    │                                       │
```

## 4. 网元直连接口（F07）

移动规范中定义的网元与网管系统的直连通信接口，绕过 TR069 协议层直接通信。

### 4.1 定位

```
常规模式:    基站 ──TR069──→ OMC
直连模式:    基站 ──直连───→ 网管系统（绕过 ACS 中间层）
```

### 4.2 适用场景

- 大容量基站需要更高效的管理通道
- 需要实时性更高的管理操作
- TR069 协议无法满足的特殊管理需求

## 5. 接口与功能域关联

| 接口类型 | 承载的功能域 | 数据类型 |
|---------|------------|---------|
| 南向接口 (TR069) | F01, F02, F03, F04, F05, F09 | 配置、性能、告警、MR、开站 |
| 北向接口 (OSS) | F08 | 性能汇总、配置快照、告警转发 |
| 网元直连接口 | F07 | 直连管理数据 |

## 6. 运营商接口差异

| 接口 | 移动 | 电信 | 联通 |
|------|------|------|------|
| 南向 TR069 | ✅ 三部分规范 | ✅ V2.6 规范 | ✅ V1.1 规范 |
| 南向数据模型 | ✅ LTE + NR 独立 | ✅ 4G + 5G | ✅ 5G NR |
| 北向 OSS | - | - | ✅ 性能/配置 + 告警 |
| 网元直连 | ✅ V2.1.0 | - | - |
| 共建共享接口 | - | ✅ | - |

# 用户组管理功能设计文档

## 1. 页面概述

用户组管理页面用于管理系统中的用户组信息，支持对用户组进行创建、编辑、删除等操作。用户组可以关联用户和角色。

## 2. 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| 组名 | group_name | 200px | 用户组名称 |
| 用户数 | user_count | 200px | 该用户组下的用户数量 |
| 角色数 | role_count | 自适应 | 该用户组关联的角色数量 |
| 操作人 | upd_user | 自适应 | 最后修改人 |
| 更新时间 | upd_time | 自适应 | 最后更新时间 |

## 3. 搜索条件

| 字段名 | 字段标识 | 类型 | 说明 |
|--------|----------|------|------|
| 组名 | group_name | 输入框 | 模糊搜索，支持回车查询 |

## 4. 工具栏按钮

| 按钮名称 | 图标 | 权限控制 | 说明 |
|----------|------|----------|------|
| 搜索 | el-icon-common-search | - | 按组名搜索 |
| 添加 | el-icon-circle-add | CODE_SYSTEM_USERS_USER_GROUP | 新增用户组 |

## 5. 列表操作

每行数据有一个操作菜单（更多按钮），包含以下操作项：

| 操作名称 | 说明 | 权限控制 | 条件 |
|----------|------|----------|------|
| 查看 | 查看用户组详细信息 | - | 所有用户组可查看 |
| 修改 | 修改用户组信息 | CODE_SYSTEM_USERS_USER_GROUP | 非内置用户组 |
| 删除 | 删除用户组 | CODE_SYSTEM_USERS_USER_GROUP | 非内置用户组（built_in != 1,2） |

## 6. 批量操作

勾选多条记录后，底部显示批量操作栏：

| 操作名称 | 说明 | 条件 |
|----------|------|------|
| 删除 | 批量删除选中用户组 | 非内置用户组 |
| 取消 | 取消选择 | - |

## 7. 添加/修改用户组

通过侧边滑出面板进行用户组信息的添加和修改。

### 表单字段

| 字段名 | 必填 | 说明 |
|--------|------|------|
| 组名 | 是 | 用户组名称 |
| 描述 | 否 | 用户组描述信息 |
| 关联角色 | 否 | 选择关联的角色 |
| 关联用户 | 否 | 选择关联的用户 |

## 8. 内置用户组说明

| built_in值 | 说明 | 可操作 |
|------------|------|--------|
| 1 | 内置用户组 | 不可修改、不可删除 |
| 2 | 内置用户组 | 不可修改、不可删除 |
| 其他 | 自定义用户组 | 可修改、可删除 |

## 9. 权限控制

| 权限码 | 说明 |
|--------|------|
| CODE_SYSTEM_USERS_USER_GROUP | 用户组管理权限 |

## 10. 交互说明

### 新增用户组
1. 点击工具栏"添加"按钮
2. 在侧边滑出面板中填写用户组信息
3. 可选择关联的角色和用户
4. 点击"确定"保存

### 修改用户组
1. 点击操作菜单中的"修改"
2. 在侧边滑出面板中修改用户组信息
3. 点击"确定"保存

### 删除用户组
1. 单个删除：点击操作菜单中的"删除"
2. 批量删除：勾选多个用户组后，点击底部"删除"按钮
3. 确认删除提示后执行删除

### 查看用户组
1. 点击操作菜单中的"查看"
2. 在侧边滑出面板中查看用户组详细信息（只读模式）

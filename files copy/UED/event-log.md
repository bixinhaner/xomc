# 事件日志页面功能

## 页面概述

事件日志页面用于查看设备上报的各类事件记录，包括配置变更、状态变化、告警事件等，支持统计和导出功能。

## Tab 页签

位于"日志管理"菜单下，页签名称：**事件日志**

---

## 列表字段

| 字段名 | 字段标识 | 宽度 | 说明 |
|--------|----------|------|------|
| ID | id | 60 | 事件记录ID |
| 设备唯一标识 | ne_code | 200 | 设备序列号 |
| 基站IP | ne_ip_address | 150 | 设备IP地址 |
| 事件类型 | event_name | 100 | 事件分类名称 |
| 原因 | event_reason | 200 | 事件发生的原因描述 |
| 时间 | time | 150 | 事件发生时间 |

---

## 页面功能按钮

### 统计

点击页面右上角 **统计** 按钮，打开事件统计弹窗。

**统计功能：**
- 按事件类型统计数量
- 按时间段统计趋势
- 按设备统计分布

### 导出

点击页面右上角 **导出** 按钮，导出当前筛选条件下的事件日志数据。

**导出参数：**
- 时间范围
- 设备ID
- 导出格式（CSV）

---

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 时间范围 | 日期范围 | 按事件时间筛选 |
| 设备标识 | 输入框 | 模糊搜索设备唯一标识 |
| 事件类型 | 下拉选择 | 选择特定事件类型 |

---

## 事件类型说明

| 事件类型 | 说明 |
|----------|------|
| 配置变更 | 设备配置参数发生变化 |
| 状态变化 | 设备运行状态改变 |
| 告警产生 | 设备产生告警 |
| 告警清除 | 设备告警被清除 |
| 连接建立 | 设备与OMC建立连接 |
| 连接断开 | 设备与OMC断开连接 |
| 软件升级 | 设备软件版本更新 |
| 重启 | 设备重启事件 |

---

## 交互说明

1. **实时刷新**：事件日志支持实时刷新，新事件自动追加到列表顶部
2. **分页加载**：大量数据时分页显示，支持调整每页条数
3. **快速筛选**：支持按时间快速筛选（今日/近7天/近30天）
4. **详情查看**：点击行可查看事件详细信息

---

## 统计弹窗

### 统计维度

1. **按事件类型统计**
   - 饼图/柱状图展示各类型事件占比
   - 显示事件数量和百分比

2. **按时间段统计**
   - 折线图展示事件趋势
   - 支持按小时/天/周聚合

3. **按设备统计**
   - 柱状图展示各设备事件数量
   - 可设置显示数量阈值

### 统计操作

- 刷新统计数据
- 导出统计报表
- 切换图表类型

---

## 数据说明

### 事件级别

| 级别 | 颜色 | 说明 |
|------|------|------|
| 信息 | 蓝色 | 一般信息事件 |
| 警告 | 橙色 | 需要关注的警告事件 |
| 错误 | 红色 | 错误或异常事件 |
| 成功 | 绿色 | 操作成功事件 |

### 数据保留策略

- 默认保留 90 天
- 支持按配置调整保留周期
- 超期数据自动归档或删除

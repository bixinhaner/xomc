## 1. 权限管理模块

权限管理是系统核心管控模块，通过用户、部门、角色、菜单的分层配置，实现精细化的权限管控体系，保障系统操作的安全性和合规性。

### 1.1 用户管理

#### 1.1.1 核心字段定义

|字段名称|字段说明|数据类型|特殊约束|
|---|---|---|---|
|用户名|用户登录标识|字符串|唯一，非空|
|密码|用户登录凭证|字符串|加密存储，非空|
|邮箱|用户联系邮箱|字符串|可选，格式校验|
|手机号|用户联系电话|字符串|可选，格式校验|
|角色|绑定的角色列表|数组|支持多角色关联|
|部门|归属的组织部门|字符串|关联部门管理模块|
|登录来源|登录终端/渠道|字符串|自动记录|
|过期时间|账号有效期截止时间|时间戳|可选|
|状态|账号启用/禁用状态|枚举|启用/禁用，默认启用|
|登录时间|最近登录系统时间|时间戳|自动更新|
|创建时间|账号创建时间|时间戳|自动生成，不可修改|
|更新时间|账号信息更新时间|时间戳|自动更新|
|创建人|账号创建操作人|字符串|关联用户表|
|更新人|账号信息更新人|字符串|关联用户表|
|备注|账号补充说明|文本|可选|
#### 1.1.2 功能需求

1. 基础操作：支持用户信息的新增、单条/批量删除、精准/模糊查询、修改；

2. 数据导入导出：支持Excel格式的用户数据批量导入，导出数据需包含核心字段且格式标准化；

3. 密码管控：管理员可重置用户密码（重置后需强制用户修改），用户支持自主修改密码（需验证原密码）；

4. 账号状态管理：支持账号启用/禁用操作，禁用状态账号无法登录系统；

5. 权限聚合规则：用户最终操作权限为其关联所有角色权限的合集，无角色关联则无任何操作权限。

#### 1.2.2 功能需求

1. 基础操作：支持部门信息的新增、删除、单条/批量查询、修改；

2. 数据导入导出：支持Excel格式的部门数据批量导入、标准化导出；

3. 结构展示：部门层级需以树状结构可视化展示，支持节点展开/折叠，新增/修改部门时需同步更新树结构；

4. 关联约束：删除部门前需校验是否关联用户，若存在关联用户则禁止删除（或提示后强制解除关联）。

|角色名称|角色标识名称|字符串|唯一，非空|

|批量操作权限|操作权限类型|枚举|单一操作/批量操作|
|创建时间|角色创建时间|时间戳|自动生成，不可修改|
|更新时间|角色信息更新时间|时间戳|自动更新|

    - 批量操作权限：配置角色对资源的操作方式，限定仅允许单一操作或支持批量操作。

4. 状态管控：停用状态的菜单不可访问，隐藏状态的菜单不在前端界面展示但仍可通过权限校验。

|更新时间|参数信息更新时间|时间戳|自动更新|

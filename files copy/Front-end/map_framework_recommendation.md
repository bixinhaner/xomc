# 地图框架技术选型推荐

> **文档版本**：v1.0
> **创建日期**：2026-03-20
> **核心需求**：高效流畅展示 10000+ 设备地理分布

---

## 一、需求分析

### 1.1 核心需求

| 需求维度 | 具体要求 | 重要性 |
|----------|----------|--------|
| 数据规模 | 10000+ 设备，预留 100 万扩展 | ⭐⭐⭐⭐⭐ |
| 渲染性能 | 首屏 < 3s，渲染 < 1s，交互响应 < 100ms | ⭐⭐⭐⭐⭐ |
| 部署环境 | 支持内网部署，可能无法访问外网 | ⭐⭐⭐⭐⭐ |
| 功能需求 | 聚合、筛选、状态可视化、详情查看 | ⭐⭐⭐⭐ |
| 扩展能力 | 热力图、测量、绘制等高级功能 | ⭐⭐⭐ |

### 1.2 性能瓶颈分析

**10000+ 设备的核心挑战**：

```
┌─────────────────────────────────────────────────────────────────┐
│                    性能瓶颈分析                                  │
└─────────────────────────────────────────────────────────────────┘

问题：10000 个设备标记如何高效渲染？

方案A: DOM 渲染 (SVG/HTML)
┌─────────────────────────────────────┐
│ 10000 个 DOM 元素                    │
│ ├── 每个元素 ~1KB 内存               │
│ ├── 布局重计算 ~100ms+              │
│ └── 页面卡顿、内存飙升              │
│ 结论: ❌ 不推荐                      │
└─────────────────────────────────────┘

方案B: 聚合 + DOM 渲染
┌─────────────────────────────────────┐
│ 10000 设备 → 聚合 → 100-500 个 DOM   │
│ ├── 聚合算法计算 ~10-50ms           │
│ ├── DOM 渲染 ~50-100ms              │
│ └── 流畅度提升                      │
│ 结论: ✅ 可行，但有上限              │
└─────────────────────────────────────┘

方案C: Canvas/WebGL 渲染
┌─────────────────────────────────────┐
│ 10000 设备 → 单 Canvas 画布          │
│ ├── GPU 加速渲染                    │
│ ├── 绘制时间 ~10-50ms               │
│ └── 支持数十万级别                  │
│ 结论: ✅✅ 最佳方案                  │
└─────────────────────────────────────┘
```

## 四、推荐方案

### 4.1 首选方案：OpenLayers

```
┌─────────────────────────────────────────────────────────────────┐
│                     推荐方案：OpenLayers                         │
└─────────────────────────────────────────────────────────────────┘

选择理由：

1. 【性能优势】Canvas/WebGL 渲染
   ├── 10000+ 设备流畅运行
   ├── GPU 加速，渲染效率高
   └── 内存占用低

2. 【聚合能力】内置 Cluster Source
   ├── 原生支持，无需第三方插件
   ├── 动态聚合距离调整
   └── 聚合样式自定义

3. 【内网支持】离线瓦片
   ├── 支持 XYZ 瓦片源
   ├── 可部署内部瓦片服务
   └── 完全离线运行

4. 【功能完整】专业 GIS 能力
   ├── 热力图 (Heatmap Layer)
   ├── 绘制/测量 (Draw Interaction)
   ├── 框选 (Box Selection)
   └── 图层管理

5. 【项目契合】
   ├── 团队已有 OpenLayers 使用经验
   ├── 可扩展至 100 万级别
   └── 长期维护成本低
```

### 4.2 备选方案：Leaflet

```
┌─────────────────────────────────────────────────────────────────┐
│                     备选方案：Leaflet                            │
└─────────────────────────────────────────────────────────────────┘

适用场景：
• 需要快速上线，时间紧迫
• 设备数量稳定在 10000 以内
• 功能需求相对简单
• 团队对 Leaflet 更熟悉

实现要点：
• 使用 Leaflet.markercluster 处理聚合
• 部署离线瓦片服务
• 控制聚合后的 DOM 数量 < 500
```

### 4.3 不推荐方案

| 方案 | 不推荐原因 |
|------|------------|
| 简化 SVG | DOM 渲染瓶颈，无法支持 10000+ 设备 |
| Mapbox GL | 不支持内网部署，数据出境风险 |
| 高德/百度 | 不支持内网部署，授权限制 |

## 五、OpenLayers 实现要点

### 5.1 核心架构

```typescript
// 1. 聚合数据源配置
import Cluster from 'ol/source/Cluster';
import VectorSource from 'ol/source/Vector';

const clusterSource = new Cluster({
  source: deviceSource,        // 设备数据源
  distance: 40,                // 聚合距离（像素）
  minDistance: 10,             // 最小距离
});

// 2. 动态聚合距离（根据缩放级别调整）
function getClusterDistance(zoom: number): number {
  if (zoom < 6) return 100;    // 全国级别：大聚合
  if (zoom < 10) return 60;    // 省级：中等聚合
  if (zoom < 13) return 40;    // 市级：小聚合
  return 0;                     // 详细级别：不聚合
}

// 3. Canvas 渲染优化
const deviceLayer = new VectorLayer({
  source: clusterSource,
  renderMode: 'image',         // 使用 image 模式，性能更优
  style: createClusterStyle,
});
```

### 5.2 性能优化策略

```typescript
// 1. 视口裁剪 - 只加载可见区域设备
const viewport = map.getView().calculateExtent(map.getSize());
const devicesInViewport = filterDevicesByBounds(allDevices, viewport);

// 2. 防抖更新 - 缩放/平移停止后更新
const debouncedUpdate = debounce(updateDevices, 300);
map.on('moveend', debouncedUpdate);

// 3. 分级加载 - 根据缩放级别选择数据源
if (zoom < 10) {
  // 大范围：使用聚合 API
  await fetchAggregatedData(bounds, zoom);
} else {
  // 小范围：使用详细数据
  await fetchDeviceDetails(bounds);
}

// 4. WebGL 加速（可选）
import WebGLVectorLayer from 'ol/layer/WebGLVector';
const webglLayer = new WebGLVectorLayer({
  source: deviceSource,
  style: webglStyle,
});
```

### 5.3 离线瓦片配置

```typescript
// 在线模式（默认）
import OSM from 'ol/source/OSM';
const onlineSource = new OSM();

// 离线模式
import XYZ from 'ol/source/XYZ';
const offlineSource = new XYZ({
  url: '/api/v1/tiles/{z}/{x}/{y}.png',
  attributions: '© Internal Map Service',
});

// 环境切换
const tileSource = import.meta.env.VITE_MAP_TILE_URL
  ? offlineSource
  : onlineSource;
```

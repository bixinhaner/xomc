## 二、开发规范 (所有模块统一遵循)

### 2.1 后端模式

```
omcgo/internal/{domain}/{module}/
├── model.go           ← 领域模型 + 枚举常量 + Filter (embed model.ListRequest)
├── repository.go      ← Repository 接口定义
├── pg_repository.go   ← PostgreSQL 实现 (squirrel + pgx/v5)
├── service.go         ← 业务逻辑 (可选, 简单 CRUD 可省略)
└── handler.go         ← Gin HTTP 处理器 + RegisterRoutes
```

- UUID 主键: `gen_random_uuid()`
- 时间字段: `TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- 数组/对象: `JSONB NOT NULL DEFAULT '[]'`
- 分页: `model.ListRequest` / `model.ListResponse[T]`
- 错误处理: `commonerrors.AbortWithError(c, status, err)`
- 注册入口: `cmd/app/main.go` 中创建 repo → service → handler → RegisterRoutes(v1)

### 2.2 前端模式

```
omcmb/webcode/src/services/api/{module}Api.ts     ← 真实 API 调用 + 字段映射
omcmb/webcode/src/hooks/api/use{Module}.ts         ← useMock ? mockService : realApi
```

- 所有 Hook 必须使用 `useMock` 开关
- **禁止**直接调用 mockService（必须走 `useMock ? mock : real` 模式）
- API 服务定义 `BackendXxx` 类型 (snake_case)，提供 `mapBackendXxx()` 转换函数

### 2.3 数据库迁移
